# Get started with AIPOCH Open-Science

Use Open-Science to organize research sources, work with an agent, run analyses and inspect saved results.

For a conceptual overview of the product, see [What Is AIPOCH Open-Science?](https://aipoch.com/blog/what-is-open-science).

## Start here

1. [Capabilities and supported inputs](./guides/capabilities.md): choose a path for your files or research question.
2. [Installation](./guides/installation.md) and [first-time setup](./guides/onboarding.md): prepare the app, agent, model and runtime.
3. [Your first project and result](./guides/first-project.md): open a small public-data table and save a checked summary.
4. [Permissions](./guides/approval-modes.md): inspect requested actions and manage remembered access.
5. [Notebook and execution evidence](./guides/notebook.md): examine code, variables and result provenance.

## Before running an example

Local walkthroughs use public PRISMA papers and the GSE60450 RNA-seq matrix. Download the linked inputs and confirm the model, runtime and permissions required by each task.

[Remote compute](./guides/remote-compute.md) includes a completed Direct SSH RNA-seq analysis, output collection, restart recovery and cancellation. Slurm terminal monitoring needs working accounting; GPU inference needs a compatible software environment.

Use [Reference](./reference/index.md) for technical limits and configuration, and [Changelog](./changelog/v0.31.1.md) for release history.
