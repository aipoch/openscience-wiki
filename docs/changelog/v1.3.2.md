# Changelog · v1.3.2

Released **2026-11-20 UTC**. [Official release notes](https://github.com/aipoch/open-science/releases/tag/v1.3.2).

## More ways to connect a model {/* #models */}

On **Model provider**, **Skip** adds Kilo Gateway without an API key and continues to Notebook runtime. After setup, **Main model** may display `kilo-auto/free`. Before your first message, open **Settings → Model**, check the selected provider and model, and switch to your intended connection, such as Codex subscription. Skip does not test inference. Upgrading preserves existing credentials and Main choices. [Kilo Gateway](../guides/providers.md#kilo).

OpenAI, MiniMax, Bailian and Volcengine Ark image services can refresh their supported image-model catalogs before saving. This contacts the configured provider with the connection's credentials. Catalog availability and a successful generation are separate checks. [Image model catalogs](../guides/image-generation.md#image-model-catalog).

## Smoother research sessions {/* #sessions */}

Long conversations use less memory, and safely saved conversation bodies can be released when they are no longer being viewed. Drafts and active work are retained. Completed replay steps show their ask/capture controls on hover or keyboard focus; touch devices retain accessible controls.

Notebook memory-pressure notices can be dismissed and expire after six seconds. A notice disappearing does not mean a blocked operation has run. Review the execution state and retry deliberately. [Notebook memory](../guides/notebook.md#memory-resources).

## Fixes that affect everyday work {/* #fixes */}

- Fresh built-in Agent, Claude Agent and Codex sessions no longer fail before their first model request in the affected Notebook preparation path. Scheduled sessions start with their intended prompt.
- PDF translation reconstructs wrapped titles, captions and mathematical statements in reading order, while retaining native formulas, links and graphics. [Check the translated layout](../guides/pdf-translation.md#scientific-layout).
- Home-page use-case download errors distinguish missing packages, timeouts, verification failures and storage problems. [Import recovery](../guides/research-packages.md#case-download-recovery).
- Windows fixes cover WSL Notebook startup and Reviewer connections.

See [installation and updates](../guides/installation.md) and [v1.3.1](v1.3.1.md).
