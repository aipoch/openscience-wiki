# Release notes · v0.33.3

Released on **2026-09-26**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.33.3).

## Read files and manage literature

Office viewers add page navigation and search, with paged PowerPoint reading. Use the existing QC files in [file previews](../guides/previews.md).

The workspace **Library** adds a compact preview for current-project or all-reference searches and abstracts. Smart collections add **Abandon run**: completed results remain, but that run cannot resume. Crossref metadata completion imports source abstracts. See [Library](../guides/library.md) and [paper screening](../workflows/screen-literature.md).

## New scientific database operations

**Genes & Ontologies** adds Enrichr library discovery and enrichment. **Clinical Genomics** adds ClinPGx queries for drugs, genes, variants, guidelines, labels and population frequencies. The complete registry now has **28 Connectors and 284 operations**: 27 data-source Connectors with 282 operations, plus two offline Molecule operations. See [database capabilities](../tools/databases.md) and the [operation reference](../reference/connector-operations.md).

## Research packages, appearance and installation

Package transfers add automatic or fixed disk-activity limits, with progress available during background work. Desktop scale shortcuts share the settings' 90%, 100%, 110% and 125% steps. Windows signing covers bundled executables. See [package transfer](../guides/research-packages.md#transfer-settings), [interface scale](../guides/appearance.md#interface-scale) and [installation](../guides/installation.md).

## Fixes

Fixes address PDF reading-tab fonts, isolated Notebook kernel recovery, native access to granted folders, recoverable retries and dismissible errors. Archive recovery prompts are scoped to affected projects. Other corrections cover initial classification-model selection, diagnostic archive suffixes, Skill metadata, managed Python and usage records in research packages.
