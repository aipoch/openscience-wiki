# Release notes · v1.3.0

Released on **2026-11-18 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.3.0).

## Schedule the next research task {/* #scheduled-tasks */}

Create a one-time or repeating task that sends an Agent message or runs a Python, R or Shell script. Choose an existing conversation or a new conversation for each message run, and inspect individual run records. The app must remain running; schedules use the configured permissions, credentials and provider quota. [Scheduled tasks](../guides/scheduled-tasks.md).

## Create images and edit presentations {/* #creation */}

Configure an image-generation service, generate from a prompt and refine an image with versioned edits. Image generation has its own model setting, separate from Main and Vision. [Image generation and editing](../guides/image-generation.md).

PPTX previews now support editing slide text and formatting. Review the saved version and reopen the downloaded presentation before sharing it. [Edit a presentation](../guides/presentation-editing.md).

## Explain the research or replay the operation {/* #films */}

Choose **Research explanation** or **Operation replay** in the research-film dialog. Branches keep independent film outputs. The dialog explains model usage before generation starts, and the session menu opens an existing film. [Film creation](../guides/research-films.md#generate-film).

## More control during longer work {/* #other-changes */}

- Scheduled runs have their own history; Notebook process monitoring shows owned processes and offers **Terminate**. [Process monitoring](../guides/notebook.md#process-monitor).
- CodeBuddy subscriptions support China and International accounts, with model discovery through the managed CLI. [Account setup](../guides/providers.md#codebuddy-subscription).
- Agent questions present choices with their trade-offs. Review the choice before continuing the task.
- Document-figure Skills prepare required libraries in managed environments on first use.
- Incremental session persistence, film recovery and Windows installation/update improvements reduce repeated work and unnecessary resource use.

See [installation and updates](../guides/installation.md) and [v1.2.2](v1.2.2.md).
