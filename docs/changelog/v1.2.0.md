# Release notes · v1.2.0

Released on **2026-11-09 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.2.0).

## Choose where a computation runs {/* #remote-compute */}

Kubernetes, Hugging Face Jobs, Modal and Ray join Direct SSH and Slurm. Configure a target, review the frozen inputs, command, resources and output collection, then approve each external submission. Recovery records help resume collection after a restart, and published outputs open from **Compute Preview**. These options use your own infrastructure or cloud account. [Remote-compute setup](../guides/remote-compute.md#compute-backends).

## Start with the built-in Agent {/* #agent */}

New setups default to **Open-Science Agent**, a built-in runtime that works with compatible model providers. Claude Agent, OpenCode, Codex, CodeBuddy and Pi remain available. The runtime and model provider are separate choices; an existing Codex setup does not need to be replaced. [Agent choices](../guides/frameworks.md#built-in-agent).

## Discuss the precise research step {/* #discussions */}

Imported `.science` research and replay steps support linked child discussions. **Ask about this step** carries the selected evidence, including a recorded Notebook run, into the discussion. Imported history highlights **Fork to continue** for starting a writable continuation. The sidebar groups sessions as **Pinned**, **Imported research**, **Active** and **Recents**. [Replay discussions](../guides/session-replay.md#discuss-replay) · [Research packages](../guides/research-packages.md#linked-discussions).

## Smaller updates and clearer controls {/* #reliability */}

- macOS updates can download changed blocks, falling back to a full download when needed. Installation checks verify the running app and identify blocking files or processes.
- **Local capabilities** replaces the **Local parsing models** tab and groups PDF extraction, OCR and research narration. [Local resources](../guides/models.md#local-capabilities).
- Manual reference entry accepts an identifier without a title, including PMID. Film controls avoid flashing unavailable actions while loading.
- PDF extraction improves text and table structure. Fixed-layout translation retains successful pages if another page fails; inspect the incomplete page before sharing. [PDF translation](../guides/pdf-translation.md).
- Notebook analysis runs outside the UI thread. Windows fixes cover managed R DLL loading and window bounds around the taskbar.
- Sending a message while reading an earlier turn preserves your reading position. Tool errors, source-link previews and startup diagnostics are clearer.

See [installation and updates](../guides/installation.md), [v1.1.0](v1.1.0.md) for research films and batch overviews, and the official release for the complete fix list.
