# Release notes · v0.37.2

Released on **2026-10-13 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.37.2).

## Restore startup and runtime connections {/* #recovery */}

Startup failures now offer recovery paths for backend, settings and network initialization. A desktop connection interruption keeps the workbench open with **Reconnect** and **Quit app**. Reconnect restores the original live backend; it does not restart a dead backend or automatically repeat submitted operations. Check the original task's state before retrying work whose response was lost.

The browser interface pauses controls while restoring missed updates and offers reload or renewed pairing when required. Large session and Notebook snapshot transfers, event bursts and redirected diagnostic logs are handled more robustly. Follow [connection and startup recovery](../guides/troubleshooting.md#connection-recovery) and [backend ownership](../reference/server.md#backend-ownership).

## Install the Linux CLI as a package {/* #linux-cli */}

Linux adds standalone `.deb` and `.rpm` CLI packages for x64 and ARM64, alongside release archives and the Homebrew CLI. The CLI packages include Node, the backend and local Web UI, with `open-science-cli` as their explicit command. They are separate from the desktop installer and do not automatically start a system service.

See [package selection, installation and upgrades](../guides/installation.md#linux-cli-packages). Stop all profiles using the package before upgrading or removing it; keep the research data and credential store.

## Research and interface fixes {/* #research-fixes */}

| Area | Change and corresponding guidance |
| --- | --- |
| Scientific PDFs | More accurate figure/table ownership and legacy math symbols; [compare the extracted structure with the source](../guides/previews.md#scientific-structure-check) |
| Notebook | First-run preparation displays incoming code; dependency and file-lineage analysis is hardened. Check the run's state and [actual execution evidence](../guides/notebook.md), not code visibility alone |
| Literature | Conflicting metadata identities are rejected, and asynchronous operations retain current state; [check identifiers before saving](../guides/library.md) |
| Model settings | Provider compression/retry behavior is published correctly; existing [provider controls](../guides/models.md) remain the place to configure supported options |
| Remote compute | Job recovery evidence is retained through cancellation and cleanup; [inspect the existing job](../guides/remote-compute.md) before submitting again |
| Other fixes | Corrected [Bgee species metadata](../tools/databases.md#bgee-species), clearer empty-image errors, quieter Windows background processes, consistent new-project labels and safer artifact publication |

**Help Center** links and Settings search now follow the interface language. Open [General → About → Help Center](../guides/appearance.md#help-center) for the corresponding documentation edition.
