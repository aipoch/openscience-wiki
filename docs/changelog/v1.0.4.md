# Release notes · v1.0.4

Released on **2026-10-27 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.4).

## Connect other tools to the workbench {/* #mcp */}

The standalone CLI provides a stdio MCP adapter for external clients. Start the authenticated local service first, then connect the client to that profile. Tools can create projects, change configuration and run research under existing permissions, including writes and model costs. [MCP setup and controls](../reference/cli.md#external-mcp).

## Check a paper's publication notices {/* #publication */}

In the Library, a reference with a valid DOI can be checked manually for retractions and corrections through Crossref. Results retain their source and check time. An empty result is not an assurance that a paper is unaffected. [Check and interpret notices](../guides/library.md#publication-checks).

## Keep daily work manageable {/* #workspace */}

- Completed turns collapse intermediate messages and tool groups; search and annotations can reveal their contents. [Expand a conversation](../guides/sessions.md#collapsed-conversation).
- Save a file from an authorized folder as an immutable conversation artifact. [Local file import](../guides/files.md#import-local-artifact).
- Bookmark a scanned GitHub Skill repository for reuse; it does not update Skills automatically. [Saved repositories](../skills/manage.md#saved-repositories).
- Question cards provide explicit **Skip** and **Skip all** actions. [Question controls](../guides/composer.md#skip-question).

Downloads are smaller. Fixes cover Windows Notebook standard execution, package exports waiting after save-location selection, folder-access dialogs, question recovery and replay event presentation. [Package transfer](../guides/research-packages.md#local-package-transfer) · [Previous release: v1.0.3](v1.0.3.md).
