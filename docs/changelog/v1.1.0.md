# Release notes · v1.1.0

Released on **2026-11-06 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.1.0).

## Turn a session into a research film {/* #research-films */}

A completed session can become a short film with English narration. Install the local narration resources, generate from the desktop session and review the playback before sharing a portable player or exporting MP4. The film presents recorded research; it does not rerun or verify the analysis. [Research-film guide](../guides/research-films.md).

## Work through a reading list {/* #literature */}

Select up to five references to generate study overviews as a batch. Pause, continue unfinished work or retry failed items while keeping completed overviews. The CLI and MCP also gain library search, citation formatting and reference-management operations. [Batch overviews](../guides/library.md#batch-overviews) · [Literature commands](../reference/cli.md#literature-library).

## Open the workspace on a mobile device {/* #mobile */}

QR pairing supports a phone or tablet on the same WiFi, or an internet connection through Pinggy. Keep the host running and inspect connection status before scanning. [Connection options](../guides/remote-access.md#mobile-pairing).

## Changes to everyday use {/* #reliability */}

- Compute settings move to **Connections**. The research-case library has a refreshed layout and clearer import destinations.
- Conversations recover more reliably after interruptions and storage failures. Completed or idle Agent connections release resources more consistently.
- Diagnostics retain Notebook execution evidence and historical backend logs. Windows adds optional resource recording for troubleshooting.
- PDF extraction improves figure and table recovery from searchable scans, and Codex Chat supports native image input.
- Notebook prefers a ready app-managed runtime. Shell failures surface as tool errors rather than successful results.
- Windows update preparation checks process identity and occupied files; local `.science` and MP4 export flows handle desktop save dialogs more reliably.

See [installation and updates](../guides/installation.md) and [the previous release](v1.0.8.md).
