# Release notes · v1.0.5

Released on **2026-10-28 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.5).

## Keep track of your reading {/* #reading */}

The Library adds manual **Unread**, **Reading** and **Read** states, with a table column, filters and bulk updates. Publication checks now use **Check now** and **Check again**, while retaining Crossref results and their check time. [Reading status](../guides/library.md#reading-status) · [Publication checks](../guides/library.md#publication-checks).

## Move research packages through the browser {/* #packages */}

Authenticated local Web users can upload a `.science` file for import and download a completed export. The home gallery also offers research cases with **Details** and **Import** actions. Review the destination and imported evidence before using **Fork to continue**. [Browser transfer and gallery](../guides/research-packages.md#local-package-transfer).

## Decide when the service should keep running {/* #service */}

An explicit CLI `start` keeps the service running after the last App quits. Ordinary CLI, Web and SDK activity does not provide that hold. Plain `stop` releases it; connected Apps can still keep the service alive. `stop --force` requests a service-wide stop and can interrupt active work. `start` now accepts `--json`. [Commands and shutdown results](../reference/server.md#lifecycle-commands).

## Find scientific records and official data files {/* #data */}

New entries cover Europe PMC search, research-dataset access and public file lists, ChEA3, bioDBnet and CTD. Existing HGNC, Cellosaurus and openFDA tools gain additional queries or file discovery. The catalog now includes **48 built-in Connectors and 418 operations**: 47 data-source Connectors with 416 operations, plus one offline Molecule Connector with two operations. File links do not mean data has been downloaded or access to a restricted dataset has been granted. [Sources and connection steps](../tools/databases.md#scientific-file-discovery).

## Updates and everyday fixes {/* #fixes */}

- Manual update controls provide installation instructions and a way to reveal a confirmed downloaded installer. [Manual installation](../guides/installation.md#manual-update).
- **Full access** allows public network destinations without individual approval cards; lowering the mode closes existing connections. Global grants appear in Network settings immediately. [Network permissions](../guides/network.md#network-mode-changes).
- Notebook package installation supports an explicit BiocManager route on Windows. [Windows Bioconductor packages](../guides/runtimes.md#windows-bioconductor).
- DOCX output better preserves template layout, tables, borders and page structure. [Word output](../guides/previews.md#docx-templates).

Other fixes cover OpenCode 2.x compatibility, macOS external Node resolution for Notebook, Windows chat startup during network-protection setup, managed Skill reference reading, conversation scroll position and table scrollbars. About also links to the security policy. [Previous release: v1.0.4](v1.0.4.md).
