# Release notes · v1.2.1

Released on **2026-11-11 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.2.1).

## Find resources in one place {/* #resource-center */}

**Resource center** brings Skills, Connectors and Specialists together with installed and marketplace views, search, filters and detail drawers. Marketplace installation is also available in the Web workspace. Opening a Skill reference from a question or sent message shows its details in the project pane while keeping the conversation in place. [Resource navigation](../guides/navigation.md#resource-center) · [Skill marketplace](../skills/marketplace.md).

## Refine a question before sending {/* #prompt-optimization */}

Use **Optimize question** in a project's Composer to rewrite a draft through the configured model. Review the result, edit it or use **Undo optimization** before sending. Project settings can hold a custom **Optimization prompt**. The action runs only when requested; it does not send the research question automatically. [Question refinement](../guides/composer.md#optimize-question).

## Use Codex subscriptions with the built-in Agent {/* #codex */}

**Open-Science Agent** now supports imported and app-owned Codex subscription accounts for Main and Subagent. Existing sign-in and credential recovery controls remain available. The built-in Agent also uses the model's output limits and improves context accounting. **Claude Fable 5.2** joins the Anthropic catalog with a 1M context window. Model availability still depends on the selected provider and account. [Agent setup](../guides/frameworks.md#built-in-agent).

## Export reference metadata as a spreadsheet {/* #csv */}

**Export → CSV** saves selected references, a project or a collection with 16 stable English column names. Selections can span pages and exclude individual items. Missing fields remain empty; PDF files, screening decisions and personal notes are not part of this metadata export. [CSV export steps](../guides/library.md#bibliography-csv).

## Keep longer work moving {/* #reliability */}

- Notebook and Compute evidence is deduplicated with verified digests, reducing repeated content in long `.science` exports. The first export also prepares older evidence. [Research packages](../guides/research-packages.md#compact-evidence).
- Modal and Hugging Face connections prepare a compatible Python runtime before browser sign-in and use the system proxy for account checks. [Compute accounts](../guides/remote-compute.md#cloud-account-runtime).
- Research-film generation continues after switching sessions. [Research films](../guides/research-films.md#generate-film).
- Opening mobile pairing leaves access off until you choose **WiFi** or **Internet**. [Mobile connection](../guides/remote-access.md#mobile-pairing).
- Notebook attachments and local file links open previews again. PDF recovery, translation isolation, literature identifiers and narrow source previews receive fixes.
- Idle interpreters are reclaimed after 15 minutes without session activity. Windows update recovery better identifies blocking files/processes, and Linux recovery avoids treating confirmed kernel threads as leaked Notebook processes.

See [installation and updates](../guides/installation.md) and [v1.2.0](v1.2.0.md).
