# Release notes · v1.0.0

<ReleaseCelebration>

**🎉 Open-Science 1.0 is here. Time to celebrate!**

After all the iterations through 0.x, we want to start with a thank you. To everyone who tried Open-Science, reported a problem or contributed: thank you for helping it reach 1.0. Research tools take patient work on real problems to get right, and your care has made a difference.

We want you to be able to return to a project weeks later and find the evidence you read, the analyses you tried and the question you wanted to pursue next. And when a colleague takes over, we hope they can spend less time hunting for files and more time continuing the research. Here is what changes with 1.0.

Released on **2026-10-14 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.0).

## Move to the 1.0 release {/* #upgrade */}

1.0 brings the existing research workspace into the stable release line. It retains historical profile upgrades and `.science` imports; the version change does not require a new profile or data format. Back up your profile and research data, finish active work, then upgrade through the official desktop installer. A binary downgrade does not undo data changes.

This publication contains **desktop packages only**. Standalone CLI archives and Linux CLI `.deb`/`.rpm` assets are absent, and website/automatic-update promotion is separate. Use the desktop-supplied command launcher for 1.0; do not rename an older CLI archive or assume Homebrew/npm already provides the same version. `open-science update` is removed: use desktop controls or the installer/package manager that owns the installation. See [installation and 1.x compatibility](../guides/installation.md#version-compatibility).

## Continue interrupted work {/* #recovery */}

A compatible desktop can adopt a surviving desktop-launched backend after its previous controller disconnects. CLI-launched services remain independent. Failed shutdown preparation keeps the window open, and reconnect restores the original conversation state before work continues. Check saved operations before resubmitting a request with an unknown outcome. See [service ownership and recovery](../reference/server.md#desktop-service-recovery).

ACP conversations resume with the selected agent; detached Codex sessions recover more reliably after Specialist switches. [Check the selected agent and original session](../guides/sessions.md#resume-selected-agent) before sending the next turn. Literature selection and cancellation during context compaction also receive fixes.

## Answer questions and read PDFs {/* #interaction */}

- Clarification cards support longer option lists and multiple selections. Review answers across questions, then choose **Finish**; a selected option alone is a draft. [Answer a clarification question](../guides/composer.md#clarification-questions).
- Annotation note buttons appear on hover, focus or selection, keeping the PDF clear while reading. [Reveal a note](../guides/pdf-notes.md#reveal-note).
- PDF extraction and translation preserve more complex source layouts, native table/figure relationships and scientific fractions. **New translation** prepares fresh source text. Compare the result with the original before reuse. [Extraction checks](../guides/previews.md#scientific-structure-check) · [Translation](../guides/pdf-translation.md#scientific-layout).

## Preserve scientific data context {/* #data-context */}

| Source | Change |
| --- | --- |
| ArrayExpress | Distinguish SDRF relationship rows from distinct sample identifiers; incomplete identifiers can return unknown sample counts |
| MetaboLights | Keep repeated sample-table columns and their original ordering instead of overwriting values |
| Bgee | Preserve anatomical and cell-type context; missing cell types remain `null` |
| dbSNP | Preserve all chromosome/assembly associations for a placement |
| OpenAlex | Remember declined credential prompts per session |

Read [the field interpretation guide](../tools/databases.md#scientific-context) and the [v1.0.0 Connector reference](../reference/connector-operations.md) before reusing saved queries. Notebook risk analysis also improves its treatment of Promise callbacks; existing approval requirements still apply.

## What 1.0 does not change {/* #scope */}

Recorded session replay does not execute code. Artifact verification needs eligible captured inputs and a usable environment; it does not establish scientific validity or deterministic reproduction of a whole session. Imported `.science` records remain read-only; use Fork for a writable continuation. Credentials, Side Chats and private bookmarks are not restored from the package. SSH/Slurm compute remains supported; managed cloud-GPU submission, a local GPU backend and real-time multi-user editing are outside this release.
