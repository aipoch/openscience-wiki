# Release notes · v1.0.3

Released on **2026-10-26 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.3).

## Follow the literature trail {/* #literature */}

Use Semantic Scholar to find a paper's references and citing papers, then send selected candidates to Inbox for review. The Library also accepts file drops and discovers supplementary materials with per-file download progress and previews. [Literature discovery and attachments](../guides/library.md#citation-discovery).

Smart collections can export all candidate decisions as CSV, separately from the included-reference bibliography. [Export screening decisions](../workflows/screen-literature.md#screening-csv).

## Move and read research {/* #research */}

- Export and import `.science` packages from the CLI and authenticated local web app. Imported sessions remain read-only. [Local package transfer](../guides/research-packages.md#local-package-transfer).
- Choose **Advanced → Content first** for a new PDF translation edition to reflow body text and captions. [Translation layout](../guides/pdf-translation.md#content-first).
- Control local Notebook and Shell folder access in Permissions. Changing the setting stops live processes and clears variables. [Folder restrictions](../reference/permissions.md#notebook-folder-restrictions).

## Reach more scientific sources {/* #sources */}

New access covers TCIA, KEGG, OmniPath, LIPID MAPS, PDBe validation, UniChem mapping, DepMap/CCLE and PDB structure similarity. Keep source-specific identifiers, licensing and measurement scales with the results. [Choose and connect sources](../tools/databases.md#expanded-sources).

Kimi K3.1 Pro joins the provider catalog. Windows protocol registration, network-approval persistence, session recovery, package transfers and PDF handling also receive fixes. [Model selection](../guides/providers.md#kimi-k31) · [Previous release: v1.0.2](v1.0.2.md).
