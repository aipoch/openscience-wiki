# Release notes · v1.2.2

Released on **2026-11-18 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.2.2).

## Choose stricter Notebook networking {/* #strict-network */}

**Settings → Network → Manage access** now offers **Relaxed** and **Strict** modes. Strict permits only manual whitelist matches by protocol, hostname or IP, and port. Unmatched requests are blocked without an authorization prompt. Relaxed remains the default. Rules can be organized into groups; Built-in and Manual labels show their origin. [Network setup](../guides/network.md#public-network-rules).

## Resume interrupted research films {/* #film-checkpoints */}

Film generation retains validated scenes, narration and timing work across process restarts. Resume from a checkpoint or deliberately start a fresh generation. Progress identifies the current stage. [Recovery steps](../guides/research-films.md#film-recovery).

## Read PDFs and recover local work {/* #recovery */}

- Native PDF extraction better preserves figures, captions, table content and reading order. Compare extracted material and translated layouts with the original PDF. [PDF extraction](../guides/previews.md#pdf-extraction).
- Windows checks a protected folder's access before saving a grant; update and uninstall recovery preserve better diagnostics.
- `.science` imports distinguish cancellation, invalid packages and timeouts. After an unconfirmed timeout, check for the imported session before submitting again. [Import a research package](../guides/research-packages.md).
- When the local service disconnects, the workspace shows recovery state and preserves the Composer draft.
- Bailian Token Plans add **Qwen4 Max Preview**, including regional catalog choices. Availability depends on the selected account. [Provider setup](../guides/providers.md#provider-regions).

See [installation and updates](../guides/installation.md) and [v1.2.1](v1.2.1.md).
