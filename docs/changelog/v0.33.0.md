# Changelog · v0.33.0

Released September 23, 2026. This release adds smart literature screening, resource access controls for individual agents, and RO-Crate metadata inside research packages.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.33.0) · [Changes since v0.32.0](https://github.com/aipoch/open-science/compare/v0.32.0...v0.33.0)

## Screen literature with explicit criteria

A **Smart collection** evaluates Library records against inclusion and exclusion criteria. Choose its scope, inspect the four decision views, and review model judgments before using the reading set. Trial runs save results; live draft previews do not. Optional full-text evidence and automatic updates have separate controls.

The new [worked screening workflow](../workflows/screen-literature.md) covers retrieval, model binding, rules, a trial, manual review and export. [Classification settings](../guides/models.md#smart-collection-model) now distinguish **Smart collections** from **Automatic capability selection**; Main can stay on Codex.

## Manage resource access and research handovers

- **Manage access** on a Skill or Connector shows Main Agent and Specialist associations together. Role activation, credentials and operation approvals remain separate. See [resource access](../guides/connectors.md#resource-access).
- Newly exported `.science` packages include RO-Crate 1.1 metadata. Recipients need a reader supporting the `ro-crate` capability; older packages remain readable. See [package compatibility](../guides/research-packages.md#package-compatibility).
- **Export diagnostics…** in a session creates a local archive from selected sources. It does not upload the archive or send it to a model. See [diagnostic export](../guides/troubleshooting.md#session-diagnostics).

## New database operations

| Resource | Added capability | Boundary |
| --- | --- | --- |
| Zenodo | Search public records and inspect version-specific metadata and file inventories | No file upload or download; public metadata does not imply open file access. |
| GDC | List cancer projects/cases, search files, inspect file metadata and generate manifests | Controlled data still requires authorization. |
| Genes & Ontologies | UniProt batch identifier mapping: submit, check status and retrieve paged results | Retain all pages, one-to-many matches and explicit unmatched IDs. |

There are **26 built-in Connectors with 263 operations**: **25 data-source Connectors / 261 operations**, plus two offline Molecule operations. Use the [database catalog](../tools/databases.md) to choose a service and the [v0.33.0 parameter reference](../reference/connector-operations.md) for exact inputs. UCSC conservation defaults are corrected for mouse assemblies.

## Models, runtime and platform fixes

Provider catalogs add MiMo v2.6 and Grok 4.7 and refresh Zen/Go. See [provider selection](../guides/providers.md#provider-catalog-updates). **Claude Agent** now reports unsupported CLI versions during readiness checks; v0.33.0 requires **2.1.118 or later**. See [agent installation](../guides/frameworks.md).

Other fixes improve streaming and long conversations, stale-run recovery, research-package credential checks, long-running Notebook shell progress, folder grants during package installation, dismissible Notebook notices, Windows R inventory and reset handling, Fedora startup packaging, and search/PDF interactions. See the official release for the complete list. The preceding release is [v0.32.0](./v0.32.0.md).
