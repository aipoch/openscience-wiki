# Release notes · v0.33.2

Released on **2026-09-24**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## Installation and literature reading

Official Windows installers gain code signing. App download links lead to the official download page and verification notes. See [installation](../guides/installation.md). Live source previews retain website sessions across visits and app restarts; see [source previews](../guides/previews.md#persistent-source-preview).

**Auto** mode reduces repeated approval prompts for built-in Library operations. File, network and resource rules still apply. See [Library approval behavior](../guides/approval-modes.md#library-auto).

## STRING interaction enrichment

**Protein Annotation** adds STRING PPI enrichment to test whether a protein set has more interactions than expected from its background. This asks a different statistical question from pathway enrichment. Follow the [gene-set workflow](../workflows/gene-set-enrichment.md#enrichr-string) and [operation reference](../reference/connector-operations.md#get_string_ppi_enrichment).

## Improvements and fixes

Completed delegation results survive later cleanup failures. Updates also cover the Figure Composer workflow, preview file-type icons and smart-collection layout. Fixes isolate macOS Notebook cleanup state and improve agent routing and shutdown; Codex backend plugin and app discovery is disabled.
