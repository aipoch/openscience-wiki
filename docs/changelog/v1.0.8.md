# Release notes · v1.0.8

Released on **2026-11-04 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.8).

## Bring a reading list into the library {/* #literature */}

Have a list of paper identifiers? **Add from DOI or link** now accepts up to 100 non-empty lines containing DOI, arXiv, PMID, PMCID or supported official article links. Review the resolved references and duplicate policy before importing. Finding metadata does not automatically retrieve the full text. [Batch import walkthrough](../guides/library.md#doi-link-import).

Reference details now include **Study overview**. Your configured main model organizes the available source into five sections: research question, study population, methods, main findings and limitations. The source label distinguishes an abstract, full text and selected passages. Use it to orient your reading, then check important claims in the original paper. [Generate an overview](../guides/library.md#study-overview).

## Settings have clearer homes {/* #settings */}

**Appearance** and **Notifications** are separate panels under **System**. General keeps app information, diagnostics, command-line tools and help, including a manual-install guide. The Settings center now has **19 panels in four groups**. [Settings map](../settings/overview.md) · [Appearance and notifications](../guides/appearance.md).

## Research and everyday reliability {/* #reliability */}

- eQTL Catalogue uses indexed release-7 files after its REST API was retired. Queries require explicit **GRCh38** coordinates; a gene ID alone is no longer a valid query. [Coordinate requirements](../tools/databases.md#eqtl-coordinates).
- PDF ordering uses positioned text to distinguish prose columns from table rows. Extraction checks crop boundaries and preserves ambiguous cell text with a reliability warning. [PDF reading and extraction](../guides/previews.md#automatic-pdf-reading-order).
- R reproduction checks invalidate stale file evidence after operations that may force arguments or dispatch methods. Provenance explains incomplete execution evidence; older Markdown artifacts repair a stale history head when opened. [Read verification evidence](../guides/reproducibility.md#execution-evidence).
- Completed sessions release provider and tool processes across all five Agent frameworks. Pi installation in packaged desktop builds is repaired.
- Update preparation identifies blocking processes more clearly. Fixes address macOS read-only file holders, Windows process detection and stale Notebook recovery records. Diagnostic packages retain the actual desktop recovery error. [Update guidance](../guides/installation.md#update-preparation).
- Completed downloads survive an unreadable destination directory or a later cleanup error. Windows PDF teardown and protection probes are more robust; notebook command-line tools can use the bundled Node runtime when an old PATH version cannot use the proxy.
- Successful full-text searches clear an earlier PDF-add error, and the Composer no longer repeats an unavailable-model notice.

Tencent TokenHub adds Hy4 and DeepSeek V4.1 Flash routes with one-million-token context, plus image input for GLM-5.3-Flash, Kimi K3 and MiniMax M3. Model availability follows the provider account and selected route. [Provider setup](../guides/providers.md).

The built-in catalog remains **48 Connectors with 418 operations**. [Current catalog](../tools/databases.md#supported-databases) · [Previous release](v1.0.7.md).
