# Release notes · v0.33.1

Released on **24 September 2026**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.33.1).

## Literature screening and PDF reading

Smart collections show a live **Screening process**, with pause/resume controls and links to their project or collection scope. Resume availability depends on the saved run remaining compatible with its rules and papers. Manual decisions still determine membership. See [screen and review papers](../workflows/screen-literature.md).

PDF evidence can accompany the first workspace message. Open a Library PDF, select **Read with agent**, choose a project and check the Reading attachment before sending the question. See [PDF context](../guides/previews.md#first-message-pdf).

## Scientific Connectors

- **HMMER** adds program-specific protein/profile/alignment searches, status and completed results.
- **InterProScan** checks existing annotation jobs and retrieves TSV reports; it does not submit jobs.
- **Genomes** adds Clustal Omega for at least three FASTA records. Follow the [multiple sequence alignment workflow](../workflows/multiple-sequence-alignment.md).
- **OpenAlex** no longer requires a key in the app; service limits still apply. See [optional credential setup](../tools/credentials.md).

The built-in registry now contains **28 Connectors and 271 operations**, including the offline Molecule Connector. [Database capabilities](../tools/databases.md) · [Operation reference](../reference/connector-operations.md).

## Settings, diagnostics and fixes

Provider catalogs add GPT-6 and Claude Opus 5.5; account access and framework compatibility still determine availability. [Model providers](../guides/providers.md#catalog-models).

Session diagnostics distinguish redacted evidence from original files flagged by a package export. Original sensitive files are unchecked by default and are included only when selected. Exports stay local. [Diagnostic export](../guides/troubleshooting.md#session-diagnostics).

Settings header and local panel search have separate shortcuts. Historical data locations are retained across upgrades. Other fixes address Windows managed Python discovery, R access-denied prompts, runtime/compute save races, ACP vision capability changes, first-send PDF identity, duplicate sends, and figure cropping/revisions. [Shortcuts](../guides/shortcuts.md#local-settings-search) · [Storage](../guides/storage.md#historical-data-location).
