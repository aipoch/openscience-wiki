# Release notes · v1.0.2

Released on **2026-10-22 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.2).

## Query more scientific sources {/* #scientific-sources */}

| Source | Open it through |
| --- | --- |
| HGNC gene nomenclature | Genes & Ontologies |
| PubTator 3 article annotations | PubMed |
| DGIdb drug–gene interactions | Clinical Genomics |
| RNAcentral records and cross-references | RNA |
| Orphadata rare-disease associations | Orphadata; enable it first |

These additions bring the catalog to **36 data-source entries with 371 operations**, plus the two offline Molecule operations. [Choose a source and connect it](../tools/databases.md#new-source-access).

GDC can filter files by case, sample type and workflow while preserving sample/aliquot associations. Ensembl VEP accepts HGVS without manual coordinate conversion; it does not validate the input reference version or perform liftover. The catalog also includes posted ClinicalTrials.gov results. See [query context](../tools/databases.md#clinical-context) and the [complete operation reference](../reference/connector-operations.md).

## Install and inspect the CLI {/* #cli */}

The CLI and Task SDK are published on npm. Follow [npm installation](../guides/installation.md#npm-cli), then use `version`, `help` and `paths` without starting a backend. The reported version belongs to the invoked installation. Desktop and standalone builds include Node 22.23.4 security updates. [Local information commands](../reference/cli.md#local-information).

## Keep control of a conversation {/* #conversation */}

Question cards distinguish **Single select** from **Multi select** and retain each question's full answer history. Queued-message errors offer an undo action; unsent drafts trigger quit/reload warnings. Credential recovery gives a specific next step while preserving drafts. Remote web chat supports artifact mentions. [Question cards and drafts](../guides/composer.md#clarification-questions).

## Continue research with clearer records {/* #research-records */}

- Package dialogs remain stable; retrying a partially committed import avoids duplicate sessions. Imported titles can be edited while research stays read-only. [Research packages](../guides/research-packages.md#browser-import).
- Large-session loading and startup recovery improve. Partial diagnostic exports show warnings. [Session diagnostics](../guides/sessions.md#session-diagnostics).
- PDF structure, DOCX numbering/borders and chained Python/R file-lineage capture receive fixes. [Lineage checks](../guides/notebook.md#chained-analysis-lineage).
- Large Skill imports use batches; reserved external names get safe local names. MiniMax M3.1 through Codex is fixed. [Provider recovery](../guides/providers.md#credential-recovery).
