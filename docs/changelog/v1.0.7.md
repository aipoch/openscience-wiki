# Release notes · v1.0.7

Released on **2026-11-02 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.7).

## From a paper link to reading notes {/* #literature */}

**Add from DOI or link** turns a DOI, doi.org link or arXiv abstract/PDF link into a reference you can review and save. Full-text retrieval remains a separate step. [Add a reference](../guides/library.md#doi-link-import).

In a Reading session, ask the Agent to locate a passage and save a highlight, area mark or note to the linked PDF. Reopen **Notes & Annotations** to check the saved location and comment. [Agent annotations](../guides/pdf-notes.md#agent-annotations).

Scanned pages can use optional OCR. Download the recognition component and select from nine language packs, then read the PDF again and inspect page coverage. Recognition helps recover text; check quotations and numerical values against the page image. [OCR setup](../guides/previews.md#scanned-pdf-ocr).

## Pi and the research-case marketplace {/* #agents-and-cases */}

Pi joins Claude Agent, OpenCode, Codex and CodeBuddy as the fifth Agent framework. Install it separately, select compatible model access and test the connection before using it for research. Updating Open-Science does not switch the active Agent. [Pi setup](../guides/frameworks.md#pi-agent).

**Sharing marketplace** is available from Home and the conversation workspace. Browse categories, search by keyword and open a case to inspect its description or download its package. Browsing state is retained when returning from a project. [Find a research case](../guides/research-packages.md#use-case-gallery).

## Fixes for ongoing work {/* #reliability */}

- Windows notebooks prepare their shell runtime before first use, restoring PowerShell on fresh backends.
- OpenCode sessions handle nonstandard compaction message identities; follow-up questions are retained while background work settles.
- Full-text retrieval handles configured proxies using Fake-IP DNS. [Download recovery](../guides/troubleshooting.md#full-text-proxy).
- Published or restored artifacts bring their latest published version forward; version relationships are clearer in provenance. [Check a file version](../guides/files.md#latest-published-version).
- The Composer uses one failure surface with recovery actions for provider, environment, input, session and internal errors. [Recover a request](../guides/composer.md#request-recovery).
- OCR settings stay responsive while saving, and a stalled component download no longer extends ordinary PDF reads beyond their deadline.

Connector descriptions are more specific in Settings. The built-in catalog remains **48 Connectors with 418 operations**; Pi, OCR and reference-import controls are not additional Connectors. [Supported databases](../tools/databases.md#supported-databases) · [Previous release](v1.0.6.md).
