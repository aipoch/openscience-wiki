# Release notes · v1.0.1

Released on **2026-10-20 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.1).

## Bring a research package into the app {/* #packages */}

A supporting website can hand a `.science` package to the desktop app on the same computer. Allow the browser to open Open-Science, keep the page open during transfer, then review the package and choose its destination in the app. Receipt by the app is not final import approval. Local packages can also be dropped onto the project home. See [browser import](../guides/research-packages.md#browser-import).

## Follow updates and waiting sessions {/* #interaction */}

The update dialog keeps downloading, release notes and installation preparation together. Windows handoff and startup receive fixes; installation availability still depends on the channel. Follow [update progress](../guides/installation.md#update-progress) and check the installed version after relaunch.

Sessions awaiting an answer or approval stay visibly waiting across Home, the sidebar and the conversation. Reopen the pending card to continue. Double-click a sidebar session to open its editor. See [waiting for input](../guides/sessions.md#waiting-for-input).

## Work with sources and credentials {/* #sources */}

- PDC adds public case demographics and diagnosis metadata, with study-version selection and external references. Keep source IDs distinct. [PDC clinical fields](../reference/connector-operations.md#pdc_list_clinical).
- MiniMax M3.1 Flash is available in both regions. Attached images can inform Skill selection. [Provider choices](../guides/providers.md#catalog-models).
- OAuth credentials are bound to their issuing authorization server. Use [reauthorization](../guides/connectors.md#oauth-reconnect) when required.
- PDF search indicates incomplete coverage; two-column reading, translated layouts, literature state and notebook recovery receive fixes. [Check PDF coverage](../guides/previews.md#pdf-search-coverage).

Desktop packages and standalone CLI archives are available again, including Linux CLI packages. Use the [current installation guide](../guides/installation.md). [Previous release: v1.0.0](v1.0.0.md).
