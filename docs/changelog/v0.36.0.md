# Release notes · v0.36.0

Released on **2026-10-08 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.36.0).

## Translate a full PDF

Full-document translation adds saved paragraph progress, resumable editions and original/translated comparison. The same managed PDF can reuse saved editions across reading entry points. The new [PDF translation guide](../guides/pdf-translation.md) covers preparation, model requirements, glossary, resuming and export. Codex subscription models are unavailable for this translation operation in v0.36.0.

## Review code before Notebook execution

Agent-submitted Notebook code is screened before dispatch. Risky or insufficiently understood operations show a review card with affected source lines and an explicit decision. Ordinary supported reads and analysis need no additional risk approval. This is separate from reviewing a completed result with Reviewer. See [execution review](../guides/notebook.md#execution-review).

## Scientific databases

Six new operations bring the registry to **35 Connectors and 349 operations**: 34 data-source families with 347 operations, plus two offline Molecule operations.

| Entry | Capability | Guide |
| --- | --- | --- |
| PDC | Versioned cancer-proteomics studies, biospecimen associations and quantitative-file metadata | [PDC setup and scope](../tools/databases.md#pdc) |
| Genomes → Ensembl | Population-specific pairwise LD and nearby proxy variants | [LD queries](../tools/databases.md#ensembl-ld) |

Use the [operation reference](../reference/connector-operations.md) for exact fields. PDC discovery does not download data; high LD does not establish causality.

## Everyday workspace changes

- Library and Inbox add a loaded-page select-all control. Check the selected count before applying a batch action; it does not select every server-side match. See [batch selection](../guides/library.md#loaded-page-selection).
- Drag a file card or open artifact into the Composer to insert a file mention. Review the draft before sending. See [file mentions](../guides/composer.md#drag-file-mention).
- The official Anthropic catalog adds Claude Haiku 5.5; model catalogs remove context-size aliases that could fail selection. Select a currently available model rather than copying an old identifier. The saved Main model is not automatically replaced.

## Reading and reliability fixes

PDF extraction improves complex tables, multi-level headers, footers and multi-panel layouts. Inspect the source whenever scientific interpretation depends on layout; see [PDF extraction](../guides/previews.md#pdf-extraction).

Notebook lineage improves Python/R readers, container transforms and callback handling. This helps capture dependencies; it does not replace a [rerun verification](../guides/reproducibility.md). Other fixes cover mentions from the Files panel in new conversations, empty-workspace search, compact mention chips and the Specialist Marketplace in Remote Web.
