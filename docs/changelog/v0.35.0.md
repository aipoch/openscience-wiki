# Release notes · v0.35.0

Released on **2026-10-04 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.35.0).

## Replay and discuss research

**View replay** presents a recorded session with playback, step navigation, Notebook records and file-version history. **Ask about this step** brings the selected context into a writable conversation. Imported `.science` research remains read-only; fork it to continue execution. Replay does not rerun code. Follow the new [session replay guide](../guides/session-replay.md).

## Scientific databases

This release adds **13 operations**, bringing the registry to **34 Connectors and 339 operations**: 33 data-source families with 337 operations, plus two offline Molecule operations.

| Entry | Added capability |
| --- | --- |
| Cellosaurus | Cell-line identity, synonyms and quality annotations |
| Monarch Initiative | Disease/gene-to-phenotype associations with source evidence |
| IEDB | Epitopes, antigens, T-cell, B-cell and MHC assays, and publications |
| Omics Archives → GEO | Discover matrix file locations and preflight already-read matrix text |
| Structures & Interactions → PDB | Find structures by protein sequence with identity, E-value and query-coverage filters |

See [capabilities and connection steps](../tools/databases.md#cell-lines-phenotypes-immunity) and the [updated operation catalog](../reference/connector-operations.md). GEO preflight checks supplied text, not a downloaded file on disk; matrix discovery does not download files.

## PDFs and workspace controls

- Uploaded PDFs join generated and Library PDFs in **Figures and tables** extraction. Bounded parallel analysis improves processing, with better handling of complex layouts. See [PDF extraction](../guides/previews.md#pdf-extraction).
- Drop files anywhere in the conversation area to attach them; inspect the attachments before sending. See [file drops](../guides/composer.md#conversation-drop).
- Usage charts allow continuous inspection across dates. See [daily usage](../guides/usage.md#inspect-daily-usage).
- Windows adds native application menus in the titlebar. PDF outlines and notes adapt better to narrow windows.

## Models and network access

The OpenCode Zen catalog expands, including Jev classification entries where supported. Main-model and classification choices remain separate; see [model catalogs](../guides/providers.md#catalog-models).

Network settings distinguish public-domain rules from trusted private services. A private grant binds to the exact hostname, port and reviewed DNS addresses, with another DNS check before saving. See [public rules](../guides/network.md#public-network-rules) and [private services](../guides/network.md#trusted-private-services).

## Fixes

Fixes cover persisted session outcomes and approval waits, replay Notebook state and file galleries, scientific execution lineage, Codex folder permissions, Windows runtime startup and sandbox access, and WSL folder paths. Identical objects in `.science` packages are deduplicated; provider and project drafts gain protection against accidental loss.
