# Release notes · v0.35.1

Released on **2026-10-06 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.35.1).

## Start and manage a conversation

The new-conversation screen places research starters beside the Composer and keeps **Import previous research** compact. Choosing a starter fills an editable draft; it does not send it. Follow [research starters](../guides/composer.md#research-starters).

The session header's **Session actions** menu groups edit, pin, Side Chat, Fork, export and archive. Its export submenu separates conversation, research-package and diagnostic outputs. Side Chat tabs and toolbars also become more compact. See [session controls](../guides/sessions.md#session-header-menu).

## Scientific databases

Four additions bring the registry to **34 Connectors and 343 operations**: 33 data-source families with 341 operations, plus two offline Molecule operations.

| Entry | Added capability | Where to start |
| --- | --- | --- |
| Human Genetics → GWAS Catalog | Discover full summary-statistics file locations, metadata and declared reference genomes; no large-file download | [GWAS files](../tools/databases.md#gwas-summary-statistics) |
| InterProScan | Submit protein sequences, then follow status and retrieve TSV annotations | [Contact email and submission](../tools/databases.md#interproscan-submit) |
| IEDB | Search TCR and BCR receptor evidence, with assay and source references | [Receptor evidence](../tools/databases.md#iedb-receptors) |

The [operation reference](../reference/connector-operations.md) includes the required fields, limits and exact examples. Aggregated receptor evidence does not establish that all conditions occur in one experiment.

## Requesty and model catalogs

**Requesty** joins the official provider picker with built-in connection validation and a curated model list. OpenRouter's catalog is also refreshed. Available protocols and models depend on the active Agent and account access; the saved Main model is not automatically replaced. See [Requesty setup](../guides/providers.md#requesty).

## PDF reading and notes

PDF context is retained before the first request is admitted, including newly attached PDFs. Follow [first-message upload and reading](../guides/previews.md#uploaded-first-message). Complex layout extraction is improved and persistent reader notices are reduced.

Verified copies of the same PDF content share a document notebook across projects, including uploads and artifacts. Matching filenames alone are insufficient, and notes do not synchronize across machines. See [where notes are shared](../guides/pdf-notes.md#where-notes-are-shared).

## Reliability fixes

Fixes preserve replay follow-up scrolling and recorded-file questions, keep imported sessions read-only, and retain Composer context when session bindings change. Replay reads recorded work; it does not rerun code. See [session replay](../guides/session-replay.md).

Notebook fixes cover cross-language file lineage, recovery around corrupt run documents, and R environments in paths containing spaces. Other fixes isolate shared-login settings by default, explain unattended Claude permission denials, and improve bookmarks, titlebar overlays and artifact-transaction retries.
