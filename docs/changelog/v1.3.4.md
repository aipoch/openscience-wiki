# Changelog · v1.3.4

Released **2026-11-23 UTC**. [Official release notes](https://github.com/aipoch/open-science/releases/tag/v1.3.4).

## Inspect the built-in Agent with tracing {/* #tracing */}

Projects gain **Agent tracing**, off by default. It sends correlated records of turns, model requests and MCP tool calls to an OTLP/HTTP receiver configured by the host operator, including generic collectors and Langfuse. Open-Science does not provide a collection service. Review the four content-capture settings before enabling it; they default to on when omitted. [Project steps](../guides/projects.md#agent-tracing) · [Receiver and capture configuration](../reference/diagnostics.md#agent-tracing).

For one Run, CLI `--otel-traces` or SDK `otelTraces: true` explicitly enables tracing even when the project switch is off. It does not change the saved project or session setting. [CLI](../reference/cli.md#otel-traces) · [SDK](../reference/api.md#otel-traces).

## Windows updates and Notebook responsiveness {/* #updates */}

Windows update preparation recognizes the app's built-in Agent and image helper, fixing stalls caused by treating them as external blockers. Stable Windows updates regain compact installer deltas; v1.3.3 used the full installer. [Update and recovery steps](../guides/installation.md#windows-134).

Long Notebook histories use fewer repeated reads and batch eligible Run transitions into durable checkpoints. The first Windows Python plot no longer stalls on an unrelated kernel-recovery fence. Compute memory usage excludes caches on macOS; Windows shows committed memory against its limit alongside physical usage. [Memory summary](../guides/notebook.md#memory-summary).

## Models and clearer task outcomes {/* #models-recovery */}

- CodeBuddy discovers supported reasoning efforts per model, restores the selected model and token-usage updates in resumed sessions, and fixes the first film-authoring request. Zhipu adds GLM-5.4. [Provider choices](../guides/providers.md#codebuddy-reasoning).
- A denied tool action ends with a retained explanation; denied calls stay distinct from completed work. [Approvals](../guides/approval-modes.md#denied-action).
- Explicit provider HTTP 402 responses such as Insufficient Balance retain their status and useful billing details. [Recovery](../guides/troubleshooting.md#provider-balance).
- A generating film keeps its conversation in Active. A blocked film dialog can open the conversation that owns the job. [Film progress](../guides/research-films.md#film-recovery).
- Edited-image versions open during publishing, and Provenance history remains accessible while image drafts are active. [Image editing](../guides/image-generation.md#edit).
- Built-in Agent side chats use their own profile's checkpoints; tool continuations with null identity fields no longer fail the turn.

See [installation and updates](../guides/installation.md) and [v1.3.3](v1.3.3.md).
