# Release notes · v1.0.6

Released on **2026-10-30 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v1.0.6).

## Bring your Zotero library with you {/* #zotero */}

Import a personal library or selected collections from Zotero 10 or later running on the same computer. Preview references before copying metadata, local PDFs, tags and collection hierarchies; review matches before reusing existing records. This is an import, not two-way synchronization. [Zotero import walkthrough](../guides/library.md#zotero-import).

The Library's normal search now also finds words in saved personal notes. Display the **Notes** column to record why a paper matters, then find it again through **Search references**. [Search by a personal note](../guides/library.md#personal-note-search).

## Read PDFs without configuring their order {/* #pdf */}

Linked PDFs use automatic text ordering. Complete logical tags take priority; available text and layout provide fallbacks. The persistent manual reading-order controls are removed, including for older messages with saved regions. Inspect the source before citing passages from complex layouts. Translated PDFs also open faster, and the DOCX toolbar stays above the document while scrolling. [PDF reading order](../guides/previews.md#automatic-pdf-reading-order).

## Update and keep working {/* #reliability */}

- Windows installation has fewer payload files and parallel extraction. The updater preserves research data beside the application and handles deep installation paths. [Windows update checks](../guides/installation.md#windows-update-data).
- Generated files remain publishable throughout an open assistant turn, without the previous two-hour expiry during long tasks.
- Custom local Connectors using **npx** or **npm** can fall back to the bundled runtime when those commands are absent. Installed commands keep priority. [Local commands](../guides/connectors.md#bundled-npm).
- Slurm records terminal outcomes before collecting logs, handles queue/controller/accounting observations independently, and reports one final cancellation result. [Job status and collection](../guides/remote-compute.md#slurm-outcome-recovery).
- Interactive system credential authorization allows up to five minutes. A timeout has its own recovery message. [Startup authorization](../tools/credentials.md#system-authorization).

Other fixes cover OpenCode tool calls and Windows launch limits, Windows cookie-store startup and R temporary paths containing spaces, session synchronization, restored drafts after stopping preparation, and imported-session error history. Split-button menus also share a consistent layout. WSL guidance now identifies **Windows 11 22H2 or later** as the requirement for mirrored networking. [WSL2 setup](../guides/runtimes.md#wsl2-preview).

The built-in Connector catalog is unchanged: **48 Connectors and 418 operations**, comprising 47 data-source Connectors with 416 operations and one offline Molecule Connector with two operations. [Supported sources](../tools/databases.md#supported-databases) · [Previous release: v1.0.5](v1.0.5.md).
