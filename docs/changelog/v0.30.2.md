# Changelog · v0.30.2

Released September 17, 2026. This update focuses on reliable Skill loading, side discussions, scientific data queries and execution recovery.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.30.2) · [Changes since v0.30.1](https://github.com/aipoch/open-science/compare/v0.30.1...v0.30.2)

## Changes to everyday use

| Area | What changes for you |
| --- | --- |
| Specialist Skills | Bound Skills are prepared for Specialist turns and delegated tasks. OpenCode can read provisioned Skill references. See the [Specialist workflow](../workflows/extend-analysis.md) for selection and usage. |
| Side Chat | Main running or waiting for approval no longer blocks Side Chat by itself. Side Chat remains mounted across application views; its own history, restoration and read-only checks still apply. [Side Chat](../guides/delegation.md) |
| Web-search approval | Supported Claude Agent native searches can remember **Allow for this conversation**. Search and page-reading grants remain separate. [Permissions](../guides/approval-modes.md#remember-web-search) |
| Reviewer | Auto-review settings survive conversation startup. Linked correction turns retain the feedback needed for the correction cycle. Inspect the revised output and subsequent review. [Reviewer](../specialists/reviewer.md) |

## Data and evidence

The [Connector reference](../reference/connector-operations.md) and downloadable registry now use v0.30.2. Reactome respects the requested supported species; Ensembl returns the resolved species and normalizes VEP region queries to the forward strand. UCSC rejects invalid coordinate bounds, and gnomAD region coordinates must be below one billion. CellGuide and OLS report relevant fetch or pagination failures instead of presenting them as empty evidence.

PubMed author parsing now preserves surname/initial/suffix distinctions. The `literature-review` Skill checks Crossref retraction relationships in both directions. A missing marker is not proof that a paper has never been retracted. See [metadata checks](../guides/library.md) and [literature evidence](../workflows/literature-review.md).

## Notebook and recovery

Windows fixes cover conda R startup, executable lookup after environment preparation, R kernel recovery and pip entry points in verification environments. Notebook replay restores supported same-turn inputs and standard-library imports. Linux read grants under temporary mounts are also corrected. See [Runtimes](../guides/runtimes.md) and [Reproducibility](../guides/reproducibility.md).

These are release/source-backed fixes. The existing Windows and Specialist screenshots retain their original versions; they are not new v0.30.2 test results. Missing input evidence or environment locks still require attention, and reproduction checks remain specific to captured result versions.

## Other improvements

The provider catalog adds DeepSeek V4.1 Flash and refreshes Volcengine Ark models while retaining older pinned choices. Marketplace cards show the source when an author is absent. OpenCode delegated tasks use isolated runtimes; queued CLI conversation snapshots and several Settings, tab, literature and tool-card interactions are corrected.

Use [Install and update](../guides/installation.md) for updating. The preceding release is [v0.30.1](./v0.30.1.md).
