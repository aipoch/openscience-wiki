# Release notes · v0.34.0

Released on **2026-09-28 UTC** (**2026-09-29 in China Standard Time**). [Official release](https://github.com/aipoch/open-science/releases/tag/v0.34.0).

## Journal datasets and literature references

The Library adds journal datasets with source, year and column mapping, displaying attributes on matching papers. Follow the dedicated [Journal datasets and reference attributes guide](../guides/journal-datasets.md).

Workspace Library actions add reference details, explicit batch selection and references in the current or another conversation's draft. You still choose when to send. See [Library actions](../guides/library.md#add-reference-to-chat).

## Scientific database expansion

Pathway Commons joins expanded Bgee, cBioPortal, openFDA and MGnify coverage, adding **16 operations**. The full registry contains **29 Connectors and 300 operations**: 28 data-source families with 298 operations, plus two offline Molecule operations.

See [database capabilities and setup](../tools/databases.md#pathway-expression-clinical), [operation parameters](../reference/connector-operations.md) and the [pathway interaction workflow](../workflows/inspect-pathway.md) with saved example results.

## Installation, models and desktop navigation

- Linux adds native ARM64 AppImage and Debian packages. See [installation](../guides/installation.md).
- The Codex CLI compatibility baseline is **0.157.1**. An existing older runtime may need its own update; see [Update Codex](../guides/frameworks.md#update-codex).
- Provider catalogs add **MiniMax M3.1 Flash Preview** and **Claude Sonnet 5.5**. See [provider settings](../guides/providers.md#catalog-models).
- Desktop tray/menu-bar navigation opens running, pinned and recent sessions. See [quick navigation](../guides/navigation.md#tray-navigation).

## Improvements and fixes

Electron upgrades to version 43, with faster workspace switching and fewer interpreter-discovery subprocesses. Fixes cover recovery after agent connection errors, delegation after stopping or restarting, interrupted reviewer assessments, PDF figure/table extraction, literature metadata, WSL runtime readiness and macOS remote directory listings. Editing protection, keyboard focus and permission explanations also improve.
