# Changelog · v1.3.3

Released **2026-11-22 UTC**. [Official release notes](https://github.com/aipoch/open-science/releases/tag/v1.3.3).

## Updates that fit around your work {/* #updates */}

Eligible official stable macOS installations can install a prepared update when you quit. Windows and Linux can prepare updates for the next launch while the desktop is idle in the background. Automatic downloads require an unrestricted, unmetered connection and enough storage; unsupported installation locations and channels retain the manual path. Linux AppImage updates preserve the application path, and stable Windows updates can use compact deltas. [Automatic and manual updates](../guides/installation.md#update-progress).

The installed macOS and Windows apps are smaller. The offline npm runtime is bundled for Node 22, reducing the number of loose files.

## The built-in Agent is the default everywhere {/* #agent */}

New projects and sessions default to **Open-Science Agent**, including clean CLI and SDK installations. An absent external Agent SDK no longer prevents those installations from starting. Install an external framework only when you choose to use it; model access still needs configuration. [Agent setup](../guides/frameworks.md#built-in-agent) · [CLI setup](../reference/cli.md#terminal-setup).

Settings restores shortcuts to installed Skills, Specialists and Connectors. Bailian's catalog adds the qwen4 family, with its plan default changed to the qwen4 preview. Check the model available to your account before starting work.

## Edit images in the conversation {/* #images */}

Enter **Edit image** from a preview and write the edit in the conversation composer. Image version navigation and comparison remain available, and the conversation stays in place when entering editing. Image details identify the Notebook kernel behind an edit. [Image editing steps](../guides/image-generation.md#edit).

PDF translation better reconnects text split at columns, captions and inline formulas, and avoids displacing notation, form labels and neighboring graphics. Continue checking exported pages against the original. [PDF translation](../guides/pdf-translation.md#scientific-layout).

## Clearer failures and recovery {/* #recovery */}

- Request, loading, attachment, import and Notebook errors explain their causes. Provider errors retain their classification and request ID across restart; stopped work is distinguished from an unanswered continuation. [Troubleshooting](../guides/troubleshooting.md#provider-errors).
- Windows preserves a pending built-in Agent question across restart, restores Notebook runtime status, and rechecks stale file blockers during a cold launch.
- Notebook memory checks account for Windows physical memory, macOS memory pressure and Linux container limits. [Memory and resources](../guides/notebook.md#memory-resources).
- Session-package exports wait for Notebook reads to settle before reporting export failures. Saved artifact links, confirmed memory deletion and GitHub Skill import errors are also corrected.

See [installation and updates](../guides/installation.md) and [v1.3.2](v1.3.2.md).
