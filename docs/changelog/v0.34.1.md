# Release notes · v0.34.1

Released on **2026-10-01 UTC**. [Official release](https://github.com/aipoch/open-science/releases/tag/v0.34.1).

## Scientific database expansion

This release adds **26 operations**, bringing the registry to **31 Connectors and 326 operations**: 30 data-source families with 324 operations, plus two offline Molecule operations.

| Entry | Added capability |
| --- | --- |
| CELLxGENE Discover | Discover public single-cell collections and datasets, inspect published versions and retrieve file inventories |
| Alliance Genome Resources | Human and model-organism genes, orthologs, disease models, phenotypes, alleles and expression |
| Variants → MaveDB | Variant-effect score sets, CSV scores, existing VRS mappings and experiments |
| Omics Archives → Metabolomics Workbench | Study samples, experimental factors, analyses, metabolite annotations and compound cross-references |

Follow [capabilities and setup](../tools/databases.md#single-cell-model-organisms) and the [operation reference](../reference/connector-operations.md). A file URL is not a completed download, and an assay-specific functional score is not a clinical classification.

## Review the Inbox within a workspace

The compact **Library** preview adds **Inbox**, with search, pagination, individual **Accept / Dismiss**, dismissal **Undo**, and explicit batch selection on the current page. **Open Inbox** on a saved-reference card opens this review beside the conversation. The queue includes candidates across projects; acceptance does not download missing full texts. See [workspace Inbox steps](../guides/library.md#workspace-inbox).

Journal imports clarify column roles and mapping hints and improve alias matching, filtering and retries. See [journal datasets](../guides/journal-datasets.md#import-columns).

## Research packages and diagnostics

- Empty **New conversation** pages add **Import previous research** for choosing or dropping a `.science` package. See [import steps](../guides/research-packages.md#import-and-inspect-a-package).
- A sensitive-content check can be followed by an explicit **Export anyway** acknowledgment. Flagged content is included without redaction; inspect it before sharing. See [sensitive export](../guides/research-packages.md#sensitive-export).
- Local diagnostic exports preserve more useful error and execution evidence. They remain separate from research packages and require inspection before sharing. See [session diagnostics](../guides/troubleshooting.md#session-diagnostics).

## Models and workspace controls

The Codex catalog adds **gpt-6.1-sol** without changing saved defaults. Available access depends on the account and active runtime; see [model selection](../guides/providers.md#catalog-models).

Plan feedback follows the configured send shortcut. The Composer makes Compute Host status more visible, run previews can jump to their message, and Skill editing gains protection for unsaved drafts.

## Fixes

Notebook fixes cover state across cells, shared sandbox tools and execution lineage. PDF extraction better preserves native figure/table content and worker handling. Other fixes cover reference URLs, annotation selection cleanup, table pinning, restored follow-up permissions, Windows reinstall paths, Linux credential storage and credential identity handling.
