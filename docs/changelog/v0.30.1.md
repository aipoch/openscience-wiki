# Changelog · v0.30.1

Released September 16, 2026. This update improves how you prepare side discussions, review method changes and share research materials.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [Changes since v0.30.0](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## Updated workflows

| Area | What changes for you |
| --- | --- |
| Side Chat | Open an empty draft, inherit the main conversation's model and reasoning effort, or choose a different model for the next send. Drafts with content survive navigation; untouched empty drafts are cleaned up. [Side Chat](../guides/delegation.md) |
| Skill updates | Inspect file changes, line numbers and added/deleted lines before **Update existing Skill**. Review affected Specialists and local edits that will be replaced. [Skill marketplace](../skills/marketplace.md) |
| Research packages | **Full export** includes available literature PDFs; **Customize contents** selects them individually. Essential export omits optional PDFs; required evidence cannot be removed. Side Chat conversations are excluded. [Research packages](../guides/research-packages.md) |
| Local gateways | A loopback Custom Gateway can leave its API key blank if the server needs no authentication. Remote gateways still require credentials and HTTPS. [Provider setup](../guides/providers.md) |
| Web-reading approval | A supported web-reading request can be remembered for the conversation, including later pages on other websites. [Permissions](../guides/approval-modes.md) |
| Tags | Search within resource tag pickers, use arrow keys and Enter, or create and assign a new tag. [Tags](../guides/tags.md) |
| Installation and recovery | macOS guides read-only copies into Applications before updating. Windows has a separate, destructive reset utility with a preview and typed confirmation. Installers display the project license. [Install and update](../guides/installation.md) · [Windows reset](../guides/troubleshooting.md#windows-data-reset) |

## Reported fixes

The release also reports fixes for plan approvals during MCP timeouts, historical artifact bindings, task cancellation and queued Notebook runs. PDF parsing can recover from blocked states and report extraction failures; figure/table layout recovery is improved. Connector fixes validate gnomAD region arguments and dataset reference builds, and correct ESM-2 batch residue pooling.

Provider checks use the tested provider's route. Missing file-backed Codex sign-ins receive a clearer import error. Literature views return to their originating conversation, and OpenCode Side Chat instructions stay separate from Main.

Use [Install and update](../guides/installation.md) for the update procedure. The preceding feature release is [v0.30.0](./v0.30.0.md).
