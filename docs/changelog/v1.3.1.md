# Changelog · v1.3.1

Released **2026-11-19 UTC**. [Official release notes](https://github.com/aipoch/open-science/releases/tag/v1.3.1).

## Find sources and follow citations {/* #sources */}

The built-in Open-Science Agent can search the public web and read pages, with source citations retained alongside the conversation. Search approvals show the query and filters. Queries go to Exa; reading a page contacts that website. [Web search and reading](../tools/web-search.md).

The Library adds an interactive citation graph. Filter references and citing papers, select a related paper as the new center, or return to the original paper. Review candidates in Inbox before adding them to your Library. [Explore the citation graph](../guides/library.md#citation-discovery).

## Connect agents and organization resources {/* #connections */}

An external MCP client can now start or reuse the local Open-Science service when it connects. The service stays running after the client disconnects; stop it explicitly when finished. [MCP configuration](../reference/cli.md#external-mcp).

In the desktop app, a Lab account gives access to your organization's assigned models and shared research cases. Model requests and shared packages go to the configured Lab server. [Lab account setup](../guides/providers.md#lab-account) · [Organization cases](../guides/research-packages.md#organization-cases).

## More control over models and resources {/* #controls */}

- Refresh supported providers' model lists in Settings. A failed refresh preserves the previous catalog; conversation errors now explain authentication, quota, rate-limit and other causes. [Provider setup](../guides/providers.md#refresh-models).
- Optionally run a test image generation before saving an image service. The first model is selected automatically if no default exists. [Image-service configuration](../guides/image-generation.md#configure).
- Notebook checks memory before execution. Use Compute to inspect and release a session's local Notebook resources, then retry work deliberately. [Memory and resource management](../guides/notebook.md#memory-resources).
- Startup loads the project home sooner. Reconnection preserves drafts and restores long branched histories and pending questions. Research-film playback no longer waits on irrelevant quality reviews.

## Updating from v1.3.0 {/* #update */}

The v1.3.0 updater can mistake an app-owned process for another program using the installation. If this blocks the update, finish active work, fully quit the app and its background service, then install the official v1.3.1 package manually. Installing v1.3.1 cannot repair the updater already running in v1.3.0. [Manual update steps](../guides/installation.md#update-from-130).

The release also fixes large-settings-file failures during Windows updates/uninstall, optional WSL setup blocking first run, incomplete deletion of imported sessions on Windows, and Linux AppImage update checks misidentifying an app-owned pipe. A missing research folder now appears by path in startup recovery, so you can reconnect its drive.

See [installation and updates](../guides/installation.md) and [v1.3.0](v1.3.0.md).
