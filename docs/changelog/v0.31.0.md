# Changelog · v0.31.0

Released September 18, 2026. This release adds independent session copies and improves continuity when a conversation or connection is restored.

[Official release](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [Changes since v0.30.2](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## Continue and inspect a session

- **Fork** creates a writable desktop copy with conversation branches, Notebook records, artifact versions, literature, annotations and private bookmarks. It assigns fresh identities and preserves the source. Imported sessions themselves remain read-only. See the [Fork walkthrough](../guides/sessions.md#fork-session) and [research packages](../guides/research-packages.md).
- The session title opens an [information card](../guides/sessions.md#session-information) with its source, counts and pin control. A continued conversation links to its source turn.
- [Session Plans](../guides/planning.md#resume-plan) retain identity, revision and pending approvals after context reconstruction. Recovery does not mean a pending step has been approved or run.

## Changed setup and data behavior

| Area | What to check |
| --- | --- |
| Provider settings | Edits are validated before they replace a saved configuration; runtime rejection updates availability. [Provider setup](../guides/providers.md#validated-provider-save) |
| Windows R | Standard-mode execution no longer requires protected-mode setup. Protected execution has separate requirements. [Runtimes](../guides/runtimes.md) |
| gnomAD | Request `include_populations: true` for per-population counts and frequencies; retain dataset, build and quality filters. [Parameters](../reference/connector-operations.md#get_variant) |
| Product name | The interface uses Open-Science. Existing installation locations, settings and data are preserved; do not rename storage folders to match. [Installation](../guides/installation.md#product-name) |

**STRING compatibility change:** `nodes` now describes the complete returned graph, including added neighbors. Filter `is_query` for mapped inputs and use `queries` for all input aliases. Do not use `n_nodes` as the number of submitted proteins. [STRING guidance](../tools/databases.md#string-network)

Other fixes cover Codex reasoning-effort changes, cancellation and continuation, UniProt secondary accessions, Ensembl identifiers, clinical-trial eligibility and cBioPortal denominators. Use the official release for the full list.

The Fork screenshots were captured with v0.31.1. Windows R changes here are release/source-backed; older platform screenshots retain their original test context. The next release is [v0.31.1](./v0.31.1.md).
