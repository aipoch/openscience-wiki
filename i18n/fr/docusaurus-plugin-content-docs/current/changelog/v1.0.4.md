# Notes de sortie · v1.0.4

Libéré le **2026-10-27 UTC**. [Communiqué officiel](https://github.com/aipoch/open-science/releases/tag/v1.0.4).

## Connectez d'autres outils à l'atelier {/* #mcp */}

Le CLI autonome fournit un adaptateur MCP stdio pour les clients externes. Commencez d'abord le service local authentifié, puis connectez le client à ce profil. Les outils peuvent créer des projets, modifier la configuration et exécuter la recherche en vertu des autorisations existantes, y compris les coûts d'écriture et de modélisation. [Configuration et contrôles MCP](../reference/cli.md#external-mcp).

## Vérifiez les avis de publication d'un papier {/* #publication */}

Dans la bibliothèque, une référence avec un DOI valide peut être vérifiée manuellement pour les rétractations et corrections via Crossref. Les résultats conservent leur source et le temps de vérification. Un résultat vide n'est pas une assurance qu'un papier n'est pas affecté. [Vérifier et interpréter les avis](../guides/library.md#publication-checks).

## Garder le travail quotidien gérable {/* #workspace */}

- Tours complétés effondrement des messages intermédiaires et des groupes d'outils; la recherche et les annotations peuvent révéler leur contenu. [Étendre une conversation](../guides/sessions.md#collapsed-conversation).
- Enregistrer un fichier dans un dossier autorisé comme artefact de conversation immuable. [Importation de fichier local](../guides/files.md#import-local-artifact).
- Enregistrer un dépôt GitHub Skill numérisé pour réutilisation; il ne met pas à jour automatiquement Skills. [Dépôts enregistrés](../skills/manage.md#saved-repositories).
- Les cartes de questions fournissent explicitement **Skip** et **Skip all** les mesures prises. [Contrôle des questions](../guides/composer.md#skip-question).

Les téléchargements sont plus petits. Les corrections couvrent l'exécution standard de Windows Notebook, les exportations de paquets en attente après la sélection de l'emplacement de sauvegarde, les dialogues dossier-accès, la récupération des questions et la présentation de l'événement replay. [Transfert de colis](../guides/research-packages.md#local-package-transfer) · [Version précédente: v1.0.3](v1.0.3.md).
