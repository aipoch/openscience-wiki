# Notes de sortie · v0.33.3 {/* #release-notes--v0333 */}

Libéré sur **2026-09-26**. [Communiqué officiel](https://github.com/aipoch/open-science/releases/tag/v0.33.3).

## Lire les fichiers et gérer la littérature {/* #read-files-and-manage-literature */}

Les téléspectateurs de bureau ajoutent la navigation et la recherche de page, avec la lecture PowerPoint paged. Utilisez les fichiers QC existants dans [prévisualisations de fichiers](../guides/previews.md).

L'espace de travail **Library** ajoute un prévisualisation compact pour les recherches et les résumés de projet courant ou de référence. Les collections intelligentes ajoutent **Abandonner l’exécution**: les résultats complétés restent, mais cette exécution ne peut pas reprendre. L'achèvement des métadonnées Crossref importe les résumés sources. Voir [Bibliothèque](../guides/library.md) et [tri sur papier](../workflows/screen-literature.md).

## Exploitation de nouvelles bases de données scientifiques {/* #new-scientific-database-operations */}

**Genes & Ontologies** ajoute la découverte et l'enrichissement de la bibliothèque Enrichr. **Génomique clinique** ajoute des requêtes ClinPGx pour les médicaments, les gènes, les variantes, les lignes directrices, les étiquettes et les fréquences de population. Le registre complet possède désormais **Connecteurs 28 et opérations 284**: 27 Data-source Connecteurs avec opérations 282, ainsi que deux opérations Molecule hors ligne. Voir [capacités de base de données](../tools/databases.md) et [Référence de l'opération](../reference/connector-operations.md).

## Packages de recherche, apparence et installation {/* #research-packages-appearance-and-installation */}

Les transferts de paquets ajoutent des limites d'activité disque automatiques ou fixes, avec des progrès disponibles pendant les travaux de fond. Des raccourcis d'échelle de bureau partagent les étapes 90%, 100%, 110% et 125% des paramètres. La signature Windows couvre les exécutables groupés. Voir [transfert de colis](../guides/research-packages.md#transfer-settings), [échelle d'interface](../guides/appearance.md#interface-scale) et [installation](../guides/installation.md).

## Corrections {/* #fixes */}

Corrige l'adresse des polices PDF reading-tab, la récupération isolée du noyau Notebook, l'accès natif aux dossiers accordés, les récupérations et les erreurs de rejet. Les appels de récupération d'archives sont étendus aux projets touchés. D'autres corrections portent sur la sélection initiale des modèles de classification, les suffixes d'archives diagnostiques, les métadonnées Skill, la gestion de Python et les enregistrements d'utilisation dans les paquets de recherche.
