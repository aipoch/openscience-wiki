# Notes de sortie · v0.36.0 {/* #release-notes--v0360 */}

Libéré sur **2026-10-08 UTC**. [Communiqué officiel](https://github.com/aipoch/open-science/releases/tag/v0.36.0).

## Traduire un PDF complet {/* #translate-a-full-pdf */}

La traduction du document complet ajoute les progrès enregistrés des paragraphes, les éditions récupérables et la comparaison originale/translationnelle. Le même PDF géré peut réutiliser les éditions sauvegardées à travers les points d'entrée de lecture. Le nouveau [Guide de traduction PDF](../guides/pdf-translation.md) couvre la préparation, les exigences du modèle, le glossaire, la reprise et l'exportation. Les modèles d'abonnement Codex ne sont pas disponibles pour cette opération de traduction dans v0.36.0.

## Revoir le code avant l'exécution de Notebook {/* #review-code-before-notebook-execution */}

Le code Notebook soumis par l'agent est examiné avant l'expédition. Les opérations risquées ou mal comprises montrent une carte d'examen avec les lignes de source touchées et une décision explicite. Les lectures et l'analyse appuyées ordinaires ne nécessitent pas d'approbation supplémentaire des risques. Ce document est distinct de l'examen d'un résultat rempli avec l'examinateur. Voir [Examen de l'exécution](../guides/notebook.md#execution-review).

## Bases de données scientifiques {/* #scientific-databases */}

Six nouvelles opérations amènent le registre à **Connecteurs 35 et opérations 349**: familles de sources de données 34 avec des opérations 347, plus deux opérations Molecule hors ligne.

| Entrée | Capacité | Guider |
| --- | --- | --- |
| PDC | Études en version cancer-protéomique, associations de biospécimens et métadonnées de fichiers quantitatifs | [Configuration et portée de PDC](../tools/databases.md#pdc) |
| Génomes → Ensembl | Variantes par paires de LD et de proxy à proximité spécifiques à la population | [requêtes LD](../tools/databases.md#ensembl-ld) |

Utilisez le [Référence de l'opération](../reference/connector-operations.md) pour les champs exacts. La découverte de PDC ne télécharge pas les données; LD élevé n'établit pas la causalité.

## L'espace de travail quotidien change {/* #everyday-workspace-changes */}

- Bibliothèque et boîte de réception ajoutent un contrôle sélecteur de page chargé. Vérifier le nombre sélectionné avant d'appliquer une action de lot; il ne sélectionne pas chaque match côté serveur. Voir [Sélection des lots](../guides/library.md#loaded-page-selection).
- Faites glisser une carte de fichier ou ouvrez un artefact dans le Compositeur pour insérer une mention de fichier. Examiner le projet avant d'envoyer. Voir [mentions de fichier](../guides/composer.md#drag-file-mention).
- Le catalogue anthropique officiel ajoute Claude Haiku 5.5; les catalogues de modèles suppriment les alias de taille de contexte qui pourraient échouer la sélection. Sélectionnez un modèle actuellement disponible plutôt que de copier un ancien identifiant. Le modèle Main sauvegardé n'est pas automatiquement remplacé.

## Corrections de lecture et de fiabilité {/* #reading-and-reliability-fixes */}

L'extraction PDF améliore les tables complexes, les en-têtes multi-niveaux, les pied de page et les mises en page multi-panneau. Inspecter la source chaque fois que l'interprétation scientifique dépend de la mise en page; Voir [Extraction de PDF](../guides/previews.md#pdf-extraction).

La gamme Notebook améliore les lecteurs, les transformateurs de conteneurs et la gestion des callbacks Python/R. Cela permet de saisir les dépendances; il ne remplace pas un [Vérification de la réexécution](../guides/reproducibility.md). D'autres corrections couvrent les mentions du panneau Fichiers dans de nouvelles conversations, recherche d'espace de travail vide, puces de mention compacte et le marché Specialist dans le Web distant.
