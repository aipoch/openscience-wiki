# Notes de sortie · v1.0.2

Libéré le **2026-10-22 UTC**. [Communiqué officiel](https://github.com/aipoch/open-science/releases/tag/v1.0.2).

## Demander plus de sources scientifiques {/* #scientific-sources */}

| Source | Ouvre-le. |
| --- | --- |
| Nomenclature des gènes HGNC | Genes &amp; Ontologies |
| PubTator 3 annotations d'article | PubMed |
| Interactions entre les médicaments et les gènes | Clinical Genomics |
| Enregistrements RNAcentral et références croisées | RNA |
| Associations de maladies rares d'Orphadata | Orphadata ; activez-le d'abord |

Ces ajouts apportent le catalogue à **36 entrées de données avec 371 opérations**, plus les deux opérations Molecule hors ligne. [Choisissez une source et connectez-la](../tools/databases.md#new-source-access).

GDC filtre les fichiers par cas, type d’échantillon et workflow en conservant les liens entre échantillons et aliquotes. Ensembl VEP accepte HGVS sans conversion manuelle des coordonnées, mais ne valide pas la version de référence saisie et ne réalise pas de liftover. Le catalogue inclut aussi les résultats publiés de ClinicalTrials.gov. Voir [contexte de requête](../tools/databases.md#clinical-context) et les [référence complète de fonctionnement](../reference/connector-operations.md).

## Installer et inspecter le CLI {/* #cli */}

L'ICL et Task SDK sont publiés sur npm. Suivre [npm installation](../guides/installation.md#npm-cli), puis utiliser `version`, `help` et `paths` sans démarrer le backend. La version affichée est celle de l’installation appelée. Les distributions desktop et autonomes incluent les mises à jour de sécurité de Node 22.23.4. [Commandes d'informations locales](../reference/cli.md#local-information).

## Gardez le contrôle d'une conversation {/* #conversation */}

Les cartes de questions distinguent **Single select** de **Multi select** et conserver l'historique complet des réponses de chaque question. Les erreurs de mesure en file d'attente offrent une action de désactivation; les brouillons non envoyés déclenchent les avertissements d'abandon/rechargement. La récupération des titres de créance donne une prochaine étape spécifique tout en préservant les ébauches. Chat web distant prend en charge les mentions d'artefact. [Cartes de questions et brouillons](../guides/composer.md#clarification-questions).

## Poursuivre la recherche avec des dossiers plus clairs {/* #research-records */}

- Les dialogues de paquets restent stables; réessayer une importation partiellement engagée évite les sessions dupliquées. Les titres importés peuvent être modifiés pendant que la recherche reste en lecture seule. [Dossiers de recherche](../guides/research-packages.md#browser-import).
- Le chargement de grande session et la récupération de démarrage améliorent. Les exportations de diagnostic partiel montrent des avertissements. [Diagnostic des séances](../guides/sessions.md#session-diagnostics).
- La structure PDF, la numérotation/frontières DOCX et la capture enchaînée de fichiers Python/R reçoivent des corrections. [Contrôles de lignage](../guides/notebook.md#chained-analysis-lineage).
- Les importations de grandes compétences utilisent des lots; les noms externes réservés obtiennent des noms locaux sûrs. MiniMax M3.1 à travers Codex est fixe. [Recouvrement du fournisseur](../guides/providers.md#credential-recovery).
