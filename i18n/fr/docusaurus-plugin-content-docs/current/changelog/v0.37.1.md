# Notes de sortie · v0.37.1 {/* #release-notes--v0371 */}

Libéré sur **2026-10-12 UTC**. [Communiqué officiel](https://github.com/aipoch/open-science/releases/tag/v0.37.1).

## Préserver la structure scientifique PDF {/* #preserve-scientific-pdf-structure */}

L'extraction de la figure préserve mieux les légendes, les légendes et les graphiques multi-panneau. Les tables en règle à côté des formules conservent les en-têtes groupés, la structure des lignes et les références des cellules sources. Les légendes, les graphiques et le texte sont conservés avec leur élément source plutôt qu'avec un élément voisin.

Lors de l'utilisation de [Figures et tableaux](../guides/previews.md#pdf-extraction), comparez l'élément extrait avec sa page d'origine avant de le citer. Vérifiez les panneaux complets, légendes, en-têtes de table, unités et notes de bas de page. La régénération PDF traduite accepte également les différences valides dans les noms de glyphes intégrés tout en préservant l'encre source d'origine; utiliser le [comparaison et contrôles à l'exportation](../guides/pdf-translation.md#compare-export).

## Windows et installation {/* #windows-and-installation */}

- Le bureau CLI gère les chemins d'installation contenant des caractères chinois et autres caractères non-ASCII, en conservant la page de code de l'appelant et le code de sortie. Mettre à jour et rouvrir le terminal si un lanceur plus âgé mal lit son chemin; Voir [Configuration de CLI](../reference/cli.md#terminal-setup).
- La traduction locale PDF gère correctement les chemins d'entraînement Windows.
- Les noyaux Notebook, les empreintes digitales de l'environnement, les inventaires de paquets et la capture de verrouillage évitent de clignoter des fenêtres de console supplémentaires.
- Desktop et des paquets d'exécution autonomes suppriment les dépendances et les actifs dupliqués inutilisés, réduisant la croissance du téléchargement introduite dans v0.37.0.

Le moteur autonome CLI et Node introduit dans [v0.37.0](v0.37.0.md) reste la base de l'exploitation du service. Utilisez le paquet correspondant à votre plateforme et gardez le répertoire d'exécution extrait intact.
