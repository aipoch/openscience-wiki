# Changelog · v0.30.1 {/* #changelog--v0301 */}

Erschienen September 16, 2026. Dieses Update verbessert die Art und Weise, wie Sie Nebendiskussionen vorbereiten, Methodenänderungen überprüfen und Forschungsmaterialien teilen.

[Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [Änderungen seit v0.30.0](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## Aktualisierte Workflows {/* #updated-workflows */}

| Bereich | Was sich für Sie ändert |
| --- | --- |
| Side Chat | Öffnen Sie einen leeren Entwurf, erben Sie das Modell und den Argumentationsaufwand des Hauptgesprächs oder wählen Sie ein anderes Modell für den nächsten Versand. Entwürfe mit Inhalt überleben Navigation; unberührte leere Züge werden gereinigt. [Side Chat](../guides/delegation.md) |
| Skill Updates | Überprüfen Sie Dateiänderungen, Zeilennummern und hinzugefügte / gelöschte Zeilen, bevor **Vorhandene Fähigkeit aktualisieren**fort. Die Überprüfung betraf Spezialisten und lokale Bearbeitungen, die ersetzt werden. [Skill-Marktplatz](../skills/marketplace.md) |
| Forschungspakete | **Full export** enthält verfügbare Literatur PDFs; **Customize contents** wählt sie individuell aus. Essential Export lässt optionale PDFs aus; erforderliche Beweise können nicht entfernt werden. Side Chat-Konversationen sind ausgeschlossen. [Forschungspakete](../guides/research-packages.md) |
| Lokale Gateways | Ein Loopback Custom Gateway kann seinen API-Schlüssel leer lassen, wenn der Server keine Authentifizierung benötigt. Remote-Gateways erfordern weiterhin Anmeldeinformationen und HTTPS. [Provider-Einrichtung](../guides/providers.md) |
| Genehmigung für das Lesen im Internet | Eine unterstützte web-leseanfrage kann für die konversation in erinnerung bleiben, einschließlich späterer seiten auf anderen websites. [Berechtigungen](../guides/approval-modes.md) |
| Tags | Suchen Sie in Ressourcen-Tag-Pickern, verwenden Sie Pfeiltasten und Enter oder erstellen und weisen Sie ein neues Tag zu. [Tags](../guides/tags.md) |
| Installation und Verwertung | macOS führt schreibgeschützte Kopien in Anwendungen vor der Aktualisierung. Windows verfügt über ein separates, destruktives Reset-Dienstprogramm mit einer Vorschau und einer getippten Bestätigung. Installateure zeigen die Projektlizenz an. [Installieren und Update](../guides/installation.md) · [Windows Reset](../guides/troubleshooting.md#windows-data-reset) |

## Berichtigte Fixes {/* #reported-fixes */}

Die Veröffentlichung berichtet auch über Fixes für Plangenehmigungen während MCP-Timeouts, historische Artefaktbindungen, Aufgabenabbruch und in die Warteschlange gestellte Notebook-Läufe. PDF-Parsing kann sich aus blockierten Zuständen erholen und Extraktionsfehler melden; Abbildung / Tabelle Layout Wiederherstellung verbessert wird. Connector korrigiert die Validierung von gnomAD-Regionalargumenten und Dataset-Referenz-Builds sowie die Korrektur des ESM-2-Batch-Restpoolings.

Anbieter-Checks verwenden die Route des getesteten Anbieters. Fehlende dateigestützte Codex-Anmeldungen erhalten einen klareren Importfehler. Literaturansichten kehren zu ihrer ursprünglichen Konversation zurück, und OpenCode Side Chat-Anweisungen bleiben von Main getrennt.

Verwenden Sie [Installieren und Update](../guides/installation.md) für das Update-Verfahren. Das vorhergehende Feature Release ist [v0.30.0](./v0.30.0.md).
