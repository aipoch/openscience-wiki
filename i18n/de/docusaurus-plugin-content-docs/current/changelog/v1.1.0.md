# Release Notes · v1.1.0

freigelassen am **2026-11-06 UTC**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v1.1.0).

## Verwandeln Sie eine Sitzung in einen Forschungsfilm {/* #research-films */}

Eine abgeschlossene Sitzung kann zu einem Kurzfilm mit englischer Erzählung werden. Installieren Sie die lokalen Erzählressourcen, generieren Sie aus der Desktop-Sitzung und überprüfen Sie die Wiedergabe, bevor Sie einen tragbaren Player freigeben oder MP4 exportieren. Der Film präsentiert aufgezeichnete Forschung; er wiederholt oder überprüft die Analyse nicht. [Forschungsfilmführer](../guides/research-films.md).

## Arbeiten Sie durch eine Leseliste {/* #literature */}

Wählen Sie bis zu fünf Referenzen aus, um Studienübersichten als Batch zu erstellen. Halten Sie an, setzen Sie unvollendete Arbeiten fort oder wiederholen Sie fehlgeschlagene Elemente, während Sie die Übersichten beibehalten. Die CLI und MCP erhalten auch Bibliothekssuche, Zitierformatierung und Referenzverwaltungsoperationen. [Chargenübersichten](../guides/library.md#batch-overviews) · [Literaturkommandos](../reference/cli.md#literature-library).

## Öffnen Sie den Arbeitsbereich auf einem mobilen Gerät {/* #mobile */}

QR-Paarung unterstützt ein Telefon oder Tablet auf dem gleichen WiFi oder eine Internetverbindung über Pinggy. Halten Sie den Host am Laufen und prüfen Sie den Verbindungsstatus vor dem Scannen. [Anschlussmöglichkeiten](../guides/remote-access.md#mobile-pairing).

## Veränderungen im täglichen Gebrauch {/* #reliability */}

- Berechnungseinstellungen verschieben sich auf **Connections**. Die Forschungsfallbibliothek hat ein aktualisiertes Layout und klarere Importziele.
- Gespräche erholen sich nach Unterbrechungen und Speicherausfällen zuverlässiger. Abgeschlossene oder untätige Agent-Verbindungen geben Ressourcen konsistenter frei.
- Diagnosen speichern Notebook-Ausführungsnachweise und historische Backend-Protokolle. Windows fügt optionale Ressourcenaufzeichnung für die Fehlersuche hinzu.
- Die PDF-Extraktion verbessert die Abbildungs- und Tabellenwiederherstellung von durchsuchbaren Scans, und Codex Chat unterstützt die native Bildeingabe.
- Notebook bevorzugt eine fertige App-verwaltete Laufzeit. Shell-Ausfälle Oberfläche als Werkzeugfehler eher als erfolgreiche Ergebnisse.
- Windows Update Vorbereitung prüft Prozessidentität und besetzte Dateien; lokal `.science` MP4- und MP4-Exportströme behandeln Desktop-Speicherdialoge zuverlässiger.

Siehe [Installation und Updates](../guides/installation.md) und [Das vorherige Release](v1.0.8.md).
