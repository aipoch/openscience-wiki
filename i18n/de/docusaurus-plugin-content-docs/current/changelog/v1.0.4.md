# Release Notes · v1.0.4

freigelassen am **2026-10-27 UTC**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v1.0.4).

## Verbinden Sie andere Tools mit der Workbench {/* #mcp */}

Das Standalone CLI bietet einen Stdio MCP Adapter für externe Clients. Starten Sie zuerst den authentifizierten lokalen Dienst und verbinden Sie dann den Client mit diesem Profil. Tools können Projekte erstellen, die Konfiguration ändern und Forschung unter vorhandenen Berechtigungen ausführen, einschließlich Schreib- und Modellkosten. [MCP-Einrichtung und -Kontrollen](../reference/cli.md#external-mcp).

## Überprüfen Sie die Publikationshinweise eines Papiers {/* #publication */}

In der Bibliothek kann eine Referenz mit einem gültigen DOI manuell auf Retraktionen und Korrekturen durch Crossref überprüft werden. Die Ergebnisse behalten ihre Quelle und überprüfen die Zeit. Ein leeres Ergebnis ist keine Zusicherung, dass ein Papier nicht betroffen ist. [Hinweise prüfen und interpretieren](../guides/library.md#publication-checks).

## Halten Sie die tägliche Arbeit überschaubar {/* #workspace */}

- Abgeschlossene Runden brechen Zwischennachrichten und Werkzeuggruppen zusammen; Suche und Anmerkungen können ihren Inhalt offenbaren. [Erweitern Sie ein Gespräch](../guides/sessions.md#collapsed-conversation).
- Speichern Sie eine Datei aus einem autorisierten Ordner als unveränderliches Konversationsartefakt. [Lokale Datei importieren](../guides/files.md#import-local-artifact).
- Lesezeichen eines gescannten GitHub Skill-Repositorys zur Wiederverwendung; es aktualisiert Skills nicht automatisch. [Gespeicherte Datenspeicher](../skills/manage.md#saved-repositories).
- Fragekarten bieten explizite **Skip** und **Skip all** Aktionen. [Fragestellungen](../guides/composer.md#skip-question).

Downloads sind kleiner. Fixes umfassen Windows Notebook-Standardausführung, Paketexporte, die nach der Speicherortauswahl warten, Ordnerzugriffsdialoge, Fragewiederherstellung und Wiedergabeereignispräsentation.
