## Wechseln Sie zum 1.0 Release {/* #upgrade */}

1.0 bringt den bestehenden Forschungsarbeitsplatz in die stabile Release-Linie. Es behält historische Profil-Upgrades und `.science`-Importe; Die Versionsänderung erfordert kein neues Profil oder Datenformat. Sichern Sie Ihr Profil und Ihre Forschungsdaten, beenden Sie die aktive Arbeit und aktualisieren Sie dann über das offizielle Desktop-Installationsprogramm. Ein binäres Downgrade macht Datenänderungen nicht rückgängig.

Diese Publikation enthält **Desktop-Pakete nur**. Standalone-CLI-Archive und Linux CLI `.deb`/`.rpm`-Assets fehlen, und die Website / automatische Aktualisierung ist separat. Verwenden Sie den vom Desktop bereitgestellten Befehlsstarter für 1.0; Benennen Sie kein älteres CLI-Archiv um oder gehen Sie davon aus, dass Homebrew/npm bereits die gleiche Version bereitstellt. `open-science update` wird entfernt: Verwenden Sie Desktop-Steuerelemente oder den Installer / Paketmanager, der die Installation besitzt. Siehe [Installation und 1.x Kompatibilität](../guides/installation.md#version-compatibility).

## Fortlaufende unterbrochene Arbeiten {/* #recovery */}

Ein kompatibler Desktop kann ein überlebendes Desktop-Backend übernehmen, nachdem der vorherige Controller getrennt wurde. CLI-gestartete Dienste bleiben unabhängig. Die fehlgeschlagene abschaltvorbereitung hält das fenster offen und stellt den ursprünglichen konversationszustand wieder her, bevor die arbeit fortgesetzt wird. Überprüfen Sie gespeicherte Vorgänge, bevor Sie eine Anforderung mit einem unbekannten Ergebnis erneut senden. Siehe [Eigentum an Diensten und Rückgewinnung](../reference/server.md#desktop-service-recovery).

ACP Gespräche mit dem ausgewählten Agenten wieder aufnehmen; Abgelöste Codex-Sitzungen erholen sich nach Specialist-Schaltungen zuverlässiger. [Überprüfen Sie den ausgewählten Agenten und die ursprüngliche Sitzung](../guides/sessions.md#resume-selected-agent) vor dem Senden der nächsten Runde. Literaturauswahl und -abbruch während der Kontextverdichtung erhalten ebenfalls Fixes.

## Fragen beantworten und PDFs lesen {/* #interaction */}

- Klarstellungskarten unterstützen längere Optionslisten und Mehrfachauswahlen. Überprüfen Sie die Antworten auf alle Fragen und wählen Sie dann **Finish**; Eine ausgewählte Option allein ist ein Entwurf. [Beantworten Sie eine Klarstellungsfrage](../guides/composer.md#clarification-questions).
- Anmerkungsnotizen erscheinen auf dem Schwebezustand, Fokus oder Auswahl, wobei der PDF beim Lesen klar bleibt. [Zeigen Sie eine Notiz](../guides/pdf-notes.md#reveal-note).
- Die PDF-Extraktion und -Übersetzung bewahrt komplexere Quellenlayouts, native Tabellen-/Figurenbeziehungen und wissenschaftliche Brüche. **New translation** bereitet frischen Quelltext vor. Vergleichen Sie das Ergebnis mit dem Original vor der Wiederverwendung. [Extraktionskontrollen](../guides/previews.md#scientific-structure-check) · [Übersetzung](../guides/pdf-translation.md#scientific-layout).

## Wissenschaftlicher Datenkontext bewahren {/* #data-context */}

| Quelle | Änderung |
| --- | --- |
| ArrayExpress | Unterscheiden von SDRF-Beziehungszeilen von unterschiedlichen Stichprobenkennungen; Unvollständige Identifikatoren können unbekannte Stichprobenzahlen zurückgeben |
| MetaboLights | Bewahren Sie wiederholte Sample-Table-Spalten und deren ursprüngliche Reihenfolge auf, anstatt Werte zu überschreiben |
| Bgee | Bewahren Sie anatomischen und zelltypischen Kontext; Fehlende Zelltypen verbleiben `null` |
| dbSNP | Bewahren Sie alle Chromosomen-/Assembly-Assoziationen für eine Platzierung auf |
| OpenAlex | Erinnern Sie sich an abgelehnte Anmeldeaufforderungen pro Sitzung |

Lesen Sie [Der Leitfaden für die Feldinterpretation](../tools/databases.md#scientific-context) und [v1.0.0 Connector Referenz](../reference/connector-operations.md), bevor Sie gespeicherte Abfragen wiederverwenden. Notebook Risikoanalyse verbessert auch seine Behandlung von Promise Callbacks; bestehende Genehmigungsanforderungen gelten weiterhin.

## Was 1.0 nicht ändert {/* #scope */}

Recorded Session Replay führt keinen Code aus. Die Artefaktüberprüfung erfordert förderfähige erfasste Inputs und eine nutzbare Umgebung. es stellt keine wissenschaftliche Gültigkeit oder deterministische Reproduktion einer ganzen Sitzung dar. Importierte `.science`-Datensätze bleiben schreibgeschützt; Verwenden Sie Fork für eine beschreibbare Fortsetzung. Anmeldeinformationen, Side Chats und private Lesezeichen werden nicht aus dem Paket wiederhergestellt. SSH/Slurm compute wird weiterhin unterstützt; Managed Cloud-GPU-Einreichung, ein lokales GPU-Backend und Echtzeit-Multi-User-Bearbeitung befinden sich außerhalb dieser Version.
