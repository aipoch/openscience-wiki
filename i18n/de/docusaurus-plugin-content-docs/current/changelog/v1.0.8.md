# Release Notes · v1.0.8

freigelassen am **2026-11-04 UTC**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v1.0.8).

## Eine Literaturliste importieren {/* #literature */}

Haben Sie eine Liste von Papier-Identifikatoren? **Add from DOI or link** akzeptiert jetzt bis zu 100 nicht leere Zeilen, die DOI, arXiv, PMID, PMCID oder unterstützte offizielle Artikellinks enthalten. Überprüfen Sie die gelösten Referenzen und doppelten Richtlinien vor dem Import. Das Suchen von Metadaten ruft den Volltext nicht automatisch ab. [Chargeneinfuhr Walkthrough](../guides/library.md#doi-link-import).

Referenzdetails jetzt inklusive **Study overview**. Ihr konfiguriertes Hauptmodell organisiert die verfügbare Quelle in fünf Abschnitte: Forschungsfrage, Studienpopulation, Methoden, Hauptergebnisse und Einschränkungen. Das Source Label unterscheidet einen abstrakten Volltext und ausgewählte Passagen. Verwenden Sie es, um Ihre Lektüre zu orientieren, und überprüfen Sie dann wichtige Ansprüche im Originalpapier. [Generieren Sie einen Überblick](../guides/library.md#study-overview).

## Forschung und tägliche Zuverlässigkeit {/* #reliability */}

- eQTL Catalogue verwendet indexierte Release-7-Dateien, nachdem die REST-API zurückgezogen wurde. Abfragen erfordern explizite **GRCh38** Koordinaten; eine Gen-ID allein ist keine gültige Abfrage mehr. [Koordinatenanforderungen](../tools/databases.md#eqtl-coordinates).
- Die PDF-Bestellung verwendet positionierten Text, um Prosaspalten von Tabellenzeilen zu unterscheiden. Die Extraktion überprüft die Grenzen der Ernte und bewahrt mehrdeutigen Zelltext mit einer Zuverlässigkeitswarnung. [PDF Lesen und Extrahieren](../guides/previews.md#automatic-pdf-reading-order).
- R-Wiedergabeprüfungen entwerten veraltete Dateibeweise nach Operationen, die Argumente oder Versandmethoden erzwingen können. Provenienz erklärt unvollständige Ausführungsbeweise; ältere Markdown-Artefakte reparieren einen veralteten Geschichtskopf, wenn sie geöffnet werden. [Auslesen von Prüfnachweisen](../guides/reproducibility.md#execution-evidence).
- Abgeschlossene Sessions Release Provider und Tool-Prozesse in allen fünf Agent Frameworks. Die Pi-Installation in verpackten Desktop-Builds wird repariert.
- Die Aktualisierungsvorbereitung identifiziert Blockierungsprozesse klarer. Behebt Adresse macOS schreibgeschützte Dateihalter, Windows Prozesserkennung und veraltete Notebook-Wiederherstellungsaufzeichnungen. Diagnosepakete behalten den tatsächlichen Desktop-Wiederherstellungsfehler bei. [Aktualisierung der Leitlinien](../guides/installation.md#update-preparation).
- Abgeschlossene Downloads bleiben erhalten, auch wenn das Zielverzeichnis nicht lesbar ist oder die anschließende Bereinigung fehlschlägt. Das Beenden des PDF-Prozesses und die Schutzprüfungen unter Windows sind robuster. Notebook-Kommandozeilenwerkzeuge können das mitgelieferte Node verwenden, wenn die Version in PATH für den Proxy zu alt ist.
- Erfolgreiche Volltextsuche löscht einen früheren PDF-Add-Fehler, und der Composer wiederholt keinen Hinweis auf ein nicht verfügbares Modell mehr.

Tencent TokenHub ergänzt Hy4 und DeepSeek-V4.1-Flash-Routen mit einem Kontextfenster von 1.000.000 Tokens sowie Bildeingaben für GLM-5.3-Flash, Kimi K3 und MiniMax M3. Die Verfügbarkeit hängt vom Anbieterkonto und der gewählten Route ab. [Provider-Einrichtung](../guides/providers.md).

Der eingebaute Katalog bleibt **48 Connectors mit 418 Operationen**. [Aktueller Katalog](../tools/databases.md#supported-databases) · [Vorherige Veröffentlichung](v1.0.7.md).
