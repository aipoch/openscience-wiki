# Release Notes · v0.37.2 {/* #release-notes--v0372 */}

Veröffentlicht auf **2026-10-13 UTC**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.37.2).

## Wiederherstellen von Start- und Laufzeitverbindungen {/* #recovery */}

Startfehler bieten jetzt Wiederherstellungspfade für Backend, Einstellungen und Netzwerkinitialisierung. Eine Desktop-Verbindungsunterbrechung hält die Workbench mit **Erneut verbinden** und **App beenden** offen. Reconnect stellt das ursprüngliche Live-Backend wieder her; Es startet kein totes Backend neu oder wiederholt automatisch eingereichte Vorgänge. Überprüfen Sie den Status der ursprünglichen Aufgabe, bevor Sie die Arbeit wiederholen, deren Antwort verloren ging.

Die Browser-Schnittstelle unterbricht die Steuerung, während verpasste Updates wiederhergestellt werden, und bietet bei Bedarf ein Nachladen oder eine erneute Kopplung. Große Session- und Notebook-Snapshot-Transfers, Event Bursts und umgeleitete Diagnoseprotokolle werden robuster gehandhabt. Folgen Sie [Verbindung und Startup Recovery](../guides/troubleshooting.md#connection-recovery) und [Backend-Besitz](../reference/server.md#backend-ownership).

## Installieren Sie das Linux CLI als Paket {/* #linux-cli */}

Linux fügt eigenständige `.deb`- und `.rpm`-CLI-Pakete für x64 und ARM64 hinzu, neben Release-Archiven und dem Homebrew CLI. Die CLI-Pakete enthalten Node, das Backend und die lokale Web-Benutzeroberfläche, mit `open-science-cli` als explizitem Befehl. Sie sind vom Desktop-Installationsprogramm getrennt und starten nicht automatisch einen Systemdienst.

Siehe [Paketauswahl, Installation und Upgrades](../guides/installation.md#linux-cli-packages). Stoppen Sie alle Profile, die das Paket verwenden, bevor Sie es aktualisieren oder entfernen; Bewahren Sie die Forschungsdaten auf und speichern Sie die Anmeldeinformationen.
