# Changelog · v1.3.1 {/* #changelog--v131 */}

**2026-11-19 UTC** freigegeben. [Offizielle Veröffentlichungen](https://github.com/aipoch/open-science/releases/tag/v1.3.1).

## Finden Sie Quellen und folgen Sie Zitaten {/* #sources */}

Der integrierte Open-Science Agent kann das öffentliche Web durchsuchen und Seiten lesen, wobei die Quellenzitate neben der Konversation beibehalten werden. Suchgenehmigungen zeigen die Abfrage und Filter an. Anfragen gehen an Exa; Lesen einer Seite kontaktiert diese Website. [Web-Suche und Lesen](../tools/web-search.md).

Die Bibliothek fügt einen interaktiven Zitationsgraphen hinzu. Filtern Sie Referenzen und zitieren Sie Papiere, wählen Sie ein verwandtes Papier als neues Zentrum aus oder kehren Sie zum Originalpapier zurück. Überprüfen Sie Kandidaten in Inbox, bevor Sie sie zu Ihrer Bibliothek hinzufügen. [Erkunden Sie den Citation Graphen](../guides/library.md#citation-discovery).

## Verbinden Sie Agenten und Organisationsressourcen {/* #connections */}

Ein externer MCP-Client kann nun den lokalen Open-Science-Dienst starten oder wiederverwenden, wenn er sich verbindet. Der Dienst läuft weiter, nachdem der Client die Verbindung getrennt hat; Stoppen Sie es explizit, wenn Sie fertig sind. [MCP-Konfiguration](../reference/cli.md#external-mcp).

In der Desktop-App bietet ein Lab-Konto Zugriff auf die zugewiesenen Modelle und freigegebenen Forschungsfälle Ihres Unternehmens. Modellanforderungen und freigegebene Pakete gehen an den konfigurierten Lab-Server. [Einrichtung eines Laborkontos](../guides/providers.md#lab-account) · [Organisationsfälle](../guides/research-packages.md#organization-cases).

## Mehr Kontrolle über Modelle und Ressourcen {/* #controls */}

- Modelllisten der unterstützten Anbieter in den Einstellungen aktualisieren. Eine fehlgeschlagene Aktualisierung bewahrt den vorherigen Katalog; Konversationsfehler erklären nun Authentifizierung, Quotierung, Rate-Limit und andere Ursachen. [Provider-Einrichtung](../guides/providers.md#refresh-models).
- Führen Sie optional eine Testbildgenerierung aus, bevor Sie einen Bilddienst speichern. Das erste Modell wird automatisch ausgewählt, wenn kein Standard existiert. [Bilddienstkonfiguration](../guides/image-generation.md#configure).
- Notebook überprüft den Speicher vor der Ausführung. Verwenden Sie Compute, um die lokalen Notebook-Ressourcen einer Sitzung zu prüfen und freizugeben und dann die Arbeit absichtlich zu wiederholen. [Speicher- und Ressourcenmanagement](../guides/notebook.md#memory-resources).
- Startup lädt das Projekt früher nach Hause. Reconnection bewahrt Entwürfe und stellt lange verzweigte Geschichten und offene Fragen wieder her. Die Wiedergabe von Forschungsfilmen wartet nicht mehr auf irrelevante Qualitätsbewertungen.

## Aktualisierung von v1.3.0 {/* #update */}

Der v1.3.0-Updater kann einen App-eigenen Prozess mit einem anderen Programm verwechseln, das die Installation verwendet. Wenn dies das Update blockiert, beenden Sie die aktive Arbeit, beenden Sie die App und den Hintergrunddienst vollständig und installieren Sie das offizielle v1.3.1-Paket manuell. Die Installation von v1.3.1 kann den Updater, der bereits in v1.3.0 ausgeführt wird, nicht reparieren. [Manuelle Aktualisierungsschritte](../guides/installation.md#update-from-130).

Die Version behebt auch Fehler bei großen Einstellungen während Windows-Updates / Deinstallation, optionale WSL-Setup-Blockierung des ersten Laufs, unvollständiges Löschen importierter Sitzungen auf Windows und Linux AppImage-Update überprüft die Fehlidentifizierung einer App-eigenen Pipe. Ein fehlender Forschungsordner erscheint nun über Pfad in der Startwiederherstellung, so dass Sie das Laufwerk wieder anschließen können.

Siehe [Installation und Updates](../guides/installation.md) und [v1.3.0](v1.3.0.md).
