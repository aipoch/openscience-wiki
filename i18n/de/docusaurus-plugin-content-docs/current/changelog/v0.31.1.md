# Changelog · v0.31.1 {/* #changelog--v0311 */}

Erschienen September 20, 2026. Neue Datenbankoperationen umfassen Sequenzierungsläufe, Gen-Set-Anreicherung und Referenzgenom-Identität. Klassifikationsmodelle sind optional.

[Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.31.1) · [Änderungen seit v0.31.0](https://github.com/aipoch/open-science/compare/v0.31.0...v0.31.1)

## Neue Datenbankoperationen {/* #new-database-operations */}

| Leistungsfähigkeit | Wo man anfängt |
| --- | --- |
| ENA Run und FASTQ Inventar | Lösen Sie einen ENA/INSDC-Beitritt, prüfen Sie die Verkürzung, fordern Sie dann Datei-URLs, Größen und vorgelagerte Prüfsummen an. Diese Tools laden keine Dateien herunter oder verifizieren sie. [Sequenzdaten](../tools/databases.md#ena-runs) |
| g:Anreicherung der Profile | Überprüfen Sie den Organismus und die Quellversionen, definieren Sie die Genliste und den Hintergrund, dann untersuchen Sie die Zuordnungen und korrigierten Ergebnisse. [Bearbeitetes Beispiel mit Outputs](../tools/databases.md#gene-set-enrichment) |
| NCBI-Referenzgenome | Lösen Sie Taxon-Mehrdeutigkeiten, prüfen Sie eine versionierte Assembly und Kartensequenz-Aliase, bevor Sie Quellen kombinieren. [Referenznummer](../tools/databases.md#reference-genome) |

Die [Betriebsnummer](../reference/connector-operations.md) und die herunterladbare Registrierung decken jetzt v0.31.1: **244 Datenquellenoperationen** sowie zwei Moleküloperationen über die gleichen 24-Steckverbinder ab.

## Einstellungen und Erholung {/* #settings-and-recovery */}

[Klassifikationsmodelle](../guides/models.md#classification-models) erscheint als Tab unter **Settings → Model**. Ein konfigurierter kompatibler dienst kann die fähigkeitsauswahl für unterstützte hauptgesprächsrouten unterstützen. **Use default method** funktioniert ohne eine; Das Hinzufügen eines Klassifikationsdienstes ersetzt nicht Main.

[Fernpaarung](../guides/remote-access.md#pairing-v0311) bringt Anfragen über vertrauenswürdige Browser und zeigt Ablauf Countdowns. Passen Sie den angezeigten Code an, bevor Sie akzeptieren. Das Abrufen des aktuellen Browsers entfernt seinen eigenen Zugriff.

Wenn der Netzwerkschutz einen R-Lauf blockiert, gibt der [Inline-Warnmeldung](../guides/network.md#r-network-warning) an, dass die Zelle nicht ausgeführt wurde, und verknüpft relevante Einstellungen. Das Ändern einer Einstellung ist keine abgeschlossene Wiederholung.

## Fixes {/* #fixes-and-verification-scope */}

Fixes umfassen persistente Windows-Kernel und Paketinventare, Sitzungswiederherstellung, Genehmigungskartenfokus, PDF-Zahlen/Tabellen, GTEx-Paginierung, Open Targets-Teilfehler und den standardmäßigen hg19-Konservierungstrack.

Für Gebrauchsanweisungen siehe [Forschungspakete](../guides/research-packages.md), [Datenbankanfragen](../tools/databases.md) und [Klassifikationsmodelle](../guides/models.md#classification-models). Das vorhergehende Release ist [v0.31.0](./v0.31.0.md).
