# Release Notes · v1.3.0 {/* #release-notes--v130 */}

Veröffentlicht auf **2026-11-18 UTC**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v1.3.0).

## Plane die nächste Forschungsaufgabe {/* #scheduled-tasks */}

Erstellen Sie eine einmalige oder sich wiederholende Aufgabe, die eine Agentennachricht sendet oder ein Python-, R- oder Shell-Skript ausführt. Wählen Sie für jeden Nachrichtenlauf eine bestehende Konversation oder eine neue Konversation aus und prüfen Sie einzelne Datensätze. Die app muss laufen bleiben; zeitpläne verwenden die konfigurierten berechtigungen, anmeldeinformationen und das anbieterkontingent. [Geplante Aufgaben](../guides/scheduled-tasks.md).

## Erstellen von Bildern und Bearbeiten von Präsentationen {/* #creation */}

Konfigurieren Sie einen Bilderzeugungsdienst, generieren Sie aus einer Eingabeaufforderung und verfeinern Sie ein Bild mit versionierten Bearbeitungen. Die Bilderzeugung hat eine eigene Modelleinstellung, getrennt von Main und Vision. [Bilderzeugung und -bearbeitung](../guides/image-generation.md).

PPTX-Vorschau unterstützt jetzt die Bearbeitung von Folientext und Formatierung. Überprüfen Sie die gespeicherte Version und öffnen Sie die heruntergeladene Präsentation erneut, bevor Sie sie teilen. [Bearbeiten einer Präsentation](../guides/presentation-editing.md).

## Erklären Sie die Forschung oder wiederholen Sie die Operation {/* #films */}

Wählen Sie **Research explanation** oder **Operation replay** im Forschungsfilmdialog. Branchen halten unabhängige Filmausgaben. Der Dialog erklärt die Modellnutzung vor dem Start der Generation und das Sitzungsmenü öffnet einen vorhandenen Film. [Filmschaffende](../guides/research-films.md#generate-film).

## Mehr Kontrolle bei längerer Arbeit {/* #other-changes */}

- Geplante Läufe haben ihre eigene Geschichte; Notebook Prozessüberwachung zeigt eigene Prozesse und bietet **Terminate**. [Prozessüberwachung](../guides/notebook.md#process-monitor).
- CodeBuddy-Abonnements unterstützen China- und internationale Konten mit Modellerkennung über die verwaltete CLI. [Einrichtung eines Kontos](../guides/providers.md#codebuddy-subscription).
- Agent Fragen gegenwärtige Entscheidungen mit ihren Trade-offs. Überprüfen Sie die Auswahl, bevor Sie die Aufgabe fortsetzen.
- Document-Figure Skills bereiten die erforderlichen Bibliotheken in verwalteten Umgebungen bei der ersten Verwendung vor.
- Inkrementelle Session-Persistenz, Filmwiederherstellung und Windows-Installation / Update-Verbesserungen reduzieren wiederholte Arbeit und unnötigen Ressourcenverbrauch.

Siehe [Installation und Updates](../guides/installation.md) und [v1.2.2](v1.2.2.md).
