# Änderungsprotokoll · v0.33.0

Erschienen September 23, 2026. Diese Version fügt intelligentes Literatur-Screening, Ressourcenzugriffskontrollen für einzelne Agenten und RO-Crate-Metadaten in Forschungspaketen hinzu.

[Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.33.0) · [Änderungen seit v0.32.0](https://github.com/aipoch/open-science/compare/v0.32.0...v0.33.0)

## Screen Literatur mit expliziten Kriterien {/* #screen-literature-with-explicit-criteria */}

Ein **Smart collection** wertet Bibliotheksdatensätze anhand von Ein- und Ausschlusskriterien aus. Wählen Sie den Anwendungsbereich, prüfen Sie die vier Entscheidungsansichten und überprüfen Sie die Modellurteile, bevor Sie das Leseset verwenden. Testläufe speichern Ergebnisse; Live Draft Previews nicht. Optionale Volltext-Beweise und automatische Updates haben separate Kontrollen.

Der neue [Workflow beim Screening](../workflows/screen-literature.md) umfasst Abruf, Modellbindung, Regeln, eine Testversion, manuelle Überprüfung und Export. [Klassifizierungseinstellungen](../guides/models.md#smart-collection-model) unterscheidet nun **Smart collections** von **Automatic capability selection**; Main kann auf Codex bleiben.

## Verwalten Sie Ressourcenzugriff und Forschungsübergaben {/* #manage-resource-access-and-research-handovers */}

- **Manage access** auf einem Skill oder Connector zeigt Main Agent und Specialist Assoziationen zusammen. Rollenaktivierung, Anmeldeinformationen und Betriebsgenehmigungen bleiben getrennt. Siehe [Ressourcenzugang](../guides/connectors.md#resource-access).
- Neu exportierte `.science`-Pakete enthalten RO-Crate 1.1 Metadaten. Empfänger benötigen einen Leser, der die `ro-crate`-Fähigkeit unterstützt; Ältere Pakete bleiben lesbar. Siehe [Packungskompatibilität](../guides/research-packages.md#package-compatibility).
- **Export diagnostics…** erstellt in einer Sitzung ein lokales Archiv aus ausgewählten Quellen. Es lädt das archiv nicht hoch oder sendet es an ein modell. Siehe [Diagnoseausfuhren](../guides/troubleshooting.md#session-diagnostics).

## Neue Datenbankoperationen {/* #new-database-operations */}

| Ressourcen | Zusätzliche Fähigkeit | Grenze |
| --- | --- | --- |
| Zenodon | Öffentliche Aufzeichnungen durchsuchen und versionenspezifische Metadaten und Dateiinventare prüfen | Keine Datei hochladen oder herunterladen; Öffentliche Metadaten bedeuten keinen offenen Dateizugriff. |
| GD | Liste Krebsprojekte/-fälle auf, suche Dateien, inspiziere Dateimetadaten und generiere Manifeste | Kontrollierte Daten erfordern weiterhin eine Autorisierung. |
| Gene & Ontologien | UniProt Batch Identifier Mapping: Einreichen, Überprüfen des Status und Abrufen von Seitenergebnissen | Bewahren Sie alle Seiten, One-to-Many-Matches und explizite unübertroffene IDs auf. |

Es gibt **26 eingebaute Steckverbinder mit 263-Operationen**: **25 Datenquellen Connectors / 261 Operationen** plus zwei Offline-Moleküloperationen. Verwenden Sie den [Datenbankkatalog](../tools/databases.md), um einen Dienst und den [v0.33.0 Parameterreferenz](../reference/connector-operations.md) für genaue Eingaben auszuwählen. UCSC-Erhaltungsvorgaben werden für Mausbaugruppen korrigiert.

## Modelle, Laufzeit und Plattformfixes {/* #models-runtime-and-platform-fixes */}

Anbieterkataloge fügen MiMo v2.6 und Grok 4.7 hinzu und aktualisieren Zen/Go. Siehe [Auswahl des Anbieters](../guides/providers.md#provider-catalog-updates). **Claude Agent** meldet jetzt nicht unterstützte CLI-Versionen während der Bereitschaftsprüfungen; v0.33.0 erfordert **2.1.118 oder höher**. Siehe [Agenteninstallation](../guides/frameworks.md).

Andere Fixes verbessern Streaming und lange Gespräche, veraltete Wiederherstellung, Recherche-Paket-Prüfungen, lang laufende Notebook-Shell-Fortschritte, Ordnerzuschüsse während der Paketinstallation, unzulässige Notebook-Benachrichtigungen, Windows R Inventar- und Reset-Handling, Fedora-Startpaketierung und Such- / PDF-Interaktionen. Siehe die offizielle Version für die vollständige Liste. Das vorhergehende Release ist [v0.32.0](./v0.32.0.md).
