# Release Notes · v0.33.2 {/* #release-notes--v0332 */}

Veröffentlicht auf **2026-09-24**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## Installation und Literaturlesen {/* #installation-and-literature-reading */}

Offizielle Windows-Installateure erhalten Codesignierung. App-Download-Links führen zur offiziellen Download-Seite und Verifizierungshinweise. Siehe [Installation](../guides/installation.md). Live-Source-Vorschauen behalten Website-Sitzungen über Besuche und App-Neustarts hinweg; siehe [Quellvorschau](../guides/previews.md#persistent-source-preview).

Der **Auto**-Modus reduziert wiederholte Genehmigungsaufforderungen für integrierte Bibliotheksoperationen. Datei-, Netzwerk- und Ressourcenregeln gelten weiterhin. Siehe [Bibliotheksgenehmigungsverhalten](../guides/approval-modes.md#library-auto).

## STRING-Interaktionsanreicherung {/* #string-interaction-enrichment */}

**Protein-Annotation** fügt STRING PPI-Anreicherung hinzu, um zu testen, ob ein Protein-Set mehr Wechselwirkungen aufweist als von seinem Hintergrund erwartet. Dies stellt eine andere statistische Frage als die Anreicherung von Pfaden. Folgen Sie dem [Gen-Set-Workflow](../workflows/gene-set-enrichment.md#enrichr-string) und [Betriebsnummer](../reference/connector-operations.md#get_string_ppi_enrichment).

## Verbesserungen und Korrekturen {/* #improvements-and-fixes */}

Abgeschlossene Delegationsergebnisse überleben spätere Bereinigungsfehler. Updates umfassen auch den Workflow von Figure Composer, Vorschau-Dateityp-Icons und Smart-Collection-Layout. Behebt Isolierung des macOS Notebook-Bereinigungszustands und Verbesserung des Agenten-Routings und -Abschaltung; Codex Backend Plugin und App Discovery ist deaktiviert.
