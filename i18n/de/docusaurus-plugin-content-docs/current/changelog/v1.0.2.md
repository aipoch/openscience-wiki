## Installieren und Inspizieren der CLI {/* #cli */}

Die CLI und das Task SDK werden auf npm veröffentlicht. Folgen [npm-Anlage](../guides/installation.md#npm-cli), dann verwenden `version`, `help` und `paths` Ohne ein Backend zu starten. Die gemeldete Version gehört zur aufgerufenen Installation. Desktop- und Standalone-Builds enthalten Node 22.23.4 Sicherheitsupdates. [Lokale Informationsbefehle](../reference/cli.md#local-information).

## Behalte die Kontrolle über ein Gespräch {/* #conversation */}

Fragekarten unterscheiden **Single select** von **Multi select** und behalten Sie die vollständige Antwortgeschichte jeder Frage bei. Queued-Message-Fehler bieten eine Rückgängig-Aktion; nicht gesendete Entwürfe lösen Quit/Reload-Warnungen aus. Credential Recovery gibt einen spezifischen nächsten Schritt, während Entwürfe zu bewahren. Remote-web-chat unterstützt artefakt-erwähnungen. [Fragekarten und Entwürfe](../guides/composer.md#clarification-questions).

## Fortsetzung der Forschung mit klareren Aufzeichnungen {/* #research-records */}

- Paketdialoge bleiben stabil; das Wiederholen eines teilweise engagierten Imports vermeidet doppelte Sitzungen. Importierte Titel können bearbeitet werden, während die Forschung schreibgeschützt bleibt. [Forschungspakete](../guides/research-packages.md#browser-import).
- Large-session laden und start-wiederherstellung verbessern. Teildiagnostische Exporte weisen Warnhinweise auf. [Sitzungsdiagnostik](../guides/sessions.md#session-diagnostics).
- PDF-Struktur, DOCX-Nummerierung / Grenzen und verkettete Python / R-Dateilinienerfassung erhalten Fixes. [Linienkontrollen](../guides/notebook.md#chained-analysis-lineage).
- Large Skill Importe verwenden Batches; reservierte externe Namen erhalten sichere lokale Namen. MiniMax M3.1 bis Codex ist behoben. [Anbieter-Wiederherstellung](../guides/providers.md#credential-recovery).
