# Changelog · v1.3.3 {/* #changelog--v133 */}

**2026-11-22 UTC** freigegeben. [Offizielle Veröffentlichungen](https://github.com/aipoch/open-science/releases/tag/v1.3.3).

## Updates, die rund um Ihre Arbeit passen {/* #updates */}

Berechtigte offizielle stabile macOS-Installationen können ein vorbereitetes Update installieren, wenn Sie beenden. Windows und Linux können Updates für den nächsten Start vorbereiten, während der Desktop im Hintergrund im Leerlauf ist. Automatische Downloads erfordern eine uneingeschränkte, unmetered Verbindung und genügend Speicherplatz; nicht unterstützte Installationsorte und -kanäle behalten den manuellen Weg bei. Linux AppImage-Updates bewahren den Anwendungspfad. Windows v1.3.3 verwendet den vollständigen Installer; Compact Deltas kehren in [v1.3.4](v1.3.4.md#updates) zurück. [Automatische und manuelle Updates](../guides/installation.md#update-progress).

Die installierten macOS und Windows Apps sind kleiner. Die Offline-NPM-Laufzeit wird für Node 22 gebündelt, wodurch die Anzahl der losen Dateien reduziert wird.

## Der eingebaute Agent ist überall standardmäßig {/* #agent */}

Neue Projekte und Sitzungen sind standardmäßig auf **Open-Science Agent**, einschließlich sauberer CLI- und SDK-Installationen. Ein abwesender externer Agent SDK verhindert nicht mehr, dass diese Installationen starten. Installieren Sie ein externes Framework nur, wenn Sie es verwenden möchten; Der Modellzugriff benötigt noch eine Konfiguration. [Agentsetup](../guides/frameworks.md#built-in-agent) · [CLI Setup](../reference/cli.md#terminal-setup).

Einstellungen stellen Verknüpfungen zu installiertem Skills, Spezialisten und Konnektoren wieder her. Bailians Katalog fügt die qwen4-Familie hinzu, wobei der Plan standardmäßig in die qwen4-Vorschau geändert wurde. Überprüfen Sie das für Ihr Konto verfügbare Modell, bevor Sie mit der Arbeit beginnen.

## Bilder im Gespräch bearbeiten {/* #images */}

Geben Sie **Edit image** aus einer Vorschau ein und schreiben Sie die Bearbeitung im Conversation Composer. Die Navigation und der Vergleich der Bildversion bleiben verfügbar, und die Konversation bleibt beim Bearbeiten an Ort und Stelle. Bilddetails identifizieren den Notebook-Kernel hinter einer Bearbeitung. [Bildbearbeitungsschritte](../guides/image-generation.md#edit).

Die PDF-Übersetzung verbindet Textsplit besser mit Spalten, Beschriftungen und Inline-Formeln und vermeidet das Verdrängen von Notationen, Formularbeschriftungen und benachbarten Grafiken. Überprüfen Sie weiterhin exportierte Seiten mit dem Original. [PDF Übersetzung](../guides/pdf-translation.md#scientific-layout).

## Deutlichere Ausfälle und Wiederherstellungen {/* #recovery */}

- Request, Loading, Attachment, Import und Notebook-Fehler erklären ihre Ursachen. Fehler des Anbieters behalten ihre Klassifizierung und Anforderungs-ID beim Neustart bei; Die gestoppte Arbeit unterscheidet sich von einer unbeantworteten Fortsetzung. [Fehlerbehebung](../guides/troubleshooting.md#provider-errors).
- Windows behält eine ausstehende integrierte Agent-Frage beim Neustart bei, stellt den Notebook-Runtime-Status wieder her und überprüft veraltete Dateiblocker während eines Kaltstarts erneut.
- Notebook-Speicherüberprüfungen berücksichtigen Windows physikalischen Speicher, macOS Speicherdruck und Linux Containergrenzen. [Speicher und Ressourcen](../guides/notebook.md#memory-resources).
- Session-Paket-Exporte warten, bis sich Notebook-Reads begleichen, bevor Exportfehler gemeldet werden. Gespeicherte Artefakt-Links, bestätigte Speicherlöschung und GitHub Skill Importfehler werden ebenfalls korrigiert.

Siehe [Installation und Updates](../guides/installation.md) und [v1.3.2](v1.3.2.md).
