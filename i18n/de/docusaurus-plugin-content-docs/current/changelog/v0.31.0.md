# Changelog · v0.31.0 {/* #changelog--v0310 */}

Erschienen September 18, 2026. Diese Version fügt unabhängige Sitzungskopien hinzu und verbessert die Kontinuität, wenn eine Konversation oder Verbindung wiederhergestellt wird.

[Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [Änderungen seit v0.30.2](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## Fortsetzung und Inspektion einer Sitzung {/* #continue-and-inspect-a-session */}

- **Fork** erstellt eine beschreibbare Desktop-Kopie mit Konversationszweigen, Notebook-Datensätzen, Artefaktversionen, Literatur, Anmerkungen und privaten Lesezeichen. Es weist neue Identitäten zu und bewahrt die Quelle. Importierte Sessions selbst bleiben schreibgeschützt. Siehe [Gabeldurchführung](../guides/sessions.md#fork-session) und [Forschungspakete](../guides/research-packages.md).
- Der Session-Titel öffnet ein [Informationskarte](../guides/sessions.md#session-information) mit seiner Quelle, Zählen und Pin-Steuerung. Eine fortgesetzte Konversation knüpft an ihren Source Turn an.
- [Sitzungspläne](../guides/planning.md#resume-plan) behält Identität, Überarbeitung und ausstehende Genehmigungen nach der Kontextrekonstruktion. Die Wiederherstellung bedeutet nicht, dass ein ausstehender Schritt genehmigt oder ausgeführt wurde.

## Verändertes Setup und Datenverhalten {/* #changed-setup-and-data-behavior */}

| Bereich | Was zu überprüfen ist |
| --- | --- |
| Anbietereinstellungen | Edits werden validiert, bevor sie eine gespeicherte Konfiguration ersetzen; Verfügbarkeit von Runtime Rejection Updates. [Provider-Einrichtung](../guides/providers.md#validated-provider-save) |
| Windows R | Die Ausführung im Standardmodus erfordert keine Einrichtung im geschützten Modus mehr. Geschützte Ausführung hat separate Anforderungen. [Laufzeiten](../guides/runtimes.md) |
| gnomAD | Anfrage `include_populations: true` für die Anzahl und Häufigkeit der einzelnen Populationen; Speichern von Dataset-, Build- und Qualitätsfiltern. [Parameter](../reference/connector-operations.md#get_variant) |
| Produktbezeichnung | Die Schnittstelle verwendet Open-Science. Vorhandene Installationsorte, Einstellungen und Daten werden beibehalten; Benennen Sie Speicherordner nicht in Übereinstimmung um. [Installation](../guides/installation.md#product-name) |

**Änderung der STRING-Kompatibilität:** `nodes` beschreibt nun den kompletten zurückgegebenen Graphen, einschließlich hinzugefügter Nachbarn. Filtern Sie `is_query` für abgebildete Eingaben und verwenden Sie `queries` für alle Eingabealiase. Verwenden Sie `n_nodes` nicht als Anzahl der eingereichten Proteine. [STRING-Leitlinien](../tools/databases.md#string-network)

Andere Fixes umfassen Codex Reasoning-Effort-Änderungen, Stornierung und Fortsetzung, UniProt Sekundär-Zugänge, Ensembl-Identifikatoren, klinische Studienberechtigung und cBioPortal-Nenner. Verwenden Sie die offizielle Version für die vollständige Liste.

Die nächste Version ist [v0.31.1](./v0.31.1.md).
