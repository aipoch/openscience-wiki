# Release Notes · v0.36.0 {/* #release-notes--v0360 */}

Veröffentlicht auf **2026-10-08 UTC**. [Offizielle Freigabe](https://github.com/aipoch/open-science/releases/tag/v0.36.0).

## Übersetzen eines vollständigen PDF {/* #translate-a-full-pdf */}

Volldokumentenübersetzung fügt gespeicherten Absatzfortschritt, resumierbare Editionen und den Original-/Übersetzungsvergleich hinzu. Das gleiche verwaltete PDF kann gespeicherte Editionen über Leseeinstiegspunkte hinweg wiederverwenden. Der neue [PDF Übersetzungsführer](../guides/pdf-translation.md) deckt Vorbereitung, Modellanforderungen, Glossar, Wiederaufnahme und Export ab. Codex Subskriptionsmodelle sind für diese Übersetzungsoperation in v0.36.0 nicht verfügbar.

## Code vor der Ausführung von Notebook überprüfen {/* #review-code-before-notebook-execution */}

Der vom Agenten eingereichte Notebook-Code wird vor dem Versand überprüft. Riskante oder unzureichend verstandene Operationen zeigen eine Bewertungskarte mit betroffenen Quellzeilen und einer expliziten Entscheidung. Gewöhnlich unterstützte Lektüren und Analysen benötigen keine zusätzliche Risikogenehmigung. Dies ist getrennt von der Überprüfung eines abgeschlossenen Ergebnisses mit Reviewer. Siehe [Ausführungsüberprüfung](../guides/notebook.md#execution-review).

## Wissenschaftliche Datenbanken {/* #scientific-databases */}

Sechs neue Operationen bringen die Registrierung zu **35 Connectors und 349 Operationen**: 34-Datenquellenfamilien mit 347-Operationen sowie zwei Offline-Moleküloperationen.

| Eingang | Leistungsfähigkeit | Begleiter |
| --- | --- | --- |
| PDC | Versionierte Krebs-Proteomik-Studien, Biospeziimen-Assoziationen und quantitative Datei-Metadaten | [PDC Einrichtung und Umfang](../tools/databases.md#pdc) |
| Genome → Ensembl | Populationsspezifische paarweise LD und nahegelegene Proxy-Varianten | [LD Abfragen](../tools/databases.md#ensembl-ld) |

Verwenden Sie den [Betriebsnummer](../reference/connector-operations.md) für genaue Felder. PDC Discovery lädt keine Daten herunter; Ein hoher LD stellt keine Kausalität dar.

## Tägliche Workspace-Veränderungen {/* #everyday-workspace-changes */}

- Bibliothek und Posteingang fügen eine geladene Seite Select-All-Steuerelement hinzu. Überprüfen Sie die ausgewählte Anzahl, bevor Sie eine Batch-Aktion durchführen; Es wählt nicht jedes serverseitige match aus. Siehe [Chargenauswahl](../guides/library.md#loaded-page-selection).
- Ziehen Sie eine Dateikarte oder ein offenes Artefakt in den Composer, um eine Dateierwähnung einzufügen. Überprüfen Sie den Entwurf vor dem Senden. Siehe [Dateivermerke](../guides/composer.md#drag-file-mention).
- Der offizielle Anthropische Katalog fügt Claude Haiku 5.5 hinzu. Modellkataloge entfernen Aliase in Kontextgröße, die möglicherweise fehlschlagen. Wählen Sie ein aktuell verfügbares Modell aus, anstatt einen alten Bezeichner zu kopieren. Das gespeicherte Main-Modell wird nicht automatisch ersetzt.

## Lese- und Zuverlässigkeitskorrekturen {/* #reading-and-reliability-fixes */}

Die PDF-Extraktion verbessert komplexe Tische, mehrstufige Kopfzeilen, Fußzeilen und Multi-Panel-Layouts. Inspizieren Sie die Quelle, wenn wissenschaftliche Interpretation vom Layout abhängt; siehe [PDF-Extraktion](../guides/previews.md#pdf-extraction).

Notebook Lineage verbessert Python/R-Lesegeräte, Containertransformationen und Callback-Handling. Dies hilft, Abhängigkeiten zu erfassen; Es ersetzt kein [Wiederholungsüberprüfung](../guides/reproducibility.md). Andere Fixes decken Erwähnungen aus dem Dateifeld in neuen Konversationen, Leerraumsuche, kompakte Erwähnungschips und den Specialist Marketplace im Remote Web ab.
