# Changelog · v1.3.2 {/* #changelog--v132 */}

**2026-11-20 UTC** freigegeben. [Offizielle Veröffentlichungen](https://github.com/aipoch/open-science/releases/tag/v1.3.2).

## Mehr Möglichkeiten, ein Modell zu verbinden {/* #models */}

Unter **Model provider** fügt **Skip** Kilo Gateway ohne API key hinzu und wechselt zu Notebook runtime. Danach kann **Main model** `kilo-auto/free` anzeigen. Öffnen Sie vor der ersten Nachricht **Settings → Model**, prüfen Sie Anbieter und Modell und wählen Sie die gewünschte Verbindung, etwa Codex subscription. Skip testet keine Inferenz. Ein Upgrade erhält vorhandene Zugangsdaten und die Main-Auswahl. [Kilo Gateway](../guides/providers.md#kilo).

OpenAI-, MiniMax-, Bailian- und Volcengine-Arch-Bilddienste können ihre unterstützten Bildmodellkataloge vor dem Speichern aktualisieren. Dieser kontaktiert den konfigurierten Provider mit den Anmeldeinformationen der Verbindung. Katalogverfügbarkeit und eine erfolgreiche Generation sind separate Prüfungen. [Bildmodellkataloge](../guides/image-generation.md#image-model-catalog).

## Glattere Forschungssitzungen {/* #sessions */}

Lange Gespräche verbrauchen weniger Speicher, und sicher gespeicherte Konversationskörper können freigegeben werden, wenn sie nicht mehr angesehen werden. Entwürfe und aktive Arbeit bleiben erhalten. Abgeschlossene Wiederholungsschritte zeigen ihre Abfrage-/Erfassungssteuerelemente im Hover- oder Tastaturfokus; Touch-Geräte behalten zugängliche Bedienelemente.

Notebook Memory-Druck-Benachrichtigungen können abgewiesen werden und nach sechs Sekunden ablaufen. Eine Nachricht, die verschwindet, bedeutet nicht, dass eine blockierte Operation ausgeführt wurde. Überprüfen Sie den Ausführungszustand und versuchen Sie es absichtlich erneut. [Notebook Speicher](../guides/notebook.md#memory-resources).

## Fixes, die die tägliche Arbeit beeinflussen {/* #fixes */}

- Frische integrierte Agent-, Claude Agent- und Codex-Sitzungen scheitern nicht mehr vor ihrer ersten Modellanforderung im betroffenen Notebook-Vorbereitungspfad. Geplante Sitzungen beginnen mit ihrer beabsichtigten Aufforderung.
- Die PDF-Übersetzung rekonstruiert gewickelte Titel, Bildunterschriften und mathematische Aussagen in Lesereihenfolge, wobei native Formeln, Links und Grafiken beibehalten werden. [Überprüfen Sie das übersetzte Layout](../guides/pdf-translation.md#scientific-layout).
- Home-Page Use-Case-Download-Fehler unterscheiden fehlende Pakete, Timeouts, Verifizierungsfehler und Speicherprobleme. [Rückforderung der Einfuhren](../guides/research-packages.md#case-download-recovery).
- Windows-Fixes decken WSL Notebook-Start- und Reviewer-Verbindungen ab.

Siehe [Installation und Updates](../guides/installation.md) und [v1.3.1](v1.3.1.md).
