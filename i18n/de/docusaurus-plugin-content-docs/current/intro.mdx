# Open-Science {/* #open-science */}

Verwenden Sie Open-Science, um Forschungsquellen zu organisieren, mit einem Agenten zu arbeiten, Analysen durchzuführen und gespeicherte Ergebnisse zu überprüfen.

Eine Übersicht zum Produkt bietet [What Is AIPOCH Open-Science?](https://aipoch.com/blog/what-is-open-science).

## Beginnen Sie hier {/* #start-here */}

1. [Fähigkeiten und unterstützte Inputs](./guides/capabilities.md): Wählen Sie einen Pfad für Ihre Dateien oder Forschungsfrage.
2. [Installation](./guides/installation.md) und [Ersteinrichtung](./guides/onboarding.md): Bereiten Sie die App, den Agenten, das Modell und die Laufzeit vor.
3. [Ihr erstes Projekt und Ergebnis](./guides/first-project.md): Öffnen Sie eine kleine öffentliche Datentabelle und speichern Sie eine geprüfte Zusammenfassung.
4. [Berechtigungen](./guides/approval-modes.md): Überprüfen Sie die angeforderten Aktionen und verwalten Sie den erinnerten Zugriff.
5. [Notebook und Ausführungsnachweise](./guides/notebook.md): Code, Variablen und Ergebnisherkunft untersuchen.

## Vor dem Ausführen eines Beispiels {/* #before-running-an-example */}

Lokale Walkthroughs verwenden öffentliche PRISMA-Papiere und die GSE60450 RNA-seq-Matrix. Laden Sie die verknüpften Eingaben herunter und bestätigen Sie das Modell, die Laufzeit und die Berechtigungen, die für jede Aufgabe erforderlich sind.

[Remote Compute](./guides/remote-compute.md) beinhaltet eine abgeschlossene Direct SSH RNA-seq-Analyse, Ausgabesammlung, Neustartwiederherstellung und -abbruch. Slurm Terminalüberwachung benötigt eine funktionierende Buchhaltung; GPU Inference benötigt eine kompatible Softwareumgebung.

Verwenden Sie [Referenz](./reference/index.md) für technische Limits und Konfigurationen und [Changelog](./changelog/v0.31.1.md) für den Releaseverlauf.
