# Skills {/* #skills */}

Skill дает агенту повторяемый метод: когда его использовать, какие входы ему нужны, что делать и как проверять его выходы. Open-Science загружает инструкции, когда это необходимо. Установка Skill не устанавливает описанное в нем научное программное обеспечение.

Найдите дополнительные методы через [Каталог Skills](marketplace.md), а затем просмотрите их входы и зависимости перед использованием.

## Выберите правильный тип способности {/* #choose-the-right-kind-of-capability */}

| Тебе нужно | Использовать | Пример |
| --- | --- | --- |
| Операция, которая возвращает данные или выполняет код | А. [инструмент](../tools/overview.md) | Читать метаданные GEO; Запуск Python |
| Метод, который координирует эти операции. | Skill | Валидировать сырую матрицу подсчета генов |
| Многоразовая роль с собственными инструкциями и возможностями | А. [Специалист](../specialists/overview.md) | Самостоятельно проверьте таблицу выборки-QC |

Начните с [Директория Skill](./directory.md), чтобы найти метод, или [рецепты](./recipes.md), чтобы выбрать из исследовательской ситуации.

## Найти и проверить Skill {/* #find-and-inspect-a-skill */}

1. Открыть **Settings → Skills**.
2. Используйте **Search skills** для поиска его имени или описания. Введите `rnaseq-count-qc` после [Создание примера](./create.md).
3. Узкие **Filter skills by source**, **Filter Skills by agent** или **Filter by Tag**, если список остается длинным.
4. Откройте результат. Прочитайте описание, инструкции, **Files**, лицензию и **Availability**. Имя дисплея может отличаться от ID пакета.
5. Вернитесь в список и проверьте **Used by**. Выявляет, какие агенты могут использовать пакет; Он не перечисляет завершенных прогонов.

### Почему некоторые переключатели нельзя отключить {/* #why-some-switches-cannot-be-turned-off */}

**Окружающая среда и пакеты**, **Настройка вычислительной среды**, **Дистанционные вычисления (SSH)** и **Customize** поддерживают основные функции приложений и остаются включенными. Их выключатели проверяются и отключаются. Наведите курсор или сфокусируйте объяснение на **This built-in Skill supports core application features and is always enabled.**

Это правило активации не устанавливает зависимости, не предоставляет учетные данные и не предоставляет разрешения на работу. Задание Specialist является отдельной областью: проверьте **Used by** и список возможностей роли.

Каталог по-прежнему содержит общедоступный пакет 23 Skills. Внутренняя поддержка Skills не является дополнительным методом выбора. [Требуемая реализация коммутатора](https://github.com/aipoch/open-science/blob/v0.27.0/src/renderer/src/pages/settings/RequiredSkillToggle.tsx).

На скриншоте показано объяснение **Customize**. Требуемый Skills остается включенным даже при отключении других дополнительных методов.

![Настройка остается включенной и объясняет, почему](/img/open-science/v0.27.0/08-always-enabled-skill.webp)

Для всплывающего окна с пер-агентом и его переплетений только для чтения см. [доступ к ресурсам](../guides/connectors.md#resource-access).

## Используйте его в разговоре {/* #use-it-in-a-conversation */}

<p className="example-label"><strong>Пример</strong> Запросить чек с rnaseq-count-qc</p>

Дайте агенту вход, требуемый Skill, результат и ограничения. Например:

> Используйте rnaseq-count-qc Skill на прилагаемой матрице GSE60450. Держите EntrezGeneID и Length в качестве метаданных. Проверяйте размеры и неотрицательные целые числа, сохраняйте исходные идентификаторы выборки и сохраняйте отдельный отчет о методах до / после ввода SHA-256. Используйте существующий Python Notebook.

При запросе на утверждение проверьте полные инструкции и работу. После выполнения, откройте отчет и запись Notebook и сравните с [Примеры данных](../reference/example-data.md). Более поздняя проверка Specialist является отдельной операцией. Наименование Specialist не означает, что делегирование произошло.

### Инструкции против функций Notebook {/* #instructions-versus-notebook-functions */}

Наш пакет `rnaseq-count-qc` содержит инструкции и один справочный файл. **не** регистрирует вызывающие функции Notebook. Агент читает инструкцию, затем пишет обычный Python или R.

Некоторые пакетные Skills также обеспечивают функции ядра. Их собственные инструкции называют функции и требуемый `kernelSkillIds`. Не добавляйте каждый установленный идентификатор Skill в это поле: пакет только для инструкций не является помощником ядра. Загруженный Skill также не может предоставлять разрешения файловой системы, сети или инструмента.

Если Skill отсутствует в пикере, проверьте его фильтр источника, включенное состояние и назначение агента. Если его инструкции загружаются, но вычисление не удается, продолжайте с [Научные инструменты](../tools/scientific.md). Это проблема времени выполнения или ввода, а не доказательство того, что пакет не удалось установить.
