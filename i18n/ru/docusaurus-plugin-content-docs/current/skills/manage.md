# Управлять и проверять Skills {/* #manage-and-validate-skills */}

Импортировать проверенный метод из локальных файлов или GitHub, экспортировать копии и поддерживать установленный Skills. Сначала экспортируйте метод, если вам нужно сохранить его текущую версию.

В управлении партиями просмотрите выбранный счетчик в нижней области действия перед применением операции. Прочитайте отзывы о завершении или отказе там, а затем проверьте полученные элементы. Выбор одной только записи не позволяет, не устанавливает и не удаляет ее.

## Установка с рынка {/* #marketplace */}

Для просмотра каталогов, установки и обновлений следуйте [Маркетинговое руководство Skill](marketplace.md). Эта глава охватывает импорт, экспорт и обслуживание установленных Skills на местном и GitHub.

## Экспорт и импорт местного пакета {/* #export-and-import-a-local-package */}

<p className="example-label"><strong>Пример</strong> Экспорт и реимпорт RNA-seq Skill</p>

1. Найдите `rnaseq-count-qc` в **Settings → Skills** и выберите **Actions → Export**. Сохраните ZIP.
2. Выберите **Add skill → Upload skills → Upload skill files** и выберите ZIP.
3. В **Confirm import** проверьте имя исходного файла и диагностику. Кандидаты изначально не проверяются.
4. Открыть **Оригинальное название: Rnaseq-count-qc**. Прочитайте SKILL.md и список файлов. Фактический экспорт сохранился `references/sample-metric-schema.md`.
5. Закройте предварительный просмотр, выберите кандидата и выберите **Выбранный импорт (1)**.
6. Найдите импортный ряд и проверьте его окончательное название и источник.

![Проверка полного пакета перед импортом](/img/open-science/capabilities-walkthrough/11-skill-package-preview.webp)

В этом примере уже существовал оригинальный Personal Skill. Предварительный просмотр отображал **Name exists**, а импорт создавал отдельный **Импортировано `rnaseq-count-qc-2`**. Оригинал и его привязка к Specialist остались. Не думайте, что каждый импортный пакет обновляется; Проверьте источник кандидата и обновите/замените диагностику.

![Импортная копия и оригинал Personal Skill](/img/open-science/capabilities-walkthrough/12-skill-imported-copy.webp)

| Контроль импорта | Цель |
| --- | --- |
| Выберите все / Перевернуть / Кандидат флажок | Выберите, какие обнаруженные пакеты импортировать; Один архив может содержать несколько Skills. |
| Превью / Close Preview | Читает инструкции и файлы перед установкой. |
| Название существует / Диагностика | Предупреждения о проблемах идентичности или контента. Проверьте полученное имя после импорта. |
| Выберите другие файлы | Заменяет существующий выбор кандидатов. |
| Импортировать выбранные | Выполняет выбранный импорт и сообщает об успехах, неизмененных пакетах или неудачах. |

Загрузка Markdown требует YAML `name` и `description`; ZIP/`.skill` требует SKILL.md. Локальная загрузка не извлекает недостающие файлы из URL-адресов, встроенных в инструкции. Неподдерживаемые форматы, отсутствующие метаданные, пределы размера архива и небезопасные пути архивирования являются сбоями проверки, а не причинами для отключения проверки.

## Импорт уже установленного локального Skill {/* #import-an-already-installed-local-skill */}

<p className="example-label"><strong>Пример</strong> Импорт локального пакета рецензирования</p>

**Add skill → Import installed skills** сканирует `~/.agents/skills` и `~/.codex/skills`. В этом примере локальное сканирование обнаружило 68-кандидатов, изначально всех отобранных. Очистите **Select all installed skills**, затем выберите конкретный метод; Использовать **Invert** можно только после проверки того, что выбрано в данный момент.

1. Откройте **Превью peer-review** и проверьте его исходную папку, инструкции и ссылочные файлы.
2. Выберите **Close preview**, выберите только `peer-review`, затем **Выбранный импорт (1)**.
3. Подождите **Импортный навык 1**. Затем кандидат маркируется **Imported** и не может быть выбран для того же импорта снова.
4. Вернитесь в Skills, найдите `peer-review` и проверьте импортный ряд. папка источника остается на месте; Open-Science использует импортную копию.
5. Используйте **Rescan** после изменения установленных папок. Перепроверить происхождение, выбор и статус перед импортом.

![Предварительный просмотр локально установленного пакета рецензирования](/img/open-science/local-todo-batch/12-installed-skill-preview.webp)

![Найти импортный пакет в списке Skills](/img/open-science/local-todo-batch/13-installed-skill-imported.webp)

После импорта проверьте шаблон и справочные файлы в деталях Skill. Прежде чем использовать метод от другого помощника, проверьте, доступны ли в этом сеансе его необходимые инструменты и функции времени выполнения.

## Импорт и обновление GitHub {/* #import-and-update-from-github */}

<p className="example-label"><strong>Пример</strong> Импорт и обновление ESM-2 Skill</p>

1. Выберите **Add skill → Import from GitHub**. Введите ключевое слово, `owner/repo`, `owner/repo@ref` или URL GitHub, затем выберите **Find skills**. Используйте фиксированное исправление для воспроизводимого источника пакета.
2. Прочитайте репозиторий и количество кандидатов. Данное сканирование изначально отбирало каждого кандидата; Очистите **Select all**, прежде чем выбрать только необходимый метод. Отличается от непроверенного экрана подтверждения ZIP.
3. Откройте **Preview** и проверьте разрешенные фиксации, папки, инструкции и файлы. Сканирование репозитория может обнаружить внутренние папки, а также Skills, ориентированный на пользователя; Это не количество Skill в комплекте приложения.
4. Закрыть предварительный просмотр, выбрать предполагаемого кандидата и выбрать **Выбранный импорт (1)**. Дождитесь результата и проверьте его название под **Imported skills**.
5. Вернитесь в Skills и найдите это имя. Проверьте его источник и доступность, прежде чем использовать его.

![Обзор GitHub Skill и его прикрепленного источника перед импортом](/img/open-science/local-todo-batch/15-github-skill-preview.webp)

Импорт `fair-esm2` из хранилища продуктов создал **`fair-esm2-2`**, потому что встроенное имя уже существовало. Встроенный пакет остался. Инструкции по импорту не устанавливают вес модели или не устанавливают, что вывод работает.

### Применять пересмотр восходящего потока {/* #apply-an-upstream-revision */}

Сканируйте тот же репозиторий с предполагаемым новым ref. Действующий кандидат может показать **Update available**. Выберите только этого кандидата и импортируйте его. Проверьте существующий импортный ряд и предварительный просмотр после этого. В проверке ESM-2 была обновлена та же копия `fair-esm2-2`, и сканирование, которое ref снова показало **Imported**. Обновленный орган инструкций соответствовал источнику хранилища. Импортер переписывает фронтматер и имя, безопасное от столкновения, поэтому байты целых файлов не должны соответствовать оригинальному SKILL.md.

![Для импортируемой копии доступен восходящий пересмотр.](/img/open-science/local-todo-batch/16-github-update-available.webp)

### Восстановление от ограничения скорости GitHub {/* #recover-from-github-rate-limiting */}

Для **Запрос GitHub был ограничен** откройте **Manage GitHub credential**, введите полезный токен и выберите **Verify and save**. После **Токен проверен и сохранен** повторите сканирование. **Cancel** уходит без сохранения. Держите токены вне скриншотов и публикуйте отчеты.

## Включить, отключить и удалить {/* #enable-disable-and-delete */}

Откройте **Manage**, отфильтруйте по источнику/статусу и выполните поиск по определенному методу. Выберите результат перед применением действия. **Выбранный (n)** показывает выбор; **Clear selection** выключает его. Просмотрите полный выбранный набор при изменении фильтров.

![Импортная копия отключена в массовом управлении](/img/open-science/capabilities-walkthrough/13-skill-bulk-disabled.webp)

После изменения доступности, снова откройте Skill, чтобы подтвердить его состояние. Держите экспорт метода, который вам нужен, прежде чем удалять его.

| Меры | Ожидаемый результат |
| --- | --- |
| Позволяет выбрать | Снова доступны выбранные подходящие пакеты. Проверьте статус строки. |
| Выбранный инвалид | Сохраняет подходящие пакеты, контролируемые пользователем, но удаляет доступ к Main Агенту для последующих запросов; Skills не может быть отключен. |
| Выбранное исключение | Открывается подтверждение с точными выбранными именами и результатами удаления. |
| Удалить n Skills | Удалите соответствующие местные пакеты после подтверждения. Отсутствует Skill мусор/восстановительный рабочий процесс. |
| Отмена | Оставляет установленные пакеты. |

Связанные с Specialist пакеты могут быть защищены от удаления. Удалите устаревшую привязку или отключите пакет, контролируемый пользователем, когда это необходимо. Skills, требуемый приложением, остается включенным; См. [Правила активации](overview.md#why-some-switches-cannot-be-turned-off). После удаления подтвердите, что выбранный пакет отсутствует в фильтрованном списке.

## Обновление и диагностика {/* #update-and-diagnose */}

| симптом | Проверка и следующие действия |
| --- | --- |
| Импортировано, но отсутствует в списке | Чистый источник, агент и фильтры тегов; Поиск полученного имени, включая суффиксы. |
| Файлы, отсутствующие после импорта | Проверить список пакетных файлов и реэкспортировать; Один файл Markdown не может автоматически включать отдельный справочный файл. |
| Конфликт при редактировании | Откройте последнюю версию, сравните изменения и сохраните намеренно. |
| Skill загружается, но функция недоступна | Проверьте, действительно ли в пакете есть помощник ядра; Обычные инструкции не являются функциями Notebook. |
| Недостающий пакет / время выполнения | Использовать [Научные инструменты](../tools/scientific.md) и менеджер пакетов выбранной среды выполнения. |
| GitHub/ошибка аутентификации | Сохранить фактический статус HTTP и дезинфицированный URL-адрес источника; смотреть [устранение неполадок](../guides/troubleshooting.md). |

## Импорт и редактирование Навыки безопасно {/* #import-batches */}

Большой выбор установленных навыков импортируется партиями. Дождитесь окончательного результата и проверьте импортный список, прежде чем повторять импорт. Внешнему мастерству с зарезервированным префиксом имени присваивается безопасное локальное имя; используйте имя, указанное в местном каталоге. При редактировании тела сохраните его и убедитесь, что отдельно отредактированные имя и описание остаются правильными. Изображения, прикрепленные к текущему сообщению, также могут информировать выбор навыков; проверьте область выбранного навыка, прежде чем позволить ему действовать.
