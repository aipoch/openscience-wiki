# Skill, Specialist и MCP форматы {/* #skill-specialist-and-mcp-formats */}

Шаблоны Skills, Specialists и Connector имеют разные границы пакетов. В этой справке перечислены их поля и импортные бюджеты. Проверьте предварительный просмотр архива перед импортом, а затем проверьте результат установки.

## Документ и ресурсы Skill {/* #skill-document-and-resources */}

Корень Skill содержит `SKILL.md`; Ссылки и скрипты живут ниже одного корня пакета. Блок метаданных YAML, за которым следуют инструкции Markdown.

<p className="example-label"><strong>Пример</strong> Минимальный документ SKILL.md</p>

```markdown
---
name: public-data-audit
description: Audit an attached public dataset before descriptive analysis.
---

# Public data audit

Read the supplied input, retain its source and checksum, and report
missingness, units and validation limits before creating derived files.
```

Парсер отделяет `name` и `description` от других метаданных, нормализует окончания строк и сохраняет значения скалярных метаданных в виде строк. Проверьте результат валидации импорта/редактора перед публикацией пакета.

| Элемент упаковки | Использовать | граница |
| --- | --- | --- |
| `name` | Стабильная идентификация вызова | Держите его в соответствии со ссылками на пакет |
| `description` | Когда агент должен выбрать Skill | Ничего не исполняет сам по себе |
| Проклятие тела | Инструкции, загруженные на вызов | Поддерживаемая инструкция не является доказательством того, что ее внешняя зависимость существует. |
| Относительные ресурсы | Скрипты, шаблоны, ссылки и данные | Держите ссылки на пути внутри структуры пакета |
| `.source.json`, `.specialist-package.json` в корне | Принадлежащие приложениям метаданные | Исключены из авторизованного пользователем бюджета пакета; Не изобретайте и не перепрофилируйте эти файлы. |

### Импортные бюджеты Skill {/* #skill-import-budgets */}

| Лимит | Значение |
| --- | ---: |
| Файлы в одном Skill | 16,384 |
| Индивидуальный декомпрессированный файл | 50 MiB |
| Полная декомпрессия Skill | 128 MiB |
| Совокупный сырой контент SKILL.md в одном ответе на предварительный просмотр | 4 MiB |
| Гнездо директории | Уровень 8 |
| GitHub запрашивает импорт | 512 |
| Сжатый архив Skill | 64 MiB |
| Загруженный снаружи связка | 256 MiB |
| Skills в комплекте | 256 |
| Записи из внешнего пакета | 32,768 |

Бюджеты применяются на разных уровнях. Пакет ниже его внешнего предела все еще может содержать Skill, который превышает внутренний предел. Проверка диагностики каждого кандидата; Не истолковывайте частичный импорт как каждого кандидата, добившегося успеха. Справочный файл персонального редактора зарезервирует одну запись пакета для SKILL.md.

[Skill парсер](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/skill-frontmatter.ts), [Общие лимиты импорта](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/skill-import-limits.ts).

## Пакет Specialist {/* #specialist-package */}

Портативный пакет Specialist содержит `manifest.json` и `specialist.json`. Связанные ресурсы Skill используют `skills/<skill-name>/<file>` с `SKILL.md` в каждом корне Skill. Имя его фронтматерии должно соответствовать названию каталога.

| Файл/поле | контракт |
| --- | --- |
| `manifest.json → schema_version` | `1` |
| `id` | идентификационный пакет; ID вклада используют строчные буквы / цифры / дефисы и избегают зарезервированных `os-` / `mcp-` префиксы |
| `version` | Семантическая версия |
| `exported_with_app_version` | Экспорт версии приложения |
| `specialist.json → name` | Стабильное имя профиля Specialist |
| `display_name` | Факультативное название презентации |
| `description` | Описание роли |
| `system_prompt` | Инструкции Specialist; snake_case на границе пакета |
| `skill_ids` | Массив непустых имен Skill без дубликатов |
| `connector_ids` | Массив непустых имен Connector без дубликатов |

Неизвестные или запрещенные поля отвергаются. В памяти полезных нагрузок используется верблюжья каша (`systemPrompt`, `skillIds`, `connectorIds`), которую не следует путать с портативным написанием поля JSON. Портативные имена Connector могут разрешаться для машинно-местных идентификаторов при импорте; Ссылки на пакеты не несут машинных учетных данных.

| Архивный лимит Specialist | Значение |
| --- | ---: |
| Сжатый размер | 50 MiB |
| Несжатый размер | 200 MiB |
| Количество файлов | 2,000 |
| Индивидуальный файл | 25 MiB |
| Соотношение сжатия | 1,000 |
| Глубина пути | 32 |

В предварительном просмотре импорта сообщается о диагностике, независимо от того, является ли она установочной, и о каждом расположении Skill: установке, повторном использовании, конфликте или замене. Перезапись требует явного подтверждения. Кандидат с просроченным сроком действия или просроченным сроком действия должен быть повторно просмотрен; Не стоит слепо переигрывать его токены. Конфликты Skill требуют явно установленного/входящего выбора.

Экспорт использует ожидаемый пересмотр и выбранный Skills. Удаление также использует предварительный просмотр / редактирование и защищает встроенный, поддерживаемый главным образом, общий или ссылающийся Skills. Удаление одного Specialist не равносильно удалению каждого Skill, к которому он может получить доступ.

[Типы пакетов и архивные бюджеты](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/specialist-package.ts), [Проверка пакета](https://github.com/aipoch/open-science/blob/v0.26.0/src/main/specialist/package/validator.ts).

## Шаблон Connector и клиентский экспорт MCP {/* #connector-template-and-mcp-client-export */}

Шаблон Open-Science Connector не является тем же документом JSON, что и конфигурация `mcpServers` клиента MCP.

| Шаблонное поле | контракт |
| --- | --- |
| `schema_version` | `1` |
| `kind` | `open-science.connector` |
| `name` | Стабильное пользовательское имя, до символов 64, строчные буквы/цифры/дефисы; Уникальное и не зарезервированное имя |
| `display_name` | Человеческая этикетка |
| `description` | Факультативное объяснение |
| `transport` | `stdio`, `streamable_http`или `sse` |
| `command`, `args` | Исполняемый локальный stdio и список аргументов |
| `url` | Удаленная конечная точка HTTP/SSE |
| `required_secrets.environment` | Названия экологических секретов для stdio; Не их ценности |
| `required_secrets.headers` | Названия секретов заголовков HTTP; Не их ценности |
| `required_secrets.oauth_client_secret` | Должен ли секрет клиента OAuth предоставляться локально |
| `oauth` | Поддерживаемая регистрация/эмитент/область/клиент/перенаправление метаданных |

Проверка на транспорте: дистанционные перевозки не содержат требуемых секретов окружающей среды; OAuth и требуемые секреты заголовка не могут быть объединены. Зарегистрированный клиент OAuth нуждается в сервере авторизации; Регистрация метаданных клиента и явный идентификатор клиента являются отдельными режимами. Для перенаправления/засекреченных метаданных требуется соответствующий идентификатор клиента.

Портативный экспорт отклоняет встроенные учетные данные в URL-адресах и аргументы команд. Клиентский экспорт MCP использует `mcpServers`, `command`/`args`/`env` для стрио или `type`/`url`/`headers` для удаленного транспорта с секретными заполнителями. Регистрация OAuth и токены исключаются из этого формата клиента, и экспорт сообщает об ограничении.

Конфигурация импорта не устанавливает внешний сервер, не входит в его сервис и не устанавливает успешное выполнение инструмента. Подтвердите состояние соединения и проверьте рекламируемые инструменты после предоставления учетных данных через приложение.
