# Страница и контрольный индекс {/* #page-and-control-index */}

Эта страница конденсирует точки входа приложения в список поиска, страницу за страницей. Государственно-зависимый контроль возникает только тогда, когда выполняются его условия. Если контроль отключен, прочитайте его подсказку и соответствующие известные проблемы; Возможные причины включают состояние сеанса, отсутствие предпосылок и дефект продукта.


<span id="current-verification-coverage" />

## Найдите подробные инструкции {/* #find-the-detailed-instructions */}

Используйте этот индекс, чтобы найти контроль. Следуйте связанному учебнику для предпосылок, шагов, ожидаемых результатов и известных проблем. [Обзор настроек](../settings/overview.md) для панелей настроек, [Короткие задачи](controls.md) для общих действий и [устранение неполадок](../guides/troubleshooting.md) для ошибок.

| --- | --- | --- |

| Среда выполнения агента | Фреймворк-карта, Установка, Re-detect, Back, Continue | Установите или выберите готовое активное время выполнения |
| Поставщик моделей | Тип провайдера, выбор аутентификации, условные поля, Тестирование и продолжение | Проверить требуемые входы и протестировать поставщика перед продвижением |

См. [Первый раз установка](../guides/onboarding.md) и [Конфигурация поставщика](../guides/providers.md) для подробного ознакомления.

## Глобальные настройки контроля {/* #global-settings-controls */}

**Search settings** перемещается по четырем группам. `Back`, `Forward`, хлебные крошки, `Maximize/Restore`, `Close settings`, мобильная навигация и ошибка `Dismiss` применяются во всех настройках. См. [Обзор настроек](../settings/overview.md) для групп и ярлыков поиска.

### Skills {/* #skills */}

Разговор Skill импорт, фильтр источника, поиск, добавление навыков, обрушение категории, детали Skill, включение переключения, создание / загрузка / импорт, предварительный просмотр, редактирование, экспорт, удаление, отмена и сохранение.

### Память, теги, учетные данные и использование {/* #memory-tags-credentials-and-usage */}

Категория памяти / запись Создавать, редактировать, удалять и очищать; Теги создают / редактируют / удаляют, присваивают, фавориты, фильтры и переупорядочение; Удостоверения создают / восстанавливают / удаляют, здоровье, использование и связывание Connector; Период использования, метрика, тепловая карта, ежедневная диаграмма, повороты / звонки и элементы управления группировкой.

### Коннекторы {/* #connectors */}

Фильтр / поиск, добавление / импорт, включение, детали, тестирование / подключение, редактирование, экспорт и удаление. Форма Add содержит Type, Display name, ID, Description, Command, Arguments, Environment variables, URL, Transport, Authentication, OAuth scopes, Authorization server URL, Client metadata URL, Headers, Trust, Cancel, and Add/Save.

### Специалисты {/* #specialists */}

Фильтр категорий, поиск, включение, детали, действия, создание и импорт. Редактор содержит иконку, цвет, имя, описание, инструкции, полный доступ, тип емкости, поиск Skill / Connector, выбранные возможности, отмену и сохранение. Импорт содержит выбор ZIP, предварительный просмотр, диагностику, отмену и импорт.

### Вычисления {/* #compute */}

Добавьте хост, карту хоста / включите, Probe / Retry, Detail / Edit / Remove, Resources, режим выполнения Direct SSH / Slurm, документ детализации, корень Scratch Edit / Input / Save / Cancel и одновременный предел вакансий Edit / Input / Save / Cancel. Утверждения исполнения предлагают Deny, один раз, сессию, проект и глобальную версию.

### Сеть {/* #network */}

Проверьте еще раз; Прокси-система/ручная/прямая; Разрешенный список доменов Notebook; Зеркало пакета Configure/Edit; Канал Conda, индекс pip и пакет CA; Посмотреть зеркала, отменить и сохранить.

### Модель {/* #model */}

Активная модель, радиоприемники и политики моделей Subagent/Reviewer/Vision/Session-details; Провайдерский тест / Редактировать / Удалить / Добавить. Форма Поставщика содержит все поля со страницы модели Onboarding, а также Отменить и Сохранить.

### Агент {/* #agent */}

Карта фреймворка OpenCode/Claude/Codex/CodeBuddy, Switch, источник установки, Install/Cancel/Retry, журнал установки, ремонт, вход/авт, импорт конфигураций/дома и подтверждение удаления.

### Разрешения {/* #permissions */}

Профиль по умолчанию, фильтр прицела, ссылка прицела гранта, подсказка разъема, Отзыв и подтверждение и предупреждение или обновление неполного магазина.

### Среды выполнения {/* #runtimes */}

Python/R; Включите среду, Добавьте интерпретатор, Загрузить / Настройка, Ремонт, Разрешить установку пакета, Пакеты, Фильтр, Добавить / Установить / Удалить пакет, Отключить / Удалить и подтверждение.

### Хранилище {/* #storage */}

Заявка на хранение: Reveal/Repair; Изменение местоположения данных, Путь, Просмотр, Проверка, Перемещение/Принятие/Отмена; Миграционный прогресс Отмена/Перезагрузка/Перезагрузка/Отказ Расширяемые категории использования дисков.

### Общие {/* #general */}

Уведомления о задачах, тематические радиоприемники, радио значки приложений, близкое поведение, токен GitHub Open/Input/Save/Clear и обновления About/Check/install.

### Дистанционный контроль {/* #remote-control */}

Start/Stop/Refresh, Copy/Open URL и QR; Remote.It setup/retry/disconnect; Доверенный браузер Revoke; Отклонить / Разрешить один раз / Всегда доверять.

### Архивировано {/* #archived */}

Управление проектами, Проект восстановления, Проект удаления; Восстановление/удаление сеанса; Подтверждение удаления Отменить/Подтвердить.
