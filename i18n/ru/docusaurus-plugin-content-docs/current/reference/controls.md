## Ссылка на клавиатуру {/* #keyboard-reference */}

| Меры | macOS | Windows/Linux | Условия и охват |
| --- | --- | --- | --- |
| Поиск приложений | `⌘K` | `Ctrl+K` | Домашний/рабочий поиск; В настройках, сфокусируйте свой поиск заголовка |
| Настройки | `⌘,` | `Ctrl+,` | Открывает настройки, когда текущее наложение позволяет ярлык |
| Новый диалог | `⌘N` | `Ctrl+N` | рабочее пространство; требуется существующий разговор с сообщениями; Игнорируется, когда блокирующий диалог открыт. |
| Переключатель боковой панели | `⌘B` | `Ctrl+B` | рабочее пространство; переключает узкоэкранный ящик или боковую панель рабочего стола |
| Отправить текст композитора | `Enter` | `Enter` | когда отправка доступна; Открытый пикер упоминаний владеет Enter; Композиция IME не представлена |
| Новая линия | `Shift+Enter` | `Shift+Enter` | Композиторский текст |
| Предыдущий/следующий оперативный проект | `↑` / `↓` | `↑` / `↓` | Начните просмотр истории с заботы в начале и без выбора; Открытый выбор упоминания имеет приоритет |
| Развернуть проект | `⌘Z` | `Ctrl+Z` | Составитель проекта истории |
| Редакция проекта | `⌘Shift+Z` | `Ctrl+Shift+Z` | Составитель проекта истории |
| Закрытая активная поверхность | `⌘W` | `Ctrl+W` | Настольное приложение: сначала предварительный просмотр, где это применимо, затем вкладка / панель предварительного просмотра, затем окно; Браузерный доступ может использовать ярлыки браузера |
| Отказаться от наложения | `Esc` | `Esc` | где поддерживается; сохранение или блокирование подтверждения может изменить поведение увольнения; |

Не нажимайте многократно на ярлык, ожидая, что он только скроет файл. После того, как предварительные просмотры закрыты, следующий вызов может закрыть окно приложения. Закрытие окон и отключение процессов являются отдельными зависимыми от платформы действиями.

Закрытие вкладки Side Chat требует подтверждения и останавливает/удаливает эту сторону обсуждения; Закрытие файла предварительного просмотра не удаляет файл. Смотрите [Side Chat](../guides/delegation.md).

## Ссылочные триггеры композитора {/* #composer-reference-triggers */}

| триггер | Выбор | Проверить перед отправкой |
| --- | --- | --- |
| `/` | Включено Skill | Подтвердите предполагаемый метод и поддерживающие зависимости |
| `@` | Доступный файл/артефакт или справочная литература/сфера применения | Подтвердите выбранный источник и версию, где показано |
| `#` | Сессионная ссылка | Подтвердите предполагаемый разговор |

Выбор предложения включает структурированную ссылку. Просто ввод знакомого имени файла или имени Skill не является доказательством того, что соответствующая ссылка была прикреплена. Проверьте вставленный чип и запрос.

## Область поиска {/* #search-scope */}

Глобальный поиск приложений охватывает проекты, сессии, текст сообщений, загруженные / сгенерированные файлы, библиотечные записи и коллекции и индексируемое содержимое поддерживаемых загрузок. Сгенерированные файлы ищут по имени; Неиндексированный контент не ищется. Выберите категорию, чтобы сузить результаты, а затем проверьте контекст результата, прежде чем открывать его. Это не означает, что каждый PDF, изображение или другой двоичный файл имеет доступный для поиска полнотекстовый индекс. См. [Навигация и поиск](../guides/navigation.md) для полного рабочего процесса.

Поиск вики является отдельным: он индексирует названия документации, заголовки и пассажи на текущем языке. Термин, такой как «Входящие», может соответствовать абзацу здесь, даже если он отсутствует в названии сессии приложения.

Технический справочник: [прикладной связывающий](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/hooks/useApplicationEventBindings.ts) · [Композитор клавиатура для управления](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/workspace/composer/ComposerEditor.tsx) · [Близкое поведение](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/hooks/useCloseActivePaneShortcut.ts) · [Глобальный поиск](https://github.com/aipoch/open-science/blob/v0.30.0/src/renderer/src/components/global-search/GlobalSearchDialog.tsx).

Настройка панельного/диалогового поиска использует **&lt;unk>K** на macOS и **Ctrl+Alt+K** на Windows/Linux. **&lt;unk>K / Ctrl+K** продолжает фокусировать поиск заголовка Настройки. Смотрите [краткая граница](../guides/shortcuts.md#local-settings-search).
