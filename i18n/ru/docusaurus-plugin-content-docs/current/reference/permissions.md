# Разрешения и контроль {/* #permissions-and-control */}

Используйте эту страницу, чтобы определить правило, ответственное за решение о разрешении. О шагах по пересмотру карты или отзыву гранта см. [Разрешения и утверждения](../guides/approval-modes.md).

## Разрешительные слои {/* #permission-layers */}

| слой | Значения или сфера применения | Чем он управляет |
| --- | --- | --- |
| Профиль беседы | `ask`, `auto`, `full` | Поведение агента для одобрения текущего разговора |
| Выбранный и эффективный профиль | зависящий от времени выполнения | Фреймворк может предоставлять меньше возможностей, чем требуется для выбранного профиля; Проверить свое объяснение |
| Запомнившийся грант возможностей | Разговор, проект, глобальный | Соответствие будущим требованиям к записанной способности и квалификации |
| Инструментальная политика Connector | Всегда разрешайте, спрашивайте каждый раз, блокируйте | Выбранный инструмент Connector; Заблокированный инструмент не срабатывает перед поиском гранта |
| Доступ к файловой системе | Выбранные пути и режимы доступа | К каким внешним локациям может получить доступ операция |
| Сетевая политика Notebook | Разрешенные пункты назначения и проверки соединения | Может ли время выполнения достичь запрашиваемого пункта назначения |
| Возможности Specialist | Назначены Skills и коннекторы | Что доступно для этой роли |

Эти слои не являются взаимозаменяемыми. Полный доступ к изменениям агентов оперативного поведения; Он не устанавливает инструмент, не предоставляет учетные данные, не делает сервер доступным или не доказывает, что сетевая защита среды выполнения позволяет подключение.

## Профили и области применения {/* #profiles-and-scopes */}

| Значение UI | контракт | Значение |
| --- | --- | --- |
| **Ask for approval** / **Ask** | `ask` | Запросить операции, требующие одобрения, при условии существующих грантов и исключений, принадлежащих заявкам. |
| **Auto-approve edits** / **Auto** | `auto` | Поддерживаемые изменения рабочего пространства и признанные операции библиотеки, принадлежащие приложениям, могут проходить автоматически; Как правило, произвольные вызовы оболочки или MCP не допускаются. Видишь? [Библиотечные правила](../guides/approval-modes.md#library-auto). |
| **Full access** | `full` | Разрешить запросы на разрешение агента без ручных подсказок, где время выполнения поддерживает его |
| **Once** | `once` | только текущий звонок; Нет долгосрочной субсидии |
| **Этот разговор** | `session` | Соответствие вызовов в этом разговоре, в том числе через перезапуск |
| **This project** | `project` | согласование вызовов в данном проекте; широкомасштабное подтверждение |
| **Global** | `global` | согласование вызовов между проектами; широкомасштабное подтверждение |

Карта предлагает только те области, которые поддерживаются этим запросом. Обычно он выбирает объем разговора, когда он доступен, а затем один раз. Не выводите «один раз» из положения кнопки; Прочитайте полный текст этикетки. Командный префикс и классификаторы категорий могут охватывать больше, чем одно и то же повторение одного вызова.

**Default permission mode** влияет на новые разговоры. Существующие разговоры сохраняют свою собственную настройку. **Auto-review** – это отдельный вариант обзора результатов. Это не профиль разрешения `auto`.

## Решение Connector {/* #connector-decision-order */}

Брокер Connector оценивает эти условия:

1. Если инструмент соответствует **Block**, откажитесь от него.
2. В противном случае, примените конфигурацию разрешения/запроса Connector. Автоматический вход на уровне Connector может разрешить вызов; Инструмент, требующий одобрения, продолжает следующую проверку.
3. Разрешить применимый запомнившийся грант для возможности и текущего проекта / разговора.
4. Если ни один из них не применяется, покажите поддерживаемые области утверждения. Если одобрение недоступно или отклонено, откажитесь от вызова.
5. Сохраняйте запомнившееся одобрение перед выпуском операции, если только абонент явно не откладывает настойчивость до своего шага авторизации.

Сохраненный грант не может переопределить **Block**. И наоборот, отзыв запомнившегося гранта не может привести к быстрому введению, если разрешительная политика или более широкий грант по-прежнему покрывает призыв. Прочитайте отображаемые политики и подсказки по охвату.

## Глобальные гранты по умолчанию {/* #default-global-grants */}

Источник определяет базовые гранты 20. Этот номер описывает встроенные по умолчанию, а не количество, которое должен отображать каждый установленный профиль.

| Семья | Базовые возможности | Граф |
| --- | --- | ---: |
| кастомизация | Создание/обновление Specialist; Публикация/редактирование Skill; прикреплять/отсоединять Skills и Коннекторы к/от Specialist | 8 |
| Skills | Ссылка на Skill | 1 |
| Читатель литературы | `read_document` | 1 |
| Инспекция Notebook | Перечислите время выполнения, прочитайте состояние Notebook, перечислите категории памяти, поисковые воспоминания, проверьте пакеты | 5 |
| Планирование прогресса | `update_step_status` | 1 |
| Библиотека источников | Поиск, чтение абстракции, чтение PDF, ссылки на формат | 4 |

Некоторые дефолты позволяют писать настройки. Не описывайте базовый уровень как «разрешения только для чтения». **Restore defaults** добавляет недостающие базовые глобальные гранты без очистки других грантов. Он не сбрасывает все настройки разрешения или отменяет выполненную работу.

Исключения, принадлежащие приложениям, также существуют за пределами этого списка: сохранение уже существующего или встроенного результата с помощью точной возможности артефакта, отображение вопроса взаимодействия и объявление группы активности могут пройти без дополнительной карты разрешения. Такие исключения зависят от проверенного идентификатора инструмента, а не от успокаивающего заголовка дисплея инструмента.

## Отмена и неполное состояние {/* #revocation-and-incomplete-state */}

| Наблюдение | Значение |
| --- | --- |
| Серия остается покрытой во всем мире или проектом. | Удаление этого более узкого гранта оставляет более широкие полномочия в действительности. |
| Политика намекает на блокировку | Политика предотвращает вызов, даже если есть запомнившаяся строка |
| Предупреждение неполных магазинов | Видимый инвентарь может не содержать грантов; Массовое аннулирование отключено до тех пор, пока не будет известен полный набор |
| Несвоевременный пересмотр или отсутствующий грант | Еще одно изменение аннулировало запрашиваемый ряд; Обновить и проверить текущее состояние |
| Уведомление | отменяет отмену гранта в пределах его отображаемой доступности; Это не отменяет эффект инструмента. |
