# Open-Science {/* #open-science */}

Используйте Open-Science для организации источников исследований, работы с агентом, анализа и проверки сохраненных результатов.

Обзор продукта: [What Is AIPOCH Open-Science?](https://aipoch.com/blog/what-is-open-science).

## Начните здесь {/* #start-here */}

1. [Возможности и вспомогательные материалы](./guides/capabilities.md): выберите путь для ваших файлов или исследовательских вопросов.
2. [Монтаж](./guides/installation.md) и [первый раз установка](./guides/onboarding.md): подготовьте приложение, агент, модель и время выполнения.
3. [Ваш первый проект и результат](./guides/first-project.md): откройте небольшую таблицу публичных данных и сохраните проверенное резюме.
4. [Разрешения](./guides/approval-modes.md): проверяйте запрошенные действия и управляйте запоминающимся доступом.
5. [Notebook и доказательства казни](./guides/notebook.md): анализ кода, переменных и происхождения результатов.

## Найдите правильный уровень детализации {/* #find-the-right-level-of-detail */}

| Раздел | Прочитайте его для |
| --- | --- |
| **Руководства** | Управление страницами, настройка и повседневные операции |
| **Исследовательские процессы** | Сценарии исследований с входными данными, решениями, результатами и проверками принятия |
| **Обзор инструментов** | Семьи инструментов, научные услуги и варианты интеграции |
| **Skills** | Многоразовые методы, каталог и управление пакетами |
| **Специалисты** | Роли, назначенные возможности, делегирование полномочий и обзор |
| **Reference** | Точные ограничения, правила конфигурации, форматы пакетов, контракты CLI/API и Changelog |

Используйте **Search** или **&lt;unk>K / Ctrl+K** для поиска заголовков, заголовков и текста. Собственный поиск приложения имеет другой объем.

## Перед тем, как привести пример {/* #before-running-an-example */}

Местные переходы используют общедоступные документы PRISMA и матрицу GSE60450 RNA-seq. Загрузите связанные входы и подтвердите модель, время выполнения и разрешения, необходимые для каждой задачи.

[Дистанционные вычисления](./guides/remote-compute.md) включает в себя завершенный анализ Direct SSH RNA-seq, сбор выходных данных, восстановление и отмену перезапуска. Мониторинг терминалов Slurm требует бухгалтерского учета; Для вывода GPU необходима совместимая программная среда.

Используйте [Справочник](./reference/index.md) для технических ограничений и конфигурации и [Изменить](./changelog/v0.32.0.md) для истории выпуска.
