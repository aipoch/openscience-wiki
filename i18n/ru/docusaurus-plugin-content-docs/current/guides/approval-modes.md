# Разрешения и утверждения {/* #permissions-and-approvals */}

Используйте **Agent controls**, чтобы выбрать, как текущий разговор запрашивает одобрение. Используйте **Settings → Permissions** для установки по умолчанию новых разговоров и проверки запомненного доступа. Это отдельные операции: изменение дефолта не сбрасывает существующие разговоры или не отзывает их гранты.

## Выберите режим разговора {/* #choose-a-conversation-mode */}

| Режим | Используйте, когда | Чего ожидать |
| --- | --- | --- |
| **Ask for approval** | Вы хотите проверить запрашиваемые операции | Карты одобрения действий, в которых отсутствует соответствующий грант или исключение |
| **Auto-approve edits** | Вы разрешаете рутинные изменения в рабочем пространстве | Поддерживаемые правки проходят автоматически; команд, сетей и MCP Операции все еще нуждаются в одобрении |
| **Full access** | Вы решили разрешить агентские операции без подсказок | Команды, изменения файлов и сетевые запросы могут выполняться без ручных карт разрешений. Остаются другие требования к доступу и обслуживанию |

Откройте **Agent controls** рядом с композитором и прочитайте выбранный режим. Проверьте любое сообщение о совместимости, показывающее, как фреймворк реализует его. Полный контроль доступа имеет свое подтверждение. **Auto-review** - это другой контроль для проверки результатов и не означает автоматическое одобрение правок.

![Реальный английский селектор режима разрешения](/img/open-science/walkthrough-2026-09-08/57-permission-modes.webp)

Проверьте эффективный режим, показанный для вашего агента; Поддерживаемое поведение одобрения может отличаться по структуре. Не все режимы были реализованы во всех четырех фреймворках.

## Прочитайте карточку одобрения {/* #read-an-approval-card */}

Прочитайте операцию, выбранную среду и предложенный код перед утверждением. Для проверки данных подтвердите, что он считывает предполагаемый вход и записывает только запрошенные выходы. Установка недостающей зависимости — это отдельная операция с другой целью и эффектом.

![Одобрение исполнения Python из публичного дела GSE60450](/img/open-science/guides-walkthrough/25-python-permission.webp)

| Контроль или информация | Что проверить или сделать |
| --- | --- |
| Название инструмента и резюме | Определите фактическую операцию, цель и источник |
| Расширяемый код или аргументы | Проверяйте пути, время выполнения, имена пакетов или входные данные службы |
| **Authorization scope** стрела | Выберите из областей, которые поддерживает этот запрос |
| **Allow once** | Освободите только этот призыв |
| **Allow for this conversation** | Запомните соответствующие призывы к этому разговору, в том числе при перезапуске. |
| **Allow for this project** | Применять согласованный доступ к проекту и подтверждать более широкий охват |
| **Allow globally** | Применять согласованный доступ к проектам и подтверждать более широкий охват |
| **Deny** | снижение представленной операции; Проверьте полученный ответ, прежде чем выбрать альтернативу |
| Дополнительные опции провайдера, если есть | Прочитайте их фактический ярлык и эффект; Доступные варианты варьируются по запросу |

Основная кнопка «Разрешить» обычно использует область разговора, когда запрос поддерживает ее. Прочитайте этикетку перед нажатием. Для получения гранта командного префикса проверьте отображаемый префикс: более поздние команды, начинающиеся с этого префикса, могут совпадать. Разрешение для одного времени выполнения не является разрешением для несвязанного внешнего сервиса.

### Запомните одобрение веб-чтения {/* #remember-web-reading-approval */}

Для поддерживаемого запроса **Чтение веб-страниц** выберите **Allow for this conversation**, чтобы запомнить эту возможность для более поздних веб-чтений в том же разговоре. Он может охватывать другие веб-сайты, а не только первый URL. **Allow once** относится только к этому вызову. Проверить или отозвать грант в соответствии с **Запомненные разрешения**; Он не добавляет хосты в список разрешений сети Notebook или не разрешает загрузку.

### Запомните одобрение веб-поиска {/* #remember-web-search */}

Начиная с v0.30.2, для поддерживаемых встроенных запросов Claude Agent **Search the web** можно выбрать **Allow for this conversation**. Последующие подходящие поисковые запросы в том же разговоре используют это разрешение. **Allow once** действует только для текущего запроса. Просмотреть или отозвать **Search the web** можно в **Remembered permissions**. Поиск и **Read web pages** — отдельные разрешения. Эта возможность поддерживается не всеми фреймворками или Connectors; проверяйте указанную область действия.

## Управление запоминающимся доступом {/* #manage-remembered-access */}

Открыть **Settings → Permissions → Remembered permissions**. Фильтр **All**, **Global**, **Project** или **Session**. Строки отображают возможности, объем и любой классификатор или более широкий охват. Сеансовая ссылка открывает разговор ее владельца; Подсказка политики Connector приводит к соответствующей конфигурации.

| Меры | Результат |
| --- | --- |
| **отозвать** в один ряд | Удалить тот, который запомнил грант немедленно; Проверить уведомление Undo |
| Группа **Revoke all** | ходатайствовать об изъятии грантов этой группы; Убедитесь, что отображаемый объем завершен перед его использованием |
| **Restore defaults** | Добавляет отсутствующие базовые глобальные гранты и оставляет нетронутым другой запоминающийся доступ |
| **Defaults restored** | Никаких базовых грантов не отсутствовало; Кнопка восстановления отключена |
| Область применения фильтра | Изменяет отображаемые строки; не предоставляет и не отменяет доступ |

Выберите **отозвать**, чтобы удалить предполагаемый грант. Используйте **Undo**, если это было ошибкой. **Restore defaults** добавляет недостающие базовые гранты; Он не восстанавливает все разрешения, которые вы ранее удалили.

### Эффективная сфера действия сохраненного гранта {/* #read-a-saved-grants-effective-scope */}

Проверить Connector / инструмент, область **Глобальный / Проект / Сессия** и классификатор **Любой вызов / Конкретный вход / Командная группа**, прежде чем отозвать грант. Записи командной группы могут включать в себя их резюме и дату утверждения.

**Blocked in Connectors; this permission is currently inactive** означает, что сэкономленный грант не отменяет политику Connector. **Allowed by Connector policy even without this permission** означает, что отмена этого гранта сама по себе не устранит это политическое пособие. Откройте Connector, чтобы проверить его правила. Используйте **Undo**, если отзыв был непреднамеренным, а затем проверьте восстановленное состояние.

### Отзыв группы в текущем объеме {/* #revoke-a-group-in-the-current-scope */}

1. Фильтр по заданному объему, например **Session**.
2. Выберите действие **Revoke all** этой группы.
3. Убедитесь, что группа была очищена и что другие области сохраняют свои гранты.
4. При следующей операции сопоставления прочитайте любой новый запрос на утверждение, прежде чем продолжить.

Отзыв влияет на будущее разрешение. Он не отменяет завершенные правки или сетевые запросы, и более широкий грант все еще может санкционировать операцию.

![Новый запрос на исполнение после отзыва группы Сеанса](/img/open-science/local-todo-batch/40-permission-request-renewed.webp)

Если инвентарь неполный, дождитесь, пока он загрузит или повторит неудавшийся запрос, прежде чем использовать групповое аннулирование. Перепроверить выбранный объем после отзыва.

## Диагностика неожиданного поведения {/* #diagnose-unexpected-behavior */}

| Проблема | Проверка и решение |
| --- | --- |
| В режиме Ask не появилась карточка подтверждения | Проверьте сохранённые разрешения, политику инструмента и исключения самого приложения. Режим Ask не требует подтверждения каждого чтения, сохранения результата или вопроса пользователю. В [справочнике разрешений](../reference/permissions.md) перечислены базовые разрешения, включая запись пользовательских настроек. |
| После отзыва разрешения операция всё ещё выполняется | Проверьте, нет ли более широкого разрешения на уровне проекта или глобально либо разрешающей политики. Удаление разрешения сеанса не отменяет глобальное разрешение. |
| Разрешённая операция завершается ошибкой | Подтверждение лишь разрешает попытку выполнения. Сначала устраните указанную причину: отсутствующий пакет, недоступный файл, неверные учётные данные или запрещённый сетевой адрес. Затем повторите попытку. Об ошибках DNS и загрузки пакетов см. [Сеть](network.md). |
| Некоторые области действия недоступны | Карточка показывает только области действия, поддерживаемые текущим запросом и контекстом проекта или сеанса. Не выбирайте более широкую область только потому, что более узкая недоступна. |

Источник: [Сэкономленные гранты и рассрочка](https://github.com/aipoch/open-science/commit/469b593b).

## Библиотечная работа в автоматическом режиме {/* #library-auto */}

С **Auto-approve edits** определенный набор встроенных операций Библиотеки может автоматически проходить одобрение агента по вызову. К ним относятся поиск и чтение ссылок, сохранение в Inbox, приобретение PDF-файлов, форматирование ссылок и подготовка документов цитирования. Это уменьшает повторяющиеся подсказки во время рутинной работы библиотеки.

Это правило распространяется на признанные литературные инструменты, принадлежащие приложениям, а не на все вызовы, команды или сетевые операции MCP. Собственные правила файлов, сетей и ресурсов по-прежнему применяются, и это решение не создает постоянного гранта. Выберите **Ask for approval**, когда вы хотите проверить запросы агента индивидуально. Проверяйте кандидатов в Inbox, прежде чем принимать их.
