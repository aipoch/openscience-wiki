# Создавать и редактировать изображения {/* #generate-and-edit-images */}

Создайте иллюстрацию из подсказки, затем уточните выбранное изображение, сохранив более ранние версии. Используйте это для пояснительных диаграмм или презентационных работ. Созданное изображение не является экспериментальным доказательством; проверьте научные ярлыки, структуры и визуальные утверждения, прежде чем делиться ими.

## Настройка службы изображений {/* #configure */}

1. Откройте **Settings → Model**, найдите **Image generation** и выберите **Image services → Add image service**.
2. Выберите **Provider type**. Для **Custom HTTP service** введите **Name**, **Base URL** и **API key**, а затем добавьте точные **Model ID** и **Предустановленный интерфейс**, поддерживаемые службой. Для пользовательской конечной точки сопоставьте ее **API format** с API изображения службы.
3. Сохраните сервис, затем выберите его в соответствии с **Image generation model**. **Not configured** означает, что генерация изображений не готова.
4. Начните с одного небольшого запроса изображения и проверьте возвращенное изображение. Новые настройки изображения применяются со следующего поворота.

![Настройка службы изображений с конечной точкой, форматом API, учетными данными и полями моделей](/img/open-science/v130/image-service.webp)

Генерация изображений и изображений имеет разные рабочие места. Основная направляет разговор; Видение читает изображения; Поколение изображений создает или редактирует их. Подписка на Codex для Main не обеспечивает автоматически API генерации изображений или его платежное пособие. Держите свою рабочую основную модель выбранной при настройке службы изображений отдельно.

## Создайте первое изображение {/* #generate */}

В разговоре о проекте опишите цель изображения, содержание, макет и любые ярлыки. Попросите сохранить изображение. Карта инструмента генерации изображений показывает запрос и его прогресс; дождитесь завершенного вывода, прежде чем открывать его в предварительном просмотре.

<p className="example-label"><strong>Пример</strong> Запросить концептуальную иллюстрацию рабочего процесса</p>

```text
Create an English illustration for a lab meeting slide showing:
research question → literature search → evidence review → reproducible analysis.
Use four clearly separated steps, a light background and readable labels.
This is a conceptual workflow, not a plot of experimental results.
Save the image so I can review it in the project.
```

Проверьте фактические метки, порядок и направление стрелки. Если запрос не выполняется, проверьте службу изображений, модель и ошибку, а не меняйте Main на несвязанного поставщика. Справки и исходные изображения, используемые для генерации или редактирования, отправляются в выбранный сервис изображений. Отмена не может отозвать уже отправленные данные.

## Редактировать, сравнивать и повторно использовать {/* #edit */}

Откройте действие редактирования изображения, выберите исходную версию и опишите целенаправленное изменение. Используйте доступные области и параметры управления только тогда, когда выбранный сервис поддерживает их. Отправьте редактирование и ждите его нового выхода. Редактирование создает новую версию, поэтому более ранние варианты остаются доступными.

Сравните кандидата с источником: проверьте запрашиваемый регион и части, которые должны оставаться неизменными. Используйте историю изображений, чтобы вернуться к версии или продолжить редактирование. Загрузите предполагаемую окончательную версию и повторно откройте файл, прежде чем поместить его в презентацию. Держите точную подпись, идентифицирующую иллюстративный контент.

Для существующих участков, которые нуждаются в численной проверке, используйте [Записная книжка](notebook.md) и [Происхождение](reproducibility.md). Для слайд-текста и форматирования см. [редактирование презентации](presentation-editing.md).
## Тестирование службы изображений перед сохранением {/* #test-service */}

В v1.3.1, форма обслуживания изображения предлагает **Test generation** после заполнения необходимых полей и модели. Просмотрите подтверждение: оно генерирует одно изображение, и поставщик может взимать плату за запрос. Пройденный тест применяется к этой точной конфигурации; Изменение модели, конечной точки или учетных данных требует нового теста. Также можно сохранить настройки без запуска теста.

После сохранения нового сервиса его первая модель становится по умолчанию только тогда, когда модель генерации изображений уже не выбрана. Проверяйте этот выбор перед первым запросом. Main остается отдельно настроенным.
