# Python и R Runtimes {/* #python-and-r-runtimes */}

Откройте **Settings → Runtimes**, чтобы выбрать среды Python и R, доступные для ноутбуков и Агента. Статус **Ready** среды указывает на успешное обнаружение/настройку; Переключатель **Enable** отдельно контролирует доступность для Агента.

Выберите среду, управляемую приложением, или существующий переводчик. Проверьте его путь, версию, состояние готовности и включить переключение перед использованием. Системы R и R, управляемые приложениями, могут сосуществовать.

<span id="verification-still-required" />

<PlatformGuide />

## Выберите среду для своего проекта {/* #before-choosing-an-environment-for-a-project */}

Запишите имя переводчика, путь и версию. Для первого анализа Python предпочтите изолированную среду, управляемую приложениями, чтобы изменения пакетов не изменили несвязанную исследовательскую среду. Проверяйте **Packages** на наличие необходимых библиотек, прежде чем запрашивать установку. Успешный список пакетов - это проверка только для чтения; Он не дает агенту разрешения на изменение внешнего переводчика.

После сбоя в выполнении различают недоступный переводчик, отсутствующий пакет, отклоненный запрос и ошибку кода. Переустановка подходит для сломанной управляемой среды выполнения, а не для каждого неудачного анализа. Если вам нужно воспроизвести результат, сохраните вводную версию и код вместе с деталями времени выполнения.

## Понять основные элементы управления {/* #understand-the-main-controls */}

| Контроль | Цель и граница |
| --- | --- |
| **Recheck** | Обновите обнаруженные переводчики и их статус. На панели показано время последней проверки. Недоступен во время конфликтной работы. |
| **Network settings** | Открытая конфигурация для защиты сети Notebook. Баннер объясняет, ограничены ли сеансы и загрузки пакетов утвержденными доменами. |
| **Let the Agent create environments** | Контролируйте, может ли Агент создавать среды и настраивать недостающие среды выполнения. Отключение этого не удаляет явные настройки пользователя или элементы управления ремонтом. |
| **Add interpreter…** | Откройте исполняемый выборщик системы для существующего переводчика. Выберите фактический исполняемый файл, затем подтвердите его обнаруженный путь и состояние готовности. |
| **Download and set up** | Подготовьте среду, управляемую приложением, когда она отсутствует. |
| **Cancel** во время установки | Запросить отмену запущенной установки. Подождите, пока операция уляжется, прежде чем начинать еще одну. |
| **Retry setup** | Попробуйте неудачную установку после устранения ее причины. |
| **Включить &#91;окружающая среда&#93;** | Сделайте окружающую среду доступной для выбора агента. Отключение среды в использовании может потребовать подтверждения воздействия. |
| **Allow package install** | Отдельное согласие на включенную внешнюю среду Python или R. Согласие R ограничено выбранной личной библиотекой. Перечисление пакетов не требует согласия на установку. |
| **Пакеты &#91;счет&#93;** | Откройте инвентарь установленного пакета для этого переводчика. |
| **Reinstall** | Открытое подтверждение перед восстановлением среды, управляемой приложением. |

## Подключение существующего переводчика {/* #connect-an-existing-interpreter */}

<PlatformContent platform="windows">

Используйте **Add interpreter…** на языке, предназначенном для открытия файловой системы Windows. Выберите фактическую среду `python.exe` или `R.exe`, затем выберите **Open**. Для пути, содержащего пробелы, используйте сборщик файлов или его поле **File name**. Вернитесь в Runtimes, проверьте обнаруженный путь и версию, выберите **Recheck** и включите эту среду. Открытый выбор не означает, что был добавлен переводчик.

</PlatformContent>

### Используйте R, уже установленный на вашем компьютере {/* #use-r-already-installed-on-your-computer */}

Выберите **Recheck** и проверьте обнаруженный путь и версию R. Если ваш интерпретатор отсутствует, используйте **Add interpreter…** для выбора исполняемого файла. **Ready** и **Enable** имеют разные значения: обнаружение подтверждает наличие переводчика; Это позволяет выбрать его агентом.

В R Notebook проверьте `R.home()`, чтобы подтвердить используемую среду. Для установки зависимостей авторизуйте личную библиотеку с помощью [Внешние установки R](#external-r-packages).

<PlatformContent platform="macos">

Обнаруженный путь, такой как `/opt/homebrew/bin/R`, идентифицирует установку системы.

</PlatformContent>

### Зарегистрируйте и используйте внешний Python {/* #register-and-use-external-python */}

<PlatformContent platform="linux">

Системный интерпретатор, такой как `/usr/bin/python3`, может уже отображаться как **Ready**. Включите среду, которую вы собираетесь использовать, прежде чем попросить агента выбрать ее. Обнаруженные ниже интерпретаторы Python отключены, а среда Python, управляемая приложением, не была настроена. Для подготовки управляемой среды используйте **Download and set up**.

![Linux обнаруживает существующие интерпретаторы Python как Ready, с выключенным Enable](/img/open-science/linux/python-detected-disabled.webp)

</PlatformContent>

1. Подготовьте среду Python, которую вы собираетесь использовать.
2. Выберите **Add interpreter…**, выберите исполняемый файл Python и проверьте **Ready**, путь и версию.
3. Используйте **Recheck** для проверки обнаружения, а затем включите эту конкретную среду.
4. Попросите агента выбрать его специально для Notebook.
5. Печатайте `sys.executable` и версию Python, прежде чем полагаться на установленные библиотеки.

<PlatformContent platform="macos">

Если интерпретатор symlink не может быть выбран в файле macOS, выберите фактический исполняемый файл из предполагаемой среды. Подтвердите `sys.executable` после связывания. Используйте стабильный путь установки, а не временный путь скриншота.

</PlatformContent>

#### Разрешение пакета и результат установки {/* #package-permission-and-installation-outcome */}

Для нового пакета во внешней среде Python сначала проверьте **Allow package install**. После предоставления разрешения дождитесь завершения установки и проверьте импорт в той же среде, прежде чем продолжить.

Если установка сообщает `403 Forbidden` или `destination resolves to a non-public network address`, проверьте имя хоста и следуйте за [Сеть](network.md) перед повторным использованием. Эти ошибки касаются доступа к сети и не доказывают, что пакет недоступен. Обеспечить сетевую защиту.

#### Отключить среду, используемую Notebook {/* #disable-an-environment-used-by-a-notebook */}

Выберите переключатель **Enable** и прочитайте активный / холостый счет ядра перед подтверждением. Отключение может закрыть ядро; После повторного включения снова выберите доступное время выполнения для сессии. Эта панель обеспечивает включение / отключение элементов управления, а не отдельное действие **Удалить переводчика**.

## Установка пакетов во внешний R {/* #external-r-packages */}

Используйте его, когда ваш существующий интерпретатор R работает, но нуждается в дополнительном пакете. Приложение предоставляет доступ к одной существующей личной библиотеке, а не к библиотекам системы или сайта.

1. В **Settings → Runtimes** включите предполагаемую внешнюю среду R и подтвердите ее путь/версию.
2. В соответствии с **Personal R package library**, проверьте обнаруженное местоположение или выберите соответствующую библиотеку. Если ни один из них не обнаружен, используйте **Advanced options → Choose library folder…**, чтобы выбрать существующую личную библиотеку, видимую для этого интерпретатора R. Это действие не создает папку.
3. Включите **Allow package install**. Прочитайте выбранный путь перед авторизацией: другие проекты, использующие эту библиотеку, могут видеть изменения установленного пакета.
4. Запросите необходимый пакет через операцию управления пакетами приложения, назвав эту среду R. Следуйте результату установки и любой инструкции перезапуска ядра.
5. Запустите `R.home()`, `.libPaths()`, `library(PACKAGE_NAME)` и `packageVersion("PACKAGE_NAME")` в этой среде, заменив заполнитель пакета. Подтвердите, что предполагаемая библиотека используется до продолжения анализа.

Отключите **Allow package install**, чтобы отозвать согласие на установку. Он не удаляет уже написанные пакеты. Отзыв согласия перед выбором другой библиотеки. Если не существует подходящей папки, подготовьте личную библиотеку R за пределами приложения или используйте среду, управляемую приложением. Не выбирайте системную библиотеку, чтобы обойти неудавшуюся проверку.

## Восстановление пакетов из захваченных замков {/* #conditional-restore */}

Для сохраненного результата откройте **Provenance → Environment** и проверьте захваченный замок. Используйте **Download bundle**, когда вам предлагают. Прочитайте инструкции и предпосылки пакета, прежде чем что-либо восстанавливать.

Внешний R требует доступной установки `renv` и поддерживаемого `renv.lock`; Внешний Python нуждается в существующем блокировке поддерживаемых требований с закреплёнными хэшами. Путь переводчика и список названий пакетов сами по себе недостаточны. Требования к интерпретатору, платформе, архитектуре и управлению пакетами должны соответствовать условиям восстановления.

Извлеките пакет, выберите новый записываемый пункт назначения, которым вы владеете, и запустите его включенный `restore-packages.py` с фактическим интерпретатором и путями назначения, следуя запакованным инструкциям. Сценарий проверяет предпосылки и контрольные суммы перед восстановлением пакетов, а затем проверяет их эффективные версии и пути. Если проверка не удалась, устраните это условие вместо того, чтобы редактировать замок, чтобы добиться успеха. Open-Science не принимает и не удаляет этот внешний пункт назначения.

Это условное восстановление упаковки, а не полный клон среды. Откройте результат и используйте [Воспроизводимость](reproducibility.md), когда для сравнения результатов доступен поддерживаемый захваченный рецепт.

## Проверка окружающей среды с помощью реального анализа {/* #verify-the-environment-with-a-real-analysis */}

Запустите небольшой расчет в выбранной среде, заново откройте его выход и сравните с [Общий базовый уровень](../reference/example-data.md). Следуйте [R Notebook](notebook.md#run-the-same-gene-count-check-in-r) для исполнения и экспорта.

[рабочий процесс качества данных](../workflows/data-quality.md) обеспечивает маршрут Python с использованием существующих зависимостей. Успешный расчет не показывает, что могут быть установлены новые пакеты или перезапущено ядро.

<PlatformContent platform="macos">

![Успешное реальное вычисление Notebook](/img/open-science/guides-walkthrough/46-notebook-result.webp)

</PlatformContent>
Если импорт не удается, проверьте выбранное время выполнения и установленные пакеты. Для загрузки, отклоненной, потому что имя хоста решает на зарезервированный адрес, следуйте [Сеть](network.md). Запуск кода с существующими пакетами не устанавливает возможности установки дополнительных пакетов.

Перед очередным анализом проверьте его требуемые пакеты в выбранной среде. При необходимости используйте поддерживаемую операцию управления пакетами, прочитайте фактический результат, следуйте любым требованиям перезапуска и проверьте импорт. Разрешение, карта прогресса или переводчик Ready не являются тестом на импорт.

Для сохранения результата с неполной средой или доказательствами выполнения откройте **Provenance** и проверьте недостающую информацию. Чтобы подготовить новую версию для проверки воспроизводимости, следуйте [экологическая подготовка](reproducibility.md#prepare-environment). Соответствие численному результату не заполняет отсутствующее происхождение.

### Подтвердить наличие активного переводчика {/* #confirm-the-active-interpreter */}

После подготовки Python или R запустите следующие команды на соответствующем языке Notebook, чтобы проверить его фактическую версию и путь. Настройки могут включать в себя несколько сред; Используйте выход текущего прогона, чтобы идентифицировать используемого.

Python:

```python
import sys
print(sys.version)
print(sys.executable)
```

R:

```r
R.version.string
R.home()
```

Затем прочитайте небольшую таблицу проекта, проверьте ее количество строк и сохраните результат. После повторного открытия приложения запустите проверку еще раз, прежде чем продолжить анализ. Удобочитаемый исторический отчет не означает, что предыдущие переменные в памяти все еще существуют. [Notebook и доказательства казни](notebook.md) для элементов управления Notebook.

## Поддерживать и ремонтировать окружающую среду {/* #maintain-and-repair-environments */}

### Отменить настройку и повторную попытку {/* #cancel-setup-and-retry */}

Во время **Download and set up** выберите **Cancel** и ждите **Режим Runtime отменен**. Выберите **Retry setup**, дождитесь **Ready** и откройте **Packages**, чтобы проверить окружающую среду. Не запускайте вторую установку, пока первая операция еще не завершена.

### Восстановление управляемой среды {/* #reinstall-a-managed-environment */}

1. Сохраняйте необходимые отчеты и записывайте любые добавленные вами пакеты.
2. Выберите **Reinstall** в управляемой среде.
3. Прочитайте уведомление о воздействии, затем выберите **Reinstall runtime**.
4. Подождите **Ready** и проверьте **Packages**.
5. Запустите новую ячейку Notebook и снова откройте сохраненные входы и выходы.

## Опциональный WSL2 Bash Preview {/* #wsl2-preview */}

Windows x64 может использовать дополнительный **Local Shell · WSL2 Bash Preview** в **Settings → Runtimes**. Держите PowerShell, если вашей задаче не нужна оболочка Linux; WSL2 не обязательно использовать Open-Science на Windows.

Выберите дистрибутив WSL2 и его точный некорневой **Linux user**, затем выберите **Save and check**. Сначала следуйте инструкциям по установке платформы / дистрибуции. Проверка готовности и сопоставление ресурсов предварительного просмотра должны пройти до того, как **Use WSL2 Bash** станет доступным; Выбор одного дистрибутива не активирует его. Выполните небольшую команду снаряда и проверьте ее результат, прежде чем начинать более длительную задачу. Используйте опцию PowerShell, чтобы вернуться в оболочку по умолчанию.

Если готовность не удается, сохраняйте заявленную причину и продолжайте работу с PowerShell, решая ее. Установка компонентов WSL может потребовать одобрения администратора Windows. Этот предварительный просмотр отличается от выбора интерпретаторов Python / R Notebook.
