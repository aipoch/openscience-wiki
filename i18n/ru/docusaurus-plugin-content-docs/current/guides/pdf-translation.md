# Перевод полной версии PDF {/* #translate-a-full-pdf */}

Прочитайте статью на другом языке, сохранив оригинал для сравнения. **Full-text translation** подготавливает текст документа, сохраняет переведенные абзацы по мере продвижения работы и сохраняет сохраненные переводы с управляемым PDF. Он не заменяет оригинальный PDF и не проверяет результаты исследования.

## Подготовить бумагу и модель {/* #prepare-translation */}

1. Получите полный PDF и откройте его из [Библиотека](library.md), Reading, Inbox, загруженного вложения или сохраненного файла. Ссылка только на метаданные или реферат не является полнотекстовым PDF.
2. Если необходимо увеличить предварительный просмотр, выберите **Full-text translation** в панели инструментов PDF.
3. Выберите **Prepare full text**. Подождите **Full text prepared**, прежде чем начать перевод. Проверяйте исходные страницы, если текст отсутствует или PDF отсканирован. Приготовление не гарантирует, что была извлечена каждая табличка или таблица.
4. Выберите **Target language**, затем **Translation method** и **Model**. Используйте модель, предлагаемую в качестве доступной пикером.

| метод | Что нужно настроить |
| --- | --- |
| **Agent** | доступной агентской модели, или **Main model** когда поддерживается. В v0.36.0 модели подписки Codex не могут выполнять эту операцию перевода PDF. Выберите совместимую модель перевода без замены модели Main. |
| **Direct API** | Настроенная, доступная модель API. Подписка не может быть использована в качестве прямого API. Видишь? [настройка провайдера](providers.md). |
| **Local model**Когда предлагается | Установите модель через отображаемые элементы управления и подождите, пока она будет готова. Локальный перевод выполняется по одному абзацу за раз. |

Для Agent и Direct API текст документа и глоссарий отправляются на выбранную модель. Проверьте выбранную услугу перед переводом ограниченного материала. На скриншоте показаны элементы управления подготовкой и моделью; Выбранная подписка Codex делает **Translate document** недоступным.

## Перевод и резюме {/* #translate-resume */}

1. Откройте **Translation glossary**, когда технический термин нуждается в согласованной формулировке. Добавьте **Source term** и его **Preferred translation** с **Add term**. Проанализируйте эти термины перед началом.
2. Оставьте **Advanced → Concurrent translations** по умолчанию для первого запуска. Более одновременные запросы могут столкнуться с ограничениями провайдера.
3. Выберите **Translate document**. смотреть перевод статьи граф; Частичный подсчет не является завершенным документом.
4. Чтобы прервать, выберите **Cancel**. Завершенные параграфы сохранены. Используйте **Continue translation** для возобновления сохраненной работы или **Retry**, когда ошибка предлагает это действие. Прочитайте ошибку абзаца перед использованием **Skip and continue**, которая оставляет пробел для рассмотрения.
5. Откройте тот же управляемый PDF и выберите его издание в **Saved translations**. Проверьте **Saved translation parameters**, чтобы подтвердить язык и модель. Чтобы изменить их, выберите **New translation**, а не смешивайте различные настройки в повторную попытку.

Подтвержденные копии одного и того же PDF сохраняют издания в Литературе, Чтении, Входящие и Рабочее пространство. Сопоставление имени файла или DOI само по себе не устанавливает идентичный контент. Этот локальный обмен не синхронизирует переводы на другой компьютер.

## Сравнение и экспорт {/* #compare-export */}

Используйте **Original**, **Translation** и **Compare**, чтобы проверить источник и переведенные страницы, когда они доступны. Проверяйте технические термины, отрицания, количества, единицы и ссылки на цифры в отношении оригинала. Обзор **Translation issues** и любых отрывков, которые сохраняют оригинальный текст; Переведенное количество абзацев не гарантирует, что каждый отрывок соответствует отображаемой странице.

Выберите **Export translated PDF**, сохраните отдельную копию, а затем снова откройте ее в считывателе PDF. Проверьте количество страниц и несколько текстовых и фигурных страниц. Непереведенный контент остается на языке оригинала; Некоторые отрывки сохраняют оригинальный текст в PDF, а их переводы остаются читаемыми на боковой панели. Держите оригинал доступным для цитирования и научной интерпретации.

| Если вы видите | Следующий шаг |
| --- | --- |
| **Подготовьте полный текст перед переводом.** | Полная подготовка и проверка того, были ли найдены соответствующие пункты. |
| **Эта модель по подписке не поддерживает перевод PDF. Выберите другую модель.** | Выберите поддерживаемую модель перевода; Изменение целевого языка не исправит совместимость модели. |
| Ограничение тарифа провайдера или временная недоступность | Подождите, затем повторите с теми же сохраненными настройками. Избегайте запуска дубликатов для одного и того же перерыва. |
| Прогресс не может быть спасен | Откройте PDF, чтобы загрузить последний сохраненный результат, прежде чем продолжить. |

Используйте [PDF аннотации и примечания к документам](pdf-notes.md) для записи вопросов чтения. Перевод и аннотация являются отдельными инструментами.
