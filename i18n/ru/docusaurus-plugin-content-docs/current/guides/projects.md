# Проекты и исходные папки {/* #projects-and-source-folders */}

Проект — это рабочий контейнер для исследовательского вопроса: он группирует сессии, исходные файлы и генерируемые результаты. **Agent Context** предоставляет надежные инструкции для каждой сессии проекта. Начните отдельный проект, когда исследовательский вопрос или разрешенный исходный материал изменится.

<span id="example-prepare-a-systematic-review-reading-pack" />

Для того, чтобы внести существующую исследовательскую запись в этот проект, используйте [Импортировать пакет сеанса](research-packages.md). Импортные сеансы только для чтения; Создайте нормальный сеанс для новой работы.

## Создать проект {/* #create-a-project */}

<p className="example-label"><strong>Практический пример</strong> Подготовьте систематический обзорный пакет для чтения</p>

Примером может служить **PRISMA - Systematic review reading pack**. Он использует опубликованные руководящие документы по отчетности с целью сохранения поддающихся проверке библиографических записей и порядка чтения. Это задача по сбору данных, а не завершенный систематический обзор.

1. Из дома выберите **New project**. В существующем рабочем пространстве меню «Имя проекта» содержит ту же самую запись.
2. Войдите в поля ниже. Сохраняйте библиографические и доказательные правила в **Agent Context**, а не только в Описании.
3. Выберите **Create project**. Подтвердите, что на левой боковой панели отображается название проекта, а на главной панели открывается **New conversation**.
4. Откройте меню «Имя проекта» и **Project settings**, чтобы проверить сохраненные значения. Успешное сохранение проекта отделено от готовности модели.

![Проект PRISMA с явной исследовательской целью и агентным контекстом](/img/open-science/local-acceptance/prisma-project-form.webp)

| Поле или кнопка | Пример или действие | Что меняется |
| --- | --- | --- |
| **Name** | `PRISMA - Systematic review reading pack` | Требуемое отображаемое имя; До персонажей 200. Пустое или только белое пространство не может быть представлено. |
| **Description** | `Build a source-checked reading collection for researchers preparing a systematic review.` | Опционально, вплоть до символов 1,000. Появляется в списке проектов; Он не является агентской инструкцией. |
| **Agent Context** | Используйте инструкции ниже. | Опционально, вплоть до символов 16,000. Включен в новые и возобновленные сеансы агентов и отправлен выбранному поставщику моделей. |
| **Create project** | Сохраните действительную форму. | Создает проект и открывает свое рабочее пространство. Ошибка сохранения остается видимой в форме. |
| **Cancel**, **Close** | Отклоните проект. | Проект не создается. Увольнение является нетрудоспособным, в то время как представление находится на рассмотрении. |
| **Save** В настройках проекта | Сохранить отредактированный проект. | обновление существующего проекта; Он не дублирует свои сессии. |

```text
Use public primary sources. Preserve DOI, title, authors and publication year.
Distinguish bibliographic metadata from claims verified in full text.
Never invent references. Report inaccessible sources explicitly.
Write outputs in English.
```

## Предоставить проекту доступ к исходным файлам {/* #give-a-project-access-to-source-files */}

Создание проекта автоматически не раскрывает папки вашего компьютера. Откройте **Files** и выберите локальную папку, когда вы хотите работать с существующим каталогом. Сборщик папок выбирает местоположение; Последующая строка разрешения определяет разрешенный доступ. Прочитайте выбранный путь и режим доступа перед подтверждением.

Используйте доступ только для чтения при просмотре исходного материала. Сохраните управляемую копию проекта, если вам нужен источник, сохраненный в проекте. Локальный предварительный просмотр файла и управляемая загрузка имеют разные жизненные циклы: перемещение внешнего файла может нарушить исходный путь, в то время как управляемая копия остается в хранилище приложений.

Изменение доступа может вызвать подтверждение Notebook, поскольку активные ядра могут сохранять доступ из своей предыдущей конфигурации. Завершите или прекратите соответствующую работу, прежде чем принять перезапуск ядра. Выбор папки не является доказательством того, что каждый файл в ней был прочитан моделью.

## Изменить или продолжить проект {/* #change-or-continue-a-project */}

Используйте меню «Имя проекта» для переключения проектов. Начните сеанс с **New**, когда следующему расследованию потребуется собственная расшифровка, сохраняя при этом тот же контекст проекта. Использовать **Project settings** для пересмотра инструкций по долговечности; проверить следующий запрос на соответствие пересмотренным правилам, так как уже полученные результаты не обновляются автоматически.

**Download artifacts…** — это выходная операция. Он может быть отключен, если в проекте нет созданных артефактов. Загрузка исходного файла сама по себе не создает сгенерированный результат. Архив завершает работу, когда вы хотите удалить его из активной навигации, сохраняя восстановление через **Settings → Archived**.

## Подтвердить результат и оправиться от проблем {/* #confirm-the-result-and-recover-from-problems */}

| Наблюдение | Толкование и следующий шаг |
| --- | --- |
| Имя проекта появляется, но отправка недоступна. | Создание проекта удалось. Проверить **Settings → Agent** и **Settings → Model** отдельно. |
| Агент игнорирует инструкции, написанные в описании | Переместить инструкции в **Agent Context** Отправьте новый, четкий запрос. Описание - это метаданные организации. |
| Открывается папка, но в письме отказывают | Разрешение только для чтения разрешает проверку, а не модификацию. Сохраните производный артефакт или просмотрите запрашиваемый объем записи. |
| Спасти оставшегося инвалида | Удалите пустые имена и проверьте длину поля; Подождите, если еще один сейф будет готов. |
| Выбирается другой проект | Проверьте название проекта, прежде чем приложить документ или отправить запрос. |

## Установите шаблон оптимизации вопросов {/* #optimization-template */}

Откройте меню имени проекта **Project settings → Advanced agent options → Optimization prompt**. Введите инструкции по переписыванию вопросов в этом проекте, затем сохраните. Оставьте его пустым, чтобы использовать встроенный по умолчанию. Это же поле доступно под **New project → Advanced agent options**.

Это поле работает только тогда, когда вы выбираете **Optimize question**. Он отделен от **Agent Context**, который предоставляет инструкции для агентских сессий проекта, а также **Description**Это для вашей ссылки.

<p className="example-label"><strong>Пример</strong> Сохранить границы учебного вопроса</p>

```text
Rewrite the question in clear English. Preserve the supplied numbers
and the hypothetical scope. Ask for a concise answer with limitations;
do not invent participants, measurements or citations.
```

![Оптимизация заказов в соответствии с расширенными возможностями агента проекта](/img/open-science/v121/optimization-template.webp)

Вернуться в Композитор и [Оптимизировать проект](composer.md#optimize-question). Просмотрите переписанный текст перед отправкой; шаблон - это письменная инструкция, а не правило научной проверки.
