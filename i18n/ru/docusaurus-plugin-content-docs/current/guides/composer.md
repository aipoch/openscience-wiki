# Разговоры и запросы в очереди {/* #conversations-and-queued-requests */}

Композитор отправляет инструкции и входные ссылки на текущую сессию и позволяет вам подготовить последующие действия во время выполнения. **Очередь · Не сохранено** означает, что запрос в очереди еще не стал сохраненной инструкцией транскрипта.

## Начните с исследовательской идеи {/* #research-starters */}

Пустая страница разговора предлагает **Analyze data**, **Compare papers**, **Find literature**, **Create charts** и другие исследовательские стартеры рядом с Композитором. Используйте стрелки, чтобы увидеть больше вариантов.

1. Открыть **New** в намеченном проекте.
2. Выберите стартовый код, такой как **Explain a paper**. Он заполняет Композитор с редактируемым запросом; Выбирая его, вы не посылаете сообщение.
3. Прикрепите фактическую бумагу или данные, дождитесь загрузки и замените общий запрос на ваш вопрос и ожидаемый результат.
4. Проверьте модель, вложения и запрос, затем отправьте. Откройте возвращенные источники и файлы, прежде чем принимать результат.

![Стартеры исследований и компактный импортный пакет исследований в новом разговоре](/img/open-science/v0351/new-conversation.webp)

**Import previous research** - это отдельная запись для пакета `.science`. Выбор стартера исследования не импортирует пакет или не предоставляет примерные данные.

## Подготовьте запрос с проверяемым результатом {/* #prepare-a-request-with-a-checkable-outcome */}

Выберите **New** в проекте и введите запрос в **Ask anything**. Назовите вход, желаемый выход и любые ограничения метода. Для полного примера, следуйте [Ваш первый проект](first-project.md).

| Вступление | Меры | Проверить перед отправкой |
| --- | --- | --- |
| + → Прикрепить файлы | Выберите локальный файл и дождитесь загрузки | Предполагаемый чип присутствует; Перенос не является активным |
| Прикрепление чипа | Предварительный просмотр поэтапного ввода | Имя и содержание соответствуют предполагаемым данным |
| Удалить вложение | Удалить свой проект ссылки | Не удаляет исходный локальный файл |
| + Ваши файлы | Выберите существующий файл проекта | Правильный артефакт/версия, а не просто похожее имя |
| `@` | Выберите файл / артефакт или доступную литературу | Выберите фактическое предложение, чтобы связать ссылку |
| `/` | Выберите доступный Skill | Метод актуален, а предпосылки имеются. |
| `#` | Ссылка на стенограмму сеанса для этого поворота | Не обещает включать все файлы / ядра этой сессии |
| + Сохранить как навык | [Превратите готовую ветку в многоразовый Skill](../skills/create.md) | завершить текущую деятельность; Проверьте подсказку, если она недоступна, и проверьте сохраненный пакет. |
| + → Контекст | Проверка текущего контекста использования | Новые неотправленные сессии могут иметь вход с ограниченными возможностями |
| + Рецензия | Просить пересмотра, когда приемлемая работа существует | Требуется результат и совместимый путь обзора. |

Длинные текстовые пасты над символами 10,000 или строками 300 становятся управляемыми вложениями. **Show in text field** восстанавливает этот текст в редакторе, когда он предлагается. В начале пустого Композитора Up/Down просматривает оперативную историю. Проверьте восстановленные вложения перед отправкой.

## Выберите, как начинается работа {/* #select-how-work-begins */}

Селектор модели выбирает среди настроенных моделей. Варианты его рассуждений зависят от модели/фреймворка. Изменения касаются последующих запросов, а не уже запущенного поворота. **Agent controls** предоставляет режим разрешений, автообзор, выбор Specialist и делегирование; Каждый из них имеет отдельный эффект.

| Отправить контроль | Использовать | Результат/граница |
| --- | --- | --- |
| Отправить сообщение | Недельная сессия, готовый запрос | Сохраните сообщение пользователя и начните выполнение |
| Больше вариантов отправки: план первый | Проверка перед выполнением | Ответить на план до начала утвержденной работы |
| Боковой чат | Обсуждение в независимой вкладке с ограниченными инструментами | Новые проекты наследуют модель разговора и усилия по рассуждению; Проверьте выбор Side Chat перед отправкой. Видишь? [Side Chat](delegation.md) |
| филиал | Независимое продолжение, доступное | Проверка наследственной истории/файлов; смотреть [Сессии](sessions.md) |
| Добавить сообщение в очередь | Подготовьте продолжение во время бега | Отложенный запрос не сохраняется до момента доставки |
| Отмена выполнения | Прекратить текущую казнь | ждать отмены; уже сохраненные результаты не отменяются автоматически |

## Отправляйте точные отзывы {/* #send-precise-feedback */}

<p className="example-label"><strong>Пример</strong> Запросить входные и выходные проверки в плане</p>

Если в плане отсутствует целостность источника или проверка выхода, запросите его перед утверждением. Адаптируйте требования к выходу ниже к вашей задаче:

```text
Add an explicit before/after SHA-256 check and reopen all three saved
outputs. Use compact sample labels in the plot, and include their exact
original column-name mapping in the CSV/report.
```

Это было представлено через **Respond to Plan → Send Plan feedback**, после чего был утвержден пересмотренный план. Это не была демонстрация доставки очередей. См. [Планирование](planning.md) для фактических элементов управления и скриншотов.

Для выполнения задачи используйте очередь, когда вам нужно изменить следующую инструкцию. Укажите, какие изменения и что еще требуется. Обновление сообщения само по себе не разрешает установку нового запрошенного пакета или более широкий доступ к файлам.

## Управляйте очередью выполнения задачи {/* #manage-a-running-tasks-queue */}

1. Задайте вопросы, пока работа активна.
2. Выберите **Add message to queue**, затем расширьте его количество, чтобы прочитать ожидающий текст.
3. Используйте **Edit queued message**, чтобы вернуть его в состав. Сохраните/очистите существующий проект, если приложение запрашивает.
4. **Remove queued message** удаляет отложенный элемент, а не уже доставленную инструкцию.
5. Перетащите рукоятку перезаказа. Для переупорядочения клавиатуры нажмите **Космос**, чтобы забрать элемент, **Вверх/вниз**, чтобы переместить его, а затем **Космос**, чтобы отбросить его.
6. **Send now** запрашивает доставку через поддерживаемый фреймворк.
7. Подтвердите, что текст отображается как сообщение пользователя, и агент признает изменение.

Читайте **Sending…**, **Stopping…** или **Очередное сообщение будет отправлено после окончания текущего пробега**. Некоторые рамочные государства откладывают доставку. **Не спасли** означает, что текст еще не является прочным транскрипционным сообщением. Сохранение важных текстов до закрытия/перезагрузки. Предупреждение о ветвях означает, что очередь принадлежит другому пути сообщения. Устраните ошибку отправки по существующему пункту перед добавлением дубликатов.

### Редактировать и переупорядочивать последующие действия, пока пишется отчет {/* #edit-and-reorder-follow-ups-while-a-report-is-being-written */}

Для пересмотра нескольких очередей сообщений отредактируйте предполагаемый запрос, скорректируйте его порядок, а затем удалите любой запрос, который вам больше не нужен:

1. Выберите **Edit queued message** рядом с предполагаемым объектом. Он перемещается в Композитор и временно покидает очередь.
2. Пересмотрите текст и выберите **Add message to queue**. Проверить его положение еще раз; Отредактированный запрос может вернуться в конце.
3. Чтобы переместить запрос раньше, нажмите на ручку **Переупорядоченное сообщение**, нажмите **Космос**, используйте клавиши со стрелками, а затем снова нажмите **Космос**.
4. Используйте **Remove queued message** рядом с напоминанием или инструкцией, которая вам больше не нужна.
5. После доставки проверьте сохраненную расшифровку для окончательного текста и заказа. Удаленные запросы не должны отображаться в виде предоставленных инструкций.

![Два оставшихся запроса после редактирования и переупорядочения](/img/open-science/local-todo-batch/14-queue-reordered.webp)

Проверьте, что доставленные ответы следуют отредактированным содержимым и порядку. Предметы с маркировкой **Не спасли** не вошли в сохраненную расшифровку; скопировать важный неотправленный текст перед закрытием или перезагрузкой.

**Exit queued editing** завершает режим редактирования очереди и оставляет текст в Композиторе. Редактирование удаляет исходный элемент из очереди, поэтому выход не возвращает его. Чтобы сохранить его, проверьте черновик и добавьте его в очередь еще раз; Чтобы отбросить его, очистите проект.

### Сохранить вложения при редактировании {/* #preserve-attachments-when-editing */}

Когда в очередь запрос включает файл, подтвердите, что его чип вложения все еще присутствует каждый раз, когда вы повторно открываете редактор. Измените инструкции, затем выберите **Add message to queue**. После доставки сравните файл, показанный в сохраненном сообщении пользователя, с предполагаемым вводом. Попросите контрольную сумму файла, когда точная личность файла имеет значение.

![Отредактированный запрос на вложение, доставленный с его файлом и контрольной суммой](/img/open-science/sept11-completion/queue-result.webp)

### Очередь привязанности становится недоступной {/* #a-queued-attachment-becomes-unavailable */}

Если отредактированное сообщение в очереди останавливается на **Управляемый файл или его сессия удаляются.**, проверьте его фишки вложения и исходный файл в файлах. Сохраните текст запроса, повторно прикрепите текущий файл в новом обычном сообщении и повторите попытку. Избегайте многократной отправки одной и той же устаревшей ссылки на вложение. Сохраняйте ошибку и идентификатор файла для диагностического отчета, если новое вложение также не работает.

## Читать активность и завершение {/* #read-activity-and-completion */}

Расширьте карту инструмента для проверки ее аргументов, кода и вывода. После завершения откройте каждый запрашиваемый результат. Если шаг не удался, используйте свою первую ошибку, чтобы выбрать действие восстановления в [устранение неполадок](troubleshooting.md).

**Show more** расширяет длительный пользовательский запрос. **Copy message** и Code Copy управляют копированием соответствующего контента. **Scroll to end** возвращается к последнему событию Рабочие столы с ходовыми знаками перескакивают между подсказками в долгом разговоре. Редактирование более раннего сообщения пользователя создает доработку; Используйте [Сессии](sessions.md), чтобы понять выбранный путь.

| Проблема | Следующая проверка |
| --- | --- |
| Отправить инвалида | Пустой текст, неполная загрузка или недоступное состояние сессии |
| Редакция отказала | Существующий проект композитора должен быть сохранен / очищен. |
| Оригинальный анализ продолжается | Подтвердить доставку обновлений по сравнению с отложенным состоянием |
| Задание ждет после утверждения плана | Отдельное разрешение на использование инструмента все еще может быть отложено |
| Модель говорит: Сделано, но инструмент не сработал | Проверить первый отказ и фактически сохраненные артефакты перед принятием. |

## Копирование, загрузка или расширение таблицы ответов {/* #copy-download-or-enlarge-an-answer-table */}

Наведите курсор или сфокусируйте таблицу ответов, чтобы показать **Стол для копирования** (Markdown, CSV или TSV), **Скачать таблицу** (CSV или Markdown) и **Посмотреть Full Screen**. Выберите нужный формат, подтвердите пункт назначения и снова откройте файл для проверки строк и заголовков. Эти действия экспортируют существующий ответ; Они не перезапускают Connector или не создают управляемую версию артефакта.

![Возвращенная таблица метаданных в полноэкранном виде](/img/open-science/guides-walkthrough/60-response-table.webp)

Для длительной работы используйте [Фоновые задачи](notebook.md#background-tasks-and-result-delivery), чтобы открыть или отменить конкретный запуск. Последующее наблюдение - это ожидающая инструкция; фоновая задача уже допущена к работе. Закрытие списка задач не останавливает выполнение.

## Бросьте файлы в разговор {/* #conversation-drop */}

Вы можете перетаскивать локальные файлы в область разговора, а не только в Композитор. Подождите, пока чипы вложения и любая загрузка закончатся, проверьте имена файлов, а затем отправьте запрос. Сбрасывание файлов не отправляет сообщение. Чтобы импортировать пакет исследований `.science`, используйте **Import previous research** на пустой странице разговора. См. [Исследовательские пакеты](research-packages.md).
