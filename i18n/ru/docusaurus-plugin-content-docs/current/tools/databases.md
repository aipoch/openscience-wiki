# Научные базы данных {/* #scientific-databases */}

Используйте эту страницу, чтобы выбрать источник данных, понять, что он может вернуть, и сделать свои инструменты доступными в Open-Science. Примеры пошаговых исследований со скриншотами и выходными файлами см. в [Исследовательские процессы](#database-workflows).

## Что вы можете сделать {/* #database-capabilities */}

| Исследовательская задача | Начнем с | Типичный выход |
| --- | --- | --- |
| Найти документы, отследить цитаты и проверить отношения DOI | Литературный график, PubMed, bioRxiv | Литературные записи, идентификаторы, ссылки на цитирование и полнотекстовая доступность |
| Найти гены или белки и сравнить последовательности | Гены и онтологии, геномы | Картографирование идентификаторов, белковые записи, отчеты FASTA и BLAST |
| Откройте для себя общедоступные данные омики и проверьте доступные файлы | факультативный; По умолчанию: 5 | Изучение/запуск метаданных и кадастров файлов с указанием мест, размеров и имеющихся контрольных сумм источников |
| Интерпретировать список генов или проверить сеть взаимодействия. | Гены и онтологии, белковая аннотация | Таблицы обогащения, онтологические аннотации и сетевые записи |
| Проверить варианты, выражения и нормативные доказательства | Варианты, клиническая геномика, генетика человека, экспрессия, регуляция | Записи источников с организмом, тканью, справочной сборкой и соответствующими полями доказательств |
| Ретривное соединение, структура или записи клинических исследований | Химия, ChEMBL, структуры и взаимодействия, клинические испытания | Химические идентификаторы/свойства, структурные записи и метаданные испытаний |

Для преобразования пакетных идентификаторов **Гены и онтологии** добавляет `submit_uniprot_id_mapping`, `get_uniprot_id_mapping_status` и `get_uniprot_id_mapping_results`. Сохраните идентификатор вакансии, проведите опрос с интервалом не менее трех секунд, а затем извлеките каждую страницу результатов. Сохраняйте отображения один-ко-многим и явный `failed_ids`; Отсутствовать на одной странице не значит быть непревзойденным. Сервис принимает до идентификаторов 100,000 и истекает через семь дней. Смотрите [Точные картографические поля](../reference/connector-operations.md#submit_uniprot_id_mapping).

**Зенодо** раскрывает метаданные публичных записей без аутентификации. Сохраняйте идентификатор записи для конкретной версии и поля доступа / лицензии с инвентарем файлов. **ГДК** раскрывает общедоступные метаданные; Манифест не является авторизацией загрузки, а контролируемые файлы требуют разрешения GDC. [Операции GDC](../reference/connector-operations.md#family-24) · [Операции Zenodo](../reference/connector-operations.md#family-25).

Реакция базы данных может поддерживать этап исследования; Он не загружает данные автоматически, не добавляет каждую статью в библиотеку литературы и не проводит полный анализ. Укажите, какие записи и файлы вы хотите сохранить.

## Подключитесь и начните использовать базу данных {/* #connect-database */}

<span id="retrieve-a-record-and-verify-its-identity" />

### 1. Включите встроенный Connector {/* #1-enable-the-built-in-connector */}

1. Откройте **Settings → Connectors** и найдите семейство, указанное выше, например **факультативный; По умолчанию: 5**.
2. Откройте его детали и расширьте **Tools**. Ознакомьтесь с входами выбранной операции, лимитами результатов и требованиями третьих сторон.
3. Включите доступность для **Главный агент** и проверьте **Used by**. Используйте **Manage access** на ресурсе для настройки ассоциаций Main Agent и Specialist. Политика в отношении наличия и утверждения каждого инструмента представляет собой отдельный контроль.

![Omics Archives детали инструмента, показывающие входы GEO и область применения только для метаданных](/img/open-science/guides-walkthrough/36-omics-tools.webp)

Эти коннекторы встроены в Вам не нужно добавлять пользовательский сервер для них. Для внешнего сервиса, которым вы управляете самостоятельно, см. [Настройка Connector](../guides/connectors.md). Перечисленный или включенный Connector не является доказательством успеха аутентификации или запроса.

<span id="connect-openalex-and-follow-citation-links" />

### 2. Добавляйте учетные данные, когда операция требует их {/* #2-add-credentials-when-the-operation-requires-them */}

| Обслуживание или состояние | Где его настроить |
| --- | --- |
| OpenAlex | Опциональный ключ. Чтобы настроить один, откройте **Settings → Connectors → Literature Graph → Manage credentials → OpenAlex**Оправдайте его, а затем спасите. |
| Прямые варианты запросов NCBI, требующие контактной информации | **Settings → Connectors → Manage credentials → Literature access**. Заполнить **Contact email** и выберите **Save**. Ключ NCBI API является необязательным. |
| Еще одна операция с требованием к учетным данным | Следуйте требованиям этого инструмента и [Руководство по учетным данным](../guides/connectors.md). Привяжите учетные данные к предполагаемой услуге. |

Введите ключи в форме учетных данных, а не в запросе на исследование или общем выходном файле. Настройка требований к выбранной операции; Вышеприведенное требование к контактной электронной почте не означает, что каждый инструмент NCBI имеет одно и то же требование.

Литературный Граф также предлагает `crossref_get_work`, `crossref_get_updates`, `datacite_search_records` и `datacite_get_record`. Эти четыре метода не требуют ключа OpenAlex. Для направления цитирования OpenAlex `openalex_citations` находит работы, ссылающиеся на работу, а `openalex_references` находит работы, которые он цитирует. [График литературы Параметры](../reference/connector-operations.md#family-2).

### 3. Подтвердите доступ с помощью небольшого запроса {/* #3-confirm-access-with-a-small-query */}

Включите **Гены и онтологии**, откройте разговор с подключенной моделью и отправьте:

<p className="example-label"><strong>Пример</strong> Проверьте известный идентификатор гена человека</p>

```text
Use Genes & Ontologies query_genes to resolve TP53 with scopes="symbol",
species="human" and fields="symbol,name,entrezgene". Return the input query,
matched records and any unmatched identifiers. Keep the response in English.
```

Проверьте фактический результат инструмента. Для человека TP53 проверьте `query`, `symbol`, Entrez Gene **7157** и имя **опухолевый белок p53**. Сохраняйте несколько совпадений, пока не подтвердите организм и не запишите. Успешный запрос подтверждает эту конкретную операцию; Он не обеспечивает доступ ко всем источникам. [Точные поля](../reference/connector-operations.md#query_genes).

## Правильно используйте возвращенные данные {/* #database-limits */}

- Сохраняйте запрос, источник, организм, ткань, единицы и версии присоединения. Записи баз данных, прогнозы и полученные резюме являются различными видами доказательств.
- Проверьте обратные подсчеты, флаги пагинации и усечения, прежде чем рассматривать ответ как полный. Нулевые совпадения, частичный ответ и ошибка запроса требуют различных последующих действий.
- Инвентарь файлов предоставляет местоположения и метаданные. Загрузка байтов, проверка контрольных сумм и анализ данных являются отдельными операциями.
- Если запросу нужны учетные данные, заполните соответствующую форму перед повторным использованием. Для ограничения тарифов следуйте за задержкой услуги; Для тайм-аутов уменьшите размер запроса. Смотрите [устранение неполадок](../guides/troubleshooting.md).

### Частоты населения и сети взаимодействия {/* #string-network */}

Для `get_variant` установите `include_populations: true` только тогда, когда нужны данные о населении. Сохраняйте набор данных и сборку ссылок. Наблюдения экзома и генома остаются отдельными. Недоступное значение - `null`, а не ноль. Перекрывающиеся популяционные или половые слои не должны суммироваться. Это наблюдаемые частоты, а не фильтрующие частоты аллелей. [Параметры Гномада](../reference/connector-operations.md#get_variant)

Из v0.31.0 `get_string_network.nodes` включает в себя возвращенные соседи и изолированные отображенные входы. - единый отображаемый входной запрос соседей; Несколько отображенных входов не расширяются. Фильтр `is_query` для восстановления входных узлов и использование `queries` для всех отображенных псевдонимов. `n_nodes` подсчитывает график; `n_mapped` подсчитывает входные отображения. Обновляйте сценарии, которые приравнивали два, прежде чем повторно использовать их. [Параметры стринга](../reference/connector-operations.md#get_string_network)

## Поиск последовательности и выравнивание {/* #sequence-tools */}

**ГММЕР** обеспечивает программно-специфическую белковую последовательность, профиль-HMM и поиск выравнивания. Выберите программу и базу данных вместе, сохраните идентификатор задания и получите результаты только после **Успех**. [Операции МММЕР](../reference/connector-operations.md#family-26).

**InterProScan** извлекает аннотации для существующей работы, представленной через службу EMBL-EBI. Держите свой идентификатор работы, проверьте статус с интервалом не менее десяти секунд и возьмите TSV после **Окончательно**. Connector не может найти новую работу. [Операции InterProScan](../reference/connector-operations.md#family-27).

**Genomes → Clustal Omega** выравнивает, по меньшей мере, три уникальные записи белка, ДНК или РНК FASTA. Настройте контактное электронное письмо, запрошенное службой, отправьте один раз, сохраните идентификатор вакансии, затем проверьте статус и сохраните возвращенное выравнивание.
