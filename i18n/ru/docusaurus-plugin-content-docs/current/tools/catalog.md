# Научный каталог инструментов {/* #scientific-tool-catalog */}

Используйте этот каталог, чтобы найти точку входа Open-Science и требования к времени выполнения для научного метода. Это индекс документации, а не страница приложения, которая устанавливает каждую перечисленную программу.

## Семьи программного обеспечения и где они работают {/* #software-families-and-where-they-run */}

| Семейство программного обеспечения | Запись Open-Science | Настройка для проверки | Полезная первая проверка |
| --- | --- | --- | --- |
| Стандартная библиотека Python и графика | Сессия Notebook | Выбранный интерпретатор Python; построение зависимостей | Читайте настоящий QC CSV и создайте небольшой сюжет |
| R/база R | Сессия Notebook; Настройки → Runtimes → R | Включенный управляемый или обнаруженный интерпретатор приложений | Печать версии R и воспроизведение резюме образцов |
| Структурно-предсказательные рамки | Релевантный пакет Skill, обычно вычисляемый | Совместимые GPU, пакеты, весы, формат ввода и внешний доступ MSA при использовании | Одна небольшая действительная последовательность/комплекс и ее выходная уверенность |
| Программы последовательного проектирования MPNN | ProteinMPNN / LigandMPNN / SolubleMPNN Skills | Репозиторий / контрольные точки и зависимости Python; Маленькие рабочие места ЦП поддерживаются этими инструкциями. | Один костяк с явными фиксированными / конструктивными положениями |
| Одноклеточные рамки | scGPT / scvi-tools Skills | AnnData, ячейки/гены, пакеты и подходящие вычисления | Проверять входные размеры и требуемые слои перед тренировкой |
| Молекулярная структура рендеринга | Молекула Connector / молекулярный зритель | Встроенный автономный маршрут OpenChemLib | Сохраните и откройте aспирин.mol |
| Файловые рендереры | Предпросмотр файла | Поддерживаемые ограничения на расширение и предварительный просмотр | Откройте фактически загруженный файл |
| Удаленное пакетное программное обеспечение | Вычислительный хост и удаленный компьютер Skills | Доступ к хосту, планировщик и названная среда | Проверка хозяина с последующей ограниченной работой |

См. [Директория Skill](../skills/directory.md) для полной таблицы методов 24-Skill. На этой странице объясняется готовность программного обеспечения; Он не дублирует все процедуры Skill.

## Проверить выбранную среду {/* #inspect-the-selected-environment */}

Используйте **Settings → Runtimes** для проверки доступных переводчиков Python/R. Выберите время выполнения, фактически связанное с сеансом, а затем проверьте пакеты там. Исполняемый файл, установленный в другом месте на компьютере, не является автоматически активным интерпретатором Notebook.

Используйте [Среды выполнения](../guides/runtimes.md) для подготовки интерпретатора и [Notebook](../guides/notebook.md) для проверки вычисления. Если необходимы дополнительные пакеты, проверьте установку и импорт в этой среде. Для сбоя загрузки следуйте [Сеть](../guides/network.md), используя затронутое имя хоста и ошибку.

## Прежде чем следовать команде установки модели {/* #before-following-a-models-install-command */}

Прочитайте точные требования Skill и поддерживаемый маршрут настройки выбранной среды. Проверяйте совпадения названий пакетов: **честность** и реализация Biohub **эсм** отличаются друг от друга, хотя они разделяют пространство имен `esm`. Код и вес загруженной модели также могут иметь различные версии и условия доступа.

Для локального Notebook используйте поддерживаемый поток управления пакетами в [Научные инструменты](./scientific.md). Для удаленного хоста используйте [Дистанционные вычисления](../guides/remote-compute.md). Рендер, отображающий PDB, доказывает, что он может просматривать структуру. Это не доказывает, что AlphaFold или другая программа предсказания установлена.

Ссылка на осуществление: [manifest.json](https://github.com/aipoch/open-science/blob/v0.26.0/resources/skills/manifest.json), [SKILL.md](https://github.com/aipoch/open-science/blob/v0.26.0/resources/skills/fair-esm2/SKILL.md), [Блокнот-runtime.ts](https://github.com/aipoch/open-science/blob/v0.26.0/src/shared/notebook-runtime.ts).

Используйте [Фоновые задачи](../guides/notebook.md#background-tasks-and-result-delivery) для отслеживания поддерживаемых длительных работ и проверки полученных результатов. Научные пакеты по-прежнему должны быть доступны в выбранное время выполнения.
