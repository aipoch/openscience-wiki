# Поиск в Интернете и чтение источников {/* #search-the-web-and-read-sources */}

Используйте встроенный **Open-Science Agent** для поиска общедоступных веб-страниц и чтения их текста в разговоре. Это полезно для поиска руководящих принципов отчетности, документации по программному обеспечению и объявлений об исследованиях. Для библиографических записей и полнотекстовых документов также используйте [Научные базы данных](databases.md) и [Библиотека](../guides/library.md).

## Начните с вопроса {/* #start */}

1. В **Settings → Agent** выберите **Open-Science Agent**. Подключение поддерживаемой модели Main в **Settings → Model**; Подписка Codex может предоставить модель.
2. Откройте разговор о проекте. Укажите, что вы хотите найти, какие источники расставить приоритеты и какие ограничения даты. Попросите агента прочитать соответствующую страницу, прежде чем отвечать.
3. Если появляется одобрение, проверьте поисковый запрос, диапазон времени, предел результата и фильтры домена. Утвердить только предполагаемый запрос. Одобрение на чтение страниц касается URL-адреса назначения.
4. Расширяйте активность инструмента и проверяйте возвращенные источники. Следуйте цитатам ответа обратно к доказательствам, прежде чем использовать его утверждения.

Пример запроса:

```text
Find the official PRISMA 2020 checklist page on the public web.
Read the relevant official page and explain what the checklist is for.
Give the source URL and distinguish the webpage text you read from any
linked PDF you did not open. Keep the answer in English.
```

Встроенный поиск отправляет запросы в **Исх.** без необходимости использования учетной записи Exa. Чтение страницы связывается с ее сайтом. Ваш режим разрешения по-прежнему применяется, и отмена не может отозвать уже отправленный запрос. Не включайте конфиденциальные данные исследования в общедоступный поисковый запрос.

## Читайте доказательства, а не только фрагмент {/* #read-sources */}

Результат поиска — это фрагмент страницы. Попросите Agent прочитать выбранную страницу и процитировать материал, подтверждающий ответ. Поддерживаются общедоступные HTML, Markdown и обычный текст. Инструмент не входит в учётные записи, не использует файлы cookie браузера и не выполняет JavaScript сайта. Для статей и вложений используйте процедуры PDF и Library; не считайте вводную HTML-страницу полным текстом статьи.

Когда возвращенный текст усечен, попросите Агента продолжить чтение отрывка сохраненной страницы, прежде чем делать выводы. Сохраненный источник отражает то, что было извлечено в то время. Попросите свежий выбор, когда текущие формулировки имеют значение. Сохраненные источники могут следовать за филиалами сессии и приемлемым экспортом исследовательского пакета; Это не архивирует весь сайт.

## Если источник не может быть прочитан {/* #recover */}

- Для ограничения скорости дождитесь указанного интервала перед повторным использованием. Не отправляйте неоднократно один и тот же неудавшийся запрос.
- Если требуемый фильтр не поддерживается, сохраните это требование и выберите другой источник или маршрут поиска. Не стоит молча расширять поиски.
- Для стены входа, заблокированной страницы или неподдерживаемого типа файла откройте официальный источник самостоятельно и предоставьте доступный разрешенный файл, когда это необходимо. Не описывайте непрочитанную страницу как проверенное доказательство.

Для поиска и скрининга исследовательских работ, продолжайте с [Ориентированный поиск литературы](../workflows/focused-literature-search.md).
