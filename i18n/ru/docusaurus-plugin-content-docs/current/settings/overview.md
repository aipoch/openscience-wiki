# Обзор настроек {/* #settings-overview */}

Откройте **Settings** из левого нижнего угла рабочего пространства. Его панели 17 организованы в четыре группы: **Intelligence**, **Connections**, **Workspace** и **System**. Выберите панель по назначению или поиск из заголовка. В этих руководствах **Settings → Model**, например, относится к панели «Модель» внутри Интеллекта.

| Глобальный контроль | поведение |
| --- | --- |
| `Back` / `Forward` | Перемещайтесь между основной панелью настроек и ее подпросмотрами «Деталь», «Добавить» или «Импортировать» |
| Кнопка Breadcrumb Back | Возвращение из подвида в его основную панель |
| `Maximize` / `Restore` | Переключение между большим диалогом и полноэкранными настройками |
| `Close settings` | Возврат к исходному проекту и сеансу без потери настроек, которые были успешно сохранены. |
| `Dismiss settings error` | Закройте баннер ошибки; Неудавшаяся операция не перепроверяется автоматически. |
| Мобильная навигация | Откройте или закройте навигационный ящик Настройки |

## Найдите настройки {/* #find-a-setting */}

1. Откройте настройки и сфокусируйте **Search settings** в заголовке. **&lt;unk>K** на macOS или **Ctrl+K** на Windows/Linux фокусирует этот поиск, пока Настройки активны.
2. Введите имя панели или задачу, такую как `Package mirror`, `Main model` или `Diagnostics`.
3. Используйте **Вверх/вниз**, чтобы выбрать результат, и **Входить**, чтобы открыть панель, или нажмите на результат. Панель назначения выделена кратко; Найдите там названную установку.
4. Используйте **Back** для возврата. Очистите запрос для поиска другой настройки. Собственный поиск панели фильтрует свой список, а не ищет все настройки.

Этот поиск охватывает репрезентативные настройки на каждой панели, а не на каждом поле или исследовательском документе. Если термин не совпадает, используйте название панели или навигационные группы ниже. Для поиска разговоров или файлов закройте Настройки и используйте [Глобальный поиск](../guides/navigation.md).

:::info&#91;Как сохраняются настройки&#93; Некоторые переключатели сохраняются немедленно. Более длинные формы используют `Save`, `Add` или `Import`. Не закрывайте приложение, пока показаны `Saving…`, `Testing…` или `Installing…`. Миграция, удаление, удаление и действия с широким разрешением требуют подтверждения. :::

## Закладки параметров модели {/* #model-tabs */}

В **Model** используйте **Conversation models** для поставщиков и моделей задач, **Classification models** для дополнительного выбора Skill / Connector и **Local parsing models** для локальных ресурсов анализа. Классификация - это вкладка в настройках модели, а не дополнительная панель настроек верхнего уровня. Смотрите [Классификация](../guides/models.md#classification-models).
