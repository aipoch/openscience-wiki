# Выпускные примечания · v1.0.4

Выпущено на **2026-10-27 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.0.4).

## Подключите другие инструменты к рабочему столу {/* #mcp */}

Отдельный CLI обеспечивает адаптер MCP для внешних клиентов. Сначала запустите аутентифицированный локальный сервис, а затем подключите клиента к этому профилю. Инструменты могут создавать проекты, изменять конфигурацию и проводить исследования в соответствии с существующими разрешениями, включая расходы на записи и модели. [Настройка MCP и элементы управления](../reference/cli.md#external-mcp).

## Проверьте уведомления о публикации статьи {/* #publication */}

В Библиотеке ссылка с действительным DOI может быть проверена вручную для опровержений и исправлений через Crossref. Результаты сохраняют источник и время проверки. Пустой результат не является гарантией того, что бумага не затронута. [Проверить и интерпретировать уведомления](../guides/library.md#publication-checks).

## Держите повседневную работу управляемой {/* #workspace */}

- Промежуточные сообщения и группы инструментов; поиск и аннотации могут раскрывать их содержимое. [Расширить разговор](../guides/sessions.md#collapsed-conversation).
- Сохраните файл из авторизованной папки как неизменный артефакт разговора. [Импорт локальных файлов](../guides/files.md#import-local-artifact).
- Закладка отсканированного репозитория навыков GitHub для повторного использования; он не обновляет навыки автоматически. [Сохраненные репозитории](../skills/manage.md#saved-repositories).
- Вопросительные карточки содержат явные **Skip** и **Skip all** действия. [Контроль вопросов](../guides/composer.md#skip-question).

Загрузки меньше. Исправления охватывают стандартное исполнение Windows Notebook, экспорт пакетов в ожидании выбора места сохранения, диалоги доступа к папкам, восстановление вопросов и презентацию событий повторного воспроизведения. [Передача пакетов](../guides/research-packages.md#local-package-transfer) · [Предыдущий выпуск: v1.0.3](v1.0.3.md).
