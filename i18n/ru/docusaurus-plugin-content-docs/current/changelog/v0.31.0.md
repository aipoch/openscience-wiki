# Changelog - v0.31.0 {/* #changelog--v0310 */}

Выпущен сентябрьский 18, 2026. Этот релиз добавляет независимые копии сеанса и улучшает непрерывность при восстановлении разговора или соединения.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [Изменения после v0.30.2](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## Продолжить и проверить сеанс {/* #continue-and-inspect-a-session */}

- **Fork** создает письменную настольную копию с ветвями разговора, записями Notebook, версиями артефактов, литературой, аннотациями и частными закладками. Он присваивает новые личности и сохраняет источник. Сами импортные сессии остаются только для чтения. См. [Вилочный переход](../guides/sessions.md#fork-session) и [исследовательские пакеты](../guides/research-packages.md).
- Заголовок сессии открывает [Информационная карточка](../guides/sessions.md#session-information) с его исходным кодом, счетами и контролем пин-кодов. Продолжение разговора связывает его с поворотом источника.
- [Сессионный план](../guides/planning.md#resume-plan) сохраняет идентичность, доработку и ожидает одобрения после реконструкции контекста. Восстановление не означает, что отложенный шаг был одобрен или запущен.

## Измененная настройка и поведение данных {/* #changed-setup-and-data-behavior */}

| Область | Что проверить |
| --- | --- |
| Настройки провайдера | Редакции проверяются до того, как они заменят сохраненную конфигурацию; Доступность обновления отказов Runtime. [Настройка поставщика](../guides/providers.md#validated-provider-save) |
| Windows R | Стандартное исполнение больше не требует настройки защищенного режима. Защищенное исполнение имеет отдельные требования. [Среды выполнения](../guides/runtimes.md) |
| гномада | Запрос `include_populations: true` для подсчета населения и частот; Сохраняйте набор данных, создайте и качественные фильтры. [Параметры](../reference/connector-operations.md#get_variant) |
| Название продукта | В интерфейсе используется Open-Science. Сохранены существующие места установки, настройки и данные; Не переименовывайте папки хранения в соответствующие. [Монтаж](../guides/installation.md#product-name) |

**Изменение совместимости:** `nodes` теперь описывает полный возвращенный график, включая добавленные соседи. Фильтр `is_query` для отображенных входов и использование `queries` для всех входных псевдонимов. Не используйте `n_nodes` в качестве количества представленных белков. [Направления по стрельбе](../tools/databases.md#string-network)

Другие исправления охватывают изменения, отмену и продолжение аргументации Codex, вторичные присоединения UniProt, идентификаторы Ensembl, право на участие в клинических испытаниях и знаменатели cBioPortal. Используйте официальный релиз для полного списка.

Следующий выпуск — [v0.31.1](./v0.31.1.md).
