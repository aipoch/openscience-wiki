# Changelog - v1.3.3 {/* #changelog--v133 */}

Выпущен **2026-11-22 UTC**. [Официальный релиз Notes](https://github.com/aipoch/open-science/releases/tag/v1.3.3).

## Обновления, которые соответствуют вашей работе {/* #updates */}

Приемлемые официальные стабильные установки macOS могут установить подготовленное обновление при выходе из системы. Windows и Linux могут подготовить обновления для следующего запуска, пока рабочий стол не работает в фоновом режиме. Автоматическая загрузка требует неограниченного, неизмеренного подключения и достаточного хранения; Неподдерживаемые места установки и каналы сохраняют ручной путь. Обновления Linux AppImage сохраняют путь приложения, а стабильные обновления Windows могут использовать компактные дельты. [Автоматические и ручные обновления](../guides/installation.md#update-progress).

Установленные приложения macOS и Windows меньше. Офлайновая среда выполнения npm поставляется в комплекте с Node 22, уменьшая количество свободных файлов.

## Встроенный агент — это дефолт везде. {/* #agent */}

Новые проекты и сессии по умолчанию для **Open-Science Agent**, включая чистые установки CLI и SDK. Отсутствующий внешний агент SDK больше не препятствует запуску этих установок. Установите внешний фреймворк только тогда, когда вы решите его использовать. Доступ к модели по-прежнему нуждается в конфигурации. [Подстава агента](../guides/frameworks.md#built-in-agent) · [Настройка CLI](../reference/cli.md#terminal-setup).

Настройки восстанавливают ярлыки к установленным Skills, специалистам и коннекторам. В каталоге Bailian добавлено семейство qwen4, а его план по умолчанию изменился на предварительный просмотр qwen4. Проверьте модель, доступную для вашей учетной записи, перед началом работы.

## Редактировать изображения в разговоре {/* #images */}

Введите **Edit image** из предварительного просмотра и напишите редактирование в разговоре композитора. Навигация и сравнение версий изображений остаются доступными, а разговор остается на месте при вводе редактирования. Детали изображения идентифицируют ядро Notebook за редакцией. [Шаги редактирования изображений](../guides/image-generation.md#edit).

Перевод PDF лучше пересоединяет текст, разделенный на столбцы, подписи и встроенные формулы, и избегает вытеснения обозначений, форм этикеток и соседней графики. Продолжить проверку экспортированных страниц на оригинал. [Перевод PDF](../guides/pdf-translation.md#scientific-layout).

## Более явные сбои и восстановление {/* #recovery */}

- Ошибки запроса, загрузки, вложения, импорта и Notebook объясняют их причины. Ошибки провайдера сохраняют свою классификацию и идентификатор запроса при перезапуске; Остановленная работа отличается от безответного продолжения. [устранение неполадок](../guides/troubleshooting.md#provider-errors).
- Windows сохраняет отложенный встроенный вопрос Агента при перезапуске, восстанавливает статус выполнения Notebook и перепроверяет устаревшие блокировщики файлов во время холодного запуска.
- Проверки памяти Notebook учитывают физическую память Windows, давление памяти macOS и ограничения контейнеров Linux. [Память и ресурсы](../guides/notebook.md#memory-resources).
- Экспорт пакетов сессий ждет, пока Notebook не уладится, прежде чем сообщать об экспортных сбоях. Также исправлены сохраненные ссылки на артефакты, подтвержденное удаление памяти и ошибки импорта GitHub Skill.
