# Записи с релизом: v0.34.1 {/* #release-notes--v0341 */}

Выпущено на **2026-10-01 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.34.1).

## Расширение научных баз данных {/* #scientific-database-expansion */}

В этом выпуске добавлен **Операции 26**, в результате чего реестр попадает в **31 Коннекторы и 326 операции**: семейства источников данных 30 с операциями 324, а также две автономные операции Molecule.

| Вступление | Добавлена возможность |
| --- | --- |
| CELLxGENE Discover | Откройте для себя общедоступные коллекции и наборы данных с одним ячейкой, проверьте опубликованные версии и извлеките кадастры файлов |
| Alliance Genome Resources | Гены человека и модельного организма, ортологи, модели заболеваний, фенотипы, аллели и экспрессия |
| Варианты MaveDB | Наборы баллов с различными эффектами, оценки CSV, существующие сопоставления и эксперименты VRS |
| Архивы Omics → Metabolomics Workbench | Образцы исследования, экспериментальные факторы, анализы, аннотации метаболитов и перекрестные ссылки на соединения |

Следуйте за [Возможности и настройка](../tools/databases.md#single-cell-model-organisms) и [Справочная информация об операции](../reference/connector-operations.md). URL-адрес файла не является завершенной загрузкой, а функциональная оценка, специфичная для анализа, не является клинической классификацией.

## Обзор Inbox в рабочем пространстве {/* #review-the-inbox-within-a-workspace */}

Компактный предварительный просмотр **Library** добавляет **Входящие**, с поиском, пагинацией, отдельным **Принять/уволить**, увольнением **Undo** и явным выбором партии на текущей странице. **Открыть входящие** на сохраненной ссылочной карте открывает этот обзор рядом с разговором. Очередь включает в себя кандидатов по проектам; Акцепт не загружает отсутствующие полные тексты. Смотрите [Рабочее пространство Шаги inbox](../guides/library.md#workspace-inbox).

Импорт журналов уточняет роли колонок и подсказки к картированию и улучшает сопоставление, фильтрацию и повторные записи псевдонимов. Смотрите [наборы данных журнала](../guides/journal-datasets.md#import-columns).

## Исследовательские пакеты и диагностика {/* #research-packages-and-diagnostics */}

- Пустые страницы **New conversation** добавляют **Импортировать предыдущее исследование** для выбора или сброса пакета `.science`. Смотрите [Импортные шаги](../guides/research-packages.md#import-and-inspect-a-package).
- После проверки конфиденциального контента может быть получено явное подтверждение **Всё равно экспортировать**. Флагированный контент включен без редактирования; Проверяйте его перед тем, как делиться. Смотрите [чувствительный экспорт](../guides/research-packages.md#sensitive-export).
- Местный диагностический экспорт сохраняет более полезные доказательства ошибок и выполнения. Они остаются отдельными от исследовательских пакетов и требуют проверки перед обменом. Смотрите [сеансовая диагностика](../guides/troubleshooting.md#session-diagnostics).

## Модели и элементы управления рабочим пространством {/* #models-and-workspace-controls */}

Каталог Codex добавляет **gpt-6.1-sol** без изменения сохраненных по умолчанию. Доступный доступ зависит от учетной записи и активного времени выполнения; См. [Выбор модели](../guides/providers.md#catalog-models).

План обратной связи следует за сконфигурированным ярлыком отправки. Композитор делает статус Compute Host более заметным, предварительные просмотры могут переходить к их сообщению, а редактирование Skill получает защиту для несохраненных черновиков.

## исправления {/* #fixes */}

Notebook фиксирует состояние клеток, общие инструменты песочницы и линию исполнения. Экстракция PDF лучше сохраняет нативное содержание фигуры / таблицы и обработку рабочего. Другие исправления охватывают справочные URL-адреса, очистку выбора аннотаций, нажатие на стол, восстановленные последующие разрешения, пути переустановки Windows, хранение учетных данных Linux и обработку учетных данных.
