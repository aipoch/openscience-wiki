# Записи с релизом: v0.37.0 {/* #release-notes--v0370 */}

Выпущено на **2026-10-11 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.37.0).

## Бегите без окна рабочего стола {/* #run-without-a-desktop-window */}

Рабочий стол, браузер, CLI и Notebook теперь имеют общий сервер Node. `open-science start` больше не запускает скрытый хост Electron Официальные релизы включают в себя автономные архивы CLI с Node и бэкэнд в комплекте. Для этих архивов не требуется отдельной установки Node. Настольные серверы выбирают бесплатный порт, когда он не указан.

Используйте [настройка терминала](../reference/cli.md#terminal-setup) для установки и входа в Codex. Прочитайте [Владение услугами и остановка](../reference/server.md#backend-ownership) перед закрытием настольного клиента или остановкой общего бэкэнда.

## Больше баз данных доказательств {/* #more-database-evidence */}

Реестр теперь содержит **36 Коннекторы и 361 операции**: семейства источников данных 35 с операциями 359, а также две автономные операции Molecule.

| Вступление | Что меняется | Гид |
| --- | --- | --- |
| ENCORI | Десять операций для мишеней miRNA, взаимодействий RNA-RNA и RBP, сетей ceRNA, сканирования мотивов, сайтов связывания, справочных таблиц и объемных файлов | [Настройка и границы результата](../tools/databases.md#encori) |
| Требования и ограничения | Подробности анализа и пагинация биоактивности за пределами первых записей 1,000 | [Анализ контекста и пагинации](../tools/databases.md#assay-submission-evidence) |
| ClinVar | Индивидуальные доказательства SCV для записи VCV | [Сравнить представления](../tools/databases.md#assay-submission-evidence) |

Сохраняйте организм, сборку, фильтры и типы доказательств с результатами. Уверенность в анализе связана с целевым назначением; a Представление ClinVar не является независимым клиническим диагнозом. [Справочная информация об операции](../reference/connector-operations.md) предоставляет точные поля и загружаемый реестр.

## Чтение PDF и выполнение Notebook {/* #pdf-reading-and-notebook-execution */}

Перевод PDF улучшает нативный порядок чтения и вложенные текстовые метки. Структурная экстракция хранит цифры и записи таблиц с их исходными элементами. Продолжить проверку [фигуры и таблицы](../guides/previews.md#pdf-extraction) и [Переводные страницы](../guides/pdf-translation.md#compare-export) на оригинал.

Готовые среды выполнения Notebook по умолчанию избегают избыточных разрешений на установку. Смешанные среды Conda/pip и метаданные сборки micromamba захватываются более точно, наряду с зависимостями ввода и обратного вызова. Эти записи поддерживают [повторная проверка](../guides/reproducibility.md); Они сами не устанавливают воспроизводимость.

## Восстановление и исправления платформы {/* #recovery-and-platform-fixes */}

- Импорт в новый проект устраняет сбой в принятии каталога `.science`. Импортные сессии остаются только для чтения; Использование [Создать ответвление](../guides/research-packages.md) для дальнейшего анализа.
- Умные коллекции повторяют неудачную партию, сохраняя завершенную работу. Смотрите [Просмотр коллекции](../guides/library.md#smart-collections).
- Аргументы об утверждении/увольнении плана и потоковом инструменте Codex восстанавливаются более надежно. Автоматический режим позволяет избежать избыточного одобрения для поддерживаемых инспекционных операций.
- Windows фиксирует пути Python, содержащие пробелы или скобки, выбранные бэкэнд-профили и передачи Specialist. Учетные данные Linux позволяют избежать повторных расследований Секретной службы после первой секретной операции.
- PDB отклоняет неправильные поисковые ответы и сохраняет статус неполной страницы; Ошибку не следует рассматривать как нулевое попадание.
- Home добавляет руководство по первому проекту. Безголовое исполнение и SDK могут снова разрешать пакетные ресурсы Notebook.
