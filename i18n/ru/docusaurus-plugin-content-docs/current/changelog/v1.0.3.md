# Выпускные примечания · v1.0.3

Выпущено на **2026-10-26 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.0.3).

## Следуйте по литературному следу {/* #literature */}

Используйте Semantic Scholar, чтобы найти ссылки на статью и цитировать статьи, а затем отправьте выбранных кандидатов в Inbox для рассмотрения. Библиотека также принимает капли файлов и обнаруживает дополнительные материалы с прогрессом загрузки каждого файла и предварительными просмотрами. [Открытие литературы и привязанности](../guides/library.md#citation-discovery).

Умные коллекции могут экспортировать все решения кандидатов в качестве CSV, отдельно от библиографии. [Решения о проверке экспорта](../workflows/screen-literature.md#screening-csv).

## Двигайтесь и читайте исследования {/* #research */}

- Экспорт и импорт `.science` пакеты из CLI и аутентифицированного локального веб-приложения. Импортные сессии остаются только для чтения. [Местный пакетный трансфер](../guides/research-packages.md#local-package-transfer).
- Выбрать **Advanced → Content first** для нового PDF-версии перевода, чтобы переделать текст тела и подписи. [План перевода](../guides/pdf-translation.md#content-first).
- Контроль доступа к локальным папкам Notebook и Shell в Разрешениях. Изменение настройки останавливает живые процессы и очищает переменные. [Ограничения по папкам](../reference/permissions.md#notebook-folder-restrictions).

## Получить больше научных источников {/* #sources */}

Новый доступ охватывает TCIA, KEGG, OmniPath, LIPID MAPS, проверку PDBe, картографирование UniChem, сходство структуры DepMap/CCLE и PDB. Сохраняйте исходные идентификаторы, шкалы лицензирования и измерения с результатами. [Выберите и подключите источники](../tools/databases.md#expanded-sources).

Kimi K3.1 Pro входит в каталог провайдеров. Регистрация протокола Windows, сохранение сетевого одобрения, восстановление сеанса, передача пакетов и обработка PDF также получают исправления. [Выбор модели](../guides/providers.md#kimi-k31) · [Предыдущий выпуск: v1.0.2](v1.0.2.md).
