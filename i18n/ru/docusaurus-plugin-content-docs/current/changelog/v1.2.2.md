# Примечания к выпуску &#42; v1.2.2 {/* #release-notes--v122 */}

Выпущено на **2026-11-18 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.2.2).

## Выберите более строгую сеть ноутбуков {/* #strict-network */}

**Settings → Network → Manage access** теперь предлагает режимы **Relaxed** и **Strict**. Strict разрешает только ручные совпадения по протоколу, имени хоста или IP и порту. Непревзойденные запросы блокируются без запроса авторизации. Расслабленный остается дефолтом. Правила могут быть организованы в группы; встроенные и ручные этикетки показывают их происхождение. [Настройка сети](../guides/network.md#public-network-rules).

## Резюме прерванных исследовательских фильмов {/* #film-checkpoints */}

Поколение фильмов сохраняет проверенные сцены, повествование и временную работу в процессе перезапуска. Резюме с контрольно-пропускного пункта или умышленное начало нового поколения. Прогресс определяет нынешний этап. [Шаги восстановления](../guides/research-films.md#film-recovery).

## Читайте PDF-файлы и восстанавливайте локальную работу {/* #recovery */}

- Нативное извлечение PDF лучше сохраняет цифры, подписи, содержимое таблицы и порядок чтения. Сравните извлеченный материал и переведенные макеты с оригинальным PDF. [PDF извлечение](../guides/previews.md#pdf-extraction).
- Windows проверяет доступ к защищенной папке перед сохранением гранта; обновление и удаление восстановления сохраняют лучшую диагностику.
- Импорт `.science` отличается отменой, недействительными пакетами и тайм-аутами. После неподтвержденного тайм-аута проверьте импортированную сессию, прежде чем отправлять снова. [Импорт исследовательского пакета](../guides/research-packages.md).
- Когда локальная служба отключается, рабочее пространство показывает состояние восстановления и сохраняет проект композитора.
- Bailian Token Plans добавляет **Обсуждение Qwen4 Max Preview**, включая региональные каталоги. Доступность зависит от выбранного аккаунта. [Настройка поставщика](../guides/providers.md#provider-regions).

См. [Установка и обновления](../guides/installation.md) и [v1.2.1](v1.2.1.md).
