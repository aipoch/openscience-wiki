# Выпускные примечания · v1.0.2

Выпущено на **2026-10-22 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.0.2).

| Источник | Откройте его через |
| --- | --- |
| Номенклатура гена HGNC | Genes &amp; Ontologies |
| PubTator 3 Статьи Аннотации | PubMed |

Эти дополнения приводят каталог к **36 записей с 371 операцией**Плюс две автономные операции с молекулами. [Выберите источник и подключите его](../tools/databases.md#new-source-access).

GDC фильтрует файлы по случаю, типу образца и процессу анализа, сохраняя связи образцов и аликвот. Ensembl VEP принимает HGVS без ручного преобразования координат, но не проверяет версию исходной референсной последовательности и не выполняет liftover. В каталог также включены опубликованные результаты ClinicalTrials.gov. См. [контекст запроса](../tools/databases.md#clinical-context) и [Полное описание операции](../reference/connector-operations.md).

## Установите и проверьте CLI {/* #cli */}

CLI и Task SDK публикуются в формате npm. Следить [npm установка](../guides/installation.md#npm-cli)затем использовать `version`, `help` и `paths` без запуска серверной части. Показанная версия относится к вызванной установке. Настольная и автономная поставки включают обновления безопасности Node 22.23.4. [Местные информационные команды](../reference/cli.md#local-information).

## Держите под контролем разговор {/* #conversation */}

Вопросительные карточки различают **Single select** из **Multi select** Сохраните полную историю ответов на каждый вопрос. Ошибки очередей-сообщений предлагают отмену действия; неотправленные черновики вызывают предупреждения об отказе / перезагрузке. Восстановление полномочий дает конкретный следующий шаг при сохранении проектов. Удаленный веб-чат поддерживает упоминания артефактов. [Вопросительные карточки и черновики](../guides/composer.md#clarification-questions).

## Продолжение исследований с более четкими записями {/* #research-records */}

- Диалоги пакетов остаются стабильными; повторный импорт избегает повторных сессий. Импортированные заголовки могут быть отредактированы, в то время как исследования остаются только для чтения. [Исследовательские пакеты](../guides/research-packages.md#browser-import).
- Улучшается загрузка и восстановление стартапов. Частичный диагностический экспорт показывает предупреждения. [Диагностика сеанса](../guides/sessions.md#session-diagnostics).
- Структура PDF, нумерация DOCX / границы и цепной захват файловой линии Python / R получают исправления. [Линейные проверки](../guides/notebook.md#chained-analysis-lineage).
- Крупный импорт навыков использует партии; зарезервированные внешние имена получают безопасные местные названия. MiniMax M3.1 через Codex. [Восстановление поставщика](../guides/providers.md#credential-recovery).
