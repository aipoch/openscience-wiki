# Changelog - v0.30.1 {/* #changelog--v0301 */}

Выпущен сентябрьский 16, 2026. Это обновление улучшает то, как вы готовите побочные обсуждения, анализируете изменения в методе и делитесь исследовательскими материалами.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [Изменения после v0.30.0](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## Обновленные рабочие процессы {/* #updated-workflows */}

| Область | Что меняется для вас |
| --- | --- |
| Side Chat | Откройте пустой черновик, унаследуйте основную модель разговора и аргументацию, или выберите другую модель для следующей отправки. Проекты с контентом выживают при навигации; Нетронутые пустые сквозняки очищаются. [Side Chat](../guides/delegation.md) |
| Обновления Skill | Проверять изменения файлов, номера строк и добавленные/удаленные строки до **Обновить существующий навык**. Обзор затронул специалистов и локальные правки, которые будут заменены. [Каталог Skills](../skills/marketplace.md) |
| Исследовательские пакеты | **Full export** включает в себя доступную литературу PDF; **Customize contents** Выбирает их индивидуально. Essential Export не включает опциональные PDF-файлы; Требуемые доказательства не могут быть удалены. Разговоры Side Chat исключены. [Исследовательские пакеты](../guides/research-packages.md) |
| Местные ворота | Пользовательский шлюз может оставить ключ API пустым, если сервер не нуждается в аутентификации. Дистанционные шлюзы по-прежнему требуют учетных данных и HTTPS. [Настройка поставщика](../guides/providers.md) |
| Одобрение на чтение в Интернете | Поддерживаемый запрос на чтение может быть запомнен для разговора, включая более поздние страницы на других веб-сайтах. [Разрешения](../guides/approval-modes.md) |
| Теги | Поиск в тегах ресурса, использование клавиш стрелок и Ввод, или создание и назначение нового тега. [Теги](../guides/tags.md) |
| Установка и восстановление | macOS направляет только прочитанные копии в Приложения перед обновлением. Windows имеет отдельную, разрушительную утилиту сброса с предварительным просмотром и типизированным подтверждением. Установщики отображают лицензию проекта. [Установка и обновление](../guides/installation.md) · [Windows сброс](../guides/troubleshooting.md#windows-data-reset) |

## Сообщенные исправления {/* #reported-fixes */}

В релизе также сообщается об исправлениях для утверждения плана во время тайм-аутов MCP, связывания исторических артефактов, отмены задач и очередей Notebook. PDF парсинг может восстанавливаться после заблокированных состояний и сообщать о сбоях извлечения; Улучшено восстановление рисунка/таблицы. Connector фиксирует валидацию аргументов области gnomAD и сборки ссылок на набор данных, а также корректирует объединение пакетных остатков ESM-2.

Проверки провайдера используют маршрут тестируемого провайдера. Отсутствующие входы Codex с файловой поддержкой получают более явную ошибку импорта. Взгляды на литературу возвращаются к их исходному разговору, а инструкции OpenCode Side Chat остаются отдельными от Main.

Используйте [Установка и обновление](../guides/installation.md) для обновления. Предыдущим релизом является [v0.30.0](./v0.30.0.md).
