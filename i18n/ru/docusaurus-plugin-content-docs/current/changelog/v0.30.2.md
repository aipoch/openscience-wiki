# Changelog - v0.30.2 {/* #changelog--v0302 */}

Выпущен сентябрьский 17, 2026. Это обновление фокусируется на надежной загрузке Skill, побочных дискуссиях, запросах научных данных и восстановлении выполнения.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.30.2) · [Изменения после v0.30.1](https://github.com/aipoch/open-science/compare/v0.30.1...v0.30.2)

## Изменения в повседневном использовании {/* #changes-to-everyday-use */}

| Область | Что меняется для вас |
| --- | --- |
| Specialist Skills | Связанные Skills готовятся к поворотам Specialist и делегированным задачам. OpenCode может считывать ссылки Skill. Видишь? [Рабочий процесс Specialist](../workflows/extend-analysis.md) Для выбора и использования. |
| Side Chat | Main, работающий или ожидающий одобрения, больше не блокирует Side Chat сам по себе. Side Chat по-прежнему устанавливается во всех видах приложений; Его собственная история, реставрация и проверки только для чтения все еще применяются. [Side Chat](../guides/delegation.md) |
| Одобрение веб-поиска | Поддерживаемый нативный поиск Claude Agent может запомнить **Allow for this conversation**. Гранты на поиск и чтение страниц остаются отдельными. [Разрешения](../guides/approval-modes.md#remember-web-search) |
| Рецензент | Настройки автоматического обзора выживают при запуске разговора. Связанные повороты коррекции сохраняют обратную связь, необходимую для цикла коррекции. Проверить пересмотренный результат и последующий обзор. [Рецензент](../specialists/reviewer.md) |

## Данные и доказательства {/* #data-and-evidence */}

[Ссылка на Connector](../reference/connector-operations.md) и загружаемый реестр теперь используют v0.30.2. Reactome уважает запрашиваемый поддерживаемый вид. Ensembl возвращает разрешенный вид и нормализует запросы области VEP в переднюю нить. UCSC отклоняет недействительные координатные границы, а координаты региона гномады должны быть ниже одного миллиарда. CellGuide и OLS сообщают о соответствующих сбоях извлечения или пагинации вместо того, чтобы представлять их в качестве пустых доказательств.

Автор PubMed теперь сохраняет различия фамилий / инициалов / суффиксов. `literature-review` Skill проверяет отношения в обоих направлениях. Отсутствующий маркер не является доказательством того, что бумага никогда не была удалена. [Проверка метаданных](../guides/library.md) и [Литературные доказательства](../workflows/literature-review.md).

## Notebook и восстановление {/* #notebook-and-recovery */}

Windows фиксирует запуск Conda R, выполняемый поиск после подготовки среды, восстановление ядра R и точки входа в проверочные среды. Восстановление воспроизведения Notebook поддерживает одновременные входы и импорт стандартной библиотеки. Linux считывают гранты под временные крепления также корректируются. [Среды выполнения](../guides/runtimes.md) и [Воспроизводимость](../guides/reproducibility.md).

Это исправления, поддерживаемые релизом / исходным кодом. Существующие скриншоты Windows и Specialist сохраняют свои оригинальные версии. Это не новые результаты теста v0.30.2. Отсутствующие входные данные или блокировки окружающей среды по-прежнему требуют внимания, а проверки воспроизведения остаются специфическими для захваченных версий результатов.

## Другие улучшения {/* #other-improvements */}

Каталог провайдеров добавляет DeepSeek V4.1 Flash и обновляет модели Volcengine Ark, сохраняя при этом старые варианты. Маркетплейс показывает источник, когда автор отсутствует. Делегированные задачи OpenCode используют изолированные среды выполнения; Выстраиваемые в очередь разговорные снимки CLI и несколько настроек, вкладок, литературы и взаимодействия с инструментами-картами корректируются.

Используйте [Установка и обновление](../guides/installation.md) для обновления Предыдущим релизом является [v0.30.1](./v0.30.1.md).
