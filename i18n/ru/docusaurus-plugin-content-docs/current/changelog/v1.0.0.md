## Перейти к релизу 1.0 {/* #upgrade */}

1.0 переносит существующее пространство для исследовательской работы в линию стабильного высвобождения. Сохраняет исторические обновления профиля и импорт `.science`; Для изменения версии не требуется новый профиль или формат данных. Резервное копирование вашего профиля и исследовательских данных, завершение активной работы, а затем обновление через официальный установщик рабочего стола. Бинарное понижение не отменяет изменения данных.

Данная публикация содержит **только настольные пакеты**. Автономные архивы CLI и активы Linux CLI `.deb`/`.rpm` отсутствуют, а продвижение сайта/автоматическое обновление является отдельным. Используйте командную пусковую установку для 1.0, поставляемую на рабочий стол; Не переименовывайте старый архив CLI и не предполагайте, что Homebrew/npm уже предоставляет ту же версию. `open-science update` удаляется: используйте элементы управления рабочего стола или установщик / менеджер пакетов, который владеет установкой. Смотрите [Совместимость с 1.x](../guides/installation.md#version-compatibility).

## Продолжить прерванную работу {/* #recovery */}

Совместимый рабочий стол может принять выживший рабочий стол-запущенный бэкэнд после того, как его предыдущий контроллер отключается. Сервисы CLI остаются независимыми. Неудачная подготовка к отключению держит окно открытым, и повторное подключение восстанавливает исходное состояние разговора до того, как работа продолжится. Проверяйте сохраненные операции перед повторным отправкой запроса с неизвестным результатом. Смотрите [Владение услугами и восстановление](../reference/server.md#desktop-service-recovery).

Возобновление разговоров с выбранным агентом; Сеансы Codex восстанавливаются после переключения Specialist. [Проверьте выбранного агента и оригинальную сессию.](../guides/sessions.md#resume-selected-agent) перед отправкой следующего поворота. Отбор литературы и отмена во время уплотнения контекста также получают исправления.

## Отвечайте на вопросы и читайте PDF {/* #interaction */}

- Разъяснительные карты поддерживают более длинные списки опций и несколько вариантов. Просмотрите ответы на все вопросы, затем выберите **Finish**. Один только выбранный вариант – это проект. [Ответить на уточняющий вопрос](../guides/composer.md#clarification-questions).
- Кнопки примечания к аннотации появляются на наведении, фокусировке или выборе, сохраняя PDF четким при чтении. [Открой записку](../guides/pdf-notes.md#reveal-note).
- Добыча и перевод PDF сохраняют более сложные исходные макеты, родные отношения таблицы/фигуры и научные фракции. **New translation** готовит исходный текст. Сравните результат с оригиналом перед повторным использованием. [Проверка экстракции](../guides/previews.md#scientific-structure-check) · [Перевод](../guides/pdf-translation.md#scientific-layout).

## Сохранение контекста научных данных {/* #data-context */}

| Источник | Изменения |
| --- | --- |
| ArrayExpress | Отличить строки отношений SDRF от различных идентификаторов выборки; Неполные идентификаторы могут возвращать неизвестные количества образцов |
| Метаболайты | Держите повторяющиеся столбцы таблицы выборки и их оригинальное упорядочивание вместо перезаписи значений. |
| Bgee | сохранение анатомического и клеточного контекста; Недостающие типы клеток остаются `null` |
| dbSNP | Сохранить все ассоциации хромосом/сборки для размещения |
| OpenAlex | Вспомните отклоненные подсказки учетных данных за сеанс |

Прочитайте [Руководство по толкованию на местах](../tools/databases.md#scientific-context) и [v1.0.0 Connector ссылка](../reference/connector-operations.md) перед повторным использованием сохраненных запросов. Анализ риска Notebook также улучшает лечение обратных вызовов Promise. По-прежнему применяются существующие требования в отношении официального утверждения.

## Что не меняется в 1.0 {/* #scope */}

Записанное повторение сеанса не выполняет код. Проверка артефактов требует приемлемых захваченных входов и пригодной для использования среды; Она не устанавливает научной обоснованности или детерминированного воспроизведения целого сеанса. Импортированные записи `.science` остаются только для чтения. Используйте вилку для написанного продолжения. Полномочия, боковые чаты и личные закладки не восстанавливаются из пакета. Поддерживается SSH/Slurm; Управляемое облачное представление GPU, локальный бэкэнд GPU и многопользовательское редактирование в режиме реального времени находятся за пределами этого выпуска.
