# Записи с релизом: v0.33.2 {/* #release-notes--v0332 */}

Выпущено на **2026-09-24**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## Установка и чтение литературы {/* #installation-and-literature-reading */}

Официальные установщики Windows получают подпись кода. Ссылки на загрузку приложений ведут на официальную страницу загрузки и заметки проверки. Смотрите [установка](../guides/installation.md). Превью с живым исходным кодом сохраняют сеансы веб-сайта во время посещений и перезапуска приложений; См. [Источник Previews](../guides/previews.md#persistent-source-preview).

Режим **Auto** уменьшает количество повторных запросов на одобрение для встроенных операций Библиотеки. По-прежнему действуют правила файлов, сетей и ресурсов. Смотрите [библиотечное одобрение поведения](../guides/approval-modes.md#library-auto).

## Обогащение взаимодействия STRING {/* #string-interaction-enrichment */}

**факультативный; По умолчанию: "gtex_v8"** добавляет обогащение PPI STRING, чтобы проверить, имеет ли белковый набор больше взаимодействий, чем ожидалось на его фоне. Это задает другой статистический вопрос, нежели обогащение путей. Следуйте за [Генно-сетевой рабочий процесс](../workflows/gene-set-enrichment.md#enrichr-string) и [Справочная информация об операции](../reference/connector-operations.md#get_string_ppi_enrichment).

## Улучшения и исправления {/* #improvements-and-fixes */}

Завершенные результаты делегации выживают после неудачных работ по очистке. Обновления также охватывают рабочий процесс Figure Composer, иконки типа файла предварительного просмотра и макет умного сбора. Исправления изолируют состояние очистки macOS Notebook и улучшают маршрутизацию и отключение агентов; Codex Backend плагин и обнаружение приложений отключены.
