# Changelog - v1.3.4 {/* #changelog--v134 */}

Выпущен **2026-11-23 UTC**. [Официальный релиз Notes](https://github.com/aipoch/open-science/releases/tag/v1.3.4).

## Проверьте встроенного агента с отслеживанием {/* #tracing */}

В проектах появился **Agent tracing**, по умолчанию отключённый. Он отправляет связанные записи ходов, запросов к модели и вызовов инструментов MCP в OTLP/HTTP-приёмник, настроенный оператором, в том числе обычный Collector или Langfuse. Open-Science не предоставляет собственный сервис сбора. Все четыре параметра сбора содержимого включены, если они не указаны явно, поэтому проверьте их перед включением трассировки. [Действия в проекте](../guides/projects.md#agent-tracing) · [Приёмник и сбор данных](../reference/diagnostics.md#agent-tracing).

CLI `--otel-traces` или SDK `otelTraces: true` явно позволяет отслеживать, даже когда проект выключен. Он не меняет сохраненный проект или настройку сеанса. [CLI](../reference/cli.md#otel-traces) · [SDK](../reference/api.md#otel-traces).

## Обновления Windows и отзывчивость Notebook {/* #updates */}

Подготовка к обновлению Windows распознает встроенный агент приложения и помощник изображения, фиксируя киоски, вызванные обращением с ними как с внешними блокаторами. Стабильные обновления Windows восстанавливают компактные дельты установщика v1.3.3 использует полный инсталлятор. [Шаги обновления и восстановления](../guides/installation.md#windows-134).

Длинные истории Notebook используют меньше повторных считываний и пакетных переходов в прочные контрольно-пропускные пункты. Первый участок Windows Python больше не приостанавливается на несвязанной ограде для восстановления ядра. Использование вычислительной памяти исключает кэши на macOS; Windows показывает встроенную память на пределе ее возможностей наряду с физическим использованием. [Резюме памяти](../guides/notebook.md#memory-summary).

## Модели и более четкие результаты задач {/* #models-recovery */}

- CodeBuddy обнаруживает поддерживаемые усилия по рассуждению для каждой модели, восстанавливает выбранную модель и обновления использования токенов в возобновленных сессиях и фиксирует первый запрос автора фильма. Жипу добавляет GLM-5.4. [Выбор провайдера](../guides/providers.md#codebuddy-reasoning).
- Отрицаемое действие инструмента заканчивается неограниченным объяснением; Отказы в звонках отличаются от выполненной работы. [Утверждения](../guides/approval-modes.md#denied-action).
- Явные ответы провайдера HTTP 402, такие как Недостаточный баланс, сохраняют свой статус и полезные реквизиты выставления счетов. [восстановление](../guides/troubleshooting.md#provider-balance).
- Создающий фильм поддерживает свой разговор в активном режиме. Заблокированный диалог с фильмом может открыть разговор, которым владеет работа. [Фильм прогресс](../guides/research-films.md#film-recovery).
- Версии с отредактированными изображениями открываются во время публикации, а история Provenance остается доступной, в то время как черновики изображений активны. [Редактирование изображений](../guides/image-generation.md#edit).
- Встроенные чаты Агентов используют контрольные точки своего профиля; Продолжения инструмента с нулевыми полями идентификации больше не выходят из строя.
