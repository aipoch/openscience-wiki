# Выпускные примечания · v1.0.8

Выпущено на **2026-11-04 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.0.8).

## Импорт списка литературы {/* #literature */}

Есть ли список бумажных идентификаторов? **Add from DOI or link** теперь принимает до 100 непустых строк, содержащих DOI, arXiv, PMID, PMCID или поддерживаемые официальные ссылки на статьи. Просмотрите разрешенные ссылки и дублирующую политику перед импортом. Поиск метаданных не позволяет автоматически получить полный текст. [Экскурсия по импорту](../guides/library.md#doi-link-import).

Справочные данные теперь включают **Study overview**. Настроенная основная модель организует доступный источник в пять разделов: вопрос исследования, популяция исследования, методы, основные выводы и ограничения. Ярлык источника выделяет абстрактный, полный текст и выбранные отрывки. Используйте его, чтобы сориентировать свое чтение, а затем проверьте важные утверждения в оригинальной статье. [Создать обзор](../guides/library.md#study-overview).

[Настройка карты](../settings/overview.md) · [Внешний вид и уведомления](../guides/appearance.md).

## Исследования и повседневная надежность {/* #reliability */}

- eQTL Catalogue использует индексированные файлы Release-7 после того, как его REST API был удален. Запросы требуют явного **GRCh38** Координаты; один только идентификатор гена больше не является действительным запросом. [Координация требований](../tools/databases.md#eqtl-coordinates).
- PDF-заказ использует позиционированный текст, чтобы отличить столбцы прозы от строк таблицы. Экстракция проверяет границы урожая и сохраняет двусмысленный клеточный текст с предупреждением о надежности. [Чтение и извлечение PDF](../guides/previews.md#automatic-pdf-reading-order).
- R-репродукция проверяет недействительность устаревших доказательств после операций, которые могут вызвать аргументы или методы отправки. Провенанс объясняет неполные доказательства исполнения; старые артефакты Маркдауна восстанавливают устаревшую историю при открытии. [Проверка доказательств](../guides/reproducibility.md#execution-evidence).
- Завершенные сеансы релиза провайдера и инструментальных процессов во всех пяти фреймворках Агента. Установка Pi в упакованных настольных сборках отремонтирована.
- Подготовка обновлений более четко определяет процессы блокировки. Исправления адресованы держателям файлов только для чтения macOS, обнаружению процесса Windows и устаревшим записям восстановления Notebook. Диагностические пакеты сохраняют фактическую ошибку восстановления рабочего стола. [Обновление руководящих принципов](../guides/installation.md#update-preparation).
- Скачанный файл сохраняется, даже если каталог назначения недоступен для чтения или последующая очистка завершается ошибкой. Улучшены завершение PDF-процесса и проверки защиты Windows. Инструменты Notebook могут использовать встроенный Node, если версия из PATH слишком стара для работы с прокси.
- Успешный полнотекстовый поиск устраняет более раннюю ошибку добавления PDF, и Композитор больше не повторяет уведомление о недоступной модели.

Tencent TokenHub добавляет Hy4 и маршруты DeepSeek V4.1 Flash с контекстом 1 000 000 токенов, а также ввод изображений для GLM-5.3-Flash, Kimi K3 и MiniMax M3. Доступность зависит от учётной записи провайдера и выбранного маршрута. [Настройка поставщика](../guides/providers.md).

Встроенный каталог остался **48 Connectors и 418 операций**. [Текущий каталог](../tools/databases.md#supported-databases) · [Предыдущий выпуск](v1.0.7.md).
