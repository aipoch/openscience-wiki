# Changelog - v1.3.2 {/* #changelog--v132 */}

Выпущен **2026-11-20 UTC**. [Официальный релиз Notes](https://github.com/aipoch/open-science/releases/tag/v1.3.2).

## Больше способов подключить модель {/* #models */}

На этапе **Model provider** кнопка **Skip** добавляет Kilo Gateway без API key и переходит к Notebook runtime. После настройки в **Main model** может отображаться `kilo-auto/free`. До первого сообщения откройте **Settings → Model**, проверьте выбранного провайдера и модель и переключитесь на нужное подключение, например Codex subscription. Skip не проверяет выполнение запросов моделью. Обновление сохраняет существующие учётные данные и выбор Main. [Kilo Gateway](../guides/providers.md#kilo).

OpenAI, MiniMax, Bailian и Volcengine Ark могут обновить поддерживаемые каталоги моделей изображений, прежде чем сохранять их. Это связывает настроенного провайдера с учетными данными соединения. Наличие каталога и успешное поколение — это отдельные проверки. [Каталоги моделей изображений](../guides/image-generation.md#image-model-catalog).

## Другие исследовательские сессии {/* #sessions */}

Длинные разговоры используют меньше памяти, и безопасно сохраненные тела разговора могут быть освобождены, когда они больше не просматриваются. Сохраняются проекты и активная работа. Завершенные шаги воспроизведения показывают свои элементы управления запросом / захватом на наведении или фокусировке клавиатуры; Сенсорные устройства сохраняют доступные элементы управления.

Уведомления о давлении памяти Notebook могут быть отклонены и истекать через шесть секунд. Исчезновение уведомления не означает, что заблокированная операция запущена. Проанализируйте состояние исполнения и повторите намеренно. [Notebook память](../guides/notebook.md#memory-resources).

## Исправления, которые влияют на повседневную работу {/* #fixes */}

- Свежие встроенные сеансы Agent, Claude Agent и Codex больше не терпят неудачу до первого запроса модели на пути подготовки Notebook. Запланированные сеансы начинаются с предполагаемой быстроты.
- Перевод PDF реконструирует завернутые заголовки, подписи и математические утверждения в порядке чтения, сохраняя при этом родные формулы, ссылки и графику. [Проверьте переведенный макет](../guides/pdf-translation.md#scientific-layout).
- Ошибки загрузки в случае использования домашней страницы различают недостающие пакеты, тайм-ауты, сбои проверки и проблемы с хранением. [Восстановление импорта](../guides/research-packages.md#case-download-recovery).
- Решения Windows охватывают запуск WSL Notebook и соединения с Рецензентом.
