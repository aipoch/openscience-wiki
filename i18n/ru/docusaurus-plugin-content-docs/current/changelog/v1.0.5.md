# Примечания к выпуску · v1.0.5

Выпущено на **2026-10-28 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.0.5).

## Следите за своим чтением {/* #reading */}

Библиотека добавляет руководство **Unread**, **Reading** и **Read** состояния, с столбцом таблицы, фильтрами и объемными обновлениями. Публикационные проверки теперь используются **Check now** и **Check again**, сохраняя результаты Crossref и время проверки. [Статус чтения](../guides/library.md#reading-status) · [Проверка публикаций](../guides/library.md#publication-checks).

## Переместить пакеты исследований через браузер {/* #packages */}

Пользователи локального Web с аутентификацией могут отправить файл `.science` файл для импорта и загрузки готового экспорта. Домашняя галерея также предлагает исследовательские материалы с **Details** и **Import** действия. Просмотреть пункт назначения и импортные доказательства перед использованием **Fork to continue**. [Перевод браузера и галерея](../guides/research-packages.md#local-package-transfer).

## Решите, когда служба должна продолжать работать {/* #service */}

Явный CLI `start` сохраняет работу сервиса после выхода последнего App. Обычные задачи CLI, Web и SDK сами по себе его не удерживают. Обычная команда `stop` Выпускает его; подключенные приложения все еще могут поддерживать работу сервиса. `stop --force` Запрашивает остановку в рамках всей службы и может прервать активную работу. `start` Теперь принимает `--json`. [Результаты команд и отключения](../reference/server.md#lifecycle-commands).

## Найти научные записи и официальные файлы данных {/* #data */}

Новые записи охватывают поиск PMC в Европе, доступ к исследовательским данным и публичные списки файлов, ChEA3, bioDBnet и CTD. Существующие инструменты HGNC, Cellosaurus и openFDA получают дополнительные запросы или открытие файлов. Каталог включает **48 встроенных коннекторов и 418 операций**: 47 коннекторов источников данных с 416 операциями и один автономный коннектор Molecule с двумя операциями. Файловые ссылки не означают, что данные были загружены или доступ к ограниченному набору данных был предоставлен. [Источники и шаги подключения](../tools/databases.md#scientific-file-discovery).

## Обновления и ежедневные исправления {/* #fixes */}

- Ручные элементы управления обновлениями предоставляют инструкции по установке и способ выявления подтвержденного загруженного установщика. [Ручная установка](../guides/installation.md#manual-update).
- **Full access** Позволяет осуществлять публичные сетевые назначения без индивидуальных карт одобрения; снижение режима закрывает существующие соединения. Глобальные гранты сразу же появляются в настройках сети. [Сетевые разрешения](../guides/network.md#network-mode-changes).
- Установка пакета Notebook поддерживает явный маршрут BiocManager в Windows. [Пакеты Windows Bioconductor](../guides/runtimes.md#windows-bioconductor).
- Выход DOCX лучше сохраняет макет шаблона, таблицы, границы и структуру страницы. [Вывод слова](../guides/previews.md#docx-templates).

Другие исправления охватывают совместимость с OpenCode 2.x, разрешение внешнего узла macOS для Notebook, запуск чата Windows во время настройки защиты сети, управляемое чтение ссылок Skill, положение прокрутки разговора и полосы прокрутки таблицы. Также есть ссылки на политику безопасности. [Предыдущий выпуск: v1.0.4](v1.0.4.md).
