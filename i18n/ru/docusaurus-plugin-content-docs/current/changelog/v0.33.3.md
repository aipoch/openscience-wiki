# Записи с релизом: v0.33.3 {/* #release-notes--v0333 */}

Выпущено на **2026-09-26**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.33.3).

## Чтение файлов и управление литературой {/* #read-files-and-manage-literature */}

Зрители Office добавляют навигацию по страницам и поиск с чтением PowerPoint. Используйте существующие файлы QC в [Файл Previews](../guides/previews.md).

Рабочее пространство **Library** добавляет компактный предварительный просмотр для текущего проекта или все ссылки на поиски и рефераты. Смарт-коллекции добавляют **Отказаться от запуска**: завершенные результаты остаются, но этот запуск не может возобновиться. Crossref метаданные завершения импорта исходные тезисы. [Библиотека](../guides/library.md) и [бумажный скрининг](../workflows/screen-literature.md).

## Новые научные базы данных {/* #new-scientific-database-operations */}

**Гены и онтологии** добавляет библиотеку Enrichr и обогащение. **факультативный; по умолчанию: 10; Минимум: 1; Максимум: 1000** добавляет запросы ClinPGx для лекарств, генов, вариантов, руководств, этикеток и частот популяции. Полный реестр теперь включает в себя **28 Коннекторы и 284 операции**: 27 Data Source Connectors с операциями 282, а также две автономные операции Molecule. [Возможности баз данных](../tools/databases.md) и [Справочная информация об операции](../reference/connector-operations.md).

## Исследовательские пакеты, внешний вид и установка {/* #research-packages-appearance-and-installation */}

Передача пакетов добавляет автоматические или фиксированные ограничения активности диска, с прогрессом, доступным во время фоновой работы. Ярлыки масштаба рабочего стола разделяют шаги настроек 90%, 100%, 110% и 125%. Подпись Windows охватывает пакетные исполняемые файлы. [пакетная передача](../guides/research-packages.md#transfer-settings), [масштаб интерфейса](../guides/appearance.md#interface-scale) и [установка](../guides/installation.md).

## исправления {/* #fixes */}

Исправления адресованы шрифтам PDF для чтения-таб, изолированному восстановлению ядра Notebook, нативному доступу к предоставленным папкам, восстанавливаемым повторным запросам и устраняемым ошибкам. Срочные запросы на восстановление архивов предназначены для пострадавших проектов. Другие исправления охватывают первоначальный выбор модели классификации, суффиксы диагностического архива, метаданные Skill, управляемый Python и записи об использовании в пакетах исследований.
