# Журнал изменений · v0.33.0

Вышел сентябрьский 23, 2026. В этом выпуске добавлен интеллектуальный скрининг литературы, средства контроля доступа к ресурсам для отдельных агентов и метаданные RO-Crate в пакетах исследований.

[Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v0.33.0) · [Изменения после v0.32.0](https://github.com/aipoch/open-science/compare/v0.32.0...v0.33.0)

## Экранная литература с явными критериями {/* #screen-literature-with-explicit-criteria */}

**Smart collection** оценивает библиотечные записи по критериям включения и исключения. Выберите его область применения, проверьте четыре мнения о принятии решений и просмотрите типовые суждения, прежде чем использовать набор для чтения. Пробные заезды спасают результаты; Живые предварительные просмотры не делают. Дополнительные полнотекстовые доказательства и автоматические обновления имеют отдельные элементы управления.

Новый [Проверка рабочего процесса](../workflows/screen-literature.md) охватывает поиск, связывание моделей, правила, пробную версию, ручную проверку и экспорт. [Классификация](../guides/models.md#smart-collection-model) теперь отличает **Smart collections** от **Automatic capability selection** Main может оставаться на Codex.

## Управление доступом к ресурсам и передачей исследований {/* #manage-resource-access-and-research-handovers */}

- **Manage access** на Skill или Connector показывает ассоциации Main Agent и Specialist вместе. Активация ролей, учетные данные и утверждения операций остаются отдельными. Смотрите [доступ к ресурсам](../guides/connectors.md#resource-access).
- Новые экспортные пакеты `.science` включают метаданные RO-Crate 1.1. Получателям нужен считыватель, поддерживающий возможности `ro-crate`; Старые пакеты остаются читаемыми. Смотрите [Совместимость пакетов](../guides/research-packages.md#package-compatibility).
- **Export diagnostics…** создает локальный архив из выбранных источников. Он не загружает архив и не отправляет его в модель. Смотрите [диагностический экспорт](../guides/troubleshooting.md#session-diagnostics).

## Новые операции с базами данных {/* #new-database-operations */}

| Источник | Добавлена возможность | граница |
| --- | --- | --- |
| Зенодо | Поиск публичных записей и проверка конкретных версий метаданных и кадастров файлов | не загружать и не скачивать файлы; Публичные метаданные не подразумевают открытый доступ к файлам. |
| ГДК | Перечислите проекты / случаи рака, поисковые файлы, проверьте метаданные файлов и создайте манифесты | Контролируемые данные по-прежнему требуют авторизации. |
| Гены и онтологии | Картирование пакетных идентификаторов UniProt: отправка, проверка статуса и извлечение результатов на страницах | Сохраняйте все страницы, совпадения один ко многим и явные непревзойденные идентификаторы. |

Есть **26 — встроенные коннекторы с операциями 263**: **25 Data Source Connectors / 261 Операции**, плюс две автономные операции с молекулами. Используйте [каталог баз данных](../tools/databases.md) для выбора службы и [Ссылка на параметры v0.33.0](../reference/connector-operations.md) для точных входов. По умолчанию UCSC консервации корректируются для мышиных сборок.

## Модели, время выполнения и исправления платформы {/* #models-runtime-and-platform-fixes */}

Каталоги провайдеров добавляют MiMo v2.6 и Grok 4.7 и обновляют Zen/Go. Смотрите [Выбор провайдера](../guides/providers.md#provider-catalog-updates). **Claude Agent** теперь сообщает о неподдерживаемых версиях CLI во время проверки готовности; v0.33.0 требует **2.1.118 или более поздняя версия**. Смотрите [агентская установка](../guides/frameworks.md).

Другие исправления улучшают потоковую передачу и длительные разговоры, устаревшее восстановление, проверки учетных данных исследовательского пакета, длительный прогресс оболочки Notebook, гранты папок во время установки пакета, отклоняемые уведомления Notebook, инвентаризация и обработка сброса Windows R, упаковка стартапа Fedora и взаимодействия поиска / PDF. Смотрите официальный релиз для полного списка. Предыдущим релизом является [v0.32.0](./v0.32.0.md).
