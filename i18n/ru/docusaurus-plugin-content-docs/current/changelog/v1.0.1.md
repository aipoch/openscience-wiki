# Выпускные примечания · v1.0.1

Выпущено на **2026-10-20 UTC**. [Официальный релиз](https://github.com/aipoch/open-science/releases/tag/v1.0.1).

## Принесите пакет исследований в приложение {/* #packages */}

Поддерживающий сайт может помочь `.science` Пакет для настольного приложения на том же компьютере. Позвольте браузеру открыть Open-Science, сохранить страницу открытой во время передачи, затем просмотреть пакет и выбрать пункт назначения в приложении. Получение приложения не является окончательным одобрением импорта. Местные пакеты также могут быть сброшены на проект дома. Видишь? [браузер импортировать](../guides/research-packages.md#browser-import).

## Следите за обновлениями и сессиями ожидания {/* #interaction */}

Диалог обновлений сохраняет загрузку, выпуск заметок и подготовку установки вместе. Передача Windows и запуск получают исправления; доступность установки по-прежнему зависит от канала. Следить [Обновление прогресса](../guides/installation.md#update-progress) Проверьте установленную версию после перезапуска.

Сеансы, ожидающие ответа или одобрения, остаются видимо ожидающими через Дом, боковую панель и разговор. Откройте ожидающую карту, чтобы продолжить. Дважды щелкните сессию боковой панели, чтобы открыть ее редактор. Видишь? [Ожидание ввода](../guides/sessions.md#waiting-for-input).

## Работа с источниками и полномочиями {/* #sources */}

- PDC добавляет общедоступные демографические данные и метаданные диагностики с выбором версии исследования и внешними ссылками. Держите идентификаторы источника отличными. [PDC клинические поля](../reference/connector-operations.md#pdc_list_clinical).
- MiniMax M3.1 Flash доступен в обоих регионах. Прикрепленные изображения могут информировать выбор навыков. [Выбор поставщика](../guides/providers.md#catalog-models).
- Учетные данные OAuth привязаны к серверу выдачи авторизации. Использовать [санкционирование](../guides/connectors.md#oauth-reconnect) когда это необходимо.
- Поиск PDF указывает на неполное покрытие; чтение с двумя колонками, переведенные макеты, состояние литературы и восстановление ноутбука получают исправления. [Проверьте PDF-версию](../guides/previews.md#pdf-search-coverage).

Настольные пакеты и автономные архивы CLI снова доступны, включая пакеты Linux CLI. Используйте [Текущее руководство по установке](../guides/installation.md). [Оригинальное название: v1.0.0](v1.0.0.md).
