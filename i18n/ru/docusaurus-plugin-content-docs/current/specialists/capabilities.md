# Назначение Skills и коннекторов {/* #assign-skills-and-connectors */}

Список возможностей Specialist определяет, к каким Skills и коннекторам он может подключиться. Connector с глобальной поддержкой не доступен автоматически для каждого ограниченного Specialist.

## Настройка эксплицитного доступа {/* #configure-explicit-access */}

<p className="example-label"><strong>Пример</strong> Назначение возможностей для RNA-seq QC Reviewer</p>

1. Откройте **Settings → Specialists**, затем отредактируйте **RNA-seq QC Рецензия**.
2. Выключите **Full access**.
3. В **Skills** выберите **Добавить навык**, найдите `rnaseq-count-qc` и добавьте сохраненный персональный пакет. Подтвердите **Skills 1**.
4. В **Connectors** выберите **Добавить разъем** и выберите **Архивы Omics**. Подтвердите **Коннектор 1**.
5. Откройте подробную информацию о возможности, чтобы убедиться, что вы выбрали предполагаемый ресурс. Сохранить и вновь открыть роль, чтобы подтвердить настойчивость.

![Specialist с явным выбором возможностей](/img/open-science/capabilities-walkthrough/05-specialist-capabilities.webp)

| Контроль | Эффект |
| --- | --- |
| Полный доступ к | Использует унаследованную область возможностей с любыми явными исключениями на каждый ресурс. Проверить список разрешенных после изменения **Manage access**. |
| Полный доступ отключен | Использует явные списки; Недостающее связывание не может быть обеспечено только путем наименования инструмента в подсказке. |
| Добавить навык / Добавить разъем | Открывает селектор для этого типа возможностей. |
| Детали способности | Проверяет ресурс; Он не управляет своим научным процессом. |
| Удалить | Удалите эту привязку без удаления ресурса. |
| Сохранить изменения | Сохраняет выбранный объем. |

Требуемый приложением Skills остается включенным во всем мире. Это не заменяет список возможностей Specialist или не включает полный доступ. Если Customize недоступен для этой роли, проверьте его обязательный и разрешенный ресурс. Смотрите [Активация Skill](../skills/overview.md#why-some-switches-cannot-be-turned-off).

## Адаптация доступа к ресурсу {/* #resource-access */}

В соответствии с **Settings → Skills** или **Connectors**, откройте всплывающее окно **Manage access** ресурса, чтобы вместе проверить ассоциации Main Agent и Specialist. Он обновляет связывание выбранной роли, а не состояние, включенное ролью. Полный доступ к ролям может иметь исключения из ресурсов; Ограниченные роли используют явные выборки. Маркетплейс-связи можно читать только в этом всплывающем окно. Смотрите [иллюстрированные элементы управления доступом](../guides/connectors.md#resource-access).

После изменения привязки подтвердите, что роль включена, ее учетные данные службы готовы и ее предполагаемая работа разрешена. **Used by** показывает задания, а не завершенные прогоны.

## Четыре отдельных проверки готовности {/* #four-separate-readiness-checks */}

| слой | Что проверить | Пример неудачи |
| --- | --- | --- |
| Роль | Установка, включение, настройка завершена | Импортная роль остается отключенной до тех пор, пока не будет сохранена настройка. |
| Способность | Назначенный ресурс назначается и решается временем выполнения | Имя дисплея / короткое имя не решается для назначенного ресурса каталога. |
| Обслуживание / Runtime | Подключенный сервер, требуемые учетные данные, доступное ядро / зависимости | Отсутствуют необходимые служебные данные или пакет. |
| Операция | Текущая вводная версия и утвержденные меры | Недоступная передача файла терпит неудачу до казни ребенка. |

Местная роль сохранила свои привязки Skill и Omics Archives после создания и импорта пакетов. Первый делегированный ребенок не решил Skill по короткому имени, которое он пытался, но завершил явно предоставленные проверки таблицы в Python. Это проверяет делегирование и арифметику, а не успешную загрузку Skill. Когда это произойдет, попросите агента проверить его доступный каталог и использовать точный идентификатор ресурса. Не расширяйте полный доступ только для того, чтобы скрыть проблему именования.

## Доступность не является режимом разрешения {/* #capability-access-is-not-permission-mode */}

Полный доступ не означает «разрешить каждое действие без запроса». [Режим утверждения](../guides/approval-modes.md), границы файловой системы / сети и правила выполнения все еще применяются. Ребенок может выдать свой собственный запрос на разрешение в разговоре с родителем. Проверьте запрашивающую роль и операцию, прежде чем отвечать.

При экспорте роли идентификаторы Connector являются ссылками, а не переносными соединениями или секретами. Выбранные файлы Skill могут быть включены в явном виде. На другом устройстве подтвердите каждое связывание, настройте учетные данные и запустите одну небольшую проверку, прежде чем полагаться на роль. Смотрите [Управлять и делиться](./manage.md).
