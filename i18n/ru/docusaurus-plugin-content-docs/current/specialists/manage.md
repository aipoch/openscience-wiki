# Управлять и делиться специалистами {/* #manage-and-share-specialists */}

Используйте пакет для перемещения сконфигурированной роли и завершения локальной настройки после импорта. Ссылки Skills, Connector и локальные разрешения имеют разные правила переносимости.

В управлении партиями просмотрите выбранный счетчик в нижней области действия перед применением операции. Прочитайте отзывы о завершении или отказе там, а затем проверьте полученные элементы. Выбор одной только записи не позволяет, не устанавливает и не удаляет ее.

## Контроль за перечнем {/* #list-controls */}

| Контроль | Операция и ожидаемый результат |
| --- | --- |
| Поиск специалистов / Категория Фильтр | Узкие установленные ряды; фильтры, если сохраненная роль отсутствует. |
| Редактировать/назвать роль | Открывает существующий редактор. Сохраните изменения и снова откройте для проверки. |
| Изменить внешность | Меняет иконку/цвет без изменения инструкции. |
| Управление тегами | Назначает организационные ярлыки. |
| переключаться | Позволяет/отключает роль, не удаляя ее. |
| Действия → Дублировать | Открывается черновик новой роли с копированными инструкциями/обязательствами и именем копии. Создание специалиста по-прежнему необходимо. |
| Действия → Экспорт ZIP | Открывает выбор экспорта и сохраняет переносной пакет. |
| Действия → Удалить | Открывает подтверждение о постоянном удалении; Отдельно проверьте опциональное удаление Skill. |

Перед удалением роли проверьте возможность удаления Skills. Держите общий Skills, если другие роли все еще используют их. Удаление дубликата не требует удаления исходной роли.

![Удаление одноразовой роли при сохранении общего Skills](/img/open-science/capabilities-walkthrough/18-specialist-delete-confirmation.webp)

## Поделиться и импортировать пакет {/* #share-and-import-a-package */}

### Экспорт с необходимыми файлами Skill {/* #export-with-the-required-skill-files */}

<p className="example-label"><strong>Пример</strong> Поделитесь ролью рецензента с Skill</p>

1. Выберите **Actions → Export ZIP** на RNA-seq QC Reviewer.
2. В **Choose Skills to include** выберите `rnaseq-count-qc`, если получателю нужны его файлы. Установленный персональный/импортный Skill не обязательно включается по умолчанию.
3. Экспортируйте и проверяйте архив перед обменом.

![Выбор Skill для включения в пакет Specialist](/img/open-science/capabilities-walkthrough/07-specialist-export.webp)

Фактический <ExampleDownload path="/examples/capabilities/rna-seq-qc-reviewer-with-skill.zip">Пакет с Skill</ExampleDownload> содержит `manifest.json`, `specialist.json`, `skills/rnaseq-count-qc/SKILL.md` и его эталонную схему. Минимальный экспорт может содержать только два файла JSON. Connector ID – это ссылки. Удостоверения, местный траст и полный доступ не передаются в качестве готового к использованию разрешения.

### Импорт, разрешение конфликтов, доработка {/* #import-resolve-conflicts-finish-setup */}

1. Выберите **Add specialist → Import ZIP → Choose ZIP**. Один пакет содержит один Specialist. **Download template** предоставляет шаблон пакета приложений.
2. Проверьте имя, неизменяемый идентификатор, версию, в комплекте Skills, пределы архива и диагностику.
3. Для каждого конфликта Skill выберите **Keep installed Skill** или **Use package Skill**. Второй вариант заменяет файлы для каждого текущего пользователя Skill. Читать **Пострадавший сейчас**.
4. Для существующего идентификатора Specialist выберите **Review overwrite**, проверьте текущие / входящие версии и экспортируйте текущую версию сначала, если это необходимо. **Overwrite and continue** является отдельным подтверждением.
5. Импортная роль сохраняется **Нетрудоспособный / SETUP INCOMPLELE**. Осмотрите инструкции и привязки к возможностям в редакторе, выберите предполагаемый объем доступа, затем **Save changes** для завершения настройки и включите его.
6. Откройте установленную роль и запустите небольшую, масштабированную задачу.

![Разрешение реального конфликта RNA-seq Skill во время импорта](/img/open-science/capabilities-walkthrough/19-specialist-import-conflict.webp)

**Версия без изменений** может сопровождать конфликт Skill. Выберите предполагаемый источник Skill, а затем повторно откройте импортируемую роль, чтобы подтвердить ее привязку и объем доступа.

| Контроль предварительного просмотра | Что нужно проверить |
| --- | --- |
| Расширение Skill | Версия, расположение, причина и список файлов. |
| Ограничения архива | 50 MB сжат, 200 MB несжат, 2,000 файлы, 25 MB на файл в этом интерфейсе. |
| Диагностика | Блокировка ошибок, предупреждений и информации; Предупреждение может потребовать четкого выбора. |
| Copy report / Скачать JSON | Экспортная диагностика для устранения неполадок. Проанализируйте отчет, прежде чем делиться им. |
| Отмена | Оставляет предварительный просмотр без установки. |
| Оригинальное название: Review overwrite | Продолжается только тогда, когда это позволяет необходимый выбор и проверка. |

**Импорт из браузера:** выбирает **Import ZIP → Choose ZIP**, затем проверяет пакет, разрешает конфликты и завершает локальную настройку, прежде чем включить роль. Полномочия и конфигурация доверия должны быть установлены на устройстве назначения. Если загрузка не удалась, сохраните ошибку и следуйте за [устранение неполадок](../guides/troubleshooting.md).

## Просмотреть маркетплейс {/* #browse-the-marketplace */}

Откройте **Marketplace**, найдите роль и выберите **View details**. Проверьте издателя, источник, версию, лицензию, размер загрузки и включите Skills / Connectors. **Refresh Marketplace** обновляет каталог **Manage Marketplace sources** управляет настроенными источниками. Фильтры All/Official/Community касаются происхождения каталога, а не готовности к работе.

![Детали пакета Auto Research Specialist](/img/open-science/capabilities-walkthrough/22-marketplace-package-detail.webp)

Выберите **Install Specialist**, затем подтвердите, что роль появляется в **Marketplace**, и проверьте состояние включения и связывания. Подсчет пакетов каталогов описывает этот пакет, а не все возможности приложения. Установка не выполняет исследовательскую задачу или не подготавливает каждую внешнюю зависимость. Завершите любую необходимую настройку перед использованием.

![Автоисследование установлено и включено](/img/open-science/capabilities-walkthrough/23-marketplace-installed.webp)

## Проверяйте, прежде чем делиться {/* #verify-before-sharing */}

После импорта или изменения роли запустите небольшую задачу, используя свои назначенные возможности и проверьте сохраненный результат. Следуйте [Продлить анализ с помощью установленного Specialist](../workflows/extend-analysis.md) для существующих методов, PCA и примеров матриц. Проверьте необходимые входы и нерешенные ограничения для выбранного маршрута.
