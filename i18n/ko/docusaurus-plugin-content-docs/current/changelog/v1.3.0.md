# 릴리스 노트 · v1.3.0 {/* #release-notes--v130 */}

**2026-11-18 UTC**에 출시. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v1.3.0).

## 다음 연구 과제 일정 {/* #scheduled-tasks */}

에이전트 메시지를 보내거나 파이썬, R 또는 쉘 스크립트를 실행하는 일회성 또는 반복 작업을 만듭니다. 각 메시지 실행에 대한 기존 대화 또는 새로운 대화를 선택하고 개별 실행 기록을 검사합니다. 앱을 실행해야 합니다. 일정은 구성된 권한, 자격 및 공급자 할당량을 사용합니다. [계획된 작업](../guides/scheduled-tasks.md).

## 이미지 및 편집 발표 {/* #creation */}

이미지 생성 서비스 구성, 프롬프트에서 생성하고 버전 편집으로 이미지를 정제. 이미지 생성은 주요과 시각에서 분리된 그것의 자신의 모형 조정이 있습니다. [이미지 생성 및 편집](../guides/image-generation.md).

PPTX 미리보기 이제 편집 슬라이드 텍스트 및 포맷을 지원합니다. 저장된 버전을 검토하고 그것을 공유하기 전에 다운로드 된 프리젠 테이션을 다시 엽니 다. [발표 편집](../guides/presentation-editing.md).

## 연구 또는 재생을 설명하십시오. {/* #films */}

**Research explanation** 또는 **Operation replay**를 연구 영화 대화 상자에서 선택하십시오. Branches는 독립적인 영화 산출을 지킵니다. 대화 상자는 생성 이전의 모델 사용을 설명하고 세션 메뉴는 기존 필름을 엽니다. [필름 제작](../guides/research-films.md#generate-film).

## 더 긴 일 도중 통제 {/* #other-changes */}

- 계획된 실행은 그들의 자신의 역사가 있습니다; 노트북 공정 감시는 소유한 과정을 보여주고 **Terminate**를 제안합니다. [공정 모니터링](../guides/notebook.md#process-monitor).
- CodeBuddy 구독 지원 중국 및 국제 계정, 관리 CLI를 통해 모델 발견. [계정 설정](../guides/providers.md#codebuddy-subscription).
- 에이전트 질문 선물 선택 그들의 거래 오프. 작업을 계속하기 전에 선택을 검토하십시오.
- 문서 구성 능력은 먼저 관리 환경에서 필요한 라이브러리를 준비합니다.
- Incremental 세션 지속, 영화 복구 및 Windows 설치 / 업데이트 개선은 반복 작업 및 불필요한 리소스 사용을 감소시킵니다.

[설치 및 업데이트](../guides/installation.md)와 [v1.2.2의](v1.2.2.md)를 참조하십시오.
