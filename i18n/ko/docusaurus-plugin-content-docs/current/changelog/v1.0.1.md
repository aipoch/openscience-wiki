# 업데이트 내역 · v1.0.1

공개일: **2026-10-20 UTC**. [공식 릴리스](https://github.com/aipoch/open-science/releases/tag/v1.0.1).

## 연구 패키지를 앱으로 가져오기 {/* #packages */}

지원하는 웹사이트는 `.science` 패키지를 같은 컴퓨터의 데스크톱 앱으로 전달할 수 있습니다. 브라우저에서 Open-Science를 열도록 허용하고 전송 중에는 페이지를 열어 두세요. 앱에서 패키지와 가져올 위치를 확인합니다. 앱이 수신한 것만으로 최종 가져오기가 승인되지는 않습니다. 로컬 파일은 프로젝트 홈에 끌어 놓을 수도 있습니다. 참고: [브라우저에서 가져오기](../guides/research-packages.md#browser-import).

## 업데이트와 입력 대기 세션 확인 {/* #interaction */}

업데이트 대화상자에서 다운로드, 릴리스 노트, 설치 준비를 함께 확인합니다. Windows 설치 전달과 시작 오류를 수정했지만 자동 설치 가능 여부는 여전히 배포 채널에 달려 있습니다. [업데이트 진행 확인](../guides/installation.md#update-progress) 을 따르고 다시 시작한 뒤 설치된 버전을 확인하세요.

답변이나 승인을 기다리는 세션은 홈, 사이드바, 대화에서 대기 상태를 계속 표시합니다. 보류 중인 카드를 다시 열어 진행하세요. 사이드바 세션을 두 번 클릭하면 편집기가 열립니다. 참고: [입력 대기](../guides/sessions.md#waiting-for-input).

## 데이터 소스와 인증 정보 {/* #sources */}

- PDC에 공개 증례의 인구통계·진단 메타데이터를 추가했습니다. 연구 버전 선택과 외부 참조를 지원합니다. 서로 다른 소스의 ID를 혼용하지 마세요. [PDC 임상 필드](../reference/connector-operations.md#pdc_list_clinical).
- 두 MiniMax 리전 모두 M3.1 Flash를 제공합니다. 첨부 이미지도 Skill 선택에 활용할 수 있습니다. [모델 선택](../guides/providers.md#catalog-models).
- OAuth 인증 정보는 이를 발급한 권한 부여 서버에 연결됩니다. 필요한 경우 [재인증](../guides/connectors.md#oauth-reconnect) 을 진행하세요.
- PDF 검색 범위가 불완전하면 표시합니다. 2단 레이아웃 읽기, 번역 레이아웃, 문헌 상태, Notebook 복구도 수정했습니다. [PDF 검색 범위 확인](../guides/previews.md#pdf-search-coverage).

Linux CLI 패키지를 포함해 데스크톱 설치 파일과 독립 CLI 압축 파일을 다시 제공합니다. 참고: [현재 설치 가이드](../guides/installation.md). [이전 릴리스: v1.0.0](v1.0.0.md).
