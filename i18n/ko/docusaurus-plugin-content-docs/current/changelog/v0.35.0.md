# 릴리스 노트 · v0.35.0 {/* #release-notes--v0350 */}

**2026-10-04 UTC의 경우**에 출시. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.35.0).

## Replay 및 연구 토론 {/* #replay-and-discuss-research */}

**View replay**는 재생, 단계 항법, Notebook 기록 및 파일 버전 역사를 가진 기록된 회의를 선물합니다. **Ask about this step**은 선택한 컨텍스트를 writable 대화로 가져옵니다. 수입된 `.science` 연구는 읽기 전용 남아 있습니다; fork는 계속 실행합니다. Replay는 다시 실행되지 않습니다. 새로운 [세션 재생 가이드](../guides/session-replay.md)을 따르십시오.

## 과학 데이터베이스 {/* #scientific-databases */}

이 릴리스는 **13 운영**, **34 연결관과 339 가동**에 레지스트리를 가져다 : 33 데이터 소스 가족 337 작업, 플러스 두 개의 오프라인 Molecule 운영.

| 이름 &#42; | 추가 기능 |
| --- | --- |
| Cellosaurus | 셀 라인 정체성, synonyms 및 품질 annotations |
| Monarch Initiative | 질병/진-to-phenotype 협회 소스 증거 |
| IEDB | Epitopes, 항원, T 세포, B 세포 및 MHC 분석실험 및 간행물 |
| Omics Archives → GEO | matrix 파일 위치 및 preflight 이미 읽기 matrix 텍스트를 발견하십시오. |
| 구조 및 상호 작용 → PDB | 정체성, E-value 및 쿼리 커버리지 필터로 단백질 시퀀스에 의한 구조 찾기 |

[기능 및 연결 단계](../tools/databases.md#cell-lines-phenotypes-immunity)과 [업데이트된 작업 카탈로그](../reference/connector-operations.md)을 참조하십시오. GEO preflight checks 제공된 텍스트, 디스크에 다운로드된 파일; matrix discovery 파일을 다운로드하지 않습니다.

## PDF 및 워크스페이스 컨트롤 {/* #pdfs-and-workspace-controls */}

- **Figures and tables** 추출에서 생성된 PDF 및 라이브러리 PDF에 업로드. Bounded 병렬 분석은 복잡한 레이아웃을 더 잘 취급하면서 처리를 개선합니다. [문학 PDF에 내장 된 테이블을 위해](../guides/previews.md#pdf-extraction) 참조.
- 대화 영역에서 파일을 드롭하여 첨부하십시오. 전송하기 전에 첨부 파일을 검사합니다. [파일 삭제](../guides/composer.md#conversation-drop) 참조.
- 사용법 도표는 날짜의 맞은편에 지속적인 검사를 허용합니다. [매일 사용](../guides/usage.md#inspect-daily-usage) 참조.
- Windows은 titlebar에서 기본 응용 프로그램 메뉴를 추가합니다. PDF 개요 및 노트는 좁은 창에 더 잘 적응시킵니다.

## 모델 및 네트워크 액세스 {/* #models-and-network-access */}

OpenCode Zen 카탈로그는 Jev 분류 항목을 포함하여 확장됩니다. Main-model 및 분류 선택은 별도 유지; [모델 카탈로그](../guides/providers.md#catalog-models) 참조.

네트워크 설정은 신뢰할 수있는 개인 서비스에서 공개 도메인 규칙을 구별합니다. 개인 보조금은 정확한 호스트 이름, 포트 및 검토 DNS 주소, 저장하기 전에 다른 DNS 체크와 결합합니다. [공공 규칙](../guides/network.md#public-network-rules) 및 [개인 서비스](../guides/network.md#trusted-private-services)을 참조하십시오.

## 수정 사항 {/* #fixes */}

수정 커버 지속 세션 결과 및 승인 대기, 재생 Notebook 국가 및 파일 갤러리, 과학 실행 라인, Codex 폴더 권한, Windows 실행 시간 시작 및 샌드 박스 액세스, WSL 폴더 경로. `.science` 패키지의 Identical 개체는 deduplicated; 공급자와 프로젝트 초안은 사고 손실에 대하여 보호를 얻습니다.
