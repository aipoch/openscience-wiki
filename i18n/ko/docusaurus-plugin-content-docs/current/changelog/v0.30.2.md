# 변경 로그 · v0.30.2 {/* #changelog--v0302 */}

9월 17 출시, 2026. 이 업데이트는 신뢰할 수있는 Skill로드, 측면 토론, 과학 데이터 쿼리 및 실행 복구에 중점을 둡니다.

[공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.30.2) · [v0.30.1 이후 변경](https://github.com/aipoch/open-science/compare/v0.30.1...v0.30.2)

## 매일의 변화 {/* #changes-to-everyday-use */}

| 영역 | 당신을 위한 어떤 변화 |
| --- | --- |
| Specialist Skills | Bound Skills는 Specialist 회전 및 위임 작업을 위해 준비됩니다. OpenCode는 규정한 Skill 참고를 읽을 수 있습니다. 이름 &#42; [Specialist 워크플로우](../workflows/extend-analysis.md) 선택 및 사용. |
| Side Chat | Main 실행 또는 승인을위한 대기는 더 이상 Side Chat 자체로 차단하지 않습니다. Side Chat는 신청 전망의 맞은편에 거치됩니다; 자신의 역사, 복원 및 읽기 전용 체크는 여전히 적용됩니다. [Side Chat](../guides/delegation.md) |
| 웹 연구 승인 | 지원되는 Claude Agent 본래 수색은 기억할 수 있습니다 **Allow for this conversation**을 진행하세요. Search and page-reading 보조금은 별도 유지됩니다. [권한](../guides/approval-modes.md#remember-web-search) |
| 리뷰어 | Auto-review 설정은 대화 시작을 살아남습니다. Linked 보정은 보정 주기에 필요한 피드백을 유지합니다. 개정된 산출 및 후에 검토를 검열하십시오. [리뷰어](../specialists/reviewer.md) |

## 데이터 및 증거 {/* #data-and-evidence */}

[Connector 참조](../reference/connector-operations.md) 및 다운로드 가능한 레지스트리는 이제 v0.30.2을 사용합니다. Reactome은 요청된 지원된 종을 존중합니다. Ensembl은 해결 된 종을 반환하고 앞으로 물가에 VEP 지역 쿼리를 정상화합니다. UCSC는 잘못된 좌표 경계를 거부하고, gnomAD 지역 좌표는 1 억 미만이어야합니다. CellGuide 및 OLS 관련 fetch 또는 pagination 실패를 빈 증거로 제시합니다.

PubMed 저자는 이제 성/이니셜/스프릭스의 차이를 보존합니다. `literature-review` Skill는 두 방향으로 크로스레프 반사 관계를 확인합니다. 누락 된 감적은 종이가 결코 철회되지 않은 것을 증명하지 않습니다. [metadata 체크](../guides/library.md) 및 [문학 증거](../workflows/literature-review.md)을 참조하십시오.

## Notebook 및 복구 {/* #notebook-and-recovery */}

Windows는 환경 준비 후 conda R 시작, 실행 가능한 조회, R 커널 복구 및 검증 환경에서 pip 항목 포인트를 수정합니다. Notebook 재생은 동일한 회전 입력 및 표준 리브 가져 오기를 지원했습니다. Linux은 임시 산의 밑에 보조금을 읽습니다 또한 정정됩니다. [런타임](../guides/runtimes.md) 및 [재현성](../guides/reproducibility.md)을 참조하십시오.

이 릴리즈/source-backed 수정입니다. 기존 Windows 및 Specialist 스크린 샷은 원래 버전을 유지; 그들은 새로운 v0.30.2 테스트 결과가 아닙니다. 입력 증거 또는 환경 잠금 여전히 주의를 요구하고, 재생산 체크는 결과 버전을 캡처하는 특정 남아있다.

## 기타 개선 {/* #other-improvements */}

공급자 카탈로그는 DeepSeek V4.1 섬광을 추가하고 오래된 핀으로 꼿는 선택을 유지하고 있는 동안 Volcengine Ark 모형을 상쾌하게 합니다. 마켓 플레이스 카드는 저자가 복부 될 때 소스를 보여줍니다. OpenCode 위임 작업은 고립 된 실행 시간을 사용합니다; CLI 대화 스냅 샷 및 여러 설정, 탭, 문학 및 도구 카드 상호 작용이 정확합니다.

업데이트에 [설치 및 업데이트](../guides/installation.md)을 사용하십시오. 미리 릴리스는 [v0.30.1](./v0.30.1.md)입니다.
