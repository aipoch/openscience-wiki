# 변경 로그 · v0.30.1 {/* #changelog--v0301 */}

9월 16 출시, 2026. 이 업데이트는 사이드 토론, 검토 방법 변경 및 연구 자료를 공유하는 방법을 개선합니다.

[공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [v0.30.0 이후 변경](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## 업데이트 된 워크플로우 {/* #updated-workflows */}

| 영역 | 당신을 위한 어떤 변화 |
| --- | --- |
| Side Chat | 빈 초안을 열고, 주요 대화의 모델을 상속하고 노력하는 것을 상속하거나 다음의 전송에 대한 다른 모델을 선택하십시오. 콘텐츠로 바로 가기; 비접촉 된 빈 초안은 정리됩니다. [Side Chat](../guides/delegation.md) |
| Skill 업데이트 | Inspect 파일 변경, 줄 번호 및 추가 / 삭제 된 줄 전에 **기존 스킬 업데이트**을 진행하세요. 영향을받는 전문가와 지역 편집을 검토하여 대체됩니다. [Skill 마켓플레이스](../skills/marketplace.md) |
| 연구 패키지 | **Full export** 유효한 문학 PDF를 포함합니다; **Customize contents** 그들을 개별적으로 선택. 필수 수출 omits 선택적인 PDF; 필수 증거는 제거될 수 없습니다. Side Chat 대화는 제외됩니다. [연구 패키지](../guides/research-packages.md) |
| 지역 관문 | 루프백 사용자 정의 게이트웨이는 서버가 인증이 필요없는 경우 API 키 공백을 남길 수 있습니다. 원격 게이트웨이는 여전히 자격과 HTTPS을 요구합니다. [공급자 설정](../guides/providers.md) |
| Web-reading 승인 | 지원된 웹 읽기 요청은 다른 웹 사이트에서 나중에 페이지를 포함하여 대화를 기억할 수 있습니다. [권한](../guides/approval-modes.md) |
| 태그 | 리소스 태그 선택기 내에서 검색, 화살표 키를 사용 하 여 입력, 또는 생성 하 고 새로운 태그를 할당. [태그](../guides/tags.md) |
| 설치 및 복구 | macOS 가이드 읽기 전용 사본을 업데이트하기 전에 응용 프로그램. Windows에는 별도의 구조상 리셋 유틸리티가 있으며 미리보기 및 유형 확인이 있습니다. Installers는 프로젝트 라이센스를 표시합니다. [설치 및 업데이트](../guides/installation.md) · [Windows 리셋](../guides/troubleshooting.md#windows-data-reset) |

## 관련 상품 {/* #reported-fixes */}

릴리스는 또한 MCP 타임 아웃, 역사적인 artifact 바인딩, 작업 취소 및 할당 된 Notebook 실행 중에 계획 승인에 대한 수정을보고합니다. PDF 파싱은 차단된 국가 및 보고 적출 실패에서 재출할 수 있습니다; 그림/테이블 배치 회복은 개량됩니다. Connector는 gnomAD 지역 인수 및 데이터셋 참조 빌드를 검증하고 ESM-2 배치 잔류물 풀링을 수정합니다.

공급자는 시험된 공급자의 노선을 사용합니다. 파일 백업 Codex 기호 인은 더 명확한 수입 오류를받습니다. 문학보기는 시작 대화로 돌아와 OpenCode Side Chat 지침은 Main에서 분리됩니다.

업데이트 절차에 대한 [설치 및 업데이트](../guides/installation.md)을 사용하십시오. 미리 설치된 특징 방출은 [v0.30.0](./v0.30.0.md)입니다.
