# 릴리스 노트 · v1.0.8

출시 예정 **2026-11-04 UTC**. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v1.0.8).

## 문헌 목록을 라이브러리로 가져오기 {/* #literature */}

종이 식별자의 목록이 있습니까? **Add from DOI or link** 에서 DOI, arXiv, PMID, PMCID 또는 지원되는 공식 논문 링크를 빈 줄을 제외하고 최대 100줄까지 입력할 수 있습니다. 검색 결과와 중복 처리 방식을 확인한 후 가져오세요. 메타데이터를 찾았다고 해서 전문까지 자동으로 가져오는 것은 아닙니다. [일괄 수입 walkthrough](../guides/library.md#doi-link-import).

지금 참조 **Study overview**· 구성 된 주요 모델은 5 개의 섹션으로 사용 가능한 소스를 구성 : 연구 질문, 연구 인구, 방법, 주요 발견 및 제한. 소스 라벨은 요약, 전체 텍스트 및 선택된 패스를 구분합니다. 당신의 독서를 동양화하기 위하여, 그 후에 본래 종이에 있는 중요한 주장을 검사하십시오. [자주 묻는 질문](../guides/library.md#study-overview).

## 설정 항목 재구성 {/* #settings */}

**Appearance** · **Notifications** 별도의 패널 **System**· 일반 앱 정보, 진단, 명령줄 도구 및 도움말, 수동 설치 가이드를 포함. 설정 센터는 이제 **4개 그룹, 19개 패널**. [설정 맵](../settings/overview.md) · [외관 및 알림](../guides/appearance.md).

## 연구와 일상적인 신뢰성 {/* #reliability */}

- eQTL 카탈로그는 REST API가 은퇴 한 후 릴리스 7 파일을 사용합니다. 견적 요청 **GRCh38** 좌표; 혼자 유전자 ID는 더 이상 유효한 쿼리가 없습니다. [연락처](../tools/databases.md#eqtl-coordinates).
- PDF 주문은 테이블 행에서 prose 열을 구별하는 텍스트를 사용합니다. 추출 검사 작물 경계 및 신뢰성 경고와 함께 주위 세포 텍스트 보존. [PDF 읽기 및 추출](../guides/previews.md#automatic-pdf-reading-order).
- R 재현성 검사는 인수 평가나 메서드 디스패치를 일으킬 수 있는 작업 후 오래된 파일 증거를 무효화합니다. 이력 패널은 실행 증거가 불완전한 상태를 설명하며, 이전 Markdown 산출물을 열면 오래된 이력 참조가 복구됩니다. [검증 증거 읽기](../guides/reproducibility.md#execution-evidence).
- 모든 5개의 에이전트 프레임워크를 통해 완료된 세션 릴리즈 제공업체 및 툴 프로세스. 패키지 데스크톱 빌드에 Pi 설치가 수리됩니다.
- 업데이트 준비는 차단 프로세스를 더 명확하게 식별합니다. 수정 주소 macOS 읽기 전용 파일 홀더, Windows 프로세스 감지 및 stale 노트북 복구 레코드. 진단 패키지는 실제 데스크탑 복구 오류를 유지합니다. [공지사항](../guides/installation.md#update-preparation).
- 대상 폴더를 읽을 수 없거나 후속 정리 작업이 실패해도 다운로드된 파일은 유지됩니다. Windows의 PDF 종료 처리와 보호 검사도 개선되었습니다. PATH의 Node 버전이 오래되어 프록시를 사용할 수 없으면 Notebook 명령줄 도구가 앱에 포함된 Node를 사용할 수 있습니다.
- Successful full-text searches clear an earlier PDF-add error, 그리고 더 이상 사용할 수 없는 모델 통지를 반복.

Tencent TokenHub에 Hy4와 100만 토큰 컨텍스트를 지원하는 DeepSeek V4.1 Flash 경로가 추가되었습니다. GLM-5.3-Flash, Kimi K3, MiniMax M3는 이미지 입력도 지원합니다. 사용 가능 여부는 제공업체 계정과 선택한 경로에 따라 달라집니다. [공급자 설정](../guides/providers.md).

내장 카탈로그가 남아 있습니다 **Connector 48개, 작업 418개**. [현재 카탈로그](../tools/databases.md#supported-databases) · [이전 버전](v1.0.7.md).
