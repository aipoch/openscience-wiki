## 1.0 릴리스로 이동 {/* #upgrade */}

1.0은 기존의 연구 작업공간을 안정적인 출시라인으로 제공합니다. 그것은 역사적인 프로파일 업그레이드 및 `.science` 가져 오기를 유지; 버전 변경은 새 프로필 또는 데이터 형식이 필요하지 않습니다. 프로필 및 연구 데이터를 백업, 활성 작업을 완료, 다음 공식 데스크톱 설치 프로그램을 통해 업그레이드. 이진 downgrade는 데이터 변경을 취소하지 않습니다.

이 간행물은 **데스크탑 패키지 만**이 포함되어 있습니다. 독립 CLI 아카이브 및 Linux CLI `.deb`/`.rpm` 자산은 absent이며 웹 사이트 / 자동 업데이트 프로모션은 별도입니다. 1.0의 데스크톱 공급 명령 실행기를 사용하십시오. 이전 CLI 아카이브를 이름을 바꾸거나 Homebrew/npm을 이미 동일한 버전을 제공합니다. `open-science update`는 제거됩니다: 임명을 소유하는 설치자/패키지 매니저를 사용하십시오. [설치 및 1.x 호환성](../guides/installation.md#version-compatibility) 참조.

## 계속 중단된 일 {/* #recovery */}

호환 바탕 화면은 이전 컨트롤러가 차단 한 후 데스크탑 발사 된 백엔드를 채택 할 수 있습니다. CLI-launched 서비스는 독립적으로 유지됩니다. 실패한 폐쇄 준비는 창을 열고, 재연결은 일의 앞에 본래 대화 국가를 계속합니다. 저장된 작업을 취소 하기 전에 요청을 취소 알 수 없는 outcome. [서비스 소유권 및 복구](../reference/server.md#desktop-service-recovery) 참조.

ACP 대화는 선택한 에이전트로 이력서; Codex 세션은 Specialist 스위치 이후보다 안정적으로 회복합니다. [선택된 에이전트와 오리지널 세션을 확인](../guides/sessions.md#resume-selected-agent) 다음 차례로 전송하기 전에. 문맥 조밀도의 문학 선택 및 취소는 수정을받습니다.

## 답변 질문 및 PDF 읽기 {/* #interaction */}

- Clarification 카드는 더 긴 선택권 명부 및 다수 선택을 지원합니다. 질문에 대한 답변을 검토하고 **Finish**을 선택하십시오. 선택된 옵션은 혼자 초안입니다. [질문 답변](../guides/composer.md#clarification-questions).
- 주석 메모 버튼은 hover, 초점 또는 선택에 나타납니다, 읽기 동안 PDF 클리어 유지. [자주 묻는 질문](../guides/pdf-notes.md#reveal-note).
- PDF 추출 및 번역은 더 복잡한 소스 레이아웃을 보존, 기본 테이블 / 관계를 구성하고 과학적인 분수. **New translation**는 신선한 소스 텍스트를 준비합니다. 재사용하기 전에 원래로 결과를 비교하십시오. [추출 검사](../guides/previews.md#scientific-structure-check) · [번역](../guides/pdf-translation.md#scientific-layout).

## 1.0이 변경되지 않습니다. {/* #scope */}

기록된 세션 재생은 코드를 실행하지 않습니다. Artifact 검증은 캡처 된 입력 및 사용 가능한 환경을 필요로합니다. 그것은 과학적 유효성 또는 전체 세션의 세분화 재생산을 설정하지 않습니다. 가져온 `.science` 레코드는 읽기 전용 유지; writable continuation를 위한 사용 포크. Credentials, 사이드 채팅 및 개인 북마크는 패키지에서 복원되지 않습니다. SSH/Slurm compute는 지원됩니다; 관리된 클라우드-GPU 제출, 로컬 GPU 백엔드 및 실시간 멀티 유저 편집은 이 릴리스 밖에 있습니다.
