# 릴리스 노트 · v1.0.6

**2026-10-30 UTC**에 출시되었습니다. [공식 릴리스](https://github.com/aipoch/open-science/releases/tag/v1.0.6).

## Zotero 문헌을 가져오세요 {/* #zotero */}

같은 컴퓨터에서 실행 중인 Zotero 10 이상에서 개인 라이브러리나 선택한 컬렉션을 가져올 수 있습니다. 메타데이터, 로컬 PDF, 태그와 컬렉션 계층을 복사하기 전에 미리 보고, 기존 문헌을 재사용할 때는 일치 내용을 확인하세요. 양방향 동기화가 아닌 가져오기 기능입니다. [Zotero 가져오기 절차](../guides/library.md#zotero-import).

일반 문헌 검색이 저장된 개인 메모의 단어도 찾습니다. **Notes** 열에 논문을 읽는 이유를 기록하고 **Search references**로 다시 찾을 수 있습니다. [개인 메모로 검색](../guides/library.md#personal-note-search).

## PDF 읽기 순서 자동화 {/* #pdf */}

연결된 PDF의 텍스트 순서를 자동으로 구성합니다. 완전한 논리 태그를 우선하고, 사용 가능한 텍스트와 레이아웃에 따라 대체 방식을 사용합니다. 지속적으로 저장되는 수동 읽기 순서 설정은 제거되었으며, 영역을 저장한 이전 메시지에도 자동 순서가 적용됩니다. 복잡한 페이지를 인용하기 전에는 원문을 확인하세요. 번역된 PDF도 더 빠르게 열리고 DOCX 도구 모음은 스크롤 중에도 문서 위에 유지됩니다. [PDF 읽기 순서](../guides/previews.md#automatic-pdf-reading-order).

## 업데이트 후 계속 작업하기 {/* #reliability */}

- Windows 설치 파일 수를 줄이고 병렬 압축 해제를 적용했습니다. 앱 옆에 저장된 연구 데이터를 보존하고 깊은 설치 경로를 지원합니다. [Windows 업데이트 확인](../guides/installation.md#windows-update-data).
- 어시스턴트의 응답 작업이 끝나기 전까지 생성 파일을 게시할 수 있습니다. 긴 작업에서 이전의 2시간 제한으로 게시 권한이 만료되던 문제를 수정했습니다.
- **npx** 또는 **npm**을 사용하는 사용자 정의 로컬 Connector는 해당 명령이 없으면 앱에 포함된 런타임을 사용합니다. 이미 설치된 명령이 우선합니다. [로컬 명령](../guides/connectors.md#bundled-npm).
- Slurm은 로그 수집 전에 최종 상태를 저장하고 큐, 컨트롤러와 작업 이력 정보를 개별적으로 처리합니다. 취소의 최종 결과는 한 번만 반환합니다. [작업 상태와 결과 수집](../guides/remote-compute.md#slurm-outcome-recovery).
- 시스템 자격 증명 접근 승인에 최대 5분을 기다립니다. 시간 초과에는 별도의 복구 메시지가 표시됩니다. [시작 시 승인](../tools/credentials.md#system-authorization).

그 밖에 OpenCode 도구 호출과 Windows 실행 제한, Windows 쿠키 저장소의 시작 처리, 공백이 있는 R 임시 경로, 세션 동기화, 준비 중단 후 초안 복원, 가져온 세션의 오류 이력을 수정했습니다. 분할 버튼 메뉴도 일관된 모양을 사용합니다. WSL 미러링 네트워크에는 **Windows 11 22H2 이상**이 필요합니다. [WSL2 설정](../guides/runtimes.md#wsl2-preview).

내장 카탈로그는 그대로 **Connector 48개, 작업 418개**입니다. 데이터 소스 Connector 47개가 작업 416개를 제공하고, 오프라인 Molecule Connector 1개가 작업 2개를 제공합니다. [지원 데이터 소스](../tools/databases.md#supported-databases) · [이전 릴리스: v1.0.5](v1.0.5.md).
