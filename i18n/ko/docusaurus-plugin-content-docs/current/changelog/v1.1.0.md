# 릴리스 노트 · v1.1.0

출시 예정 **24시간**. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v1.1.0).

## 연구 필름으로 세션을 켭니다. {/* #research-films */}

완료된 세션은 짧은 영화가 될 수 있습니다. 로컬 narration 리소스를 설치하고 데스크톱 세션에서 생성하고 휴대용 플레이어 또는 MP4를 내보내기 전에 재생을 검토하십시오. 영화는 기록 된 연구; 그것은 다시 실행하거나 분석을 확인하지 않습니다. [연구 필름 가이드](../guides/research-films.md).

## 본문 바로가기 {/* #literature */}

최대 5개의 참조를 선택하여 연구 개요를 일괄 처리로 생성합니다. 일시 중지, 계속 unfinished work or retry failed items while keep complete Summarys. CLI 및 MCP도 라이브러리 검색, 인용 서식 및 참조 관리 작업을 얻을 수 있습니다. [Batch 개요](../guides/library.md#batch-overviews) · [문학 명령](../reference/cli.md#literature-library).

## 모바일 기기에서 workspace를 엽니다. {/* #mobile */}

QR 페어링은 같은 WiFi 또는 Pinggy를 통해 인터넷 연결에 전화 또는 태블릿을 지원합니다. 호스트 실행을 유지하고 스캔하기 전에 연결 상태를 검사. [연결 옵션](../guides/remote-access.md#mobile-pairing).

## 매일의 변화 {/* #reliability */}

- Compute 설정으로 이동 **Connections**· 연구 케이스 라이브러리에는 새로 고침 레이아웃과 더 명확한 수입 목적지가 있습니다.
- 대화는 중단과 저장 실패 후에 더 안정적으로 회복합니다. 완료 또는 idle 에이전트 연결 릴리스 리소스 더 일관성.
- 진단은 노트북 실행 증거와 역사적인 백엔드 로그를 유지합니다. Windows는 문제 해결을 위한 선택적인 자원 기록을 추가합니다.
- PDF 추출은 검색 가능한 스캔에서 그림과 테이블 복구를 개선하고 Codex Chat은 기본 이미지 입력을 지원합니다.
- 노트북은 준비된 앱 관리 실행 시간을 선호합니다. Shell 실패 표면은 공구 오류로 인해 성공적인 결과보다.
- Windows Update 준비는 프로세스 정체성과 점유된 파일을 확인합니다. 로컬 `.science` 그리고 MP4 수출은 데스크탑 저장 대화 상자를 안정적으로 취급합니다.
