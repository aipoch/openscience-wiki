# 릴리스 노트 · v0.33.1 {/* #release-notes--v0331 */}

**24 9월 2026**에 출시. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.33.1).

## 문학 상영 및 PDF 독서 {/* #literature-screening-and-pdf-reading */}

Smart 컬렉션은 라이브 **Screening process**, 일시 정지 / 이력서 제어 및 프로젝트 또는 수집 범위에 대한 링크를 보여줍니다. Resume 가용성은 그것의 규칙 및 종이와 호환이 되는 저장한 달리에 달려 있습니다. 수동 결정은 여전히 회원을 결정합니다. [스크린과 검토 종이](../workflows/screen-literature.md) 참조.

PDF 증거는 첫번째 업무 공간 메시지를 동반할 수 있습니다. 라이브러리 PDF을 열고 **Read with agent**을 선택하고, 프로젝트를 선택하고, 질문을 보내기 전에 독서 첨부 파일을 확인하십시오. [PDF 컨텍스트](../guides/previews.md#first-message-pdf) 참조.

## 과학적인 연결관 {/* #scientific-connectors */}

- **HMMER의 장점**은 프로그램별 단백질/프로필/ 정렬 검색, 상태 및 완료 결과를 추가합니다.
- **InterProScan의 장점**은 기존의 주석 작업을 확인하고 TSV 보고서를 검색합니다. 작업에 제출하지 않습니다.
- **한국어 (Korean)**은 최소 3개의 FASTA 레코드를 위한 클러스터 오메가를 추가합니다. [다중 상태 정렬 워크플로우](../workflows/multiple-sequence-alignment.md)을 따르십시오.
- **OpenAlex** 더 이상 앱의 키가 필요 없습니다; 서비스 제한은 여전히 적용됩니다. [옵션 자격 설정](../tools/credentials.md) 참조.

내장 레지스트리에는 오프라인 Molecule Connector을 포함한 **28 연결관과 271 가동**이 포함되어 있습니다. [데이터베이스 기능](../tools/databases.md) · [가동 참고](../reference/connector-operations.md).

## 설정, 진단 및 수정 {/* #settings-diagnostics-and-fixes */}

공급자 카탈로그는 GPT-6와 클로드 Opus 5.5를 추가합니다; 계정 액세스 및 프레임 워크 호환성은 여전히 가용성을 결정합니다. [모델 공급자](../guides/providers.md#catalog-models).

Session Diagnostics는 패키지 수출에 의해 원본 파일에서 적정된 증거를 구별합니다. Original 민감한 파일은 기본적으로 체크되지 않으며 선택한 경우만 포함됩니다. 수출 지역. [진단 수출](../guides/troubleshooting.md#session-diagnostics).

설정 헤더 및 로컬 패널 검색은 별도의 단축키가 있습니다. 역사 데이터 위치는 업그레이드를 통해 유지됩니다. 다른 고정 주소 Windows 관리 Python 발견, R 액세스 밀도 프롬프트, 런타임/컴퓨트 득점 경주, ACP 비전 기능 변경, 첫 번째 엔드 PDF 정체성, 복제 전송 및 그림 작물/비젼. [퀵메뉴](../guides/shortcuts.md#local-settings-search) · [저장소](../guides/storage.md#historical-data-location).
