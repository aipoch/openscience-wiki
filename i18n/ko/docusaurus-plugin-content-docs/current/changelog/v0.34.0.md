# 릴리스 노트 · v0.34.0 {/* #release-notes--v0340 */}

**2026-09-28 UTC의 경우** (**중국 표준 시간에 있는 2026-09-29**)에 출시되었습니다. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.34.0).

## 저널 데이터셋 및 문학 자료 {/* #journal-datasets-and-literature-references */}

도서관은 원본, 년 및 열 매핑이있는 저널 데이터 세트를 추가하고, 일치하는 종이에 속성을 표시합니다. 전용 [Journal datasets 및 참고 속성 가이드](../guides/journal-datasets.md)을 따르십시오.

Workspace Library 작업은 현재 또는 다른 대화의 초안에서 참조 세부 사항, 명시된 일괄 선택 및 참조를 추가합니다. 당신은 아직도 보낼 때 선택합니다. [도서관 활동](../guides/library.md#add-reference-to-chat) 참조.

## 과학 데이터베이스 확장 {/* #scientific-database-expansion */}

Pathway Commons 확장된 가입 Bgee· cBioPortal· openFDA 으로 MGnify 적용, 추가 **16 운영**... 전체 레지스트리에는 **29 연결관과 300 가동** : 28 데이터 소스 제품군과 298 운영, 두 개의 오프라인 Molecule 운영이 포함되어 있습니다.

[데이터베이스 기능 및 설정](../tools/databases.md#pathway-expression-clinical), [작업 매개 변수](../reference/connector-operations.md) 및 [pathway 상호 작용 워크플로우](../workflows/inspect-pathway.md)를 저장한 예 결과를 보십시오.

## 설치, 모델 및 데스크탑 탐색 {/* #installation-models-and-desktop-navigation */}

- Linux은 ARM64 AppImage 및 Debian 패키지를 추가합니다. [설치하기](../guides/installation.md) 참조.
- Codex CLI 호환성 기본은 **0.157.1**입니다. 기존의 이전 실행 시간은 자체 업데이트가 필요할 수 있습니다. [Codex 업데이트](../guides/frameworks.md#update-codex) 참조.
- 공급자 카탈로그는 **MiniMax M3.1 플래시 미리보기**와 **클로드 Sonnet 5.5**를 추가합니다. [공급자 설정](../guides/providers.md#catalog-models) 참조.
- 데스크탑 트레이 / Menu-bar 네비게이션은 실행, 핀 및 최근 세션을 엽니다. [빠른 탐색](../guides/navigation.md#tray-navigation) 참조.

## 개선 및 수정 {/* #improvements-and-fixes */}

43 버전으로 전자 업그레이드, 빠른 작업 공간 전환 및 몇 가지 해석기-Discovery 하위 처리. 에이전트 연결 오류 후 커버 복구, 중지 또는 재시작 후 위임, 중단 된 검토자 평가, PDF 그림 / 테이블 추출, 문학 메타 데이터, WSL 실행 시간 읽음 및 macOS 원격 디렉토리 목록. 보호, 키보드 초점 및 권한 설명도 개선.

[설치 또는 업데이트](../guides/installation.md) · [이전 릴리스: v0.33.3](v0.33.3.md).
