# 변경 로그 · v0.31.0 {/* #changelog--v0310 */}

9월 18 출시, 2026. 이 릴리스는 독립적 인 세션 사본을 추가하고 대화 또는 연결이 복원 될 때 연속성을 향상시킵니다.

[공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [v0.30.2 이후 변경](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## 계속하고 세션을 검사 {/* #continue-and-inspect-a-session */}

- **Fork**은 대화 지점, Notebook 레코드, artifact 버전, 문헌, 주석 및 개인 책갈피와 일치할 수 있는 데스크탑 복사본을 만듭니다. 그것은 신선한 식별을 할당하고 소스를 보존합니다. 수입된 세션 자체는 읽기 전용 유지. [포크 walkthrough](../guides/sessions.md#fork-session) 및 [연구 패키지](../guides/research-packages.md)을 참조하십시오.
- 세션 타이틀은 소스, 카운트 및 핀 컨트롤과 함께 [정보 카드](../guides/sessions.md#session-information)을 엽니다. 그 소스 턴에 대한 지속적인 대화 링크.
- [세션 계획](../guides/planning.md#resume-plan)은 컨텍스트 재건축 후 정체성, 개정 및 종료 승인을 유지합니다. 복구는 종료 단계가 승인되었거나 실행되지 않습니다.

## 설정 및 데이터 동작 변경 {/* #changed-setup-and-data-behavior */}

| 영역 | 자주 묻는 질문 |
| --- | --- |
| 공급자 설정 | 편집은 저장된 구성을 대체하기 전에 검증됩니다. runtime rejection 업데이트 가용성. [공급자 설정](../guides/providers.md#validated-provider-save) |
| Windows R | 표준 모드 실행 더 이상 보호 모드 설정이 필요 없습니다. 보호된 실행은 분리된 필요조건을 비치하고 있습니다. [런타임](../guides/runtimes.md) |
| 뚱 베어 | 요청 `include_populations: true` per-population 조사 및 빈도를 위해; dataset, build 및 품질 필터를 유지하십시오. [제품 설명](../reference/connector-operations.md#get_variant) |
| 제품 이름 | 인터페이스는 Open-Science을 사용합니다. 설치 위치, 설정 및 데이터 보존; 일치하기 위하여 저장 폴더를 이름을 바꾸지 마십시오. [설치하기](../guides/installation.md#product-name) |

**STRING 호환성 변화:** `nodes`은 이제 추가 이웃을 포함하여 완전한 반환 그래프를 설명합니다. mapped 입력을 위한 필터 `is_query` 및 모든 입력 별명으로 `queries`를 사용하십시오. `n_nodes`을 제출한 단백질 수로 사용하지 마십시오. [STRING 소개](../tools/databases.md#string-network)

다른 수정 커버 Codex 이유 불편 변경, 취소 및 오염, UniProt 보조 액세스, Ensembl 식별자, 임상 적격성 및 cBioPortal 디노미네이터. 전체 목록의 공식 출시를 사용합니다.

포크 스크린 샷은 v0.31.1로 캡처되었습니다. Windows R 변경 사항이 릴리스 / 리소스 백업입니다. 이전 플랫폼 스크린 샷은 원래의 테스트 컨텍스트를 유지합니다. 다음 릴리스는 [v0.31.1](./v0.31.1.md)입니다.
