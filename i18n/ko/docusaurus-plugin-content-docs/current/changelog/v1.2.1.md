# 릴리스 노트 · v1.2.1

출시 예정 **2026-11-11 통화**. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v1.2.1).

## 한 곳에서 자원 찾기 {/* #resource-center */}

**Resource center** 설치 및 시장 전망, 검색, 필터 및 세부 서랍과 함께 기술, 커넥터 및 전문가를 가져옵니다. Marketplace 설치는 Web 작업 공간에서도 사용할 수 있습니다. 질문에서 기술 참조를 열거나 메시지를 보내면 프로젝트에 대한 세부 정보를 보여줍니다. [회사연혁](../guides/navigation.md#resource-center) · [기술 시장](../skills/marketplace.md).

## 보내기 전에 질문을 정의 {/* #prompt-optimization */}

제품 정보 **Optimize question** 프로젝트의 Composer에서 구성 된 모델을 통해 초안을 다시 작성합니다. 결과 검토, 편집 또는 사용 **Undo optimization** 전송하기 전에. 프로젝트 설정은 사용자 정의 할 수 있습니다 **Optimization prompt**· 행동은 요청할 때만 실행됩니다; 그것은 자동적으로 연구 질문을 보내지 않습니다. [질문 refinement](../guides/composer.md#optimize-question).

## Codex 구독을 사용하여 내장 에이전트 {/* #codex */}

**Open-Science Agent** 이제는 Main 및 Subagent에 대한 수입 및 승인 된 Codex 구독 계정을 지원합니다. Existing sign-in와 credential 회복 통제는 유효합니다. 내장 에이전트는 모델의 출력 제한을 사용하고 context 회계를 개선합니다. **Claude Fable 5.2** Anthropic 카탈로그에 1M 컨텍스트 창이 있습니다. 모델 가용성은 여전히 선택한 공급자와 계정에 달려 있습니다. [에이전트 설정](../guides/frameworks.md#built-in-agent).

## 스프레드 시트로 내보내기 참조 메타데이터 {/* #csv */}

**Export → CSV** 선택한 참조, 프로젝트 또는 컬렉션 16 안정적인 영어 열 이름. 선택은 페이지와 개별 항목을 제외 할 수 있습니다. Missing 필드는 비어 있습니다. PDF 파일, 심사 결정 및 개인 노트는이 메타 데이터 수출의 일부가 아닙니다. [CSV 수출 단계](../guides/library.md#bibliography-csv).

## 더 긴 작업 이동을 유지 {/* #reliability */}

- 노트북과 컴퓨터 증거는 긴에 있는 반복한 내용을 감소하는 확인한 소화로 deduplicated `.science` 수출. 첫번째 수출은 또한 오래된 증거를 준비합니다. [연구 패키지](../guides/research-packages.md#compact-evidence).
- Modal 및 Hugging Face Connection은 브라우저 로그인 전에 호환 된 Python 실행 시간을 준비하고 계정 확인을위한 시스템 프록시를 사용합니다. [Compute 계정](../guides/remote-compute.md#cloud-account-runtime).
- 연구 필름 발생은 전환 세션 후 계속됩니다. [연구 필름](../guides/research-films.md#generate-film).
- 당신이 선택할 때까지 이동할 수 있는 페어링 잎 접근 **WiFi** 또는 **Internet**. [모바일 연결](../guides/remote-access.md#mobile-pairing).
- 노트북 첨부 파일 및 로컬 파일 링크가 다시 미리보기를 엽니 다. PDF 복구, 번역 고립, 문학 식별자 및 좁은 소스 미리보기는 수정을받습니다.
- Idle 해석기는 세션 활동 없이 15 분 후에 재발견됩니다. Windows Update Recovery는 파일/처리를 차단하고, Linux 복구는 누출된 노트북 프로세스로 확인된 커널 스레드를 처리하는 것을 방지합니다.
