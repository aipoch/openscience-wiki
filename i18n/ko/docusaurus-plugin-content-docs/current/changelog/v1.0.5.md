# 릴리스 노트 · v1.0.5

**2026-10-28 UTC** 출시. [공식 릴리스](https://github.com/aipoch/open-science/releases/tag/v1.0.5).

## 문헌 읽기 상태 관리 {/* #reading */}

Library에 수동 **Unread**, **Reading**, **Read** 상태가 추가되었습니다. 열 표시, 필터 및 일괄 변경을 지원합니다. 출판 공지는 **Check now**와 **Check again**으로 확인하며 Crossref 결과와 확인 시각을 보관합니다. [읽기 상태](../guides/library.md#reading-status) · [출판 공지](../guides/library.md#publication-checks).

## 브라우저로 연구 패키지 전송 {/* #packages */}

인증된 로컬 Web에서 `.science` 파일을 업로드하여 가져오고, 완성된 내보내기 파일을 다운로드할 수 있습니다. 홈 사례에는 **Details**와 **Import**가 있습니다. 대상 프로젝트와 자료를 확인한 뒤 **Fork to continue**로 연구를 이어갑니다. [브라우저 전송 및 사례](../guides/research-packages.md#local-package-transfer).

## 서비스가 계속 실행되는 조건 {/* #service */}

CLI에서 명시적으로 `start`를 실행하면 마지막 App을 종료한 뒤에도 서비스가 유지됩니다. 일반 CLI, Web, SDK 작업만으로는 유지되지 않습니다. 일반 `stop`은 이 설정을 해제하지만 App이 연결되어 있으면 서비스는 남습니다. `stop --force`는 전체 서비스 중지를 요청하므로 작업을 중단할 수 있습니다. `start`에 `--json` 지원이 추가되었습니다. [명령 및 중지 결과](../reference/server.md#lifecycle-commands).

## 과학 데이터와 공식 파일 검색 {/* #data */}

Europe PMC, 연구 데이터 접근 안내 및 공개 파일 목록, ChEA3, bioDBnet, CTD가 추가되었습니다. HGNC, Cellosaurus, openFDA도 확장되었습니다. 카탈로그에는 **내장 Connector 48개와 작업 418개**가 있습니다. 데이터 소스 Connector 47개가 작업 416개를, 오프라인 Molecule Connector 1개가 작업 2개를 제공합니다. 링크를 찾았다고 파일을 다운로드했거나 제한 데이터 접근 권한을 얻은 것은 아닙니다. [소스 및 연결](../tools/databases.md#scientific-file-discovery).

## 업데이트와 일상 작업 개선 {/* #fixes */}

- 수동 설치 안내와 확인된 다운로드 설치 파일의 위치 표시를 제공합니다. [수동 설치](../guides/installation.md#manual-update).
- **Full access**는 공개 네트워크 대상의 개별 승인을 생략합니다. 더 제한적인 모드로 바꾸면 기존 연결을 닫습니다. 전역 허용도 설정에 즉시 반영됩니다. [네트워크 권한](../guides/network.md#network-mode-changes).
- Windows Notebook 패키지 설치 시 BiocManager를 명시할 수 있습니다. [Bioconductor](../guides/runtimes.md#windows-bioconductor).
- DOCX 템플릿 배치, 표, 테두리 및 페이지 구조 보존을 개선했습니다. [Word 출력](../guides/previews.md#docx-templates).

OpenCode 2.x 호환성, macOS Notebook의 외부 Node 검색, Windows 네트워크 보호 설정 중 채팅 시작, 관리형 Skill 참고 자료 읽기, 대화 스크롤 위치와 표 스크롤바도 수정했습니다. About에 보안 정책 링크가 추가되었습니다. [이전 버전: v1.0.4](v1.0.4.md).
