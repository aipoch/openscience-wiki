# 릴리스 노트 · v1.0.4

**2026-10-27 UTC** 출시. [공식 릴리스](https://github.com/aipoch/open-science/releases/tag/v1.0.4).

## 외부 도구를 연구 환경에 연결하기 {/* #mcp */}

독립 CLI의 stdio MCP 어댑터를 사용할 수 있습니다. 인증된 로컬 서비스를 먼저 시작한 뒤 해당 프로필에 연결합니다. 기존 권한으로 프로젝트 생성, 설정 변경, 연구 실행이 가능하며 파일 쓰기나 모델 비용이 발생할 수 있습니다. [MCP 설정과 제어](../reference/cli.md#external-mcp).

## 논문의 출판 공지 확인하기 {/* #publication */}

유효한 DOI가 있는 문헌의 철회·정정을 Crossref에서 수동으로 조회합니다. 결과에는 출처와 확인 시간이 남습니다. 공지가 없어도 문제가 없다는 보장은 아닙니다. [공지 확인 및 해석](../guides/library.md#publication-checks).

## 일상 작업 정리하기 {/* #workspace */}

- 완료된 차례의 중간 메시지와 도구 그룹을 접고, 검색이나 주석으로 다시 펼칩니다. [대화 펼치기](../guides/sessions.md#collapsed-conversation).
- 승인된 폴더의 파일을 변경 불가능한 대화 산출물로 저장합니다. [로컬 파일 가져오기](../guides/files.md#import-local-artifact).
- 검색한 GitHub Skill 저장소를 저장합니다. Skill이 자동 업데이트되지는 않습니다. [저장된 저장소](../skills/manage.md#saved-repositories).
- 질문 카드에 **Skip**과 **Skip all**이 추가되었습니다. [질문 제어](../guides/composer.md#skip-question).

배포 파일이 작아졌습니다. Windows Notebook 표준 모드, 저장 위치 선택 후 내보내기 대기, 폴더 승인 대화상자, 질문 복구 및 재생 이벤트 표시도 수정되었습니다. [패키지 전송](../guides/research-packages.md#local-package-transfer) · [이전 버전: v1.0.3](v1.0.3.md).
