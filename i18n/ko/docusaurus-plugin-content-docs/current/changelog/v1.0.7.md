# 릴리스 노트 · v1.0.7

출시일: **2026-11-02 UTC**. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v1.0.7).

## 논문 링크에서 읽기 메모까지 {/* #literature */}

**Add from DOI or link** DOI, doi.org 링크 또는 arXiv 요약/PDF 링크를 참조하여 검토 및 저장 할 수 있습니다. Full-text retrieval은 별도의 단계로 유지됩니다. [참고사항](../guides/library.md#doi-link-import).

Reading 세션에서 Agent에게 구절을 찾아 연결된 PDF에 하이라이트, 영역 표시 또는 메모를 저장하도록 요청할 수 있습니다. 저장 위치와 내용은 다시 연 **Notes & Annotations** 에서 확인하세요. [Agent 주석](../guides/pdf-notes.md#agent-annotations).

스캔된 페이지는 선택적인 OCR를 사용할 수 있습니다. 인식 구성 요소를 다운로드하고 9 개의 언어 팩에서 선택한 다음 PDF를 다시 읽고 페이지를 검사합니다. 인식은 텍스트를 복구하는 데 도움이됩니다. 페이지 이미지에 대한 인용 및 숫자 값을 확인하십시오. [OCR 설정](../guides/previews.md#scanned-pdf-ocr).

## Pi 및 연구 케이스 시장 {/* #agents-and-cases */}

Pi가 다섯 번째 Agent 프레임워크로 추가되어 Claude Agent, OpenCode, Codex, CodeBuddy와 함께 선택할 수 있습니다. 별도로 설치하고 호환 모델 접근 방식을 설정한 뒤 연결을 확인하세요. Open-Science를 업데이트해도 현재 Agent가 자동으로 바뀌지는 않습니다. [Pi 설정](../guides/frameworks.md#pi-agent).

**Sharing marketplace** 홈과 대화 작업 공간에서 사용할 수 있습니다. 검색 카테고리, 키워드로 검색하고 그 설명을 검사하거나 패키지를 다운로드 할 경우를 엽니 다. Browsing 상태는 프로젝트에서 반환 할 때 유지됩니다. [연구 사례 찾기](../guides/research-packages.md#use-case-gallery).

## 지속적인 작업에 대한 수정 {/* #reliability */}

- Windows Notebook은 처음 사용하기 전에 Shell 런타임을 준비하여 새 백엔드에서 PowerShell을 사용할 수 없는 문제를 해결합니다.
- OpenCode는 컨텍스트 압축 시 비표준 메시지 ID를 처리합니다. 백그라운드 작업이 마무리되는 동안 보낸 후속 질문도 유지됩니다.
- Fake-IP DNS를 사용하여 전체 텍스트 검색 핸들 구성 프록시. [다운로드 Recovery](../guides/troubleshooting.md#full-text-proxy).
- 산출물을 게시하거나 복원하면 최신 게시 버전이 우선 표시되며, 이력 패널에서 버전 간 관계를 더 명확히 확인할 수 있습니다. [파일 버전 확인](../guides/files.md#latest-published-version).
- Composer는 제공업체, 환경, 입력, 세션 및 내부 오류를 공통 알림 영역에 표시하고 복구 동작을 제공합니다. [자주 묻는 질문](../guides/composer.md#request-recovery).
- OCR 설정을 저장하는 동안에도 화면이 응답합니다. 구성 요소 다운로드가 멈춰도 일반 PDF 읽기가 기존 제한 시간을 넘기지 않습니다.

연결관 묘사는 조정에서 더 구체적입니다. 내장 카탈로그가 남아 있습니다 **48 Connectors with 418 operations**; Pi, OCR 및 참고 항구 통제는 추가 연결관이 아닙니다. [지원된 데이터베이스](../tools/databases.md#supported-databases) · [이전 버전](v1.0.6.md).
