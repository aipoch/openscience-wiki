# 릴리스 노트 · v1.0.3

**2026-10-26 UTC** 출시. [공식 릴리스](https://github.com/aipoch/open-science/releases/tag/v1.0.3).

## 인용 관계를 따라 문헌 찾기 {/* #literature */}

Semantic Scholar에서 참고문헌과 인용 논문을 찾고 후보를 Inbox에서 검토할 수 있습니다. 파일 끌어 놓기, 보충 자료 검색, 첨부별 다운로드 진행 및 미리보기도 지원합니다. [문헌 발견과 첨부](../guides/library.md#citation-discovery).

스마트 컬렉션은 모든 후보의 결정을 CSV로 내보내며 채택 문헌 목록과 별도로 보관할 수 있습니다. [선별 결정 내보내기](../workflows/screen-literature.md#screening-csv).

## 연구 기록 옮기고 읽기 {/* #research */}

- CLI와 인증된 로컬 웹 앱에서 `.science`를 가져오고 내보냅니다. 가져온 기록은 읽기 전용입니다. [로컬 전송](../guides/research-packages.md#local-package-transfer).
- 새 PDF 번역본의 **Advanced → Content first**에서 본문과 캡션을 재배치합니다. [번역 레이아웃](../guides/pdf-translation.md#content-first).
- Permissions에서 로컬 Notebook·Shell 폴더 접근을 관리합니다. 변경하면 프로세스가 중지되고 변수가 지워집니다. [폴더 제한](../reference/permissions.md#notebook-folder-restrictions).

## 과학 데이터 출처 확대 {/* #sources */}

TCIA, KEGG, OmniPath, LIPID MAPS, PDBe 검증, UniChem, DepMap/CCLE, PDB 구조 유사성 검색이 추가되었습니다. 결과에 식별자, 라이선스, 측정 척도를 보존하세요. [출처 선택과 연결](../tools/databases.md#expanded-sources).

Kimi K3.1 Pro가 모델 목록에 추가되었습니다. Windows 프로토콜 등록, 네트워크 승인 유지, 세션 복구, 패키지 전송 및 PDF 처리도 수정되었습니다. [모델 선택](../guides/providers.md#kimi-k31) · [이전 버전: v1.0.2](v1.0.2.md).
