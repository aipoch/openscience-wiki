# 릴리스 노트 · v0.33.2 {/* #release-notes--v0332 */}

**2026-09-24**에 출시. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## 설치 및 문학 독서 {/* #installation-and-literature-reading */}

공식 Windows 인스톨러는 코드 서명을 얻습니다. 앱 다운로드 링크는 공식 다운로드 페이지와 검증 노트로 이어집니다. [설치하기](../guides/installation.md) 참조. 라이브 소스 미리보기는 방문 및 앱 재시작을 통해 웹 사이트 세션을 유지; [소스 미리보기](../guides/previews.md#persistent-source-preview) 참조.

**Auto** 모드는 내장된 라이브러리 작업을 위한 반복된 승인 프롬프트를 감소시킵니다. 파일, 네트워크 및 리소스 규칙은 여전히 적용됩니다. [Library 승인 행동](../guides/approval-modes.md#library-auto) 참조.

## STRING 상호 작용 {/* #string-interaction-enrichment */}

**단백질 표기**는 단백질 세트가 배경에서 예상보다 더 많은 상호 작용을 가지고 있는지 테스트하는 STRING PPI 농축물을 추가합니다. 이것은 Pathway enrichment에서 다른 통계 질문을합니다. [Gene-set 워크플로우](../workflows/gene-set-enrichment.md#enrichr-string) 및 [및 다운로드 가능한 레지스트리는 이제 v0.31.1 :](../reference/connector-operations.md#get_string_ppi_enrichment)을 따르십시오.

## 개선 및 수정 {/* #improvements-and-fixes */}

완성된 위임 결과는 나중에 정리 실패를 살아남습니다. 또한 그림 Composer 워크플로우, 파일 유형 아이콘 및 스마트컬렉션 레이아웃을 커버합니다. 격리된 macOS Notebook 세척 국가를 고치고 대리인 여정과 폐쇄를 개량하십시오; Codex 백엔드 플러그인 및 앱 발견이 비활성화됩니다.
