# 업데이트 내역 · v1.0.2

공개일: **2026-10-22 UTC**. [공식 릴리스](https://github.com/aipoch/open-science/releases/tag/v1.0.2).

## 더 많은 과학 데이터 소스 조회 {/* #scientific-sources */}

| 데이터 소스 | 사용할 설정 항목 |
| --- | --- |
| HGNC 유전자 명명 정보 | Genes &amp; Ontologies |
| PubTator 3 논문 주석 | PubMed |
| DGIdb 약물·유전자 상호작용 | Clinical Genomics |
| RNAcentral 기록과 교차 참조 | RNA |
| Orphadata 희귀질환 연관 정보 | Orphadata — 먼저 활성화 |

추가 후 카탈로그에는 **36개 데이터 소스 항목과 371개 작업**이 포함되며, 별도로 오프라인 Molecule 작업 2개가 있습니다. [데이터 소스 선택 및 연결](../tools/databases.md#new-source-access).

GDC는 검체·분주 검체 연결을 유지하면서 증례, 검체 유형, 워크플로로 파일을 필터링합니다. Ensembl VEP는 수동 좌표 변환 없이 HGVS를 받지만, 입력 참조 버전을 검증하거나 게놈 좌표를 변환하지는 않습니다. ClinicalTrials.gov의 공개 결과도 카탈로그에 포함됩니다. 참고: [조회 결과의 맥락](../tools/databases.md#clinical-context) 및 [전체 작업 참조](../reference/connector-operations.md).

## CLI 설치 및 확인 {/* #cli */}

CLI와 Task SDK가 npm에 공개되었습니다. 먼저 [npm 설치 방법](../guides/installation.md#npm-cli)을 따르세요. 다음 명령은 `version`, `help` 및 `paths` 백엔드를 시작하지 않고 사용할 수 있습니다. 표시되는 버전은 호출한 설치본의 버전입니다. 데스크톱·독립 실행 배포본에는 Node 22.23.4 보안 업데이트가 포함됩니다. [로컬 정보 명령](../reference/cli.md#local-information).

## 대화 상태를 확인하며 진행하기 {/* #conversation */}

질문 카드는 **Single select** 와 **Multi select** 를 구분하며 질문별 전체 답변 기록을 보존합니다. 대기 메시지 오류에는 실행 취소가 제공되고, 보내지 않은 초안이 있으면 종료·새로고침 시 경고합니다. 인증 복구는 초안을 유지하면서 다음 조치를 안내합니다. 원격 웹 대화에서도 산출물을 멘션할 수 있습니다. [질문 카드와 초안](../guides/composer.md#clarification-questions).

## 연구 기록 개선 {/* #research-records */}

- 연구 패키지 대화상자를 안정화하고, 일부 저장된 가져오기를 재시도할 때 세션 중복을 방지합니다. 가져온 제목은 편집할 수 있지만 연구 기록은 읽기 전용으로 유지됩니다. [연구 패키지](../guides/research-packages.md#browser-import).
- 대규모 세션 로딩과 시작 시 복구를 개선했습니다. 진단 내보내기가 일부만 완료되면 경고합니다. [세션 진단](../guides/sessions.md#session-diagnostics).
- PDF 구조, DOCX 번호·테두리 및 연속 Python/R 분석의 파일 계보 기록을 수정했습니다. [계보 확인](../guides/notebook.md#chained-analysis-lineage).
- 많은 Skill은 일괄 단위로 가져옵니다. 외부 예약 이름에는 안전한 로컬 이름을 부여합니다. Codex를 통한 MiniMax M3.1 연결도 수정했습니다. [모델 연결 복구](../guides/providers.md#credential-recovery).
