# 릴리스 노트 · v1.2.0

출시 예정 **2026-11-09 통화**. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v1.2.0).

## 계산 실행을 선택 {/* #remote-compute */}

Kubernetes, Hugging Face Jobs, Modal 및 Ray가 직접 SSH 및 Slurm에 합류했습니다. 대상 구성, 냉동 입력, 명령, 리소스 및 출력 수집을 검토 한 다음 각 외부 제출을 승인합니다. 복구 기록은 재시작 후 수집을 재개하고, 발행된 출력은 에서 열립니다 **Compute Preview**· 이 옵션은 자체 인프라 또는 클라우드 계정을 사용합니다. [Remote-compute 설정](../guides/remote-compute.md#compute-backends).

## 내장 에이전트로 시작 {/* #agent */}

새로운 설정 기본값으로 **Open-Science Agent**, 호환 모델 제공 업체와 함께 작동 하는 내장 런타임. Claude Agent, OpenCode, Codex, CodeBuddy 및 Pi는 사용할 수 있습니다. 런타임 및 모델 공급자는 별도의 선택입니다. 기존 Codex 설정은 대체 할 필요가 없습니다. [에이전트 선택](../guides/frameworks.md#built-in-agent).

## 정확한 연구 단계 토론 {/* #discussions */}

관련 상품 `.science` 연구 및 재생 단계 지원 연결된 어린이 토론. **Ask about this step** 기록 된 노트북을 포함하여 선택한 증거를 운반, 토론으로. 수입된 역사 하이라이트 **Fork to continue** writable continuation 시작을 위해. 사이드바 그룹 세션 **Pinned**, **Imported research**, **Active** · **Recents**. [Replay 토론](../guides/session-replay.md#discuss-replay) · [연구 패키지](../guides/research-packages.md#linked-discussions).

## 더 작은 업데이트 및 Clearer 컨트롤 {/* #reliability */}

- macOS 업데이트는 변경된 블록을 다운로드 할 수 있습니다. 필요한 경우 전체 다운로드로 다시 떨어지십시오. 설치 체크는 실행 앱을 확인하고 파일 또는 프로세스를 식별합니다.
- **Local capabilities** 대체하기 **Local parsing models** 탭 및 그룹 PDF 추출, OCR 및 연구 narration. [지역 자원](../guides/models.md#local-capabilities).
- 수동 참조 항목은 PMID를 포함한 제목없이 식별자를 허용합니다. 필름 컨트롤은 사용할 수없는 작업을 번쩍이는 것을 방지합니다.
- PDF 추출은 텍스트 및 테이블 구조를 향상시킵니다. 수정 지연 번역은 다른 페이지가 실패하면 성공적인 페이지를 유지; 공유하기 전에 불완전한 페이지를 검사. [PDF 번역](../guides/pdf-translation.md).
- 노트북 분석은 UI 실 밖에 실행됩니다. Windows Fixes 덮개 관리된 R DLL 선적 및 창은 taskbar의 주위에 경계합니다.
- 이전의 턴을 읽는 동안 메시지를 보내기 도구 오류, 소스 링크 미리보기 및 시작 진단은 더 명확합니다.
