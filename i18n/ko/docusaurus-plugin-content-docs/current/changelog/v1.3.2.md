# 변경 로그 · v1.3.2 {/* #changelog--v132 */}

**2026-11-20 UTC의 경우** 출시 [공식 출시 노트](https://github.com/aipoch/open-science/releases/tag/v1.3.2).

## 모델을 연결하는 방법 {/* #models */}

**Model provider**에서 **Skip**을 선택하면 API key 없는 Kilo Gateway가 추가되고 Notebook runtime으로 넘어갑니다. 설정 후 **Main model**에 `kilo-auto/free`가 표시될 수 있습니다. 첫 메시지를 보내기 전에 **Settings → Model**에서 선택된 제공업체와 모델을 확인하고, Codex subscription 등 원하는 연결로 바꾸세요. Skip은 모델의 요청 처리 기능을 테스트하지 않습니다. 업그레이드는 기존 인증 정보와 Main 선택을 유지합니다。 [Kilo Gateway](../guides/providers.md#kilo).

OpenAI, MiniMax, Bailian 및 Volcengine Ark 이미지 서비스는 저장하기 전에 지원되는 이미지 모델 카탈로그를 재생할 수 있습니다. 이 연결의 자격 증명을 가진 형성된 공급자에 접촉합니다. 카탈로그 가용성 및 성공적인 세대는 별도의 체크입니다. [이미지 모델 카탈로그](../guides/image-generation.md#image-model-catalog).

## 스무더 연구 세션 {/* #sessions */}

긴 대화는 더 적은 기억을 이용하고, 안전하게 저장된 대화 몸은 더 이상 전망될 때 풀어 놓일 수 있습니다. 초안과 활성 작업이 유지됩니다. 완전한 재생 단계는 hover 또는 키보드 초점에 그들의 물/캡처 통제를 보여줍니다; 터치 디바이스는 접근 가능한 컨트롤을 유지한다.

Notebook 메모리 압력 통지는 6 초 후에 해체되고 만료될 수 있습니다. 차단된 동작이 실행되지 않는 통지가 사라집니다. 실행 상태 및 재발행을 정의합니다. [Notebook 메모리](../guides/notebook.md#memory-resources).

## 일상에 영향을 미치는 수정 {/* #fixes */}

- 새로운 내장 에이전트, Claude Agent 및 Codex 세션 더 이상 영향을받는 Notebook 준비 경로에 자신의 첫 번째 모델 요청 전에 실패하지 않습니다. 계획된 세션은 의도된 프롬프트로 시작합니다.
- PDF 번역 재구성은 기본 공식, 링크 및 그래픽을 유지하면서 판독 주문에서 제목, 캡션 및 수학 진술을 감싸고 있습니다. [번역된 레이아웃 확인](../guides/pdf-translation.md#scientific-layout).
- Home-page use-case 다운로드 오류는 누락된 패키지, 타임아웃, 검증 실패 및 저장 문제를 구별합니다. [수입 복구](../guides/research-packages.md#case-download-recovery).
- Windows는 WSL Notebook 시작 및 검토 연결 덮개를 고쳤습니다.

[설치 및 업데이트](../guides/installation.md) 및 [v1.3.1](v1.3.1.md)을 참조하십시오.
