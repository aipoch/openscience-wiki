# 변경 로그 · v1.3.3 {/* #changelog--v133 */}

**2026-11-22 UTC의 경우** 출시 [공식 출시 노트](https://github.com/aipoch/open-science/releases/tag/v1.3.3).

## 작업에 맞는 업데이트 {/* #updates */}

Eligible 공식적인 안정되어 있는 macOS 임명은 당신이 종료할 때 준비한 갱신을 설치할 수 있습니다. Windows 및 Linux은 바탕 화면이 배경에 속해있는 동안 다음 발사에 대한 업데이트를 준비 할 수 있습니다. 자동 다운로드는 제한되지 않은, unmetered 연결 및 충분한 저장을 요구합니다; 지원되지 않은 설치 위치 및 채널은 수동 경로를 유지합니다. Linux AppImage 업데이트는 애플리케이션 경로 유지, 안정적인 Windows 업데이트는 컴팩트한 deltas를 사용할 수 있습니다. [자동 및 수동 업데이트](../guides/installation.md#update-progress).

설치된 macOS 및 Windows 앱은 작습니다. 오프라인 npm 런타임은 Node 22에 묶어 느슨한 파일의 수를 줄입니다.

## 내장 에이전트는 어디에나 기본입니다. {/* #agent */}

CLI 및 SDK 설치를 포함하여 **Open-Science Agent**에 새로운 프로젝트 및 세션 기본. 더 이상 absent 외부 에이전트 SDK 시작에서 그 설치를 방지. 사용 할 때 외부 프레임 워크 만 설치; 모델 접근은 아직도 윤곽을 필요로 합니다. [에이전트 설정](../guides/frameworks.md#built-in-agent) · [CLI 설정](../reference/cli.md#terminal-setup).

설정은 Skills, Specialists 및 커넥터를 설치하기 위해 단축키를 복원합니다. Bailian의 카탈로그는 qwen4 가족을 추가하고, 계획 기본은 qwen4 미리보기로 변경됩니다. 시작하기 전에 계정으로 사용할 수있는 모델을 확인하십시오.

## 대화에서 이미지 편집 {/* #images */}

미리보기에서 **Edit image**을 입력하고 대화 작곡가에서 편집을 작성합니다. 이미지 버전 내비게이션 및 비교는 사용할 수 있으며, 대화는 편집할 때 열립니다. 이미지 세부사항은 편집 뒤에 Notebook 커널을 확인합니다. [Image 편집 단계](../guides/image-generation.md#edit).

PDF 번역은 컬럼, 캡션 및 인라인 공식에서 텍스트 분할을 더 잘 재연결하고, 불충분, 모양 라벨 및 이웃 그래픽을 피합니다. 원래에 대한 수출 된 페이지를 계속. [PDF 번역](../guides/pdf-translation.md#scientific-layout).

## 더 명확한 실패 및 회복 {/* #recovery */}

- 요청, 로딩, 첨부 파일, 가져 오기 및 Notebook 오류는 그들의 원인을 설명합니다. 공급자 오류는 재시작을 통해 분류 및 요청 ID를 유지합니다. 중단된 일은 unanswered continuation에서 구별됩니다. [관련 링크](../guides/troubleshooting.md#provider-errors).
- Windows는 재시작을 통해 보류된 내장 에이전트 질문을 보존하고 Notebook 런타임 상태를 복원하고, 콜드 실행 중에 stale 파일 차단기를 재검사합니다.
- Notebook 메모리 체크 계정 Windows 물리적 메모리, macOS 메모리 압력 및 Linux 컨테이너 제한. [기억과 자원](../guides/notebook.md#memory-resources).
- Session-package exports wait for Notebook는 수출 실패를 보고하기 전에 해결하기 위하여 읽습니다. 저장된 artifact 링크, 메모리 삭제 및 GitHub Skill 가져 오기 오류가 수정되었습니다.

[설치 및 업데이트](../guides/installation.md) 및 [v1.3.2](v1.3.2.md)을 참조하십시오.
