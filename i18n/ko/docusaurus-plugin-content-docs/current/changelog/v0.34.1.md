# 릴리스 노트 · v0.34.1 {/* #release-notes--v0341 */}

**2026-10-01 UTC의 경우**에 출시. [공식 출시](https://github.com/aipoch/open-science/releases/tag/v0.34.1).

## 과학 데이터베이스 확장 {/* #scientific-database-expansion */}

이 릴리스는 **26 운영**, **31 연결관과 326 가동**에 레지스트리를 가져다 : 30 데이터 소스 가족 324 작업, 플러스 두 개의 오프라인 Molecule 운영.

| 이름 &#42; | 추가 기능 |
| --- | --- |
| CELLxGENE Discover | 공개 단일 셀 컬렉션 및 데이터 세트를 발견, 출판 된 버전 및 검색 파일 재고를 검사 |
| Alliance Genome Resources | 인간 및 모델 조직 유전자, 정형화, 질병 모델, 페형화, 알레르기 및 표현 |
| 잔류물 → MaveDB | 채식 효과 점수 세트, CSV 점수, 기존 VRS 매핑 및 실험 |
| Omics Archives → Metabolomics Workbench | 연구 샘플, 실험적인 요인, 분석, 대사학적인 표기 및 화합물 교차점 |

[기능 및 설정](../tools/databases.md#single-cell-model-organisms)과 [및 다운로드 가능한 레지스트리는 이제 v0.31.1 :](../reference/connector-operations.md)을 따르십시오. 파일 URL은 완료된 다운로드가 아니며, assay-specific Function score는 임상 분류가 아닙니다.

## Workspace 내의 Inbox 검토 {/* #review-the-inbox-within-a-workspace */}

컴팩트 한 **Library** 미리보기는 **받은 편지함**, 검색, pagination, 개별 **수락/해제**, dismissal **Undo** 및 현재 페이지에 명시된 배치 선택을 추가합니다. **받은 편지함 열기** 저장 설정 카드에서 대화 옆에이 리뷰를 엽니다. queue는 프로젝트 전반에 걸쳐 후보를 포함합니다; 합격은 풀 텍스트를 다운로드하지 않습니다. [workspace Inbox 단계](../guides/library.md#workspace-inbox) 참조.

저널은 열 역할을 명확하게하고 힌트를 맵핑하고 별칭, 필터링 및 retries를 개선합니다. [학술자료](../guides/journal-datasets.md#import-columns) 참조.

## 연구 패키지 및 진단 {/* #research-packages-and-diagnostics */}

- 빈 **New conversation** 페이지는 **이전 연구 가져오기**을 선택하거나 드롭하여 `.science` 패키지를 추가합니다. [수입 단계](../guides/research-packages.md#import-and-inspect-a-package) 참조.
- 민감한 내용 체크는 명시된 **위험을 감수하고 내보내기** acknowledgment에 의해 따를 수 있습니다. Flagged 내용은 redaction 없이 포함됩니다; 공유하기 전에 그것을 검사합니다. [민감한 수출](../guides/research-packages.md#sensitive-export) 참조.
- 지역 진단 수출은 더 유용한 과실 및 실행 증거를 보존합니다. 그들은 연구 패키지에서 분리 남아 있으며 공유하기 전에 검사해야합니다. [세션 진단](../guides/troubleshooting.md#session-diagnostics) 참조.

## 모델 및 작업 공간 제어 {/* #models-and-workspace-controls */}

Codex 카탈로그는 저장 된 기본값을 변경하지 않고 **gpt-6.1 솔**을 추가합니다. 사용 가능한 액세스는 계정과 활성 실행 시간에 따라 달라집니다. [모델 선택](../guides/providers.md#catalog-models) 참조.

계획 피드백은 구성 된 단축키를 보냅니다. Composer는 Compute Host 상태가 더 눈에 띄는 것을 만들고 미리보기는 메시지로 뛰어나고 Skill 편집은 비등한 초안을 보호합니다.

## 수정 사항 {/* #fixes */}

Notebook은 셀, 공유 샌드박스 도구 및 실행 라인의 상태를 커버합니다. PDF 추출은 기본 그림/테이블 콘텐츠 및 작업자 취급을 더 잘 보존합니다. 다른 고정 커버 참조 URL, 주석 선택 정리, 테이블 핀, 복원 후속 권한, Windows 다시 설치 경로, Linux 자격 저장 및 자격 ID 처리.
