# 개인 읽기 북마크 {/* #private-reading-bookmarks */}

책갈피를 사용하여 구문을 유지하고 싶은 구문을 유지하고, 체크해야 할 테이블 또는 나중에 독서에 대한 메모. **For me**은 현재 세션에서 개인 독서 레코드를 저장합니다. **To Agent**은 요청에 대한 주석을 준비합니다. bookmark를 저장하거나 에이전트 컨텍스트에 추가하지 않습니다.

## 통행 또는 PDF 지역을 저장하십시오 {/* #save-a-passage-or-pdf-region */}

1. 기존의 저장된 세션을 엽니다. 대화 또는 지원된 텍스트 미리보기에서 텍스트를 선택하십시오. PDF에서 텍스트를 선택하거나 지역 선택 컨트롤을 사용하여 필요한 영역을 표시하십시오.
2. 선택의 주석 컨트롤을 열고 **For me**을 선택합니다.
3. **Note (optional)**을 추가하십시오. "이 비율을 비교하기 전에 denominator를 확인하십시오." **Bookmark**을 선택하십시오.
4. Composer에서 **Bookmarks**을 열고 저장된 항목을 확인합니다. 통행 금지 또는 PDF 지역으로 반환하는 것을 확인하기 위하여 그것을 선택합니다.

대화가 저장 된 후 책갈피가 가능합니다. 제어가 사용할 수없는 경우, 다시 시도하기 전에 기존 세션으로 돌아갑니다. 모든 임베디드 또는 외부 오픈 뷰어는 bookmarks에 대한 텍스트 선택을 지원합니다.

## 반환, 편집 또는 제거 {/* #return-edit-or-remove */}

세션의 **Bookmarks** 목록을 열고 입력을 선택하거나 **Show bookmark source**을 사용하십시오. 관리 파일의 경우, bookmark는 저장된 파일 버전을 참조합니다. 새 결과와 비교할 때 페이지, 패스 및 버전 확인.

**Edit bookmark note** 을 목록 또는 통로 옆에 지속적 인 마커에서 선택하고 메모를 편집하고 **Save**을 선택하십시오. **Cancel**은 저장되지 않은 메모를 나눕니다. **Delete bookmark**는 독서 책갈피를 제거합니다; 소스 메시지 또는 파일을 삭제하지 않습니다.

소스가 사용할 수 없거나 정확한 위치가 발견될 수 없는 경우, 해당 케이스를 구별하기 위해 표시된 메시지를 사용할 수 있습니다. 책갈피를 대체하기 전에 소스를 수동으로 찾습니다; 가장 가까운 표시된 텍스트가 원래 선택임을 가정하지 마십시오.

## 개인과 공유되는 것은 무엇입니까? {/* #what-stays-private-and-what-is-shared */}

- 앱을 다시 시작 한 후 세션을 다시 열 때 책갈피와 노트 persist.
- 그들은 그 세션에 속한다. 그들은 다른 지점으로 이동하지 않거나 기계 건너 동기화, 세션을 삭제하는 것은 책갈피를 제거합니다.
- [.science 연구 패키지](research-packages.md) 이 개인 책갈피를 제외합니다. colleague가 저장된 보고서 또는 커머스를 준비하기 전에 대화에 필요한 정보를 입력합니다.
- 통행에 대한 대리인을 요청하려면 **To Agent**을 사용하며, 전송하기 전에 의도 된 초안에서 주석을 검토하십시오. Main과 사이드 토론 사이의 대화는 [Side Chat](delegation.md)에서 덮여있다.

## 포크의 책갈피 {/* #bookmarks-in-fork */}

v0.31.0에서 [팟캐스트](sessions.md#fork-session) 사본 개인 책갈피와 노트는 새로운 세션으로 신선한 식별합니다. 나중에 사본에 편집은 소스 북마크를 편집하지 않습니다. 이것은 전환 지점에서 다르거나 `.science` 파일을 내보내기 : 개인 북마크는 여전히 포장 수출에 가입하거나 기계 전반에 동기화하지 않습니다.
