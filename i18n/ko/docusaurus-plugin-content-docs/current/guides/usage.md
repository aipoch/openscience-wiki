# 토큰 사용 및 활동 {/* #token-usage-and-activity */}

**Settings → Usage**을 사용하여 토큰 볼륨 및 로컬 활동을 검사합니다. 응답의 **Token usage** 메뉴 또는 세션 **Context window**을 좁은 전망에 사용합니다. 이 질문에 대한 답변 : 총 통화는 현재 상황에 따라 많은 토큰을 소비 할 수 있으며 훨씬 작은 창을 차지합니다.

표시된 기간과 메트릭을 사용하여 각 차트를 해석합니다. 보고서 토큰은 활성을 설명합니다; 공급자와 함께 구독 제한 또는 청구를 확인합니다.

## 자주 묻는 질문 {/* #filter-the-summary */}

1. 사용법을 열고 **Today**, **This week**, **Last 30 days** 또는 **All time**를 선택하십시오.
2. 신선도 라벨을 읽으십시오. 페이지가 stale인 경우 완료된 실행 후 **Refresh**을 사용하십시오.
3. 4개의 토큰 필드와 New/Total 활동 카운터를 비교하십시오.
4. 도표의 자신의 기간 상표를 검사하기 전에 요약에 그것을 비교하십시오.

![오늘 별도의 일일 차트 요약](/img/open-science/guides-walkthrough/13-usage-today.webp)

| (주) | 회사연혁 |
| --- | --- |
| 총 토큰 | 선택된 기간 동안 집계를 보고했습니다. |
| 입력 토큰 | 표시된 입력 성분; 현지 텍스트 길이 견적을 대체하지 마십시오. |
| 캐시 토큰 | 사용법 보고 백엔드에 의해 캐시에 특성. |
| 캐시 공유 | 관련 입력/통량의 비율; dash는 사용할 수없는, 제로 가격 실행. |
| 출력 토큰 | 생성된 산출 성분을 보고했습니다. |
| 새로운 세션/프로젝트/런/artifacts | 선택된 기간에 생성된 항목. |
| 총 세션/프로젝트/런/artifacts | 전체적인 조사; 그들은 시대의 새로운 수와 동일하지 않습니다. |

운영중인 오늘보기에서 토큰 총은 현재 실행 전에 0이 기록되었지만, 고정 30 일 차트는 여전히 어제의 활동을 포함했습니다. 그것은 예상된 기간 행동, 의도하지 않은 계산. 업로드 및 생성 된 artifacts는 다른 리소스입니다. 소스 파일을 업로드하면 생성 된 artifact를 만들 수 없습니다.

## 일일 활동 및 구성 읽기 {/* #read-daily-activity-and-composition */}

**Daily activity metric**은 총 토큰, 입력 토큰, 출력 토큰, 캐시 토큰, 새로운 세션, 새로운 프로젝트, 새로운 artifacts 및 실행을 제공합니다. 메트릭을 선택하면 날짜 셀을 검사합니다. Darker 셀은 표시된 스케일 내에서 더 큰 값을 나타냅니다.

**Daily token usage**는 겹쳐 쌓이는 입력, 캐시 및 산출 성분 보여줍니다. 두 차트는 **마지막 30 일** 라벨; 상단 요약 기간을 변경하지 않는 변경하지 않는 고정 범위. 증가에 대한 결론을 그리기 전에 같은 기간을 비교합니다.

## 불완전하거나 예기치 않은 값 {/* #explain-missing-or-unexpected-values */}

| 관련 기사 | 【특전】 |
| --- | --- |
| 완료된 대화는 사용하지 않습니다. | 몇몇 공급자 및 이전 기록 omit telemetry. 한 번 상쾌한, 그 후에 응답의 자신의 사용법을 검열합니다. |
| 높은 합계 그러나 작은 Context는 백분율을 사용했습니다 | 총 사용은 전화를 축적; 시간에 점에서 불안정한 측정. |
| 토큰 사용 없이 새로운 카운터 변경 | 프로젝트 작성 및 세션 관리는 모델 요청없이 발생할 수 있습니다. |
| Totals는 송장과 닮지 않습니다. | 이 페이지는 공급자의 청구 ledger 또는 구독 제한 대쉬보드가 아닙니다. |
| 큰 캐시 구성 요소 | 보고된 고장을 읽으십시오; 공급자의 실제 청구 규칙없이 현금 저축을 사용하지 마십시오. |

페이지는 단지 보고된 사용법만 포함합니다. 누락된 역사를 재구성하지 않습니다. 컨텍스트 구성 및 압축을 위해 [기억과 대화 맥락](./memory.md)을 참조하십시오.

근원: [사용법 패널과 도표 통제](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/settings/TokenUsagePanel.tsx).

## 인접 일 검사 {/* #inspect-daily-usage */}

**Daily token usage** 차트를 통해 성공 날짜와 입력, 캐시 및 출력 내역을 검사합니다. 키보드 액세스의 경우 **탭 / Shift+Tab**을 사용하여 하루에 초점을 맞추고 **뚱 베어**은 세부 사항을 닫습니다. 표시된 날짜와 성분을 비교하십시오; 이 차트는 여전히 마지막 30 일 커버하고 누락 된 공급자 telemetry를 재구성하지 않습니다.
