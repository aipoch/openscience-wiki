# 권한 및 승인 {/* #permissions-and-approvals */}

**Agent controls**을 사용하여 현재 대화 요청 승인 방법을 선택하십시오. **Settings → Permissions**을 사용하여 새로운 대화를 기본 설정하고 기억된 액세스를 검사합니다. 이 별도의 작업: 기본 변경은 기존 대화를 재설정하지 않거나 보조금을 수정하지 않습니다.

## 대화 모드 선택 {/* #choose-a-conversation-mode */}

| 모드 | 그것을 때 사용 | 기대할 것 |
| --- | --- | --- |
| **Ask for approval** | 요청된 작업을 검사하고 싶습니다. | 적용 가능한 보조금 또는 예외가 없는 행동에 대한 승인 카드 |
| **Auto-approve edits** | 작업 공간 내에서 일상적인 변화를 허용 | 지원된 편집은 자동적으로 통과합니다; 명령, 네트워크 및 MCP 작업은 여전히 승인이 필요할 수 있습니다. |
| **Full access** | 당신은 프롬프트없이 에이전트 작업을 허용하도록 선택 | 명령, 파일 변경 및 네트워크 요청은 수동 권한 카드없이 진행할 수 있습니다. 다른 접근 및 서비스 요구는 남아 있습니다 |

작곡가 옆에 **Agent controls**을 열고 선택한 모드를 읽습니다. 프레임 워크가 어떻게 구현하는지 보여주는 호환성 메시지 확인. 완전한 접근 제한에는 그것의 자신의 확인이 있습니다. **Auto-review**은 결과를 검토하고 자동 승인 편집을 의미하지 않는 다른 제어입니다.

![실제 영어 권한 모드 선택기](/img/open-science/walkthrough-2026-09-08/57-permission-modes.webp)

당신의 대리인을 위해 보이는 효과적인 형태를 검사하십시오; 지원된 승인 행위는 기구에 의해 다를 수 있습니다. 모든 모드가 모든 4개의 프레임워크를 통해 연습되지 않았습니다.

## 승인 카드를 읽으십시오 {/* #read-an-approval-card */}

작업, 선택한 환경 및 제안 된 코드를 승인하기 전에 읽어보십시오. 데이터 검사를 위해, 의도한 입력을 읽고 요청한 출력만 쓸 수 있다는 것을 확인합니다. 누락된 의존성 설치는 다른 목적과 효력을 가진 분리되는 가동입니다.

![Python 공개 GSE60450 케이스에서 실행 승인](/img/open-science/guides-walkthrough/25-python-permission.webp)

| 통제 또는 정보 | 검사 또는 할 수있는 것 |
| --- | --- |
| 도구 제목 및 요약 | 실제 작업, 대상 및 소스 식별 |
| 확장 가능한 코드 또는 인수 | 경로, 실행 시간, 패키지 이름 또는 서비스 입력 확인 |
| **Authorization scope** 넓이 | 이 요청의 범위에서 선택 지원 |
| **Allow once** | 이 전화 만 게시 |
| **Allow for this conversation** | 재시작을 포함한 이 대화에 대한 통화를 기억하십시오. |
| **Allow for this project** | 프로젝트의 매칭 액세스를 적용하고 더 넓은 범위를 확인합니다. |
| **Allow globally** | 프로젝트의 매칭 접근을 적용하고 더 넓은 범위를 확인합니다. |
| **Deny** | 발표 된 작업을 결정; 대체를 선택하기 전에 결과 응답을 검사 |
| 추가 공급자 옵션, 현재 경우 | 실제 라벨과 효과를 읽으십시오. 사용 가능한 옵션은 요청에 따라 다릅니다. |

기본 허용 버튼은 일반적으로 요청이 지원될 때 대화 범위를 사용합니다. 클릭하기 전에 라벨을 읽으십시오. 명령 접두사 보조금의 경우, 표시된 접두사를 검사합니다: 그 접두사로 시작하는 나중에 명령은 일치할 수 있습니다. 한 번의 실행에 대한 권한은 관련 외부 서비스에 대한 권한이 없습니다.

### 웹 읽기 승인 {/* #remember-web-reading-approval */}

지원된 **웹페이지 읽기** 요청을 위해 **Allow for this conversation**을 선택하여 나중에 웹이 동일한 대화에서 읽는 기능을 기억하십시오. 그것은 다른 웹 사이트를 커버 할 수, 뿐만 아니라 첫 번째 URL. **Allow once**은 해당 통화에만 적용됩니다. **기억된 권한**의 보조금을 검토하거나 수정; Notebook 네트워크 수당에 호스트를 추가하거나 업로드를 승인하지 않습니다.

### 웹 연구 승인 {/* #remember-web-search */}

v0.30.2부터 지원되는 Claude Agent의 기본 **Search the web** 요청에서도 **Allow for this conversation**을 선택할 수 있습니다. 같은 대화의 후속 검색에서 이 권한을 재사용할 수 있습니다. **Allow once**는 현재 요청만 허용합니다. **Remembered permissions**에서 **Search the web** 권한을 확인하거나 철회하세요. 검색과 **Read web pages**는 별도의 권한입니다. 모든 프레임워크나 Connector가 이 기능을 지원하는 것은 아니므로 실제로 표시된 범위를 확인하세요.

## 자주 묻는 질문 {/* #manage-remembered-access */}

**Settings → Permissions → Remembered permissions**을 엽니다. **All**, **Global**, **Project** 또는 **Session**로 필터링합니다. 줄은 기능, 범위 및 어떤 정량제 또는 더 넓은 적용을 표시합니다. 세션 링크는 소유자 대화를 엽니 다. Connector 정책 힌트는 관련 구성으로 리드합니다.

| (주) | 결과 |
| --- | --- |
| **팟캐스트** 1개의 줄에 | 즉시 교부금을 기억하는 제거; 무도 통지를 검사 |
| 이름 &#42; **Revoke all** | 그 그룹의 보조금의 제거 요청; 표시된 범위가 사용하기 전에 완료되었는지 확인하십시오. |
| **Restore defaults** | 누락 된 기본 글로벌 보조금을 추가하고 다른 기억에 남는 액세스 intact |
| **Defaults restored** | 기본 보조금이 누락되지 않습니다; 복원 버튼은 비활성화 |
| 범위 필터 | 표시된 줄 변경; 그것은 교부금 또는 재발견하지 않습니다 |

**팟캐스트**을 선택하여 의도한 교부금을 제거하십시오. **Undo**을 사용하면 실수가 발생했을 때 제안됩니다. **Restore defaults**는 누락된 기본 보조금을 추가합니다; 제거된 모든 권한은 복원되지 않습니다.

### 저장된 보조금의 효과적인 범위를 읽으십시오 {/* #read-a-saved-grants-effective-scope */}

Connector/tool, **글로벌 / 프로젝트 / 세션** 범위 및 **모든 통화 / 특정 입력 / 명령 그룹** 정량 조절을 재조정하기 전에 검사합니다. 명령 그룹 항목은 승인 요약 및 날짜를 포함 할 수 있습니다.

**Blocked in Connectors; this permission is currently inactive**은 Connector 정책을 과도하게 저장된 보조금을 의미합니다. **Allowed by Connector policy even without this permission**은 이 교부금을 단독으로 부활시키는 것을 의미한다. Connector라는 이름을 열어 규칙을 검사합니다. **Undo**을 사용하여 재발견이 무인 상태인지 확인한 후 복원된 상태를 확인합니다.

### 현재 범위에 그룹을 공개 {/* #revoke-a-group-in-the-current-scope */}

1. **Session**과 같은 대상 범위에 의해 필터.
2. 그 그룹의 **Revoke all** 동작을 선택합니다.
3. 그룹이 명확하고 다른 범위는 보조금을 유지합니다.
4. 다음 매칭 작업에서 진행하기 전에 새로운 승인 요청을 읽으십시오.

Revocation는 미래 승인에 영향을 미칩니다. 그것은 완료된 편집 또는 네트워크 요청을 반전하지 않으며, 더 넓은 보조금은 여전히 작동을 승인 할 수 있습니다.

![세션 그룹 재직 후 새로운 실행 요청](/img/open-science/local-todo-batch/40-permission-request-renewed.webp)

재고가 불완전한 경우, 그룹 재직을 사용하기 전에 실패한 요청을 로드하거나 다시 시도하십시오. 개정 후 선택된 범위를 재확인합니다.

## 예상치 못한 행동 진단 {/* #diagnose-unexpected-behavior */}

| 문제 | 확인 및 해결 방법 |
| --- | --- |
| Ask 모드에서 승인 카드가 표시되지 않음 | 저장된 권한, 도구 정책, 애플리케이션 자체의 예외를 확인하세요. Ask 모드에서도 모든 읽기, 결과물 저장, 사용자에게 하는 질문에 승인 요청이 표시되는 것은 아닙니다. [권한 참고 자료](../reference/permissions.md)에서 사용자 지정 설정 쓰기를 포함한 기본 권한을 확인할 수 있습니다. |
| 권한을 취소한 뒤에도 같은 작업이 실행됨 | 더 넓은 프로젝트 또는 전역 권한이나 허용 정책이 있는지 확인하세요. 세션 권한을 삭제해도 전역 권한은 삭제되지 않습니다. |
| 허용한 작업이 실패함 | 승인은 작업 시도를 허용하는 것입니다. 패키지 누락, 접근할 수 없는 파일, 잘못된 인증 정보, 거부된 네트워크 대상 등 표시된 원인을 해결한 뒤 다시 시도하세요. DNS 및 패키지 다운로드 오류는 [네트워크](network.md)를 참고하세요. |
| 일부 권한 범위를 선택할 수 없음 | 카드에는 현재 요청과 프로젝트/세션 상황에서 지원하는 범위만 표시됩니다. 좁은 범위를 선택할 수 없다는 이유만으로 더 넓은 범위를 허용하지 마세요. |

## Auto Mode에서 라이브러리 작업 {/* #library-auto */}

**Auto-approve edits**과 함께 내장 라이브러리 운영의 정의된 세트는 자동으로 에이전트의 호출 승인을 통과할 수 있습니다. 이 문서는 Inbox, PDF, 서식 참조 및 인용 문서를 작성하는 검색 및 판독 참조를 포함합니다. 이것은 일상적인 도서관 작업 중에 반복된 프롬프트를 감소시킵니다.

규칙은 모든 MCP 호출, 명령 또는 네트워크 작업이 아닌 공인 된 문학 도구에 적용됩니다. 도구의 자체 파일, 네트워크 및 리소스 규칙은 여전히 적용되며,이 결정은 영구적 인 보조금을 만듭니다. **Ask for approval**을 선택하면 에이전트 요청을 개별적으로 검사 할 수 있습니다. Inbox 후보를 검토하여 받아 들일 수 있습니다.
