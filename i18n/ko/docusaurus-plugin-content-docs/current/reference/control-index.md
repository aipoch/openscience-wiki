# 페이지 및 제어 색인 {/* #page-and-control-index */}

이 페이지는 검색할 수 있는 애플리케이션의 입력점을 집계, 페이지별 목록으로 집계합니다. 상태에 따라 제어는 해당 조건이 충족될 때만 나타납니다. 제어가 비활성화되면 도구 끝과 관련된 알려진 문제를 읽으십시오. 가능한 원인에는 세션 상태, 누락된 우선순위 및 제품 결함이 포함됩니다.


<span id="current-verification-coverage" />

## 자주 묻는 질문 {/* #find-the-detailed-instructions */}

이 인덱스를 사용하여 제어를 찾습니다. prerequisites, 단계, 예상 결과 및 알려진 문제에 대한 링크 된 튜토리얼을 따르십시오. 설정 패널의 [설정 개요](../settings/overview.md), 일반적인 행동의 [작업 단축키](controls.md), 오류의 [문제 해결](../guides/troubleshooting.md)를 참조하십시오.

## 회사 소개 {/* #onboarding */}

| 페이지, 마법사 순서에서 | 제품정보 | 결과 또는 필수품 |
| --- | --- | --- |
| 환경 | 다시 확인, 계속, 체크 행 | Recheck 호스트 요구 사항; 패스워드 |
| 데이터 위치 | Browse..., 대신 기본 위치를 사용, 뒤, 계속 | 데이터 위치를 선택하십시오; 사용자 정의 선택은 기본 또는 Restart 확인을 유지해야합니다. |
| 에이전트 런타임 | 프레임 워크 카드, 설치, 재검출, 다시, 계속 | Active runtime 설치 또는 선택 |
| 모델 제공업체 | 공급자 유형, 인증 선택, 조건 필드, 테스트 & 계속 | 필수 입력 및 승인 전에 공급자를 시험하십시오 |
| Notebook 런타임 | Interpreter 통제, 환경 설정, 포장, 뒤, 끝 | 옵션 설정; 종료 또는 종료하기 전에 진행중인 환경 작업이 이미 취소 |

자세한 연습을 위해 [첫 번째 시간 설정](../guides/onboarding.md) 및 [공급자 구성](../guides/providers.md)을 참조하십시오.

## 글로벌 설정 제어 {/* #global-settings-controls */}

**Search settings**은 4개의 패널 그룹을 통해 탐색합니다. `Back`, `Forward`, 빵크램프, `Maximize/Restore`, `Close settings`, 모바일 네비게이션 및 오류 `Dismiss`는 설정 전체에 적용됩니다. 그룹에 [설정 개요](../settings/overview.md)을 참조하고 단축키를 검색하십시오.

### Skills {/* #skills */}

대화 Skill 가져 오기, 소스 필터, 검색, 기술 추가, 카테고리 붕괴, Skill 세부 사항, 스위치를 활성화, Create/Upload/Import, 미리보기, 편집, 내보내기, 삭제, 취소 및 저장.

### 기억, 꼬리표, Credentials 및 사용법 {/* #memory-tags-credentials-and-usage */}

메모리 카테고리/입구 만들기, 편집, 삭제, 및 정리; 태그 create/edit/delete, 할당, 즐겨찾기, 필터, 재주문; Credentials는/복구/제거, 건강, 사용법 및 Connector 바인딩을 창조합니다; 사용법 기간, 미터, heatmap, 매일 도표, 회전/달 및 그룹화 통제.

### 커넥터 {/* #connectors */}

Filter/Search, Add/Import, Enable, Detail, Test/Reconnect, Edit, Export 및 제거. 추가 양식에는 유형, 표시 이름, ID, 설명, 명령, Arguments, 환경 변수, URL, 전송, 인증, OAuth 범위, 권한 서버 URL, 클라이언트 메타 데이터 URL, 헤더, 신뢰, 취소 및 추가 / 저장이 포함됩니다.

### 스페셜리스트 {/* #specialists */}

범주 필터, 검색, 사용 가능, 세부 사항, 행동, 생성 및 수입. 편집기에는 아이콘, 색상, 이름, 설명, 지침, 전체 액세스, 기능 유형, Skill / Connector 검색, 선택된 기능, 취소 및 저장이 포함되어 있습니다. 가져 오기에는 ZIP, 미리보기, 진단, 취소 및 가져 오기가 포함됩니다.

### 컴퓨팅 {/* #compute */}

호스트, 호스트 카드 / 사용 가능, Probe / 리트리, 세부 / Edit / Remove, 리소스, Direct SSH / Slurm 실행 모드, 세부 문서, 스크래치 루트 편집 / 입력 / 저장 / 캔, 및 동시 작업 제한 편집 / 입력 / 저장 / 캔. 실행 승인은 Deny, 한 번, 세션, 프로젝트 및 글로벌을 제공합니다.

### 네트워크 {/* #network */}

다시 확인; 프록시 시스템 / 수동 / 직접; Notebook 도메인 수당; 포장 거울 Configure/Edit; Conda 수로, pip 색인 및 CA 뭉치; 거울, 취소 및 저장.

### 모델 {/* #model */}

능동태 모델, 충전 라디오, Subagent/Reviewer/Vision/Session-details 모델 정책; 공급자 시험/Edit/Delete/Add. 공급자 양식은 Onboarding Model page에서 모든 필드를 추가하고 취소 및 저장합니다.

### 에이전트 {/* #agent */}

OpenCode/Claude/Codex/CodeBuddy 프레임 워크 카드, 스위치, 설치 소스, Install/Cancel/Retry, Install log, Repair, Sign in/auth, Import config/home, 그리고 제거 확인.

### 권한 {/* #permissions */}

기본 프로필, 범위 필터, 보조 범위 링크, 커넥터 힌트, Revoke 및 확인, 그리고 불완전 저장 경고 또는 새로 고침.

### 런타임 {/* #runtimes */}
