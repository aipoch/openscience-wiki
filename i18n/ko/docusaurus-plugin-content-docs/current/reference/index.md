# 참고 자료 {/* #reference */}

필드, 제한 및 인터페이스 계약을 찾습니다. 설정 및 [공공데이터 워크플로우](../workflows/data-quality.md)에 대한 [사용 가이드](../intro.mdx)을 사용하여 end-to-end 연구 작업.

| 더 보기 | 이름 &#42; |
| --- | --- |
| 필드 소유권, 기본 우선권 및 업데이트 규칙 | [구성 및 컨텍스트](configuration.md) |
| 승인 범위, 정책 주문 및 기본 보조금 | [권한 및 통제](permissions.md) |
| 버튼 엔트리 포인트, 키보드 작업 및 검색 범위 | [제어 및 키보드 참조](controls.md) |
| 확장, 미리보기 경계 및 수입 제한 | [파일 형식 및 제한](formats.md) |
| Skill, Specialist 및 Connector 형식 | [패키지 형식](packages.md) |
| CLI 인수, 상태 및 구조 출력 | [CLI](cli.md) |
| SDK 방법, 로컬 HTTP 경로 및 이벤트 | [작업 SDK 및 API](api.md) |
| Lifecycle, discovery, 브라우저 액세스 및 업데이트 | [Headless 서비스](server.md) |
| 구성 요소 소유권, 증거 주 및 오류 기록 | [건축과 진단](diagnostics.md) |
| 공개 예제 입력, 소스 해시 및 예상 QC 값 | [예시자료](example-data.md) |
| 데이터베이스 운영 이름, 필수 필드 및 기본값 | [Connector 운영](connector-operations.md) |

**⌘K / Ctrl + K**을 사용하여 제목, 제목 및 본문을 현재 문서 언어에서 검색합니다.
