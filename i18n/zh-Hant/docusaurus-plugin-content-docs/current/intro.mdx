# Open-Science {/* #open-science */}

使用 Open-Science 整理研究資料、與代理協作、執行分析並檢查儲存後的結果。

## 從這裡開始 {/* #从这里开始 */}

1. [能力與支援的輸入](./guides/capabilities.md)：根據檔案或研究問題選擇路徑。
2. [安裝](./guides/installation.md)與[首次設定](./guides/onboarding.md)：準備應用、代理、模型和執行時。
3. [第一個專案與結果](./guides/first-project.md)：建立專案，用一份小表格生成並重新開啟說明報告。
4. [權限與審批](./guides/approval-modes.md)：檢查操作請求，管理記住的授權。
5. [Notebook 與執行證據](./guides/notebook.md)：檢視程式碼、變數和產物來源。

## 執行示例前 {/* #运行示例前 */}

本地示例使用公開 PRISMA 論文和 GSE60450 RNA-seq 矩陣。下載章節中的輸入檔案，確認任務所需的模型、執行時和權限。

[遠端計算](./guides/remote-compute.md)已包含 Direct SSH RNA-seq 分析、結果回收、重啟恢復和取消實操。Slurm 終態監控需要可用的記賬查詢，GPU 推理需要相容的軟體環境。

技術限制和配置查詢見 [Reference](./reference/index.md)，版本變化見 [Changelog](./changelog/v0.31.1.md)。
