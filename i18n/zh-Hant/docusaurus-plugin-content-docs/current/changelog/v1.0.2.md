# 更新日誌 · v1.0.2

發佈於 **2026-10-22 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.2)。

## 查詢更多科學數據源 {/* #scientific-sources */}

| 數據源 | 對應入口 |
| --- | --- |
| HGNC 基因命名 | Genes & Ontologies |
| PubTator 3 論文標註 | PubMed |
| DGIdb 藥物—基因相互作用 | Clinical Genomics |
| RNAcentral 記錄與交叉引用 | RNA |
| Orphadata 罕見病關聯 | Orphadata；需要先啓用 |

當前目錄包含 **36 個數據源入口、371 個操作**，另有兩個離線 Molecule 操作。詳見[選擇與連接數據源](../tools/databases.md#new-source-access)。

GDC 文件查詢支持按病例、樣本類型和分析流程篩選，並保留樣本／aliquot 關聯。Ensembl VEP 可直接接收 HGVS，無需先手工換算座標；它不驗證輸入參考版本，也不執行 liftover。目錄還包括 ClinicalTrials.gov 已公佈的試驗結果。見[查詢上下文](../tools/databases.md#clinical-context)及[完整操作參考](../reference/connector-operations.md)。

## 安裝和檢查 CLI {/* #cli */}

CLI 和 Task SDK 已發佈到 npm。按 [npm 安裝說明](../guides/installation.md#npm-cli)操作後，可在不啓動後端的情況下使用 `version`、`help` 和 `paths`。顯示的版本屬於實際調用的安裝。桌面及獨立發行包包含 Node 22.23.4 安全更新。見[本地信息命令](../reference/cli.md#local-information)。

## 處理會話中的選擇與草稿 {/* #conversation */}

問題卡片明確區分 **Single select** 與 **Multi select**，並保留每個問題的完整歷史答案。排隊消息出錯時可撤銷；未發送草稿會觸發退出／重載提醒。憑據恢復提供具體下一步並保留草稿。遠程網頁會話支持引用產物。見[問題卡片與草稿](../guides/composer.md#clarification-questions)。

## 繼續研究並檢查記錄 {/* #research-records */}

- 研究包對話框保持穩定；重試部分提交的導入可避免重複會話。導入標題可以編輯，研究記錄仍只讀。見[研究包](../guides/research-packages.md#browser-import)。
- 大會話加載和啓動恢復得到優化；部分診斷導出會顯示警告。見[會話診斷](../guides/sessions.md#session-diagnostics)。
- PDF 結構、DOCX 編號／邊框，以及 Python／R 連續分析的文件依賴記錄得到修復。見[依賴檢查](../guides/notebook.md#chained-analysis-lineage)。
- 大批量 Skill 分批導入；外部保留名稱會轉換爲安全本地名稱。MiniMax M3.1 通過 Codex 連接的問題已修復。見[模型恢復](../guides/providers.md#credential-recovery)。
