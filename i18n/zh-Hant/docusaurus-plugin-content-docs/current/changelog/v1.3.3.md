# 更新日誌 · v1.3.3 {/* #更新日志--v133 */}

釋出於 **2026 年 11 月 22 日（UTC）**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v1.3.3)。

## 讓更新配合你的工作節奏 {/* #updates */}

符合條件的 macOS 官方穩定版可在退出應用時安裝已準備好的更新。Windows 和 Linux 可在桌面處於後臺空閒時，為下次啟動準備更新。自動下載要求非計量、未受限制的網路連線和足夠儲存空間；不支援的安裝位置或渠道仍使用手動方式。Linux AppImage 更新保留應用路徑，Windows 穩定版更新可使用較小的差分包。見[自動與手動更新](../guides/installation.md#update-progress)。

macOS 和 Windows 的安裝體積縮小，離線 npm 執行時也改為面向 Node 22 的打包形式，減少零散檔案。

## 各種安裝方式統一預設使用內建 Agent {/* #agent */}

新專案和會話預設使用 **Open-Science Agent**，包括全新的 CLI 和 SDK 安裝。缺少外部 Agent SDK 不再阻止這些安裝啟動；僅在選擇外部框架時才需要安裝它，模型接入仍需單獨配置。見 [Agent 設定](../guides/frameworks.md#built-in-agent)與 [CLI 設定](../reference/cli.md#terminal-setup)。

Settings 恢復了已安裝 Skills、Specialists 和 Connectors 的快捷入口。百鍊模型目錄加入 qwen4 系列，其套餐預設模型改為 qwen4 預覽版；開始任務前仍應檢查賬戶實際可用的模型。

## 在會話中編輯圖片 {/* #images */}

從預覽進入 **Edit image**，在會話輸入框中填寫修改要求。編輯時仍可切換版本、比較圖片，進入編輯也不會移動會話訊息的位置。圖片詳情顯示生成該次編輯的 Notebook 核心。見[圖片編輯步驟](../guides/image-generation.md#edit)。

PDF 翻譯進一步重組被分欄、圖注和行內公式切斷的正文，避免譯文擠佔原生符號、表單標籤與相鄰圖形的位置。匯出後仍需對照原文檢查。見 [PDF 翻譯](../guides/pdf-translation.md#scientific-layout)。

## 更清楚的錯誤與恢復提示 {/* #recovery */}

- 請求、載入、附件、匯入和 Notebook 錯誤給出具體原因。提供商錯誤在重啟後仍保留分類與請求 ID；使用者停止的任務與未收到後續響應的任務分開顯示。見[故障排查](../guides/troubleshooting.md#provider-errors)。
- Windows 保留內建 Agent 在重啟前等待回答的問題，恢復 Notebook 執行時狀態，並在冷啟動時重新檢查過期的檔案佔用。
- Notebook 記憶體檢查考慮 Windows 實體記憶體、macOS 記憶體壓力和 Linux 容器限制。見[記憶體與資源](../guides/notebook.md#memory-resources)。
- 會話研究包匯出先等待 Notebook 讀取結束，再說明匯出失敗的原因；同時修復已儲存產物連結、確認後的記憶刪除和 GitHub Skill 匯入錯誤提示。

見[安裝與更新](../guides/installation.md)及 [v1.3.2](v1.3.2.md)。
