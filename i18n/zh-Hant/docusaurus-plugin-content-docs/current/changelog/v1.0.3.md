# 更新日誌 · v1.0.3

發佈於 **2026-10-26 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.3)。

## 沿着引用關係尋找文獻 {/* #literature */}

通過 Semantic Scholar 查找論文的參考文獻和引用論文，將選中的候選送到 Inbox 審閱。文獻庫也支持拖入文件、查找補充材料，並顯示逐個附件的下載進度與預覽。[文獻發現與附件操作](../guides/library.md#citation-discovery)。

智能集合可以將全部候選的篩選決定導出爲 CSV，與入選文獻目錄分開保存。[導出篩選決定](../workflows/screen-literature.md#screening-csv)。

## 搬運與閱讀研究記錄 {/* #research */}

- CLI 和已認證的本地網頁支持導入、導出 `.science` 研究包，導入會話仍爲只讀。[本地研究包傳輸](../guides/research-packages.md#local-package-transfer)。
- 新建 PDF 譯文時，可通過 **Advanced → Content first** 重排正文和圖注。[譯文排版](../guides/pdf-translation.md#content-first)。
- 在 Permissions 中控制本地 Notebook 與 Shell 的文件夾訪問；更改設置會停止運行中的進程並清空變量。[文件夾限制](../reference/permissions.md#notebook-folder-restrictions)。

## 查詢更多科研來源 {/* #sources */}

新增訪問覆蓋 TCIA、KEGG、OmniPath、LIPID MAPS、PDBe 驗證、UniChem 映射、DepMap/CCLE 和 PDB 結構相似性。使用結果時保留來源對應的標識、許可和測量量綱。[選擇並連接來源](../tools/databases.md#expanded-sources)。

模型目錄加入 Kimi K3.1 Pro。Windows 協議註冊、網絡審批的持久保存、會話恢復、研究包傳輸及 PDF 處理也有修復。[模型選擇](../guides/providers.md#kimi-k31) · [上一版本：v1.0.2](v1.0.2.md)。
