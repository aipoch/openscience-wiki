# 更新日誌 · v0.37.0 {/* #更新日志--v0370 */}

釋出於 **2026-10-11 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.37.0).

## 不開啟桌面視窗也能執行 {/* #不打开桌面窗口也能运行 */}

桌面、瀏覽器、CLI 和 Notebook 現在共用普通 Node 後端。`open-science start` 不再啟動隱藏的 Electron 程序。官方發行版提供包含 Node 與後端的獨立 CLI 壓縮包，使用這些壓縮包無需另裝 Node。未指定埠時，桌面後端會選擇空閒埠。

安裝與 Codex 登入見[終端設定](../reference/cli.md#terminal-setup)。關閉桌面客戶端或停止共享後端前，先了解[服務歸屬與關閉規則](../reference/server.md#backend-ownership)。

## 更多資料庫證據 {/* #更多数据库证据 */}

介面目錄現有 **36 個 Connector、361 項操作**：其中 35 類資料來源包含 359 項操作，另有兩項離線 Molecule 操作。

| 入口 | 變化 | 說明 |
| --- | --- | --- |
| ENCORI | 十項操作，覆蓋 miRNA 靶標、RNA–RNA 與 RBP 互作、ceRNA 網路、motif 掃描、結合位點、參考表和批次檔案 | [連線與結果邊界](../tools/databases.md#encori) |
| ChEMBL | 實驗詳情，以及超過前 1,000 條記錄的活性資料分頁 | [實驗條件與分頁](../tools/databases.md#assay-submission-evidence) |
| ClinVar | 查詢 VCV 記錄中的逐條 SCV 提交證據 | [比較提交記錄](../tools/databases.md#assay-submission-evidence) |

保留結果的物種、參考基因組、過濾條件與證據型別。實驗置信度描述靶標歸屬；ClinVar 提交記錄不等於獨立臨床診斷。精確欄位與可下載目錄見[操作參考](../reference/connector-operations.md)。

## PDF 閱讀與 Notebook 執行 {/* #pdf-阅读与-notebook-执行 */}

PDF 翻譯改進原生閱讀順序與巢狀文字標籤。結構提取更完整地保留歸屬於原文的影象和表格記錄。仍應對照原文檢查[圖表](../guides/previews.md#pdf-extraction)與[翻譯頁面](../guides/pdf-translation.md#compare-export)。

已就緒的預設 Notebook 執行時減少重複設定授權，混合 Conda/pip 環境、micromamba 構建資訊以及輸入和回撥依賴的記錄更加準確。這些記錄可輔助[重跑驗證](../guides/reproducibility.md)，本身不代表結果可復現。

## 恢復與平臺修復 {/* #恢复与平台修复 */}

- 修復 `.science` 匯入新專案時的目錄接納失敗。匯入會話仍為只讀，繼續分析請使用 [Fork](../guides/research-packages.md)。
- 智慧集合重試失敗批次並保留已完成部分，見[集合篩選](../guides/library.md#smart-collections)。
- 改進 Plan 批准／關閉和 Codex 流式工具引數的恢復；Auto 模式減少受支援檢視操作的重複授權。
- Windows 修復含空格或括號的 Python 路徑、選定後端配置與 Specialist 交接；Linux 憑據避免首次秘密操作後重復探測 Secret Service。
- PDB 拒絕格式異常的查詢響應，並保留未完成的分頁狀態；報錯不能解釋為零命中。
- 首頁增加首次建立專案引導；無介面及 SDK 執行恢復對附帶 Notebook 資源的定位。
