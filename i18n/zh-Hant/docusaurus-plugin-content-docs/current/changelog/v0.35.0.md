# 更新日誌 · v0.35.0 {/* #更新日志--v0350 */}

釋出於 **2026-10-04 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.35.0)。

## 回放並討論研究過程 {/* #回放并讨论研究过程 */}

**View replay** 展示已記錄會話，支援播放、步驟跳轉、Notebook 記錄和檔案版本歷史。**Ask about this step** 可將所選上下文帶入可寫會話討論。匯入的 `.science` 研究仍為只讀，需要繼續執行時應 Fork。回放不會重新執行程式碼，完整操作見新增的[會話回放指南](../guides/session-replay.md)。

## 科學資料庫 {/* #科学数据库 */}

本版新增 **13 個操作**，登錄檔達到 **34 個 Connector、339 個操作**：其中 33 個資料來源家族共 337 個操作，另有離線 Molecule 的兩個操作。

| 入口 | 新增能力 |
| --- | --- |
| Cellosaurus | 細胞系身份、別名和質量註釋 |
| Monarch Initiative | 疾病或基因與表型的關聯及來源證據 |
| IEDB | 表位、抗原、T 細胞、B 細胞和 MHC 實驗及文獻 |
| Omics Archives → GEO | 發現矩陣檔案位置，預檢查已經讀取的矩陣文字 |
| Structures & Interactions → PDB | 按蛋白質序列搜尋結構，支援一致性、E-value 和查詢覆蓋度篩選 |

見[能力與連線步驟](../tools/databases.md#cell-lines-phenotypes-immunity)及[更新後的操作目錄](../reference/connector-operations.md)。GEO 預檢查讀取傳入文字，不讀取磁碟檔案；矩陣發現也不會自動下載檔案。

## PDF 與工作區操作 {/* #pdf-与工作区操作 */}

- 上傳的 PDF 與生成的、文獻庫中的 PDF 一樣，可以使用 **Figures and tables** 提取圖表。受控並行分析改善處理速度，並加強複雜版式的處理，見 [PDF 提取](../guides/previews.md#pdf-extraction)。
- 可在會話區域拖入檔案作為附件，傳送前檢查附件內容，見[拖放檔案](../guides/composer.md#conversation-drop)。
- 用量圖表支援連續檢視不同日期，見[每日用量](../guides/usage.md#inspect-daily-usage)。
- Windows 標題欄加入原生應用選單；PDF 大綱與筆記更好地適配窄視窗。

## 模型與網路訪問 {/* #模型与网络访问 */}

OpenCode Zen 模型目錄擴充套件，在支援的角色中提供 Jev 分類模型。主模型與分類模型仍分別設定，見[模型目錄](../guides/providers.md#catalog-models)。

網路設定區分公網域名規則與可信私有服務。私有授權繫結完整主機名、埠和稽核過的 DNS 地址，儲存前再次檢查 DNS。見[公網規則](../guides/network.md#public-network-rules)和[私有服務](../guides/network.md#trusted-private-services)。

## 修復 {/* #修复 */}

修復涵蓋會話結果和等待審批狀態的儲存、回放 Notebook 狀態和檔案列表、科學執行溯源、Codex 資料夾權限、Windows 執行時啟動及沙箱訪問，以及 WSL 資料夾路徑。`.science` 包內相同物件會去重；提供商和專案草稿增加防止意外丟失的保護。
