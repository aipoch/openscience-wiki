# 更新日誌 · v1.2.0

發佈於 **2026-11-09 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.2.0)。

## 選擇計算在哪裏運行 {/* #remote-compute */}

在 Direct SSH 和 Slurm 之外，新增 Kubernetes、Hugging Face Jobs、Modal 和 Ray。配置目標後，覈對凍結的輸入、命令、資源及輸出收集範圍，再逐次批准外部提交。重啓後可依據恢復記錄繼續收集，已發佈的輸出從 **Compute Preview** 打開。這些方式使用你自己的基礎設施或雲賬戶。[遠程計算配置](../guides/remote-compute.md#compute-backends)。

## 從內置 Agent 開始 {/* #agent */}

全新配置默認使用 **Open-Science Agent**，這是隨應用提供、可連接兼容模型服務商的內置運行時。Claude Agent、OpenCode、Codex、CodeBuddy 和 Pi 仍然可用。運行時與模型提供方是獨立選擇，現有 Codex 配置不必更換。[Agent 選擇](../guides/frameworks.md#built-in-agent)。

## 圍繞具體研究步驟討論 {/* #discussions */}

導入的 `.science` 研究及回放步驟支持關聯的子討論。**Ask about this step** 會把選中的證據帶入討論，也包括已記錄的 Notebook 運行。導入歷史突出顯示 **Fork to continue**，用於建立可繼續操作的分支。側欄按 **Pinned**、**Imported research**、**Active**、**Recents** 分組。[回放討論](../guides/session-replay.md#discuss-replay) · [研究包](../guides/research-packages.md#linked-discussions)。

## 更輕的更新和更清晰的操作 {/* #reliability */}

- macOS 更新可只下載變化的數據塊，需要時自動回退到完整下載；安裝檢查會覈對正在運行的應用，並指出佔用文件或進程。
- **Local capabilities** 取代 **Local parsing models** 標籤頁，集中管理 PDF 提取、OCR 和研究旁白。[本地資源](../guides/models.md#local-capabilities)。
- 手動添加文獻允許只輸入標識符而不填標題，包括 PMID；影片控件避免在加載時閃現不可用操作。
- PDF 提取改善正文與表格結構；固定版式翻譯在個別頁面失敗時保留其他成功頁面，分享前應檢查未完成頁。[PDF 翻譯](../guides/pdf-translation.md)。
- Notebook 分析移出界面線程；Windows 修復託管 R 的 DLL 加載及任務欄周圍的窗口邊界。
- 在較早的會話位置發送消息時保留閱讀位置，並改善工具錯誤、來源鏈接預覽和啓動診斷。

另見[安裝與更新](../guides/installation.md)。研究影片及批量概覽見 [v1.1.0](v1.1.0.md)，完整修複列表見官方發佈說明。
