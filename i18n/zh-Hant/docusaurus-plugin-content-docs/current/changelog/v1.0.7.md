# 更新日誌 · v1.0.7

發佈於 **2026-11-02 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.7)。

## 從論文鏈接，走到閱讀筆記 {/* #literature */}

有了 DOI、doi.org 鏈接或 arXiv 摘要/PDF 鏈接，可以通過 **Add from DOI or link** 查找文獻信息，覈對後保存。獲取全文仍是單獨的步驟。[添加文獻](../guides/library.md#doi-link-import)。

在 Reading 會話中，可以讓 Agent 定位段落，把高亮、區域標記或筆記保存到關聯 PDF。完成後打開 **Notes & Annotations**，檢查保存的位置和內容。[Agent 批註](../guides/pdf-notes.md#agent-annotations)。

掃描件可以使用可選的 OCR。下載識別組件、選擇九種語言包中的所需語言後，重新讀取 PDF 並查看頁面覆蓋情況。識別出的引用和數值仍需對照頁面圖像覈查。[OCR 設置](../guides/previews.md#scanned-pdf-ocr)。

## Pi 與研究案例市場 {/* #agents-and-cases */}

Pi 成爲第五種 Agent 框架，與 Claude Agent、OpenCode、Codex 和 CodeBuddy 並列。需要單獨安裝、配置兼容的模型訪問方式，並測試連接。更新 Open-Science 不會自動切換當前 Agent。[Pi 設置](../guides/frameworks.md#pi-agent)。

首頁和會話工作區都能進入 **Sharing marketplace**。按分類瀏覽、輸入關鍵詞搜索，再打開案例查看說明或下載研究包；從項目返回時會保留瀏覽位置與篩選條件。[查找研究案例](../guides/research-packages.md#use-case-gallery)。

## 讓手頭的工作繼續下去 {/* #reliability */}

- Windows Notebook 會在首次使用前準備 Shell 運行時，修復新後端無法使用 PowerShell 的問題。
- OpenCode 會話可以處理壓縮上下文時的非標準消息標識；後臺任務收尾期間發送的追問也會保留。
- 全文下載支持使用 Fake-IP DNS 的已配置代理。[下載恢復](../guides/troubleshooting.md#full-text-proxy)。
- 發佈或恢復產物後，前臺採用最新已發佈版本，溯源面板也更清楚地展示版本關係。[覈對文件版本](../guides/files.md#latest-published-version)。
- Composer 統一顯示提供商、環境、輸入、會話和內部錯誤，並給出對應恢復操作。[恢復請求](../guides/composer.md#request-recovery)。
- OCR 語言選項保存時保持響應，識別組件下載卡住也不會讓普通 PDF 讀取超出原有等待期限。

設置中的 Connector 說明更具體了。內置目錄仍爲 **48 個 Connector、418 項操作**；Pi、OCR 和文獻導入入口不計入 Connector 數量。[科學數據庫](../tools/databases.md#supported-databases) · [上一版](v1.0.6.md)。
