# 更新日誌 · v1.1.0

發佈於 **2026-11-06 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.1.0)。

## 把會話做成研究影片 {/* #research-films */}

已完成的會話可以生成帶英文旁白的短片。安裝本地旁白資源後，從桌面端會話啓動生成，檢查播放內容，再分享便攜播放器或導出 MP4。影片用於呈現已有研究，不會重新執行或驗證分析。[研究影片教程](../guides/research-films.md)。

## 批量處理閱讀清單 {/* #literature */}

一次選擇最多五篇文獻，批量生成論文概覽。可以暫停、繼續未完成項目或重試失敗條目，已完成的概覽會保留。CLI 與 MCP 也新增了文獻庫搜索、引用格式化和文獻管理操作。[批量概覽](../guides/library.md#batch-overviews) · [文獻命令](../reference/cli.md#literature-library)。

## 用手機打開工作區 {/* #mobile */}

手機或平板可以掃描二維碼，通過同一 WiFi 或 Pinggy 互聯網隧道連接。保持主機運行，並在掃碼前檢查連接狀態。[連接方式](../guides/remote-access.md#mobile-pairing)。

## 日常使用改進 {/* #reliability */}

- Compute 設置移至 **Connections** 分組，研究案例庫調整了佈局和導入目的地提示。
- 改善中斷和存儲失敗後的會話恢復，更及時地釋放已完成或閒置的 Agent 連接。
- 診斷導出保留 Notebook 執行證據與歷史後端日誌；Windows 新增可選的資源記錄功能，方便排查問題。
- PDF 提取改善可搜索掃描件的圖表恢復，Codex Chat 支持原生圖片輸入。
- Notebook 優先使用已就緒的應用託管運行環境；Shell 執行失敗以工具錯誤返回。
- Windows 更新準備檢查進程身份和佔用文件，本地 `.science` 與 MP4 導出更可靠地處理桌面保存對話框。

另見[安裝與更新](../guides/installation.md)及[上一版本](v1.0.8.md)。
