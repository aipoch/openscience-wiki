# 更新日誌 · v0.34.0 {/* #更新日志--v0340 */}

釋出於 **2026-09-29（北京時間）**，對應官方 UTC 日期 **2026-09-28**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.34.0)。

## 期刊資料集和文獻引用 {/* #期刊数据集和文献引用 */}

文獻庫新增帶來源、年份和欄位對映的期刊資料集，可在匹配文獻中顯示屬性。見獨立教程[期刊資料集與文獻屬性](../guides/journal-datasets.md)。

工作區 Library 提供文獻詳情、明確開啟的批次選擇，以及將引用加入當前或其他會話草稿的操作。加入草稿後仍由使用者決定何時傳送。見[文獻庫操作](../guides/library.md#add-reference-to-chat)。

## 科學資料庫擴充套件 {/* #科学数据库扩展 */}

新增 Pathway Commons，擴充套件 Bgee、cBioPortal、openFDA 和 MGnify，共新增 **16 個操作**。完整目錄為 **29 個 Connector、300 個操作**；其中 28 個資料來源家族提供 298 個操作，另有離線 Molecule 的兩個操作。

見[資料庫能力與連線](../tools/databases.md#pathway-expression-clinical)、[操作引數](../reference/connector-operations.md)及實際儲存結果的[通路互作工作流](../workflows/inspect-pathway.md)。

## 安裝、模型和桌面導航 {/* #安装模型和桌面导航 */}

- Linux 增加原生 ARM64 的 AppImage 和 Debian 安裝包，見[安裝說明](../guides/installation.md)。
- Codex CLI 相容基線提高到 **0.157.1**；已有舊執行時可能需要單獨更新，見[更新 Codex](../guides/frameworks.md#update-codex)。
- 模型目錄新增 **MiniMax M3.1 Flash Preview** 和 **Claude Sonnet 5.5**，見[Provider 設定](../guides/providers.md#catalog-models)。
- 桌面托盤／選單欄可訪問執行中、固定和近期會話，見[快捷導航](../guides/navigation.md#tray-navigation)。

## 改進與修復 {/* #改进与修复 */}

升級到 Electron 43，最佳化工作區切換和直譯器發現。修復代理連線錯誤後的恢復、停止或重啟後的委派、Reviewer 中斷恢復、PDF 圖表提取、文獻後設資料補全、WSL 執行時就緒狀態和 macOS 遠端目錄列表，並改進編輯保護、鍵盤焦點及權限說明。
