# 更新日誌 · v0.32.0 {/* #更新日志--v0320 */}

釋出於 2026 年 9 月 21 日。本版新增持久儲存的 PDF 閱讀筆記、序列相似性檢索，以及公共測序和蛋白質組資料的發現方式。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.32.0) · [相對 v0.31.1 的變化](https://github.com/aipoch/open-science/compare/v0.31.1...v0.32.0)

## PDF 批註與文件筆記 {/* #pdf-批注与文档笔记 */}

高亮段落、標記區域，或新增頁面筆記和文件筆記。筆記屬於受管理的檔案版本，可附評論與標籤。可以在筆記檢視或全域搜尋中找回，並匯出 Markdown、CSV 或帶批註的獨立 PDF。原始 PDF 位元組保持不變。

文獻庫附件在使用同一受管理版本的位置共享筆記；專案上傳檔案和產物在所屬專案的會話間共享。標註、搜尋和匯出步驟見[帶截圖的 PDF 筆記教程](../guides/pdf-notes.md)。這類筆記與[會話私有書籤](../guides/bookmarks.md)用途不同。

## 序列與組學資料發現 {/* #序列与组学数据发现 */}

| 能力 | 使用入口 |
| --- | --- |
| UniProt 發現 | 按基因、蛋白名稱短語和物種查詢條目，再獲取選中條目的序列。見[蛋白檢索](../workflows/protein-sequence-search.md#sequence-search) |
| NCBI BLAST | 提交公開的核酸或蛋白序列，保留 RID，按規定間隔查詢狀態並獲取完成後的報告。見[序列檢索](../workflows/protein-sequence-search.md#sequence-search) |
| ENA 發現 | 組合物種、文庫策略和關鍵詞條件，分別列出歸檔 FASTQ 與原始提交檔案。見[發現與檔案清單](../workflows/public-omics-data.md#omics-discovery) |
| PRIDE 檔案列表 | 分頁讀取專案檔案後設資料和公開下載位置，無需下載資料檔案。見[檔案清單](../workflows/public-omics-data.md#omics-discovery) |

[操作參考](../reference/connector-operations.md)現覆蓋 **251 個資料來源操作**，另有兩個 Molecule 操作，共 24 個 Connector。gnomAD 線粒體查詢接受 `gnomad_r3` 和 `gnomad_r4` 資料集。

## 模型與自動化 {/* #模型与自动化 */}

- **Custom HTTP service** 可把能力選擇連線到相容 TypeSafe 的分類服務。它有獨立的端點、模型和金鑰，不會更換 Main。見[分類模型](../guides/models.md#custom-classification)。
- **StepFun Step-5 Preview** 新增 China 和 Global 區域，在[提供方設定](../guides/providers.md#stepfun-regions)中選擇端點區域。
- 本地 PDF 解析模型在主下載源不可達時，可使用經過批准並校驗完整性的備用映象。見[PDF 提取](../guides/previews.md#pdf-extraction)。
- [CLI](../reference/cli.md#unattended-runs) 和 [SDK](../reference/api.md#unattended-runs) 任務可使用 `permission-prompts none` 拒絕需要等待人工處理的請求。原有審批規則仍然生效，不會自動授予權限。

本版還在匯出後端增加完整的 RO-Crate 1.1 打包配置：包含已驗證的產物版本及精確輸入檔案，核對宣告的大小與校驗和、合併相同內容，並拒絕衝突。Wiki 中的桌面操作仍按現有 [.science 交接](../guides/research-packages.md)和[逐版本可復現性檢查](../guides/reproducibility.md)教程進行。

## 修復與互動變化 {/* #修复与交互变化 */}

[Side Chat](../guides/delegation.md#side-chat-可用范围) 的對話和待送達建議保留在本次應用執行中。切換檢視或重新載入介面時可重新連線。確認 **Close Side chat** 會移除該旁聊，完整重啟應用會清除其餘旁聊。已經送達 Main 的訊息仍保留在 Main 中。

其他變化涉及啟動和長會話效能、連結 PDF 閱讀、後臺計算結果交付與取消、OpenCode 會話間工具隔離、PDF 文字選擇、設定搜尋、檔案焦點和恢復提示。完整列表見官方釋出說明。上一版為 [v0.31.1](./v0.31.1.md)。
