# 更新日誌 · v0.35.1 {/* #更新日志--v0351 */}

釋出於 **2026-10-06 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.35.1)。

## 開始與管理會話 {/* #开始与管理会话 */}

新會話頁把研究任務建議放在輸入區旁，並簡化 **Import previous research** 入口。選擇建議會填入可編輯的草稿，不會直接傳送。見[從研究任務建議開始](../guides/composer.md#research-starters)。

會話頂部的 **Session actions** 選單集中提供編輯、置頂、Side Chat、Fork、匯出及歸檔。匯出子選單區分對話、研究包和診斷材料。Side Chat 標籤與工具欄也更加緊湊。見[會話操作](../guides/sessions.md#session-header-menu)。

## 科學資料庫 {/* #科学数据库 */}

新增四個操作，登錄檔達到 **34 個 Connector、343 個操作**：33 個資料來源家族提供 341 個操作，另有兩個離線 Molecule 操作。

| 入口 | 新增能力 | 使用說明 |
| --- | --- | --- |
| Human Genetics → GWAS Catalog | 發現完整彙總統計檔案的位置、後設資料和宣告的參考基因組，不下載大型檔案 | [GWAS 檔案](../tools/databases.md#gwas-summary-statistics) |
| InterProScan | 提交蛋白序列，再查詢狀態並獲取 TSV 註釋 | [聯絡郵箱與提交步驟](../tools/databases.md#interproscan-submit) |
| IEDB | 檢索 TCR 與 BCR 受體證據，保留實驗與來源引用 | [受體證據](../tools/databases.md#iedb-receptors) |

[操作引數參考](../reference/connector-operations.md)同步補充必填欄位、限制和準確呼叫示例。聚合後的受體證據不能證明所有條件在同一實驗中成立。

## Requesty 與模型目錄 {/* #requesty-与模型目录 */}

**Requesty** 加入官方提供商選擇器，提供內建連線驗證和整理後的模型列表。OpenRouter 目錄也已更新。實際可用協議與模型取決於當前 Agent 和賬號權限，不會自動替換已儲存的 Main 模型。見 [Requesty 配置](../guides/providers.md#requesty)。

## PDF 閱讀與筆記 {/* #pdf-阅读与笔记 */}

首次請求開始前會保留 PDF 上下文，包括剛上傳的附件。見[上傳後直接閱讀](../guides/previews.md#uploaded-first-message)。複雜版式提取有所改進，閱讀器減少了持續顯示的提示。

經核驗內容相同的 PDF 副本可以跨專案共享文件筆記，包括上傳檔案和產物。同名檔案不足以建立共享關係，筆記也不會跨裝置同步。見[筆記共享範圍](../guides/pdf-notes.md#笔记的共享范围)。

## 穩定性修復 {/* #稳定性修复 */}

修復涉及回放追問的滾動與記錄檔案提問、匯入會話的只讀歷史，以及會話繫結變化時輸入區上下文的保留。回放讀取已有記錄，不會重新執行程式碼。見[會話回放](../guides/session-replay.md)。

Notebook 修復涉及跨語言檔案來源關係、損壞執行記錄的隔離恢復，以及路徑包含空格時的 R 環境。其他修復包括預設隔離共享登入設定、解釋無人值守 Claude 的權限拒絕，以及書籤、標題欄浮層和產物事務重試。
