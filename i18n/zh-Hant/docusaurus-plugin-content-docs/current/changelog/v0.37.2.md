# 更新日誌 · v0.37.2 {/* #更新日志--v0372 */}

釋出於 **2026-10-13 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.37.2)。

## 恢復啟動與執行連線 {/* #recovery */}

後端、設定和網路初始化失敗時，現在提供相應恢復路徑。桌面連線中斷後，工作區保持開啟，並提供 **Reconnect** 和 **Quit app**。重連恢復原先仍在執行的後端，不會啟動已停止的後端，也不會自動重複已提交操作。未收到響應時，先檢查原任務狀態再決定是否重試。

瀏覽器介面恢復遺漏更新時會暫停控制元件，並在需要時提供重新載入或重新配對提示。大型會話及 Notebook 快照傳輸、密集事件和重定向診斷日誌的處理也得到改進。操作見[連線與啟動恢復](../guides/troubleshooting.md#connection-recovery)和[服務歸屬](../reference/server.md#backend-ownership)。

## 透過安裝包使用 Linux CLI {/* #linux-cli */}

除發行版壓縮包和 Homebrew CLI 外，Linux 新增 x64 與 ARM64 的獨立 `.deb`、`.rpm` CLI 安裝包。安裝包包含 Node、後端和本地 Web UI，明確入口為 `open-science-cli`。它與桌面安裝包分開，不會自動啟動系統服務。

[安裝包選擇、安裝與升級](../guides/installation.md#linux-cli-packages)說明了具體步驟。升級或解除安裝前，停止使用該安裝包的所有配置例項，並保留研究資料與憑據儲存。

| 範圍 | 變化與對應說明 |
| --- | --- |
