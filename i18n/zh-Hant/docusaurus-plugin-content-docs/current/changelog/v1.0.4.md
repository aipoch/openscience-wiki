# 更新日誌 · v1.0.4

發佈於 **2026-10-27 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.4)。

## 讓其他工具連接科研工作臺 {/* #mcp */}

獨立 CLI 提供 stdio MCP 適配器。先啓動已認證的本地服務，再讓客戶端連接該配置。工具可以創建項目、修改配置，並在已有權限範圍內運行研究任務，包括寫入文件和產生模型費用。[MCP 配置與控制](../reference/cli.md#external-mcp)。

## 檢查論文的出版通知 {/* #publication */}

在文獻庫中，可對具有有效 DOI 的記錄手動查詢 Crossref 撤稿與更正通知。結果保留來源和檢查時間；沒有返回通知並不保證論文不受影響。[檢查與解讀通知](../guides/library.md#publication-checks)。

## 日常工作更容易整理 {/* #workspace */}

- 一輪結束後收起中間消息與工具分組，搜索和批註可以展開對應內容。[展開會話](../guides/sessions.md#collapsed-conversation)。
- 將已授權文件夾內的文件保存爲會話中的不可變產物。[導入本地文件](../guides/files.md#import-local-artifact)。
- 收藏已掃描的 GitHub Skill 倉庫，便於再次使用；不會自動更新 Skill。[保存倉庫](../skills/manage.md#saved-repositories)。
- 問題卡提供明確的 **Skip** 和 **Skip all** 操作。[問題卡控制](../guides/composer.md#skip-question)。

安裝包體積縮小，同時修復 Windows Notebook 標準模式執行、選定保存位置後研究包導出仍等待、文件夾授權對話框、問題卡恢復及回放事件展示等問題。[研究包傳輸](../guides/research-packages.md#local-package-transfer) · [上一版本：v1.0.3](v1.0.3.md)。
