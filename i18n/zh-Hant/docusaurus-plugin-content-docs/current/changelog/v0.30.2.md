# 更新日誌 · v0.30.2 {/* #更新日志--v0302 */}

釋出於 2026 年 9 月 17 日。本次更新主要改善 Skill 載入、旁聊、科研資料查詢和執行恢復的可靠性。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.30.2) · [相較 v0.30.1 的變更](https://github.com/aipoch/open-science/compare/v0.30.1...v0.30.2)

## 日常使用變化 {/* #日常使用变化 */}

| 範圍 | 對使用的影響 |
| --- | --- |
| Specialist Skills | 為專家對話輪次和委派任務準備繫結的 Skill；OpenCode 可讀取應用提供的 Skill 參考檔案。選擇與使用方法見[擴充套件分析案例](../workflows/extend-analysis.md) |
| Side Chat | Main 正在執行或等待審批本身不再阻止旁聊；切換應用檢視時保留旁聊，仍需滿足旁聊自身的歷史儲存、恢復和只讀狀態要求。[Side Chat](../guides/delegation.md) |
| 網頁搜尋授權 | 受支援的 Claude Agent 原生搜尋可以記住 **Allow for this conversation**；搜尋與網頁讀取仍是兩項獨立授權。[權限說明](../guides/approval-modes.md#remember-web-search) |
| Reviewer | 啟動會話時保留 Auto-review 設定，關聯糾錯輪次保留糾錯所需的反饋；仍需檢查修改後的輸出及後續審閱。[Reviewer](../specialists/reviewer.md) |

## 資料與證據 {/* #数据与证据 */}

[Connector 操作參考](../reference/connector-operations.md)與下載目錄已更新至 v0.30.2。Reactome 按請求的受支援物種查詢；Ensembl 返回實際解析的物種，並將 VEP 區域查詢規範為正鏈。UCSC 拒絕無效座標，gnomAD 區域座標須小於十億。CellGuide 和 OLS 會報告相關獲取或分頁失敗，避免把它們呈現為空證據。

PubMed 作者解析更正了姓氏、名字縮寫與字尾的區分。`literature-review` Skill 會檢查 Crossref 兩個方向的撤稿關係；未發現標記不能證明論文從未撤稿。參閱[後設資料核對](../guides/library.md)和[文獻證據提取](../workflows/literature-review.md)。

## Notebook 與恢復 {/* #notebook-与恢复 */}

Windows 修復涉及 conda R 啟動、環境準備後的可執行檔案查詢、R 核心恢復，以及驗證環境中的 pip 入口。Notebook 重放可恢復受支援的同輪輸入與標準庫匯入；Linux 臨時掛載目錄下的讀取授權也已修正。參閱[執行環境](../guides/runtimes.md)和[可復現性](../guides/reproducibility.md)。

以上依據釋出說明和對應原始碼。既有 Windows 與 Specialist 截圖保留原版本，不是 v0.30.2 新實測結果。缺失的輸入證據或環境鎖仍需處理，可復現檢查仍針對具體的已捕獲結果版本。

## 其他改進 {/* #其他改进 */}

提供方目錄加入 DeepSeek V4.1 Flash，並更新火山引擎 Ark 模型，同時保留舊的固定模型選擇。市場卡片在缺少作者時顯示來源；OpenCode 委派任務使用獨立執行時。另修正 CLI 排隊會話快照，以及部分設定、標籤、文獻和工具卡片互動。

更新步驟見[安裝與更新](../guides/installation.md)，前一版本見 [v0.30.1](./v0.30.1.md)。
