# 更新日誌 · v0.30.1 {/* #更新日志--v0301 */}

釋出於 2026 年 9 月 16 日。本次更新改善旁聊準備、方法變更稽核和研究材料交接。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [相對 v0.30.0 的變化](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## 使用流程更新 {/* #使用流程更新 */}

| 範圍 | 對使用的影響 |
| --- | --- |
| Side Chat | 可先開啟空草稿，繼承主會話的模型與推理強度，也能為下一次傳送另選模型；含內容的草稿在切換時保留，未填寫的空草稿會清理，見 [Side Chat](../guides/delegation.md) |
| Skill 更新 | 在 **Update existing Skill** 前檢視檔案變化、行號和增刪內容，核對受影響的 Specialist 及將被替換的本地修改，見 [Skill 市場](../skills/marketplace.md) |
| 研究包 | **Full export** 包含可用文獻 PDF，**Customize contents** 可逐項選擇；Essential export 省略可選 PDF，必需證據不能移除；不匯出 Side Chat 對話，見[研究包](../guides/research-packages.md) |
| 本地閘道器 | 無需認證的迴環 Custom Gateway 可將 API key 留空；遠端閘道器仍需要憑據和 HTTPS，見[模型接入](../guides/providers.md) |
| 網頁讀取授權 | 支援的網頁讀取請求可按會話記住授權，覆蓋同一會話後續對其他網站的讀取，見[權限與審批](../guides/approval-modes.md) |
| 標籤 | 資源標籤選擇器支援搜尋、方向鍵與 Enter，也可以直接建立並分配新標籤，見[標籤](../guides/tags.md) |
| 安裝與恢復 | macOS 在更新前引導只讀副本安裝到 Applications；Windows 提供獨立的資料重置工具，帶預覽與輸入確認，會刪除資料；安裝器顯示專案許可，見[安裝與更新](../guides/installation.md)、[Windows 重置](../guides/troubleshooting.md#windows-data-reset) |

## 釋出說明中的修復 {/* #发布说明中的修复 */}

本版還報告修復了 MCP 超時期間的計劃審批、歷史產物繫結、任務取消和 Notebook 排隊狀態。PDF 解析可從被阻塞狀態恢復並報告提取失敗，圖表版式恢復也得到改進。資料介面方面，修正 gnomAD 區間引數與資料集參考基因組匹配，以及 ESM-2 批次殘基池化。

提供方連線檢查使用被測試提供方自身的路由；缺少檔案式 Codex 登入時給出更明確的匯入錯誤。文獻檢視返回原來的專案會話，OpenCode Side Chat 指令與 Main 保持分離。

更新步驟見[安裝與更新](../guides/installation.md)，前一功能版本見 [v0.30.0](./v0.30.0.md)。
