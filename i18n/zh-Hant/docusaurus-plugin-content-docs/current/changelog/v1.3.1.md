# 更新日誌 · v1.3.1 {/* #更新日志--v131 */}

釋出於 **2026-11-19 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v1.3.1)。

## 查詢來源，沿引用繼續閱讀 {/* #sources */}

內建 Open-Science Agent 可以搜尋公開網頁並閱讀正文，來源引用隨會話保留。搜尋授權卡片會展示搜尋詞和過濾條件。搜尋詞傳送到 Exa，閱讀網頁則連線目標網站。[網頁搜尋與閱讀](../tools/web-search.md)。

文獻庫新增互動式引用圖。可以篩選參考文獻和施引文獻，把相關論文設為新的中心，再返回原始論文。候選文獻先在 Inbox 稽核，再收入文獻庫。[探索引用圖](../guides/library.md#citation-discovery)。

## 連線外部 Agent 與組織資源 {/* #connections */}

外部 MCP 客戶端連線時，現在可以自動啟動或複用本地 Open-Science 服務。客戶端斷開後，服務仍會執行；使用完畢後需要主動停止。[MCP 配置](../reference/cli.md#external-mcp)。

桌面版可登入 Lab 賬戶，使用組織分配的模型和共享研究案例。模型請求和共享研究包會傳送到配置的 Lab 伺服器。[Lab 賬戶設定](../guides/providers.md#lab-account) · [組織案例](../guides/research-packages.md#organization-cases)。

## 更清楚地管理模型與資源 {/* #controls */}

- 在 Settings 重新整理受支援提供商的模型列表。重新整理失敗會保留原有列表；會話錯誤會說明認證、額度、限流等具體原因。[提供商設定](../guides/providers.md#refresh-models)。
- 儲存影象服務前，可以選擇執行一次測試生成。尚無預設模型時，會自動選中首個模型。[影象服務配置](../guides/image-generation.md#configure)。
- Notebook 執行前會檢查記憶體。可以在 Compute 檢查並釋放某個會話的本地 Notebook 資源，再決定是否重試任務。[記憶體與資源管理](../guides/notebook.md#memory-resources)。
- 專案首頁啟動更快。重新連線時保留草稿，恢復較長的分支歷史和待回答問題；研究影片播放不再等待與播放無關的質量審查。

## 從 v1.3.0 更新 {/* #update */}

v1.3.0 更新程式可能把應用自身程序誤判為佔用安裝目錄的外部程式。如果因此阻止更新，先完成當前任務，徹底退出應用及其後臺服務，再手動安裝官方 v1.3.1 安裝包。新安裝包無法改變正在執行的 v1.3.0 更新程式。[手動更新步驟](../guides/installation.md#update-from-130)。

本版還修復了 Windows 更新或解除安裝時設定檔案過大導致的失敗、可選 WSL 設定阻塞首次啟動、Windows 匯入會話刪除不完整，以及 Linux AppImage 更新誤判應用自身管道的問題。研究目錄不可用時，啟動恢復對話方塊會顯示具體路徑，方便重新連線對應磁碟。

參見[安裝與更新](../guides/installation.md)和 [v1.3.0](v1.3.0.md)。
