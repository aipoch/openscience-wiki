# 更新日誌 · v1.3.0 {/* #更新日志--v130 */}

發佈於 **2026-11-18 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.3.0)。

## 把下一次研究任務安排好 {/* #scheduled-tasks */}

創建一次性或重複任務，定時發送 Agent 消息，或者運行 Python、R、Shell 腳本。消息任務可以繼續已有會話，也可以每次創建新會話；每次運行都有獨立記錄。應用需要保持運行，任務使用配置的權限、憑據和提供商額度。[定時任務教程](../guides/scheduled-tasks.md)。

## 生成圖片，直接修改演示文稿 {/* #creation */}

配置圖像生成服務後，可以根據提示詞生成圖片，再通過版本化編輯逐步調整。圖像生成擁有獨立的模型設置，與 Main、Vision 分開。[圖像生成與編輯](../guides/image-generation.md)。

PPTX 預覽現在可以編輯幻燈片文字和格式。保存後檢查新版本，分享前重新打開下載的演示文稿。[編輯演示文稿](../guides/presentation-editing.md)。

## 講清研究，或者回放操作 {/* #films */}

在研究影片對話框中選擇 **Research explanation** 或 **Operation replay**。會話分支分別保存自己的影片；生成前會說明模型用量，已有影片可從會話菜單打開。[影片生成步驟](../guides/research-films.md#generate-film)。

## 長任務中的更多控制 {/* #other-changes */}

- 定時任務保留運行歷史；Notebook 進程監控展示所屬進程，並提供 **Terminate** 操作。[進程監控](../guides/notebook.md#process-monitor)。
- CodeBuddy 訂閱支持中國站和國際站賬戶，通過受管 CLI 發現可用模型。[賬戶設置](../guides/providers.md#codebuddy-subscription)。
- Agent 提問會展示不同選項及其取捨，確認選擇後繼續任務。
- 文檔配圖 Skill 首次使用時，在受管環境中準備所需依賴。
- 會話增量保存、影片恢復和 Windows 安裝更新改進，減少重複工作與不必要的資源佔用。

參見[安裝與更新](../guides/installation.md)和 [v1.2.2](v1.2.2.md)。
