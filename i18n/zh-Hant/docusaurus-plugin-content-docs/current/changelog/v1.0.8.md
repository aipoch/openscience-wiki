# 更新日誌 · v1.0.8

發佈於 **2026-11-04 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.8)。

## 把一份閱讀清單帶進文獻庫 {/* #literature */}

手頭有一串論文編號？**Add from DOI or link** 現在一次可以接收最多 100 個非空行，混合填寫 DOI、arXiv、PMID、PMCID 或支持的官方論文鏈接。覈對識別結果和重複記錄處理方式後再導入；找到文獻信息不等於已經取得全文。[批量導入教程](../guides/library.md#doi-link-import)。

文獻詳情新增 **Study overview**。配置好的主模型會根據可用來源，整理研究問題、研究對象、方法、主要發現和侷限五個部分。來源標籤區分摘要、全文和選取的段落。可以用它快速瞭解論文，再回到原文覈查重要論斷。[生成論文概覽](../guides/library.md#study-overview)。

## 設置各歸其位 {/* #settings */}

**Appearance** 和 **Notifications** 成爲 **System** 下的獨立面板。General 保留應用信息、診斷、命令行工具和幫助，並提供手動安裝指南入口。設置中心現在共 **四組、19 個面板**。[設置總覽](../settings/overview.md) · [外觀與通知](../guides/appearance.md)。

## 科研與日常使用的修復 {/* #reliability */}

- eQTL Catalogue 在舊 REST API 停用後，改用 release-7 索引文件。查詢必須明確提供 **GRCh38** 座標，不能再只傳基因 ID。[座標要求](../tools/databases.md#eqtl-coordinates)。
- PDF 排序結合文字位置區分正文分欄與表格行；提取時檢查裁剪邊界，無法可靠解釋的單元格保留原始文字並提示可靠性問題。[PDF 閱讀與提取](../guides/previews.md#automatic-pdf-reading-order)。
- R 復現檢查會在可能觸發參數求值或方法分派的操作後，撤銷過期的文件證據。溯源面板會解釋執行證據不完整的情況；打開舊 Markdown 產物時會修復過期的歷史指向。[理解驗證證據](../guides/reproducibility.md#execution-evidence)。
- 五種 Agent 框架在會話完成後釋放提供方和工具進程；修復打包桌面版中 Pi 的安裝問題。
- 更新準備更清楚地顯示阻塞進程，並修復 macOS 只讀文件佔用、Windows 進程識別和過期 Notebook 恢復記錄的問題。診斷包保留桌面恢復失敗的實際錯誤。[更新指南](../guides/installation.md#update-preparation)。
- 下載完成後，目標目錄不可讀或後續清理報錯不再使已保存的文件失效。Windows PDF 退出清理和保護檢查更穩定；PATH 中的舊 Node 無法使用代理時，Notebook 命令行工具可以使用應用自帶的 Node。
- 重新查找全文成功後會清除之前的 PDF 添加錯誤；Composer 不再重複顯示模型不可用提示。

騰訊 TokenHub 新增 Hy4 和支持百萬 Token 上下文的 DeepSeek V4.1 Flash 路由，併爲 GLM-5.3-Flash、Kimi K3、MiniMax M3 增加圖像輸入。實際可用性取決於提供方賬戶和所選路由。[提供方配置](../guides/providers.md)。

內置目錄仍爲 **48 個 Connector、418 項操作**。[當前目錄](../tools/databases.md#supported-databases) · [上一版本](v1.0.7.md)。
