# 更新日誌 · v0.31.0 {/* #更新日志--v0310 */}

釋出於 2026 年 9 月 18 日。本版新增獨立會話副本，並改進會話與連線恢復後的繼續使用體驗。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [相對 v0.30.2 的變更](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## 繼續使用與檢查會話 {/* #继续使用与检查会话 */}

- **Fork** 在桌面端建立可寫副本，包含對話分支、Notebook 記錄、檔案版本、文獻、批註和私有書籤。副本使用新標識，源會話保持不變；匯入會話本身仍只讀。見 [Fork 操作](../guides/sessions.md#fork-session)和[研究包](../guides/research-packages.md)。
- 點選會話標題可開啟[資訊卡片](../guides/sessions.md#session-information)，檢視來源、數量並置頂。繼續建立的會話還會連結到來源訊息。
- 上下文重建後，[Session Plan](../guides/planning.md#resume-plan) 保留標識、修訂和待審批狀態。計劃恢復不代表待辦步驟已經獲批或執行。

## 設定與資料行為變化 {/* #设置与数据行为变化 */}

| 範圍 | 需要核對的內容 |
| --- | --- |
| 提供方設定 | 修改透過驗證後才替換已儲存配置；執行時被拒絕會更新可用狀態。[模型接入](../guides/providers.md#validated-provider-save) |
| Windows R | 標準模式執行不再要求先配置保護模式；受保護執行仍有獨立前提。[執行環境](../guides/runtimes.md) |
| gnomAD | 使用 `include_populations: true` 請求各人群計數和頻率，同時保留資料集、參考組裝與質量過濾。[引數](../reference/connector-operations.md#get_variant) |
| 產品名稱 | 介面統一使用 Open-Science；已有安裝位置、設定和資料保留，不要為了名稱一致而重新命名儲存目錄。[安裝](../guides/installation.md#product-name) |

**STRING 相容性變化：**`nodes` 現在描述完整返回網路，包含新增鄰居。只需對映後的輸入節點時篩選 `is_query`，需要全部輸入別名時使用 `queries`。不能再把 `n_nodes` 當作提交蛋白數量。[STRING 使用說明](../tools/databases.md#string-network)

其他修復涉及 Codex 推理強度切換、取消與繼續、UniProt 次級登入號、Ensembl 標識、臨床試驗納入條件和 cBioPortal 分母。完整列表見官方釋出說明。

下一版為 [v0.31.1](./v0.31.1.md)。
