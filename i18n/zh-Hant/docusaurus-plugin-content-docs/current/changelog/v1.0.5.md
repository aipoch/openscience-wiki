# 更新日誌 · v1.0.5

發佈於 **2026-10-28 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.5)。

## 給文獻標記閱讀進度 {/* #reading */}

文獻庫新增手動設置的 **Unread**、**Reading** 和 **Read** 狀態，支持表格列、篩選和批量修改。出版通知檢查改用 **Check now** 和 **Check again**，仍保留 Crossref 結果與檢查時間。[閱讀狀態](../guides/library.md#reading-status) · [出版通知檢查](../guides/library.md#publication-checks)。

## 在瀏覽器裏收發研究包 {/* #packages */}

經過身份驗證的本地 Web 界面可以上傳 `.science` 文件並導入，也可以下載已導出的研究包。首頁案例展示提供 **Details** 和 **Import** 入口。導入前確認目標項目，導入後檢查材料；繼續研究時使用 **Fork to continue**。[瀏覽器傳輸與案例展示](../guides/research-packages.md#local-package-transfer)。

## 明確後臺服務何時繼續運行 {/* #service */}

顯式執行 CLI `start` 後，即使最後一個 App 退出，服務也會繼續運行。普通 CLI、Web 和 SDK 活動不會單獨保持服務運行。普通 `stop` 解除這個持續運行設置，但仍連接的 App 可以讓服務繼續運行。`stop --force` 請求停止整個服務，可能中斷正在執行的工作。`start` 現已支持 `--json`。[命令與停止結果](../reference/server.md#lifecycle-commands)。

## 查找科研記錄與官方數據文件 {/* #data */}

新增 Europe PMC 檢索、研究數據集訪問與公開文件列表、ChEA3、bioDBnet 和 CTD 入口；HGNC、Cellosaurus、openFDA 也補充了查詢或文件發現操作。目錄現有 **48 個內建 Connector、418 項操作**：其中 47 個資料來源 Connector 提供 416 項操作，1 個離線 Molecule Connector 提供 2 項操作。取得文件鏈接不等於已經下載數據，也不代表獲得受限數據集權限。[數據來源與連接步驟](../tools/databases.md#scientific-file-discovery)。

## 更新與日常使用修復 {/* #fixes */}

- 手動更新入口提供安裝說明，並可定位已經確認的下載包。[手動安裝](../guides/installation.md#manual-update)
- **Full access** 對公開網絡目標不再逐項彈出授權卡片；降低模式會關閉已有連接。全局授權會立即顯示在 Network 設置中。[網絡權限](../guides/network.md#network-mode-changes)
- Windows Notebook 安裝 Bioconductor 包時支持明確選擇 BiocManager 路徑。[Windows Bioconductor 包](../guides/runtimes.md#windows-bioconductor)
- DOCX 輸出改進了模板佈局、表格、邊框和分頁的保留。[Word 輸出](../guides/previews.md#docx-templates)

其他修復涉及 OpenCode 2.x 兼容、macOS Notebook 的外部 Node 查找、Windows 配置網絡保護期間的對話啓動、讀取應用管理的 Skill 參考資料、會話滾動位置及表格滾動條。About 中也增加了安全政策入口。[上一版本：v1.0.4](v1.0.4.md)。
