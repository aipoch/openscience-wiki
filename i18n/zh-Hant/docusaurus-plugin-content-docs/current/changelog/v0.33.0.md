# 更新日誌 · v0.33.0

釋出於 2026 年 9 月 23 日。本版加入智慧文獻篩選、按代理管理資源訪問，以及研究包內的 RO-Crate 後設資料。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.33.0) · [與 v0.32.0 的差異](https://github.com/aipoch/open-science/compare/v0.32.0...v0.33.0)

## 按明確標準篩選文獻 {/* #按明确标准筛选文献 */}

**Smart collection** 根據納入和排除標準評估文獻庫記錄。先限定範圍，再檢視四種判斷檢視，複核模型決定後使用閱讀集。試執行會儲存結果，實時草稿預覽不會儲存；全文證據和自動更新分別控制。

新增[智慧篩選實操](../workflows/screen-literature.md)，覆蓋檢索、模型繫結、規則、試執行、人工複核和匯出。[分類模型設定](../guides/models.md#smart-collection-model)區分 **Smart collections** 與 **Automatic capability selection**，主會話可以繼續使用 Codex。

## 資源訪問與研究交接 {/* #资源访问与研究交接 */}

- Skill 或 Connector 的 **Manage access** 集中顯示 Main Agent 和 Specialist 關聯。角色啟用、憑證和操作批准仍分別管理，見[資源訪問](../guides/connectors.md#resource-access)。
- 新匯出的 `.science` 研究包包含 RO-Crate 1.1 後設資料，接收方須使用支援 `ro-crate` 能力的讀取器；舊研究包仍可讀取，見[研究包相容性](../guides/research-packages.md#package-compatibility)。
- 會話中的 **Export diagnostics…** 按所選來源生成本地歸檔，不上傳，也不傳送給模型，見[診斷匯出](../guides/troubleshooting.md#session-diagnostics)。

## 新增資料庫操作 {/* #新增数据库操作 */}

| 資源 | 新能力 | 範圍 |
| --- | --- | --- |
| Zenodo | 檢索公開記錄，檢視版本級後設資料和檔案清單 | 不上傳或下載檔案；公開後設資料不表示檔案開放訪問 |
| GDC | 列出癌症專案與病例，檢索檔案、檢視後設資料並生成清單 | 受控資料仍需相應授權 |
| Genes & Ontologies | UniProt 批次識別符號對映：提交、查詢狀態、分頁取結果 | 保留全部頁面、一對多匹配及明確的未匹配 ID |

共有 **26 個內建 Connector、263 個操作**：其中 **25 個資料來源 Connector、261 個操作**，另有兩個離線 Molecule 操作。按[科學資料庫目錄](../tools/databases.md)選擇服務，在 [v0.33.0 操作參考](../reference/connector-operations.md)查準確引數。本版也修正了小鼠基因組的 UCSC 保守性預設軌道。

## 模型、執行時與平臺修復 {/* #模型运行时与平台修复 */}

服務商目錄加入 MiMo v2.6、Grok 4.7，並更新 Zen/Go，見[模型服務商選擇](../guides/providers.md#provider-catalog-updates)。**Claude Agent** 會在就緒檢查中提示不受支援的 CLI 版本；v0.33.0 要求 **2.1.118 或更高版本**，見[安裝代理](../guides/frameworks.md)。

其他修復涉及流式響應與長會話、殘留執行狀態恢復、研究包憑證檢查、Notebook 長命令進度、安裝軟體包時的資料夾授權、可關閉的 Notebook 提示、Windows R 清單與重置處理、Fedora 啟動打包，以及搜尋和 PDF 互動。完整內容見官方釋出說明，上一版為 [v0.32.0](./v0.32.0.md)。
