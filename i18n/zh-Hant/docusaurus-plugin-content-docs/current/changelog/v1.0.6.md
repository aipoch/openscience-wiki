# 更新日誌 · v1.0.6

發佈於 **2026-10-30 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.6)。

## 把 Zotero 文獻庫帶過來 {/* #zotero */}

可以從同一臺電腦上運行的 Zotero 10 或更高版本導入個人文獻庫或選定集合。先預覽條目，再導入元數據、本地 PDF、標籤和集合層級；複用已有記錄前，需要覈對匹配結果。這是一次導入，不是雙向同步。[Zotero 導入教程](../guides/library.md#zotero-import)。

文獻庫的普通搜索現在也能找到個人筆記中的文字。顯示 **Notes** 列，記下爲什麼要讀這篇論文，之後通過 **Search references** 找回來。[按個人筆記檢索](../guides/library.md#personal-note-search)。

## 閱讀 PDF，不用再設置讀取順序 {/* #pdf */}

關聯 PDF 改用自動文本讀取順序，優先使用完整的邏輯標籤，再根據可用文本和版面回退。持久化的手動讀取順序控件已移除，帶有舊區域設置的歷史消息也按新規則讀取。引用複雜版面中的段落前，仍需對照原文。翻譯後的 PDF 打開更快，DOCX 工具欄在滾動時也會保持在文檔上方。[PDF 讀取順序](../guides/previews.md#automatic-pdf-reading-order)。

## 更新後繼續工作 {/* #reliability */}

- Windows 安裝減少了包內文件並使用並行解壓；更新時保留應用目錄旁的研究數據，也修復了深層安裝路徑的問題。[Windows 更新檢查](../guides/installation.md#windows-update-data)。
- 生成文件的發佈權限覆蓋整個尚未結束的助手回合，長任務不再因爲原先的兩小時期限而失去發佈權限。
- 自定義本地 Connector 使用 **npx** 或 **npm** 時，如果系統找不到對應命令，可以使用隨應用提供的運行時；已安裝的命令仍然優先。[本地命令](../guides/connectors.md#bundled-npm)。
- Slurm 會先保存任務終態，再收集日誌；隊列、控制器和記賬信息分別處理，取消操作只返回一次最終結果。[任務狀態與結果收集](../guides/remote-compute.md#slurm-outcome-recovery)。
- 系統憑據的交互授權最多等待五分鐘，超時會顯示專門的恢復提示。[啓動授權](../tools/credentials.md#system-authorization)。

其他修復涉及 OpenCode 工具調用和 Windows 啓動限制、Windows Cookie 存儲啓動檢查、含空格臨時路徑中的 R 執行、會話同步、停止準備後恢復草稿，以及導入會話的錯誤歷史。分體按鈕菜單也統一了佈局。WSL 指南明確：鏡像網絡要求 **Windows 11 22H2 或更高版本**。[WSL2 設置](../guides/runtimes.md#wsl2-preview)。

內置 Connector 目錄沒有新增：仍爲 **48 個 Connector、418 項操作**，其中 47 個數據源 Connector 提供 416 項操作，另有 1 個離線 Molecule Connector 提供 2 項操作。[支持的數據源](../tools/databases.md#supported-databases) · [上一版：v1.0.5](v1.0.5.md)。
