# 更新日誌 · v0.31.1 {/* #更新日志--v0311 */}

釋出於 2026 年 9 月 20 日。新增資料庫操作覆蓋測序執行、基因集富集和參考基因組身份核對；分類模型為可選設定。

[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.31.1) · [相對 v0.31.0 的變更](https://github.com/aipoch/open-science/compare/v0.31.0...v0.31.1)

## 新增資料庫操作 {/* #新增数据库操作 */}

| 能力 | 從哪裡開始 |
| --- | --- |
| ENA 測序執行與 FASTQ 清單 | 解析 ENA/INSDC 登入號，檢查截斷標誌，再查詢檔案地址、大小與上游校驗值。工具本身不下載或校驗檔案。[測序資料](../tools/databases.md#ena-runs) |
| g:Profiler 富集 | 核對物種和資料來源版本，指定基因集與背景，再檢查對映及校正結果。[帶結果檔案的實操案例](../tools/databases.md#gene-set-enrichment) |
| NCBI 參考基因組 | 消除物種歧義，核對帶版本的組裝，並在合併來源前轉換序列別名。[參考身份](../tools/databases.md#reference-genome) |

[操作參考](../reference/connector-operations.md)與下載登錄檔已更新到 v0.31.1：仍為 24 個 Connector，包含 **244 個資料來源操作**及兩個 Molecule 操作。

## 設定與恢復 {/* #设置与恢复 */}

[分類模型](../guides/models.md#classification-models)位於 **Settings → Model** 內的標籤頁。配置相容服務後，可輔助受支援主會話的能力選擇；不配置也可使用 **Use default method**。新增分類服務不會替換 Main。

[遠端配對](../guides/remote-access.md#pairing-v0311)將待處理請求放到受信瀏覽器列表上方，並顯示到期倒計時。接受前核對螢幕程式碼；撤銷當前瀏覽器會移除它自己的訪問權限。

網路保護阻止 R 執行時，[內聯提示](../guides/network.md#r-network-warning)會說明單元格未執行，並連結到相關設定。修改設定不等於已經重跑成功。

## 修復與驗證範圍 {/* #修复与验证范围 */}

修復涉及 Windows 常駐核心與包列表、會話恢復、審批卡片焦點、PDF 圖表提取、GTEx 分頁、Open Targets 部分錯誤及 hg19 保守性預設軌道。

Wiki 已在 v0.31.1 實跑本地 Fork 繼續計算和兩個 g:Profiler 操作，並檢查分類模型表單。本輪未驗證付費分類服務、重跑 Windows 測試或配對遠端瀏覽器；這些變化依據對應版本原始碼和釋出說明編寫。上一版為 [v0.31.0](./v0.31.0.md)。
