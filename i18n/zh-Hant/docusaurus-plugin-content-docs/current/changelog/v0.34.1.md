# 更新日誌 · v0.34.1 {/* #更新日志--v0341 */}

釋出於 **2026-10-01（UTC；北京時間同日）**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.34.1)。

## 科學資料庫擴充套件 {/* #科学数据库扩展 */}

本版新增 **26 個操作**，完整目錄達到 **31 個 Connector、326 個操作**；其中 30 個資料來源家族提供 324 個操作，另有離線 Molecule 的兩個操作。

| 入口 | 新增能力 |
| --- | --- |
| CELLxGENE Discover | 發現公開單細胞集合和資料集，檢查釋出版本，獲取檔案清單 |
| Alliance Genome Resources | 人類與模式生物基因、直系同源、疾病模型、表型、等位基因及表達 |
| Variants → MaveDB | 變異效應分數集、CSV 分數、已有 VRS 對映和實驗資訊 |
| Omics Archives → Metabolomics Workbench | 研究樣本、實驗因素、分析、代謝物註釋和化合物交叉引用 |

見[能力與連線方式](../tools/databases.md#single-cell-model-organisms)及[操作引數](../reference/connector-operations.md)。返回檔案 URL 不代表已下載，實驗特定的功能分數也不是臨床分類。

## 在工作區稽核 Inbox {/* #在工作区审核-inbox */}

緊湊 **Library** 預覽新增 **Inbox**，支援搜尋、分頁、逐條 **Accept / Dismiss**、忽略後的 **Undo**，以及當前頁的明確批次選擇。儲存文獻卡片的 **Open Inbox** 會在會話旁開啟佇列。佇列包含所有專案的候選，接受記錄不會自動獲取缺失全文。見[工作區 Inbox 操作](../guides/library.md#workspace-inbox)。

期刊匯入補充列角色和欄位對映提示，並改進別名匹配、篩選和重試。見[期刊資料集](../guides/journal-datasets.md#import-columns)。

## 研究包與診斷匯出 {/* #研究包与诊断导出 */}

- 空白 **New conversation** 頁增加 **Import previous research**，可選擇或拖入 `.science` 研究包，見[匯入步驟](../guides/research-packages.md#import-and-inspect-a-package)。
- 敏感內容檢查後可明確確認 **Export anyway**。標記內容會原樣包含，不會脫敏；分享前需檢查，見[敏感內容匯出](../guides/research-packages.md#sensitive-export)。
- 本地診斷匯出保留更多錯誤與執行證據。它與研究包用途不同，分享前仍需檢查，見[會話診斷](../guides/troubleshooting.md#session-diagnostics)。

## 模型與工作區操作 {/* #模型与工作区操作 */}

Codex 目錄新增 **gpt-6.1-sol**，不改變已儲存的預設選擇。實際訪問取決於賬號及當前執行時，見[模型選擇](../guides/providers.md#catalog-models)。

Plan 反饋沿用已配置的傳送快捷鍵；輸入區更清楚地顯示 Compute Host 狀態；執行預覽可跳到對應訊息；Skill 編輯增加未儲存草稿保護。

## 修復 {/* #修复 */}

Notebook 修復跨單元狀態、共享沙箱工具及執行來源記錄；PDF 提取改進原生圖表內容保留和 worker 處理。其他修復涉及文獻 URL、註釋選區清理、表格固定、恢復後的後續執行權限、Windows 重灌路徑、Linux 憑據儲存與憑據身份處理。
