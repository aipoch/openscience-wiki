# 更新日誌 · v0.33.1 {/* #更新日志--v0331 */}

釋出於 **2026 年 9 月 24 日**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.33.1)。

## 文獻篩選與 PDF 閱讀 {/* #文献筛选与-pdf-阅读 */}

智慧集合新增實時 **Screening process**，可暫停、繼續，並跳轉到範圍對應的專案或集合。續跑要求儲存的執行仍與規則、文獻相容，人工決定仍決定最終成員。見[篩選與複核文獻](../workflows/screen-literature.md)。

PDF 證據可隨工作區第一條訊息傳送。在 Library 開啟 PDF，選擇 **Read with agent** 和專案，傳送問題前檢查 Reading 中的檔案。見 [PDF 上下文](../guides/previews.md#first-message-pdf)。

## 科學資料庫 Connector {/* #科学数据库-connector */}

- **HMMER** 新增按程式選擇的蛋白序列／profile／比對檢索、任務狀態與完整結果。
- **InterProScan** 查詢已有註釋任務並獲取 TSV，不支援提交任務。
- **Genomes** 新增 Clustal Omega，輸入至少三條 FASTA，見[多序列比對工作流](../workflows/multiple-sequence-alignment.md)。
- **OpenAlex** 在應用中不再強制要求金鑰，服務方限額仍適用，見[可選憑據配置](../tools/credentials.md)。

完整登錄檔現有 **28 個 Connector、271 個操作**，其中包括離線 Molecule Connector。[資料庫能力](../tools/databases.md) · [操作參考](../reference/connector-operations.md)。

## 設定、診斷與修復 {/* #设置诊断与修复 */}

提供商目錄新增 GPT-6 和 Claude Opus 5.5，能否使用仍取決於賬戶權限和框架相容性，見[模型提供商](../guides/providers.md#catalog-models)。

會話診斷區分研究包匯出觸發的脫敏掃描證據和原始檔案。原始敏感檔案預設不勾選，僅主動選擇後包含，匯出儲存在本地，見[診斷匯出](../guides/troubleshooting.md#session-diagnostics)。

設定頁頭與區域性搜尋使用不同快捷鍵；升級會保留歷史資料位置。其他修復包括 Windows 託管 Python 發現、R 訪問被拒絕提示、執行環境與計算設定儲存競爭、ACP 影象能力變化、首次傳送的 PDF 標識、重複傳送，以及影象裁剪和修訂流程。[快捷鍵](../guides/shortcuts.md#local-settings-search) · [儲存位置](../guides/storage.md#historical-data-location)。
