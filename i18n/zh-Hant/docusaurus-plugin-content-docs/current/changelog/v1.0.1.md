# 更新日誌 · v1.0.1

發佈於 **2026-10-20 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.0.1)。

## 將研究包導入應用 {/* #packages */}

支持該功能的網站可以把 `.science` 研究包傳給同一臺電腦上的桌面應用。允許瀏覽器打開 Open-Science，傳輸期間保持網頁打開，再到應用中檢查研究包並選擇導入位置。應用接收到文件，不等於最終批准導入。本地研究包也可拖到項目首頁。操作見[網頁導入](../guides/research-packages.md#browser-import)。

## 跟進更新和等待中的會話 {/* #interaction */}

更新對話框集中顯示下載、發佈說明及安裝準備狀態。Windows 安裝交接和啓動得到修復；是否能安裝仍取決於安裝通道。按[更新進度說明](../guides/installation.md#update-progress)操作，重新啓動後確認實際版本。

需要回答或批准的會話，會在首頁、側欄和會話中持續顯示等待狀態。重新打開待處理卡片即可繼續。側欄會話支持雙擊打開編輯器。詳見[等待輸入](../guides/sessions.md#waiting-for-input)。

## 使用數據源與憑據 {/* #sources */}

- PDC 新增公開病例人口學、診斷信息，支持選擇研究版本和保留外部引用。不同來源的 ID 不可混用。見 [PDC 臨牀字段](../reference/connector-operations.md#pdc_list_clinical)。
- 兩個 MiniMax 區域均提供 M3.1 Flash；消息附圖也可參與 Skill 選擇。見[模型選擇](../guides/providers.md#catalog-models)。
- OAuth 憑據綁定到簽發它的授權服務器；必要時按[重新授權](../guides/connectors.md#oauth-reconnect)操作。
- PDF 搜索會提示覆蓋不完整；雙欄閱讀、翻譯佈局、文獻狀態及 Notebook 恢復得到修復。見[檢查 PDF 覆蓋範圍](../guides/previews.md#pdf-search-coverage)。

本版重新提供桌面安裝包與獨立 CLI 壓縮包，包括 Linux CLI 安裝包。安裝方法見[當前指南](../guides/installation.md)。[上一版本：v1.0.0](v1.0.0.md)。
