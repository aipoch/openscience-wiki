# 更新日誌 · v0.36.0 {/* #更新日志--v0360 */}

釋出於 **2026-10-08 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.36.0)。

## PDF 全文翻譯 {/* #pdf-全文翻译 */}

全文翻譯新增逐段儲存進度、繼續翻譯和原文／譯文對照。同一受管理 PDF 可在不同閱讀入口複用已儲存譯本。獨立的 [PDF 全文翻譯教程](../guides/pdf-translation.md) 介紹全文準備、模型要求、術語表、繼續翻譯和匯出。v0.36.0 的這項翻譯操作不支援 Codex 訂閱模型。

## Notebook 執行前審查 {/* #notebook-执行前审查 */}

Agent 提交的 Notebook 程式碼會在執行前檢查。存在風險或無法充分判斷的操作，會顯示包含相關原始碼行和明確決策按鈕的審查卡片；受支援的普通讀取與分析無需額外風險批准。它與 Reviewer 對已完成結果的檢查不同，見[執行前審查](../guides/notebook.md#execution-review)。

## 科學資料庫 {/* #科学数据库 */}

新增六個操作，登錄檔達到 **35 個 Connector、349 個操作**：34 個資料來源家族提供 347 個操作，另有兩個離線 Molecule 操作。

| 入口 | 能力 | 說明 |
| --- | --- | --- |
| PDC | 癌症蛋白組研究版本、生物樣本關聯和定量檔案後設資料 | [PDC 連線與範圍](../tools/databases.md#pdc) |
| Genomes → Ensembl | 指定人群中的兩變異 LD 與鄰近代理變異 | [LD 查詢](../tools/databases.md#ensembl-ld) |

精確欄位見[操作參考](../reference/connector-operations.md)。PDC 檢索不會下載資料；高 LD 不代表因果關係。

## 日常操作變化 {/* #日常操作变化 */}

- Library 與 Inbox 新增已載入頁面的全選控制元件。執行批次操作前核對已選數量；它不會選中服務端全部匹配記錄，見[批次選擇](../guides/library.md#loaded-page-selection)。
- 將檔案卡片或已開啟的產物拖入 Composer，可插入檔案引用。傳送前檢查草稿，見[檔案引用](../guides/composer.md#drag-file-mention)。
- 官方 Anthropic 目錄加入 Claude Haiku 5.5；模型目錄移除了可能導致選擇失敗的上下文大小別名。應選擇當前可用模型，不要照抄舊識別符號。更新不會自動替換已儲存的 Main 模型。

## 閱讀與可靠性修復 {/* #阅读与可靠性修复 */}

PDF 提取改進複雜表格、多級表頭、頁尾和多面板佈局。科學解釋依賴版式時，仍需回看原文，見 [PDF 提取](../guides/previews.md#pdf-extraction)。

Notebook 改進 Python／R 讀取器、容器變換和回撥中的依賴記錄。這有助於保留來源關係，但不代替[重新執行驗證](../guides/reproducibility.md)。其他修復涉及新會話 Files 面板的引用、空工作區查詢、緊湊引用標籤，以及 Remote Web 中的 Specialist Marketplace。
