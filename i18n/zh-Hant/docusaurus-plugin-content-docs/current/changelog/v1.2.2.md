# 更新日誌 · v1.2.2 {/* #更新日志--v122 */}

發佈於 **2026-11-18 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.2.2)。

## 爲 Notebook 選擇更嚴格的網絡規則 {/* #strict-network */}

**Settings → Network → Manage access** 新增 **Relaxed** 和 **Strict** 模式。Strict 只允許手動白名單中匹配協議、域名或 IP、端口的請求；未匹配的請求直接阻止，不再彈出授權。Relaxed 仍爲默認模式。規則可以分組，Built-in 和 Manual 標記表示規則來源。[網絡設置步驟](../guides/network.md#public-network-rules)。

## 從中斷處繼續生成研究影片 {/* #film-checkpoints */}

影片生成會保留已驗證的場景、旁白和時間安排，應用進程重啓後也能繼續利用這些內容。可以從檢查點恢復，也可以明確選擇重新生成；進度界面會顯示當前階段。[恢復步驟](../guides/research-films.md#film-recovery)。

## 閱讀 PDF 與恢復本地工作 {/* #recovery */}

- 原生 PDF 提取改進了圖形、圖注、表格內容和閱讀順序的保留。使用提取結果或翻譯版面時，仍應與原 PDF 對照。[PDF 提取](../guides/previews.md#pdf-extraction)。
- Windows 在保存受保護文件夾授權前檢查訪問權限，並改進更新、卸載恢復與診斷信息保留。
- `.science` 導入區分取消、無效研究包和超時。超時導致結果未確認時，先檢查會話是否已導入，再決定是否重試。[導入研究包](../guides/research-packages.md)。
- 本地服務斷開時，工作區顯示恢復狀態，並保留輸入框草稿。
- 百鍊 Token Plan 加入 **Qwen4 Max Preview**，提供對應區域的目錄選項；實際可用性取決於賬戶。[提供商設置](../guides/providers.md#provider-regions)。

參見[安裝與更新](../guides/installation.md)和 [v1.2.1](v1.2.1.md)。
