# 更新日誌 · v1.2.1

發佈於 **2026-11-11 UTC**。[官方發佈說明](https://github.com/aipoch/open-science/releases/tag/v1.2.1)。

## 在同一個入口找到研究資源 {/* #resource-center */}

**Resource center** 集中管理 Skills、Connectors 和 Specialists，提供已安裝資源與市場視圖、搜索、篩選和詳情抽屜。Web 工作區也能從市場安裝資源。從問題草稿或已發送消息打開 Skill 引用時，詳情顯示在項目面板中，當前會話保持原位。[資源導航](../guides/navigation.md#resource-center) · [Skill 市場](../skills/marketplace.md)。

## 發送前，把問題說得更清楚 {/* #prompt-optimization */}

在項目輸入框中使用 **Optimize question**，由已配置的模型改寫草稿。檢查結果後可以繼續編輯，或通過 **Undo optimization** 恢復原文，再自行發送。項目設置可保存自定義 **Optimization prompt**。只有主動點擊纔會調用模型，不會自動發送研究問題。[優化問題](../guides/composer.md#optimize-question)。

## 內置 Agent 也能使用 Codex 訂閱 {/* #codex */}

**Open-Science Agent** 現在支持 Main 和 Subagent 使用導入的或應用內登錄的 Codex 訂閱賬戶，沿用現有登錄與憑據恢復入口。內置 Agent 同時改進輸出長度上限和上下文用量計算。Anthropic 模型目錄新增支持 1M 上下文的 **Claude Fable 5.2**；實際可用性仍取決於提供方與賬戶權限。[Agent 配置](../guides/frameworks.md#built-in-agent)。

## 把文獻元數據導出爲表格 {/* #csv */}

**Export → CSV** 可導出選中文獻、整個項目或集合，使用 16 個固定英文列名。支持跨頁選擇並排除個別條目，缺失字段保持爲空。此導出不包含 PDF、篩選結論或個人筆記。[CSV 導出步驟](../guides/library.md#bibliography-csv)。

## 更順暢地處理長會話 {/* #reliability */}

- Notebook 與 Compute 證據按內容去重並校驗摘要，減少長會話 `.science` 導出中的重複數據；首次導出也會整理舊證據。[研究包](../guides/research-packages.md#compact-evidence)。
- Modal 與 Hugging Face 在瀏覽器登錄前準備兼容的 Python 運行環境，賬戶檢查使用系統代理。[雲賬戶連接](../guides/remote-compute.md#cloud-account-runtime)。
- 切換會話後，研究影片繼續生成。[研究影片](../guides/research-films.md#generate-film)。
- 打開手機配對面板不會自行開啓訪問，需主動選擇 **WiFi** 或 **Internet**。[移動設備連接](../guides/remote-access.md#mobile-pairing)。
- 修復聊天中的 Notebook 附件和本地文件鏈接預覽，改進 PDF 恢復、翻譯隔離、文獻標識符處理與窄屏來源預覽。
- 會話無活動 15 分鐘後回收閒置解釋器；Windows 更新恢復更明確地定位佔用文件和進程，Linux 恢復不再把已確認的內核線程誤判爲殘留 Notebook 進程。

另見[安裝與更新](../guides/installation.md)和 [v1.2.0](v1.2.0.md)。
