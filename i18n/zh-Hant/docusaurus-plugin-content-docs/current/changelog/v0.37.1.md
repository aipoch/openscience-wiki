# 更新日誌 · v0.37.1 {/* #更新日志--v0371 */}

釋出於 **2026-10-12 UTC**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.37.1).

## 保留科學 PDF 的結構 {/* #保留科学-pdf-的结构 */}

影象提取更完整地保留圖注、圖例與多面板圖。公式旁的線框表格保留分組表頭、行結構及單元格來源引用，圖注、圖形和文字也更準確地歸屬於原文中的對應元素。

使用 [Figures & Tables](../guides/previews.md#pdf-extraction) 時，引用前對照原始頁面檢查完整面板、圖例、表頭、單位與腳註。翻譯 PDF 重新生成時，也能識別嵌入字型中合理的字形名稱差異並保留原文字形；檢查方法見[對照與匯出](../guides/pdf-translation.md#compare-export)。

## Windows 與安裝 {/* #windows-与安装 */}

- 桌面 CLI 支援包含中文等非 ASCII 字元的安裝路徑，保留呼叫終端的內碼表與退出碼。舊啟動器誤讀路徑時，更新應用並重新開啟終端，見 [CLI 設定](../reference/cli.md#terminal-setup)。
- 本地 PDF 翻譯正確處理 Windows 磁碟機代號路徑。
- Notebook 核心、環境指紋、軟體包清單與鎖定資訊採集不再額外閃現控制檯視窗。
- 桌面與獨立執行包移除重複依賴和未使用資源，減小 v0.37.0 後端拆分帶來的下載體積增長。

[v0.37.0](v0.37.0.md) 引入的獨立 CLI 與 Node 後端繼續適用。選擇與平臺匹配的壓縮包，並保留解壓後的執行目錄結構。
