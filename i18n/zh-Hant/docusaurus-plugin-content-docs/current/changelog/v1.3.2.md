# 更新日誌 · v1.3.2 {/* #更新日志--v132 */}

釋出於 **2026 年 11 月 20 日（UTC）**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v1.3.2)。

## 更多模型接入選擇 {/* #models */}

在 **Model provider** 點 **Skip**，會新增不帶 API key 的 Kilo Gateway，並繼續到 Notebook runtime。完成後，**Main model** 可能顯示 `kilo-auto/free`。傳送第一則訊息前，開啟 **Settings → Model**，檢查實際選中的提供商與模型；如果打算使用 Codex 訂閱，就切換到對應連線。Skip 不會驗證模型能否完成請求。 升級會保留已有憑據和 Main 模型選擇。 [Kilo Gateway](../guides/providers.md#kilo).

OpenAI、MiniMax、百鍊和火山方舟影象服務可在儲存前重新整理支援的影象模型目錄。重新整理會攜帶該連線的憑據訪問所配置的提供商；目錄中有模型與實際生成成功是兩項不同的檢查。見[影象模型目錄](../guides/image-generation.md#image-model-catalog)。

## 研究會話更流暢 {/* #sessions */}

長會話佔用更少記憶體；不再檢視且已安全儲存的會話正文可以釋放，草稿和活動任務仍保留。回放中已完成步驟的提問與捕獲按鈕在懸停或鍵盤聚焦時顯示，觸屏裝置保留可操作的入口。

Notebook 記憶體壓力通知可關閉，並在六秒後消失。通知消失不代表被阻止的操作已經執行；檢查任務狀態，再決定是否重試。見 [Notebook 記憶體管理](../guides/notebook.md#memory-resources)。

## 影響日常操作的修復 {/* #fixes */}

- 修復內建 Agent、Claude Agent 和 Codex 新會話在特定 Notebook 準備過程中、首次模型請求前失敗的問題；定時會話按預定提示詞啟動。
- PDF 翻譯按閱讀順序重組換行的標題、圖注和數學陳述，並保留原生公式、連結與圖形。見[翻譯版式檢查](../guides/pdf-translation.md#scientific-layout)。
- 首頁案例下載錯誤區分包缺失、超時、校驗失敗和儲存問題。見[案例匯入恢復](../guides/research-packages.md#case-download-recovery)。
- Windows 修復涉及 WSL Notebook 啟動和 Reviewer 連線。

見[安裝與更新](../guides/installation.md)及 [v1.3.1](v1.3.1.md)。
