# 更新日誌 · v0.33.3 {/* #更新日志--v0333 */}

釋出於 **2026-09-26**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.33.3).

## 閱讀檔案和管理文獻 {/* #阅读文件和管理文献 */}

Office 檔案支援分頁閱讀與搜尋，PowerPoint 提供逐頁導航。沿用已有 QC 檔案，檢視[檔案預覽教程](../guides/previews.md)。

工作區 **Library** 增加緊湊預覽，可按當前專案或全部文獻查詢記錄並檢視摘要。智慧集合增加 **Abandon run**：保留已完成結果，結束這次執行且不再恢復。Crossref 後設資料補全支援匯入來源摘要。見[文獻庫](../guides/library.md)和[篩選工作流](../workflows/screen-literature.md)。

## 新增科學資料庫操作 {/* #新增科学数据库操作 */}

**Genes & Ontologies** 加入 Enrichr 庫發現與富集查詢；**Clinical Genomics** 加入 ClinPGx 藥物、基因、變異、指南、標籤及族群頻率查詢。完整目錄現有 **28 個 Connector、284 個操作**，其中資料來源為 27 個、282 個操作，其餘兩個屬於離線 Molecule。見[資料庫能力](../tools/databases.md)和[操作參考](../reference/connector-operations.md)。

## 研究包、外觀和安裝 {/* #研究包外观和安装 */}

研究包傳輸增加自動調整或固定的磁碟活動上限，後臺執行仍可檢視進度。桌面介面縮放快捷鍵與設定統一為 90%、100%、110%、125%。Windows 簽名覆蓋到隨應用分發的可執行檔案。見[研究包傳輸](../guides/research-packages.md#transfer-settings)、[介面縮放](../guides/appearance.md#interface-scale)及[安裝說明](../guides/installation.md)。

## 修復 {/* #修复 */}

修復 PDF 閱讀標籤字型、Notebook 核心恢復隔離、已授權資料夾的原生訪問、可恢復的重試提示及錯誤提示關閉。歸檔恢復提示限定到受影響專案；分類模型選擇器的初始選擇、診斷歸檔字尾、Skill 後設資料、託管 Python 以及研究包中的用量記錄也得到修正。
