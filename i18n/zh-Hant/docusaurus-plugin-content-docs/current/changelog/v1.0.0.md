## 升級到 1.0 {/* #upgrade */}

1.0 將現有科研工作區納入穩定版本線，繼續支援歷史配置升級與 `.science` 匯入；版本號變化不要求新建配置或更換資料格式。先備份配置和科研資料、結束活動任務，再使用官方桌面安裝器升級。降級程式不會撤銷資料變化。

本次僅釋出**桌面安裝包**，不含獨立 CLI 歸檔和 Linux CLI `.deb`／`.rpm`；網站下載和自動更新通道單獨釋出。需要 1.0 命令列入口時使用桌面附帶的啟動器，不要重新命名舊歸檔，也不要推斷 Homebrew／npm 已提供同版本。`open-science update` 已移除，改用桌面控制元件或原安裝器／包管理器。見[安裝與 1.x 相容範圍](../guides/installation.md#version-compatibility)。

## 繼續中斷的工作 {/* #recovery */}

原桌面控制連線斷開後，相容桌面可以接管仍存活的桌面後端；CLI 啟動的服務仍保持獨立。關閉準備失敗時保留視窗，重連會先恢復原會話狀態，再允許繼續操作。響應丟失時先檢查已儲存操作，避免重複提交。見[服務歸屬與恢復](../reference/server.md#desktop-service-recovery)。

ACP 會話按選中的代理繼續；切換 Specialist 後，Codex 脫離會話的恢復也得到修復。傳送下一條訊息前，[檢查所選代理與原會話](../guides/sessions.md#resume-selected-agent)。本版同時修復文獻選擇狀態和上下文壓縮期間的取消處理。

## 回答問題與閱讀 PDF {/* #interaction */}

- 澄清卡片支援更長的選項列表和多選。前後檢查回答，最後點 **Finish**；僅選中選項仍是草稿。見[回答澄清問題](../guides/composer.md#clarification-questions)。
- PDF 筆記按鈕在懸停、聚焦或選中標記時出現，減少閱讀遮擋。見[按需顯示筆記入口](../guides/pdf-notes.md#reveal-note)。
- PDF 提取和翻譯進一步保留複雜排版、原生表格與圖片歸屬、科學分式。**New translation** 會重新準備源文字，複用前仍需對照原文。見[提取核對](../guides/previews.md#scientific-structure-check)與[全文翻譯](../guides/pdf-translation.md#scientific-layout)。

## 保留科學資料的背景 {/* #data-context */}

| 來源 | 變化 |
| --- | --- |
| ArrayExpress | 區分 SDRF 關係行與去重後的樣本標識，標識不完整時樣本計數可為未知 |
| MetaboLights | 保留樣本表重名列及原始順序，避免覆蓋值 |
| Bgee | 保留解剖結構與細胞型別，缺失細胞型別仍為 `null` |
| dbSNP | 保留同一定位結果關聯的全部染色體／組裝資訊 |
| OpenAlex | 按會話記住已拒絕的憑據提示 |

複用舊查詢前，檢視[欄位解讀說明](../tools/databases.md#scientific-context)與 [v1.0.0 Connector 參考](../reference/connector-operations.md)。Notebook 風險分析也改進了 Promise 回撥的處理；原有批准要求仍然適用。

## 1.0 沒有改變的範圍 {/* #scope */}

錄製的會話回放不執行程式碼。產物驗證需要符合條件的輸入記錄與可用環境，不代表科學結論已成立，也不保證整個會話確定性復現。匯入的 `.science` 仍為只讀，繼續編輯需 Fork；包不會恢復憑據、Side Chat 或私人書籤。遠端計算繼續支援 SSH／Slurm；託管雲 GPU 提交、本地 GPU 後端和多人實時編輯不在本版範圍內。
