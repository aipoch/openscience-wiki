# 更新日誌 · v0.33.2 {/* #更新日志--v0332 */}

釋出於 **2026-09-24**。[官方釋出說明](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## 安裝與文獻閱讀 {/* #安装与文献阅读 */}

官方 Windows 安裝程式加入程式碼簽名；應用下載入口指向官方下載頁及校驗說明。見[安裝與更新](../guides/installation.md)。來源網頁預覽保留登入會話等站點狀態，再次訪問及重啟應用後可繼續使用。見[來源網頁預覽](../guides/previews.md#persistent-source-preview)。

**Auto** 模式減少內建文獻庫操作的重複批准提示，檔案、網路和資源規則仍然適用。見[文獻庫批准規則](../guides/approval-modes.md#library-auto)。

## STRING 互作富集 {/* #string-互作富集 */}

**Protein Annotation** 新增 STRING PPI enrichment，檢查一組蛋白的互作數量是否高於背景預期。它與通路富集是不同的統計問題。見[基因集富集工作流](../workflows/gene-set-enrichment.md#enrichr-string)及[引數參考](../reference/connector-operations.md#get_string_ppi_enrichment)。

## 改進與修復 {/* #改进与修复 */}

委派任務完成的結果在後續清理失敗時得以保留；更新 Figure Composer 流程、檔案預覽圖示及智慧集合佈局。另修復 macOS Notebook 清理狀態隔離、代理路由與退出處理，並關閉 Codex 後端的外掛和應用發現。
