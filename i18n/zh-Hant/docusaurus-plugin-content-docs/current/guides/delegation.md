# 任務委派與 Side Chat {/* #任务委派与-side-chat */}

想在當前任務旁討論一個問題，可以使用 Side Chat；需要另一個代理處理獨立任務，可以使用任務委派。如果要沿另一條思路繼續完整對話，使用[會話分支](sessions.md)。

## Side Chat {/* #side-chat-可用范围 */}

### 使用場景 {/* #使用场景 */}

閱讀分析結果時解釋一個術語、比較兩種分析思路，或先討論報告應如何表述，都可以開啟 Side Chat。討論後，再把選定的建議交給主對話 Main。

### 使用說明 {/* #使用说明 */}

1. 在已有會話中，開啟傳送按鈕旁的 **More send options → Side chat**。主輸入框為空時也可以開啟，新的 Side Chat 草稿會立即出現。在旁聊中填寫問題，核對模型與推理強度後傳送。
2. 在獨立的 **Side chat** 預覽標籤中閱讀回答，透過 **Side chat follow up** 繼續追問。同一會話下可以保留多個旁聊，在標籤之間切換，同時繼續使用 Main。
3. 如果希望主對話採用某條建議，明確要求旁聊轉交，例如：“把這條建議發給 Main：報告中單獨說明缺失值的處理方法。”隨後在 Main 檢查標為 **Side chat** 的訊息；如果 Main 空閒，傳送下一條請求讓它繼續處理。
4. 使用 **Cancel Side chat response** 停止當前回答。切換標籤或收起預覽區即可返回 Main；重啟應用後仍需要的資訊，應先轉交 Main 或儲存為報告。

含文字或批註的草稿會在切換檢視時保留。離開未填寫內容的空草稿時，它會自動清理；僅開啟草稿不會向模型傳送請求。

### 把批註移入需要的草稿 {/* #把批注移入需要的草稿 */}

對於選中的段落或區域，使用批註的 **Move to Side chat…**，選擇已有旁聊或新建旁聊。也可以在 Main 與 Side Chat 草稿之間拖動批註。傳送前檢查目標和轉移後的內容：移動批註只是準備草稿，不會提交請求。

私人 **For me** 書籤是另一種閱讀工具，參閱[閱讀書籤](bookmarks.md)。

### 注意點 {/* #注意点 */}

- **模型設定**：新建 Side Chat 繼承當前主會話的模型與推理強度。可以在旁聊中另行選擇，修改會用於它的下一次傳送；也支援 Codex 訂閱。傳送前檢查實際選擇。
- **轉交與執行**：普通回答不會自動傳送給 Main，也不能代替主對話的權限審批。轉交後檢查訊息是否送達，再讓 Main 執行需要的操作。
- **關閉標籤**：確認前閱讀 **Close Side chat?**。關閉會停止該旁聊並移除對話；選擇 **Cancel** 可保留。只是返回 Main 時，切換標籤或收起預覽區即可。清理失敗時，標籤會恢復並顯示錯誤。
- **重啟應用**：Side Chat 對話和尚未送達 Main 的建議只保留在本次應用執行中。重新載入介面或切換專案時，可重新連線這些記憶體中的狀態；完整重啟應用後清除。退出前，把有用建議轉交 Main 或儲存為報告。已經送達 Main 的訊息仍保留在主會話中。
- **可用條件**：從 v0.30.2 起，Main 正在執行或等待審批本身不會阻止旁聊。先在主會話傳送至少一條訊息；匯入的只讀會話或不可用的主會話不能開啟旁聊。旁聊不接收檔案附件。按按鈕的實際提示處理，連線問題見[故障排查](troubleshooting.md)。

## 任務委派 {/* #任务委派 */}

### 使用場景 {/* #使用场景-1 */}

當任務可以拆成獨立部分時，例如分別核對文獻來源、檢查資料檔案或審閱分析結果，可以讓其他代理處理，再由主代理彙總。需要複用具有固定職責的助手時，參閱[Specialist 委派](../specialists/delegate.md)。

### 使用說明 {/* #使用说明-1 */}

1. 在輸入框的 **Agent controls** 中檢查 **Delegation** 是否可用。
2. 在 **Settings → Model → Subagent** 中選擇繼承主模型，或配置相容的獨立模型與推理強度。
3. 在請求中說明要委派的任務、輸入檔案、期望輸出和驗收要求。
4. 在活動記錄中檢視子任務的執行狀態，處理出現的權限請求。
5. 開啟返回的檔案或來源連結，核對結果；需要檢視執行記錄時，在 Notebook 的 **Agent** 篩選中選擇對應執行者。

### 注意點 {/* #注意点-1 */}

- 可用能力取決於代理框架和配置。啟用 Delegation 後，仍需在活動記錄中確認子任務是否實際啟動。
- 子代理不一定共享主對話的全部上下文或 Python 變數，應提供完成任務所需的檔案和說明。
- 主任務的計劃批准不會自動批准子代理的所有操作；遇到權限請求時，核對具體動作和範圍。
- 若介面提供 **Release**，可用它結束或釋放子任務資源，主會話中的證據仍保留。
