# 私人閱讀書籤 {/* #私人阅读书签 */}

需要稍後重讀某個段落、核對一張表，或記下閱讀疑問時，可以儲存書籤。**For me** 在當前會話中儲存私人閱讀記錄；**To Agent** 則為請求準備批註。儲存書籤不會傳送訊息，也不會把它加入 Agent 上下文。

## 儲存段落或 PDF 區域 {/* #保存段落或-pdf-区域 */}

1. 開啟一個已儲存的會話，選中對話或支援的文字預覽中的文字。閱讀 PDF 時，可以選中文字，也可以使用區域選擇控制元件框選需要的部分。
2. 開啟選區的批註控制元件，選擇 **For me**。
3. 按需填寫 **Note (optional)**，例如“比較這些百分比前，先核對分母”，然後點選 **Bookmark**。
4. 開啟輸入框中的 **Bookmarks**，確認條目已儲存；點選該條目，檢查是否返回正確的段落或 PDF 區域。

會話儲存後才能使用書籤。如果控制元件不可用，先返回已有會話再試。並非所有嵌入式預覽或外部開啟的檢視器都支援選中文字建立書籤。

## 返回、修改或刪除 {/* #返回修改或删除 */}

開啟該會話的 **Bookmarks** 列表，點選條目或 **Show bookmark source**。對於應用管理的檔案，書籤會開啟它引用的儲存版本；與新結果比較時，核對頁碼、段落和版本。

在列表或段落旁的常駐標記中選擇 **Edit bookmark note**，修改備註後點選 **Save**。**Cancel** 保留原備註；**Delete bookmark** 只刪除閱讀書籤，不刪除來源訊息或檔案。

如果提示來源不可用或無法找到精確位置，先根據提示區分情況，手動找到來源後再決定是否重建書籤，不要把附近顯示的文字直接當成原選區。

## 私人記錄與分享範圍 {/* #私人记录与分享范围 */}

- 重啟應用並重新開啟會話後，書籤和備註仍然保留。
- 書籤屬於當前會話，不會轉入其他分支或跨機器同步；刪除會話時會一併刪除其書籤。
- [.science 研究包](research-packages.md) 不包含這些私人書籤。同事需要的資訊，應先寫入儲存的報告或對話，再準備交接材料。
- 需要讓 Agent 處理某段內容時，使用 **To Agent**，在目標草稿中檢查批註後再傳送。Main 與旁聊之間的批註轉移見 [Side Chat](delegation.md)。

## Fork 副本中的書籤 {/* #bookmarks-in-fork */}

從 v0.31.0 起，[Fork](sessions.md#fork-session) 會將私人書籤和筆記複製到新會話，並賦予獨立標識。之後修改副本中的書籤不會修改原書籤。這與切換分支或匯出 `.science` 檔案不同：私人書籤仍不隨研究包匯出，也不會跨電腦同步。
