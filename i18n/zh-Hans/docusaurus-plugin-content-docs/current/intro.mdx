# Open-Science

使用 Open-Science 整理研究资料、与代理协作、运行分析并检查保存后的结果。

## 从这里开始

1. [能力与支持的输入](./guides/capabilities.md)：根据文件或研究问题选择路径。
2. [安装](./guides/installation.md)与[首次设置](./guides/onboarding.md)：准备应用、代理、模型和运行时。
3. [第一个项目与结果](./guides/first-project.md)：创建项目，用一份小表格生成并重新打开说明报告。
4. [权限与审批](./guides/approval-modes.md)：检查操作请求，管理记住的授权。
5. [Notebook 与执行证据](./guides/notebook.md)：查看代码、变量和产物来源。

## 运行示例前

本地示例使用公开 PRISMA 论文和 GSE60450 RNA-seq 矩阵。下载章节中的输入文件，确认任务所需的模型、运行时和权限。

[远程计算](./guides/remote-compute.md)已包含 Direct SSH RNA-seq 分析、结果回收、重启恢复和取消实操。Slurm 终态监控需要可用的记账查询，GPU 推理需要兼容的软件环境。

技术限制和配置查询见 [Reference](./reference/index.md)，版本变化见 [Changelog](./changelog/v0.32.0.md)。
