# Open Science

Open Science 是 AIPOCH 面向科研工作的开源 AI 工作台。它把对话式代理、项目文件、Python/R Notebook、科研文件预览、执行记录和 artifact provenance 放在同一个本地优先的桌面应用中。本 Wiki 对应 **Open Science v0.14.0**，依据 `aipoch/open-science` 最新 `main` 分支源码、渲染测试和隔离环境中的实际运行编写。

![完成一次对话后的 Open Science 工作区](/img/open-science/conversation-completed.png)

## 你可以完成什么

| 工作 | Open Science 提供的能力 |
| --- | --- |
| 发起研究 | 创建带描述和 Agent Context 的项目；选择模型、推理强度、专家和权限模式 |
| 组织材料 | 上传或引用项目文件；搜索文件；在网格、列表和分栏模式间切换 |
| 执行分析 | 让代理调用 shell、Python/R Notebook、Skills、Connectors 和远程算力 |
| 检查结果 | 预览代码、CSV、Markdown、JSON、PDF、Office、图片、分子、PDB、FASTA 等 |
| 复现与审计 | 查看 Session Notebook、artifact 版本、Code、Execution Log、Messages、Environment 和 Review |
| 控制风险 | 在每次请求时 Allow/Deny，或设置 Ask、Auto-approve edits、Full access 以及逐工具策略 |
| 远程协作 | 启用 Remote control，通过受保护的本地 Web 入口访问正在运行的桌面应用 |

## 版本与边界

- 应用仓库：`aipoch/open-science`，文档验证版本 `v0.14.0`。
- Wiki 仓库：`aipoch/openscience-wiki`，使用 Docusaurus 自动生成侧边栏。
- macOS、Windows 和 Linux 的控件名称基本一致；系统文件选择器、托盘和关闭窗口行为会因平台不同而变化。
- 删除项目、删除会话、卸载 runtime、迁移数据目录、保存 API key 等高影响操作在本文中说明确认步骤，但不会对用户真实数据执行。
