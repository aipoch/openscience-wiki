# 任务委派与 Side Chat

想在当前任务旁讨论一个问题，可以使用 Side Chat；需要另一个代理处理独立任务，可以使用任务委派。如果要沿另一条思路继续完整对话，使用[会话分支](sessions.md)。

## Side Chat {/* #side-chat-可用范围 */}

### 使用场景

阅读分析结果时解释一个术语、比较两种分析思路，或先讨论报告应如何表述，都可以打开 Side Chat。讨论后，再把选定的建议交给主对话 Main。

### 使用说明

1. 在已有会话中，打开发送按钮旁的 **More send options → Side chat**。主输入框为空时也可以打开，新的 Side Chat 草稿会立即出现。在旁聊中填写问题，核对模型与推理强度后发送。
2. 在独立的 **Side chat** 预览标签中阅读回答，通过 **Side chat follow up** 继续追问。同一会话下可以保留多个旁聊，在标签之间切换，同时继续使用 Main。
3. 如果希望主对话采用某条建议，明确要求旁聊转交，例如：“把这条建议发给 Main：报告中单独说明缺失值的处理方法。”随后在 Main 检查标为 **Side chat** 的消息；如果 Main 空闲，发送下一条请求让它继续处理。
4. 使用 **Cancel Side chat response** 停止当前回答。切换标签或收起预览区即可返回 Main；重启应用后仍需要的信息，应先转交 Main 或保存为报告。

含文字或批注的草稿会在切换视图时保留。离开未填写内容的空草稿时，它会自动清理；仅打开草稿不会向模型发送请求。

### 把批注移入需要的草稿

对于选中的段落或区域，使用批注的 **Move to Side chat…**，选择已有旁聊或新建旁聊。也可以在 Main 与 Side Chat 草稿之间拖动批注。发送前检查目标和转移后的内容：移动批注只是准备草稿，不会提交请求。

私人 **For me** 书签是另一种阅读工具，参阅[阅读书签](bookmarks.md)。

### 注意点

- **模型设置**：新建 Side Chat 继承当前主会话的模型与推理强度。可以在旁聊中另行选择，修改会用于它的下一次发送；也支持 Codex 订阅。发送前检查实际选择。
- **转交与执行**：普通回答不会自动发送给 Main，也不能代替主对话的权限审批。转交后检查消息是否送达，再让 Main 执行需要的操作。
- **关闭标签**：确认前阅读 **Close Side chat?**。关闭会停止该旁聊并移除对话；选择 **Cancel** 可保留。只是返回 Main 时，切换标签或收起预览区即可。清理失败时，标签会恢复并显示错误。
- **重启应用**：Side Chat 对话和尚未送达 Main 的建议只保留在本次应用运行中。重新加载界面或切换项目时，可重新连接这些内存中的状态；完整重启应用后清除。退出前，把有用建议转交 Main 或保存为报告。已经送达 Main 的消息仍保留在主会话中。
- **可用条件**：从 v0.30.2 起，Main 正在运行或等待审批本身不会阻止旁聊。先在主会话发送至少一条消息；导入的只读会话或不可用的主会话不能打开旁聊。旁聊不接收文件附件。按按钮的实际提示处理，连接问题见[故障排查](troubleshooting.md)。

## 任务委派

### 使用场景

当任务可以拆成独立部分时，例如分别核对文献来源、检查数据文件或审阅分析结果，可以让其他代理处理，再由主代理汇总。需要复用具有固定职责的助手时，参阅[Specialist 委派](../specialists/delegate.md)。

### 使用说明

1. 在输入框的 **Agent controls** 中检查 **Delegation** 是否可用。
2. 在 **Settings → Model → Subagent** 中选择继承主模型，或配置兼容的独立模型与推理强度。
3. 在请求中说明要委派的任务、输入文件、期望输出和验收要求。
4. 在活动记录中查看子任务的执行状态，处理出现的权限请求。
5. 打开返回的文件或来源链接，核对结果；需要查看运行记录时，在 Notebook 的 **Agent** 筛选中选择对应执行者。

### 注意点

- 可用能力取决于代理框架和配置。启用 Delegation 后，仍需在活动记录中确认子任务是否实际启动。
- 子代理不一定共享主对话的全部上下文或 Python 变量，应提供完成任务所需的文件和说明。
- 主任务的计划批准不会自动批准子代理的所有操作；遇到权限请求时，核对具体动作和范围。
- 若界面提供 **Release**，可用它结束或释放子任务资源，主会话中的证据仍保留。
