# 私人阅读书签

需要稍后重读某个段落、核对一张表，或记下阅读疑问时，可以保存书签。**For me** 在当前会话中保存私人阅读记录；**To Agent** 则为请求准备批注。保存书签不会发送消息，也不会把它加入 Agent 上下文。

## 保存段落或 PDF 区域

1. 打开一个已保存的会话，选中对话或支持的文本预览中的文字。阅读 PDF 时，可以选中文字，也可以使用区域选择控件框选需要的部分。
2. 打开选区的批注控件，选择 **For me**。
3. 按需填写 **Note (optional)**，例如“比较这些百分比前，先核对分母”，然后点击 **Bookmark**。
4. 打开输入框中的 **Bookmarks**，确认条目已保存；点击该条目，检查是否返回正确的段落或 PDF 区域。

会话保存后才能使用书签。如果控件不可用，先返回已有会话再试。并非所有嵌入式预览或外部打开的查看器都支持选中文字建立书签。

## 返回、修改或删除

打开该会话的 **Bookmarks** 列表，点击条目或 **Show bookmark source**。对于应用管理的文件，书签会打开它引用的保存版本；与新结果比较时，核对页码、段落和版本。

在列表或段落旁的常驻标记中选择 **Edit bookmark note**，修改备注后点击 **Save**。**Cancel** 保留原备注；**Delete bookmark** 只删除阅读书签，不删除来源消息或文件。

如果提示来源不可用或无法找到精确位置，先根据提示区分情况，手动找到来源后再决定是否重建书签，不要把附近显示的文字直接当成原选区。

## 私人记录与分享范围

- 重启应用并重新打开会话后，书签和备注仍然保留。
- 书签属于当前会话，不会转入其他分支或跨机器同步；删除会话时会一并删除其书签。
- [.science 研究包](research-packages.md) 不包含这些私人书签。同事需要的信息，应先写入保存的报告或对话，再准备交接材料。
- 需要让 Agent 处理某段内容时，使用 **To Agent**，在目标草稿中检查批注后再发送。Main 与旁聊之间的批注转移见 [Side Chat](delegation.md)。

## Fork 副本中的书签 {/* #bookmarks-in-fork */}

从 v0.31.0 起，[Fork](sessions.md#fork-session) 会将私人书签和笔记复制到新会话，并赋予独立标识。之后修改副本中的书签不会修改原书签。这与切换分支或导出 `.science` 文件不同：私人书签仍不随研究包导出，也不会跨电脑同步。
