# 文献资料库

从首页或工作区侧栏打开 **Library**。资料库在本机 Open Science 中共享；项目和集合链接只负责组织文献，不会创建重复记录。

![使用一次性示例文献的资料库](/img/open-science/v0.26.0/literature-library.png)

## 添加文献

选择 **Add**，然后选择：

- **Add reference**：手动录入元数据。标题为必填项；已知时补充作者、日期、出版物、标识符、URL、摘要、笔记和评分。
- **Import PDF**：从单个本地 PDF 提取候选文献；保存前核对提取的元数据。
- **Import references**：预览并导入 BibTeX、RIS 或 NBIB。提交前，预览会标出无效、不完整和已存在的记录。

系统会规范化 DOI、PMID、PMCID 和 arXiv 标识符以便匹配。若标识符或元数据已有匹配项，可选择复用现有记录、保留独立记录，或只填补空缺字段。不要仅凭标题相似就合并；先核对作者、年份、期刊/会议和标识符。

智能体发现的文献和下载的 PDF 会先进入 **Inbox**，不会静默加入资料库。接受候选项后才进入资料库，也可将其忽略；批量操作只处理已选候选项。下载的 PDF 只有通过来源校验并经用户确认后才会保存。

## 整理与检索

- 用 **Collections** 建立可嵌套的主题集合；删除集合不会删除其中的文献。
- 将一条文献链接到一个或多个项目；项目视图只显示与该项目关联的文献。
- 可搜索标题、作者、出版物、标识符、摘要和笔记，并按类型、年份、标签和全文可用性筛选。
- 可显示、隐藏和排序表格列；每页可选 25、50 或 100 条。
- 移入 **Trash** 会从活动搜索中隐藏文献；确认没有保留工作流依赖它后，才能在 Trash 中永久删除。

在 Composer 中，`@` 可选择单条资料库文献、当前项目的 Library 或某个 Collection。单条引用只暴露该记录；Library/Collection chip 授予的是检索范围，并不会一次发送所有记录与 PDF。发送前核对范围，因为匹配元数据或附件文本可能提供给当前模型。

## 查找并附加全文

打开文献并选择全文操作。Open Science 会并行查询所有适用来源：

| 来源 | 前提 |
| --- | --- |
| Europe PMC / PubMed Central | 视情况需要 DOI、PMID 或 PMCID；无需 API key |
| OpenAlex | 需要 DOI；可选配置 API key |
| Unpaywall | 需要 DOI 和联系邮箱 |
| arXiv | 需要 arXiv 标识符 |

选择 **Add attachment** 前检查候选文件的来源、版本标签和 URL。已有附件会保留。“No freely accessible full-text PDF was found”只表示已查询的公共来源没有返回可附加文件，并不证明合法副本不存在。不要绕过出版商访问控制，也不要上传无权处理的材料。

已附加 PDF 使用不可变版本。可预览并在适当时选择 **Read with agent**；后续 turn 不应再收到正文时及时取消链接。凭据、联系邮箱和 provider 响应属于设备数据；不要把 secret 写进引用笔记或 prompt。

## 重复项与引用输出

打开 **Duplicates** 查看按标识符或元数据形成的匹配组。逐项对照，选择保留记录和冲突字段，再执行合并；附件、项目链接和集合链接会保留到 surviving record。批量合并有数量限制且需要复核，不能替代人工书目判断。

文献详情可生成 APA、MLA、Vancouver、BibTeX 与 RIS。**Settings → Citation styles** 提供内置 CSL 样式，也可导入本地 `.csl`。投稿前仍需对照来源核验姓名、日期、大小写、标识符和定位信息。格式化结果记录样式和源修订，但不会验证被引用的科学结论。

## 故障处理

- 元数据补全失败时保留现有记录并手动编辑，不要丢弃已经核验的字段。
- 某个 provider 不可用时可稍后重试或换用其他适用来源；部分来源失败意味着结果不完整。
- PDF 校验或下载失败时，不应视为已附加；检查网络与存储状态后从文献详情重试。
- 导入报告重复时，先比较现有记录，再决定是否选择 **separate**。
- 批量查找/下载任务可在 **Background tasks** 中于当前文献处理完后暂停、恢复、复核或取消。
