# 更新日志 · v0.34.0

发布于 **2026-09-29（北京时间）**，对应官方 UTC 日期 **2026-09-28**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.34.0)。

## 期刊数据集和文献引用

文献库新增带来源、年份和字段映射的期刊数据集，可在匹配文献中显示属性。见独立教程[期刊数据集与文献属性](../guides/journal-datasets.md)。

工作区 Library 提供文献详情、明确开启的批量选择，以及将引用加入当前或其他会话草稿的操作。加入草稿后仍由用户决定何时发送。见[文献库操作](../guides/library.md#add-reference-to-chat)。

## 科学数据库扩展

新增 Pathway Commons，扩展 Bgee、cBioPortal、openFDA 和 MGnify，共新增 **16 个操作**。完整目录为 **29 个 Connector、300 个操作**；其中 28 个数据源家族提供 298 个操作，另有离线 Molecule 的两个操作。

见[数据库能力与连接](../tools/databases.md#pathway-expression-clinical)、[操作参数](../reference/connector-operations.md)及实际保存结果的[通路互作工作流](../workflows/inspect-pathway.md)。

## 安装、模型和桌面导航

- Linux 增加原生 ARM64 的 AppImage 和 Debian 安装包，见[安装说明](../guides/installation.md)。
- Codex CLI 兼容基线提高到 **0.157.1**；已有旧运行时可能需要单独更新，见[更新 Codex](../guides/frameworks.md#update-codex)。
- 模型目录新增 **MiniMax M3.1 Flash Preview** 和 **Claude Sonnet 5.5**，见[Provider 设置](../guides/providers.md#catalog-models)。
- 桌面托盘／菜单栏可访问运行中、固定和近期会话，见[快捷导航](../guides/navigation.md#tray-navigation)。

## 改进与修复

升级到 Electron 43，优化工作区切换和解释器发现。修复代理连接错误后的恢复、停止或重启后的委派、Reviewer 中断恢复、PDF 图表提取、文献元数据补全、WSL 运行时就绪状态和 macOS 远程目录列表，并改进编辑保护、键盘焦点及权限说明。
