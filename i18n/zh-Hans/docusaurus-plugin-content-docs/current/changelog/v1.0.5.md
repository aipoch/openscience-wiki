# 更新日志 · v1.0.5

发布于 **2026-10-28 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.5)。

## 给文献标记阅读进度 {/* #reading */}

文献库新增手动设置的 **Unread**、**Reading** 和 **Read** 状态，支持表格列、筛选和批量修改。出版通知检查改用 **Check now** 和 **Check again**，仍保留 Crossref 结果与检查时间。[阅读状态](../guides/library.md#reading-status) · [出版通知检查](../guides/library.md#publication-checks)。

## 在浏览器里收发研究包 {/* #packages */}

经过身份验证的本地 Web 界面可以上传 `.science` 文件并导入，也可以下载已导出的研究包。首页案例展示提供 **Details** 和 **Import** 入口。导入前确认目标项目，导入后检查材料；继续研究时使用 **Fork to continue**。[浏览器传输与案例展示](../guides/research-packages.md#local-package-transfer)。

## 明确后台服务何时继续运行 {/* #service */}

显式执行 CLI `start` 后，即使最后一个 App 退出，服务也会继续运行。普通 CLI、Web 和 SDK 活动不会单独保持服务运行。普通 `stop` 解除这个持续运行设置，但仍连接的 App 可以让服务继续运行。`stop --force` 请求停止整个服务，可能中断正在执行的工作。`start` 现已支持 `--json`。[命令与停止结果](../reference/server.md#lifecycle-commands)。

## 查找科研记录与官方数据文件 {/* #data */}

新增 Europe PMC 检索、研究数据集访问与公开文件列表、ChEA3、bioDBnet 和 CTD 入口；HGNC、Cellosaurus、openFDA 也补充了查询或文件发现操作。目录现有 **48 个内置 Connector、418 项操作**：其中 47 个数据源 Connector 提供 416 项操作，1 个离线 Molecule Connector 提供 2 项操作。取得文件链接不等于已经下载数据，也不代表获得受限数据集权限。[数据来源与连接步骤](../tools/databases.md#scientific-file-discovery)。

## 更新与日常使用修复 {/* #fixes */}

- 手动更新入口提供安装说明，并可定位已经确认的下载包。[手动安装](../guides/installation.md#manual-update)
- **Full access** 对公开网络目标不再逐项弹出授权卡片；降低模式会关闭已有连接。全局授权会立即显示在 Network 设置中。[网络权限](../guides/network.md#network-mode-changes)
- Windows Notebook 安装 Bioconductor 包时支持明确选择 BiocManager 路径。[Windows Bioconductor 包](../guides/runtimes.md#windows-bioconductor)
- DOCX 输出改进了模板布局、表格、边框和分页的保留。[Word 输出](../guides/previews.md#docx-templates)

其他修复涉及 OpenCode 2.x 兼容、macOS Notebook 的外部 Node 查找、Windows 配置网络保护期间的对话启动、读取应用管理的 Skill 参考资料、会话滚动位置及表格滚动条。About 中也增加了安全政策入口。[上一版本：v1.0.4](v1.0.4.md)。
