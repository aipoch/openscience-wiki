# 更新日志 · v0.34.1

发布于 **2026-10-01（UTC；北京时间同日）**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.34.1)。

## 科学数据库扩展

本版新增 **26 个操作**，完整目录达到 **31 个 Connector、326 个操作**；其中 30 个数据源家族提供 324 个操作，另有离线 Molecule 的两个操作。

| 入口 | 新增能力 |
| --- | --- |
| CELLxGENE Discover | 发现公开单细胞集合和数据集，检查发布版本，获取文件清单 |
| Alliance Genome Resources | 人类与模式生物基因、直系同源、疾病模型、表型、等位基因及表达 |
| Variants → MaveDB | 变异效应分数集、CSV 分数、已有 VRS 映射和实验信息 |
| Omics Archives → Metabolomics Workbench | 研究样本、实验因素、分析、代谢物注释和化合物交叉引用 |

见[能力与连接方式](../tools/databases.md#single-cell-model-organisms)及[操作参数](../reference/connector-operations.md)。返回文件 URL 不代表已下载，实验特定的功能分数也不是临床分类。

## 在工作区审核 Inbox

紧凑 **Library** 预览新增 **Inbox**，支持搜索、分页、逐条 **Accept / Dismiss**、忽略后的 **Undo**，以及当前页的明确批量选择。保存文献卡片的 **Open Inbox** 会在会话旁打开队列。队列包含所有项目的候选，接受记录不会自动获取缺失全文。见[工作区 Inbox 操作](../guides/library.md#workspace-inbox)。

期刊导入补充列角色和字段映射提示，并改进别名匹配、筛选和重试。见[期刊数据集](../guides/journal-datasets.md#import-columns)。

## 研究包与诊断导出

- 空白 **New conversation** 页增加 **Import previous research**，可选择或拖入 `.science` 研究包，见[导入步骤](../guides/research-packages.md#import-and-inspect-a-package)。
- 敏感内容检查后可明确确认 **Export anyway**。标记内容会原样包含，不会脱敏；分享前需检查，见[敏感内容导出](../guides/research-packages.md#sensitive-export)。
- 本地诊断导出保留更多错误与执行证据。它与研究包用途不同，分享前仍需检查，见[会话诊断](../guides/troubleshooting.md#session-diagnostics)。

## 模型与工作区操作

Codex 目录新增 **gpt-6.1-sol**，不改变已保存的默认选择。实际访问取决于账号及当前运行时，见[模型选择](../guides/providers.md#catalog-models)。

Plan 反馈沿用已配置的发送快捷键；输入区更清楚地显示 Compute Host 状态；运行预览可跳到对应消息；Skill 编辑增加未保存草稿保护。

## 修复

Notebook 修复跨单元状态、共享沙箱工具及执行来源记录；PDF 提取改进原生图表内容保留和 worker 处理。其他修复涉及文献 URL、注释选区清理、表格固定、恢复后的后续执行权限、Windows 重装路径、Linux 凭据存储与凭据身份处理。
