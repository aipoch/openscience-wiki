# 更新日志 · v1.2.1

发布于 **2026-11-11 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.2.1)。

## 在同一个入口找到研究资源 {/* #resource-center */}

**Resource center** 集中管理 Skills、Connectors 和 Specialists，提供已安装资源与市场视图、搜索、筛选和详情抽屉。Web 工作区也能从市场安装资源。从问题草稿或已发送消息打开 Skill 引用时，详情显示在项目面板中，当前会话保持原位。[资源导航](../guides/navigation.md#resource-center) · [Skill 市场](../skills/marketplace.md)。

## 发送前，把问题说得更清楚 {/* #prompt-optimization */}

在项目输入框中使用 **Optimize question**，由已配置的模型改写草稿。检查结果后可以继续编辑，或通过 **Undo optimization** 恢复原文，再自行发送。项目设置可保存自定义 **Optimization prompt**。只有主动点击才会调用模型，不会自动发送研究问题。[优化问题](../guides/composer.md#optimize-question)。

## 内置 Agent 也能使用 Codex 订阅 {/* #codex */}

**Open-Science Agent** 现在支持 Main 和 Subagent 使用导入的或应用内登录的 Codex 订阅账户，沿用现有登录与凭据恢复入口。内置 Agent 同时改进输出长度上限和上下文用量计算。Anthropic 模型目录新增支持 1M 上下文的 **Claude Fable 5.2**；实际可用性仍取决于提供方与账户权限。[Agent 配置](../guides/frameworks.md#built-in-agent)。

## 把文献元数据导出为表格 {/* #csv */}

**Export → CSV** 可导出选中文献、整个项目或集合，使用 16 个固定英文列名。支持跨页选择并排除个别条目，缺失字段保持为空。此导出不包含 PDF、筛选结论或个人笔记。[CSV 导出步骤](../guides/library.md#bibliography-csv)。

## 更顺畅地处理长会话 {/* #reliability */}

- Notebook 与 Compute 证据按内容去重并校验摘要，减少长会话 `.science` 导出中的重复数据；首次导出也会整理旧证据。[研究包](../guides/research-packages.md#compact-evidence)。
- Modal 与 Hugging Face 在浏览器登录前准备兼容的 Python 运行环境，账户检查使用系统代理。[云账户连接](../guides/remote-compute.md#cloud-account-runtime)。
- 切换会话后，研究影片继续生成。[研究影片](../guides/research-films.md#generate-film)。
- 打开手机配对面板不会自行开启访问，需主动选择 **WiFi** 或 **Internet**。[移动设备连接](../guides/remote-access.md#mobile-pairing)。
- 修复聊天中的 Notebook 附件和本地文件链接预览，改进 PDF 恢复、翻译隔离、文献标识符处理与窄屏来源预览。
- 会话无活动 15 分钟后回收闲置解释器；Windows 更新恢复更明确地定位占用文件和进程，Linux 恢复不再把已确认的内核线程误判为残留 Notebook 进程。

另见[安装与更新](../guides/installation.md)和 [v1.2.0](v1.2.0.md)。
