# 更新日志 · v0.36.0

发布于 **2026-10-08 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.36.0)。

## PDF 全文翻译

全文翻译新增逐段保存进度、继续翻译和原文／译文对照。同一受管理 PDF 可在不同阅读入口复用已保存译本。独立的 [PDF 全文翻译教程](../guides/pdf-translation.md) 介绍全文准备、模型要求、术语表、继续翻译和导出。v0.36.0 的这项翻译操作不支持 Codex 订阅模型。

## Notebook 执行前审查

Agent 提交的 Notebook 代码会在执行前检查。存在风险或无法充分判断的操作，会显示包含相关源码行和明确决策按钮的审查卡片；受支持的普通读取与分析无需额外风险批准。它与 Reviewer 对已完成结果的检查不同，见[执行前审查](../guides/notebook.md#execution-review)。

## 科学数据库

新增六个操作，注册表达到 **35 个 Connector、349 个操作**：34 个数据源家族提供 347 个操作，另有两个离线 Molecule 操作。

| 入口 | 能力 | 说明 |
| --- | --- | --- |
| PDC | 癌症蛋白组研究版本、生物样本关联和定量文件元数据 | [PDC 连接与范围](../tools/databases.md#pdc) |
| Genomes → Ensembl | 指定人群中的两变异 LD 与邻近代理变异 | [LD 查询](../tools/databases.md#ensembl-ld) |

精确字段见[操作参考](../reference/connector-operations.md)。PDC 检索不会下载数据；高 LD 不代表因果关系。

## 日常操作变化

- Library 与 Inbox 新增已加载页面的全选控件。执行批量操作前核对已选数量；它不会选中服务端全部匹配记录，见[批量选择](../guides/library.md#loaded-page-selection)。
- 将文件卡片或已打开的产物拖入 Composer，可插入文件引用。发送前检查草稿，见[文件引用](../guides/composer.md#drag-file-mention)。
- 官方 Anthropic 目录加入 Claude Haiku 5.5；模型目录移除了可能导致选择失败的上下文大小别名。应选择当前可用模型，不要照抄旧标识符。更新不会自动替换已保存的 Main 模型。

## 阅读与可靠性修复

PDF 提取改进复杂表格、多级表头、页脚和多面板布局。科学解释依赖版式时，仍需回看原文，见 [PDF 提取](../guides/previews.md#pdf-extraction)。

Notebook 改进 Python／R 读取器、容器变换和回调中的依赖记录。这有助于保留来源关系，但不代替[重新运行验证](../guides/reproducibility.md)。其他修复涉及新会话 Files 面板的引用、空工作区查找、紧凑引用标签，以及 Remote Web 中的 Specialist Marketplace。
