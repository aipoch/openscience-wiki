# 更新日志 · v0.33.3

发布于 **2026-09-26**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.33.3).

## 阅读文件和管理文献

Office 文件支持分页阅读与搜索，PowerPoint 提供逐页导航。沿用已有 QC 文件，查看[文件预览教程](../guides/previews.md)。

工作区 **Library** 增加紧凑预览，可按当前项目或全部文献查找记录并查看摘要。智能集合增加 **Abandon run**：保留已完成结果，结束这次运行且不再恢复。Crossref 元数据补全支持导入来源摘要。见[文献库](../guides/library.md)和[筛选工作流](../workflows/screen-literature.md)。

## 新增科学数据库操作

**Genes & Ontologies** 加入 Enrichr 库发现与富集查询；**Clinical Genomics** 加入 ClinPGx 药物、基因、变异、指南、标签及族群频率查询。完整目录现有 **28 个 Connector、284 个操作**，其中数据源为 27 个、282 个操作，其余两个属于离线 Molecule。见[数据库能力](../tools/databases.md)和[操作参考](../reference/connector-operations.md)。

## 研究包、外观和安装

研究包传输增加自动调整或固定的磁盘活动上限，后台运行仍可查看进度。桌面界面缩放快捷键与设置统一为 90%、100%、110%、125%。Windows 签名覆盖到随应用分发的可执行文件。见[研究包传输](../guides/research-packages.md#transfer-settings)、[界面缩放](../guides/appearance.md#interface-scale)及[安装说明](../guides/installation.md)。

## 修复

修复 PDF 阅读标签字体、Notebook 内核恢复隔离、已授权文件夹的原生访问、可恢复的重试提示及错误提示关闭。归档恢复提示限定到受影响项目；分类模型选择器的初始选择、诊断归档后缀、Skill 元数据、托管 Python 以及研究包中的用量记录也得到修正。
