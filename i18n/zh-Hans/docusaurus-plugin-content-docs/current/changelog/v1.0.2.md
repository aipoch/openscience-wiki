# 更新日志 · v1.0.2

发布于 **2026-10-22 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.2)。

## 查询更多科学数据源 {/* #scientific-sources */}

| 数据源 | 对应入口 |
| --- | --- |
| HGNC 基因命名 | Genes & Ontologies |
| PubTator 3 论文标注 | PubMed |
| DGIdb 药物—基因相互作用 | Clinical Genomics |
| RNAcentral 记录与交叉引用 | RNA |
| Orphadata 罕见病关联 | Orphadata；需要先启用 |

当前目录包含 **36 个数据源入口、371 个操作**，另有两个离线 Molecule 操作。详见[选择与连接数据源](../tools/databases.md#new-source-access)。

GDC 文件查询支持按病例、样本类型和分析流程筛选，并保留样本／aliquot 关联。Ensembl VEP 可直接接收 HGVS，无需先手工换算坐标；它不验证输入参考版本，也不执行 liftover。目录还包括 ClinicalTrials.gov 已公布的试验结果。见[查询上下文](../tools/databases.md#clinical-context)及[完整操作参考](../reference/connector-operations.md)。

## 安装和检查 CLI {/* #cli */}

CLI 和 Task SDK 已发布到 npm。按 [npm 安装说明](../guides/installation.md#npm-cli)操作后，可在不启动后端的情况下使用 `version`、`help` 和 `paths`。显示的版本属于实际调用的安装。桌面及独立发行包包含 Node 22.23.4 安全更新。见[本地信息命令](../reference/cli.md#local-information)。

## 处理会话中的选择与草稿 {/* #conversation */}

问题卡片明确区分 **Single select** 与 **Multi select**，并保留每个问题的完整历史答案。排队消息出错时可撤销；未发送草稿会触发退出／重载提醒。凭据恢复提供具体下一步并保留草稿。远程网页会话支持引用产物。见[问题卡片与草稿](../guides/composer.md#clarification-questions)。

## 继续研究并检查记录 {/* #research-records */}

- 研究包对话框保持稳定；重试部分提交的导入可避免重复会话。导入标题可以编辑，研究记录仍只读。见[研究包](../guides/research-packages.md#browser-import)。
- 大会话加载和启动恢复得到优化；部分诊断导出会显示警告。见[会话诊断](../guides/sessions.md#session-diagnostics)。
- PDF 结构、DOCX 编号／边框，以及 Python／R 连续分析的文件依赖记录得到修复。见[依赖检查](../guides/notebook.md#chained-analysis-lineage)。
- 大批量 Skill 分批导入；外部保留名称会转换为安全本地名称。MiniMax M3.1 通过 Codex 连接的问题已修复。见[模型恢复](../guides/providers.md#credential-recovery)。
