# 更新日志 · v0.33.0

发布于 2026 年 9 月 23 日。本版加入智能文献筛选、按代理管理资源访问，以及研究包内的 RO-Crate 元数据。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.33.0) · [与 v0.32.0 的差异](https://github.com/aipoch/open-science/compare/v0.32.0...v0.33.0)

## 按明确标准筛选文献

**Smart collection** 根据纳入和排除标准评估文献库记录。先限定范围，再查看四种判断视图，复核模型决定后使用阅读集。试运行会保存结果，实时草稿预览不会保存；全文证据和自动更新分别控制。

新增[智能筛选实操](../workflows/screen-literature.md)，覆盖检索、模型绑定、规则、试运行、人工复核和导出。[分类模型设置](../guides/models.md#smart-collection-model)区分 **Smart collections** 与 **Automatic capability selection**，主会话可以继续使用 Codex。

## 资源访问与研究交接

- Skill 或 Connector 的 **Manage access** 集中显示 Main Agent 和 Specialist 关联。角色启用、凭证和操作批准仍分别管理，见[资源访问](../guides/connectors.md#resource-access)。
- 新导出的 `.science` 研究包包含 RO-Crate 1.1 元数据，接收方须使用支持 `ro-crate` 能力的读取器；旧研究包仍可读取，见[研究包兼容性](../guides/research-packages.md#package-compatibility)。
- 会话中的 **Export diagnostics…** 按所选来源生成本地归档，不上传，也不发送给模型，见[诊断导出](../guides/troubleshooting.md#session-diagnostics)。

## 新增数据库操作

| 资源 | 新能力 | 范围 |
| --- | --- | --- |
| Zenodo | 检索公开记录，查看版本级元数据和文件清单 | 不上传或下载文件；公开元数据不表示文件开放访问 |
| GDC | 列出癌症项目与病例，检索文件、查看元数据并生成清单 | 受控数据仍需相应授权 |
| Genes & Ontologies | UniProt 批量标识符映射：提交、查询状态、分页取结果 | 保留全部页面、一对多匹配及明确的未匹配 ID |

共有 **26 个内置 Connector、263 个操作**：其中 **25 个数据源 Connector、261 个操作**，另有两个离线 Molecule 操作。按[科学数据库目录](../tools/databases.md)选择服务，在 [v0.33.0 操作参考](../reference/connector-operations.md)查准确参数。本版也修正了小鼠基因组的 UCSC 保守性默认轨道。

## 模型、运行时与平台修复

服务商目录加入 MiMo v2.6、Grok 4.7，并更新 Zen/Go，见[模型服务商选择](../guides/providers.md#provider-catalog-updates)。**Claude Agent** 会在就绪检查中提示不受支持的 CLI 版本；v0.33.0 要求 **2.1.118 或更高版本**，见[安装代理](../guides/frameworks.md)。

其他修复涉及流式响应与长会话、残留运行状态恢复、研究包凭证检查、Notebook 长命令进度、安装软件包时的文件夹授权、可关闭的 Notebook 提示、Windows R 清单与重置处理、Fedora 启动打包，以及搜索和 PDF 交互。完整内容见官方发布说明，上一版为 [v0.32.0](./v0.32.0.md)。
