# 更新日志 · v0.30.1

发布于 2026 年 9 月 16 日。本次更新改善旁聊准备、方法变更审核和研究材料交接。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [相对 v0.30.0 的变化](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## 使用流程更新

| 范围 | 对使用的影响 |
| --- | --- |
| Side Chat | 可先打开空草稿，继承主会话的模型与推理强度，也能为下一次发送另选模型；含内容的草稿在切换时保留，未填写的空草稿会清理，见 [Side Chat](../guides/delegation.md) |
| Skill 更新 | 在 **Update existing Skill** 前查看文件变化、行号和增删内容，核对受影响的 Specialist 及将被替换的本地修改，见 [Skill 市场](../skills/marketplace.md) |
| 研究包 | **Full export** 包含可用文献 PDF，**Customize contents** 可逐项选择；Essential export 省略可选 PDF，必需证据不能移除；不导出 Side Chat 对话，见[研究包](../guides/research-packages.md) |
| 本地网关 | 无需认证的回环 Custom Gateway 可将 API key 留空；远程网关仍需要凭据和 HTTPS，见[模型接入](../guides/providers.md) |
| 网页读取授权 | 支持的网页读取请求可按会话记住授权，覆盖同一会话后续对其他网站的读取，见[权限与审批](../guides/approval-modes.md) |
| 标签 | 资源标签选择器支持搜索、方向键与 Enter，也可以直接创建并分配新标签，见[标签](../guides/tags.md) |
| 安装与恢复 | macOS 在更新前引导只读副本安装到 Applications；Windows 提供独立的数据重置工具，带预览与输入确认，会删除数据；安装器显示项目许可，见[安装与更新](../guides/installation.md)、[Windows 重置](../guides/troubleshooting.md#windows-data-reset) |

## 发布说明中的修复

本版还报告修复了 MCP 超时期间的计划审批、历史产物绑定、任务取消和 Notebook 排队状态。PDF 解析可从被阻塞状态恢复并报告提取失败，图表版式恢复也得到改进。数据接口方面，修正 gnomAD 区间参数与数据集参考基因组匹配，以及 ESM-2 批量残基池化。

提供方连接检查使用被测试提供方自身的路由；缺少文件式 Codex 登录时给出更明确的导入错误。文献视图返回原来的项目会话，OpenCode Side Chat 指令与 Main 保持分离。

更新步骤见[安装与更新](../guides/installation.md)，前一功能版本见 [v0.30.0](./v0.30.0.md)。
