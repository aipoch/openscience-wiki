# 更新日志 · v1.3.0

发布于 **2026-11-18 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.3.0)。

## 把下一次研究任务安排好 {/* #scheduled-tasks */}

创建一次性或重复任务，定时发送 Agent 消息，或者运行 Python、R、Shell 脚本。消息任务可以继续已有会话，也可以每次创建新会话；每次运行都有独立记录。应用需要保持运行，任务使用配置的权限、凭据和提供商额度。[定时任务教程](../guides/scheduled-tasks.md)。

## 生成图片，直接修改演示文稿 {/* #creation */}

配置图像生成服务后，可以根据提示词生成图片，再通过版本化编辑逐步调整。图像生成拥有独立的模型设置，与 Main、Vision 分开。[图像生成与编辑](../guides/image-generation.md)。

PPTX 预览现在可以编辑幻灯片文字和格式。保存后检查新版本，分享前重新打开下载的演示文稿。[编辑演示文稿](../guides/presentation-editing.md)。

## 讲清研究，或者回放操作 {/* #films */}

在研究影片对话框中选择 **Research explanation** 或 **Operation replay**。会话分支分别保存自己的影片；生成前会说明模型用量，已有影片可从会话菜单打开。[影片生成步骤](../guides/research-films.md#generate-film)。

## 长任务中的更多控制 {/* #other-changes */}

- 定时任务保留运行历史；Notebook 进程监控展示所属进程，并提供 **Terminate** 操作。[进程监控](../guides/notebook.md#process-monitor)。
- CodeBuddy 订阅支持中国站和国际站账户，通过受管 CLI 发现可用模型。[账户设置](../guides/providers.md#codebuddy-subscription)。
- Agent 提问会展示不同选项及其取舍，确认选择后继续任务。
- 文档配图 Skill 首次使用时，在受管环境中准备所需依赖。
- 会话增量保存、影片恢复和 Windows 安装更新改进，减少重复工作与不必要的资源占用。

参见[安装与更新](../guides/installation.md)和 [v1.2.2](v1.2.2.md)。
