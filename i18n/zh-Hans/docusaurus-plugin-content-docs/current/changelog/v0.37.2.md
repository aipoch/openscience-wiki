# 更新日志 · v0.37.2

发布于 **2026-10-13 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.37.2)。

## 恢复启动与运行连接 {/* #recovery */}

后端、设置和网络初始化失败时，现在提供相应恢复路径。桌面连接中断后，工作区保持打开，并提供 **Reconnect** 和 **Quit app**。重连恢复原先仍在运行的后端，不会启动已停止的后端，也不会自动重复已提交操作。未收到响应时，先检查原任务状态再决定是否重试。

浏览器界面恢复遗漏更新时会暂停控件，并在需要时提供重新加载或重新配对提示。大型会话及 Notebook 快照传输、密集事件和重定向诊断日志的处理也得到改进。操作见[连接与启动恢复](../guides/troubleshooting.md#connection-recovery)和[服务归属](../reference/server.md#backend-ownership)。

## 通过安装包使用 Linux CLI {/* #linux-cli */}

除发行版压缩包和 Homebrew CLI 外，Linux 新增 x64 与 ARM64 的独立 `.deb`、`.rpm` CLI 安装包。安装包包含 Node、后端和本地 Web UI，明确入口为 `open-science-cli`。它与桌面安装包分开，不会自动启动系统服务。

[安装包选择、安装与升级](../guides/installation.md#linux-cli-packages)说明了具体步骤。升级或卸载前，停止使用该安装包的所有配置实例，并保留研究数据与凭据存储。

## 科研功能与界面修复 {/* #research-fixes */}

| 范围 | 变化与对应说明 |
| --- | --- |
| 科学 PDF | 改进图表归属和旧式数学符号解码；[将提取结构与原文核对](../guides/previews.md#scientific-structure-check) |
| Notebook | 首次运行准备时显示接收中的代码，强化依赖和文件来源分析；检查运行状态及[实际执行证据](../guides/notebook.md)，不能仅凭看到代码判断完成 |
| 文献库 | 拒绝身份冲突的元数据提交，异步操作保留当前状态；[保存前核对标识符](../guides/library.md) |
| 模型设置 | 修正 Provider 压缩／重试行为的发布；支持的选项仍在原[Provider 控件](../guides/models.md)中配置 |
| 远程计算 | 取消和清理期间保留任务恢复证据；再次提交前先[检查原任务](../guides/remote-compute.md) |
| 其他修复 | 修正 [Bgee 物种元数据](../tools/databases.md#bgee-species)，明确空图片错误，减少 Windows 后台进程弹窗，统一新建项目文字，并改进产物发布时序 |
