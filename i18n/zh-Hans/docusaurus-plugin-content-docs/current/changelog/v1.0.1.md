# 更新日志 · v1.0.1

发布于 **2026-10-20 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.1)。

## 将研究包导入应用 {/* #packages */}

支持该功能的网站可以把 `.science` 研究包传给同一台电脑上的桌面应用。允许浏览器打开 Open-Science，传输期间保持网页打开，再到应用中检查研究包并选择导入位置。应用接收到文件，不等于最终批准导入。本地研究包也可拖到项目首页。操作见[网页导入](../guides/research-packages.md#browser-import)。

## 跟进更新和等待中的会话 {/* #interaction */}

更新对话框集中显示下载、发布说明及安装准备状态。Windows 安装交接和启动得到修复；是否能安装仍取决于安装通道。按[更新进度说明](../guides/installation.md#update-progress)操作，重新启动后确认实际版本。

需要回答或批准的会话，会在首页、侧栏和会话中持续显示等待状态。重新打开待处理卡片即可继续。侧栏会话支持双击打开编辑器。详见[等待输入](../guides/sessions.md#waiting-for-input)。

## 使用数据源与凭据 {/* #sources */}

- PDC 新增公开病例人口学、诊断信息，支持选择研究版本和保留外部引用。不同来源的 ID 不可混用。见 [PDC 临床字段](../reference/connector-operations.md#pdc_list_clinical)。
- 两个 MiniMax 区域均提供 M3.1 Flash；消息附图也可参与 Skill 选择。见[模型选择](../guides/providers.md#catalog-models)。
- OAuth 凭据绑定到签发它的授权服务器；必要时按[重新授权](../guides/connectors.md#oauth-reconnect)操作。
- PDF 搜索会提示覆盖不完整；双栏阅读、翻译布局、文献状态及 Notebook 恢复得到修复。见[检查 PDF 覆盖范围](../guides/previews.md#pdf-search-coverage)。

本版重新提供桌面安装包与独立 CLI 压缩包，包括 Linux CLI 安装包。安装方法见[当前指南](../guides/installation.md)。[上一版本：v1.0.0](v1.0.0.md)。
