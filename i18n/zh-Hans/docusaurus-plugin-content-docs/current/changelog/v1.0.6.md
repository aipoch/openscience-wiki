# 更新日志 · v1.0.6

发布于 **2026-10-30 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.6)。

## 把 Zotero 文献库带过来 {/* #zotero */}

可以从同一台电脑上运行的 Zotero 10 或更高版本导入个人文献库或选定集合。先预览条目，再导入元数据、本地 PDF、标签和集合层级；复用已有记录前，需要核对匹配结果。这是一次导入，不是双向同步。[Zotero 导入教程](../guides/library.md#zotero-import)。

文献库的普通搜索现在也能找到个人笔记中的文字。显示 **Notes** 列，记下为什么要读这篇论文，之后通过 **Search references** 找回来。[按个人笔记检索](../guides/library.md#personal-note-search)。

## 阅读 PDF，不用再设置读取顺序 {/* #pdf */}

关联 PDF 改用自动文本读取顺序，优先使用完整的逻辑标签，再根据可用文本和版面回退。持久化的手动读取顺序控件已移除，带有旧区域设置的历史消息也按新规则读取。引用复杂版面中的段落前，仍需对照原文。翻译后的 PDF 打开更快，DOCX 工具栏在滚动时也会保持在文档上方。[PDF 读取顺序](../guides/previews.md#automatic-pdf-reading-order)。

## 更新后继续工作 {/* #reliability */}

- Windows 安装减少了包内文件并使用并行解压；更新时保留应用目录旁的研究数据，也修复了深层安装路径的问题。[Windows 更新检查](../guides/installation.md#windows-update-data)。
- 生成文件的发布权限覆盖整个尚未结束的助手回合，长任务不再因为原先的两小时期限而失去发布权限。
- 自定义本地 Connector 使用 **npx** 或 **npm** 时，如果系统找不到对应命令，可以使用随应用提供的运行时；已安装的命令仍然优先。[本地命令](../guides/connectors.md#bundled-npm)。
- Slurm 会先保存任务终态，再收集日志；队列、控制器和记账信息分别处理，取消操作只返回一次最终结果。[任务状态与结果收集](../guides/remote-compute.md#slurm-outcome-recovery)。
- 系统凭据的交互授权最多等待五分钟，超时会显示专门的恢复提示。[启动授权](../tools/credentials.md#system-authorization)。

其他修复涉及 OpenCode 工具调用和 Windows 启动限制、Windows Cookie 存储启动检查、含空格临时路径中的 R 执行、会话同步、停止准备后恢复草稿，以及导入会话的错误历史。分体按钮菜单也统一了布局。WSL 指南明确：镜像网络要求 **Windows 11 22H2 或更高版本**。[WSL2 设置](../guides/runtimes.md#wsl2-preview)。

内置 Connector 目录没有新增：仍为 **48 个 Connector、418 项操作**，其中 47 个数据源 Connector 提供 416 项操作，另有 1 个离线 Molecule Connector 提供 2 项操作。[支持的数据源](../tools/databases.md#supported-databases) · [上一版：v1.0.5](v1.0.5.md)。
