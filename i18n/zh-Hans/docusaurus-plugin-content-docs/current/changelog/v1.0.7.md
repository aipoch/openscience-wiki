# 更新日志 · v1.0.7

发布于 **2026-11-02 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.7)。

## 从论文链接，走到阅读笔记 {/* #literature */}

有了 DOI、doi.org 链接或 arXiv 摘要/PDF 链接，可以通过 **Add from DOI or link** 查找文献信息，核对后保存。获取全文仍是单独的步骤。[添加文献](../guides/library.md#doi-link-import)。

在 Reading 会话中，可以让 Agent 定位段落，把高亮、区域标记或笔记保存到关联 PDF。完成后打开 **Notes & Annotations**，检查保存的位置和内容。[Agent 批注](../guides/pdf-notes.md#agent-annotations)。

扫描件可以使用可选的 OCR。下载识别组件、选择九种语言包中的所需语言后，重新读取 PDF 并查看页面覆盖情况。识别出的引用和数值仍需对照页面图像核查。[OCR 设置](../guides/previews.md#scanned-pdf-ocr)。

## Pi 与研究案例市场 {/* #agents-and-cases */}

Pi 成为第五种 Agent 框架，与 Claude Agent、OpenCode、Codex 和 CodeBuddy 并列。需要单独安装、配置兼容的模型访问方式，并测试连接。更新 Open-Science 不会自动切换当前 Agent。[Pi 设置](../guides/frameworks.md#pi-agent)。

首页和会话工作区都能进入 **Sharing marketplace**。按分类浏览、输入关键词搜索，再打开案例查看说明或下载研究包；从项目返回时会保留浏览位置与筛选条件。[查找研究案例](../guides/research-packages.md#use-case-gallery)。

## 让手头的工作继续下去 {/* #reliability */}

- Windows Notebook 会在首次使用前准备 Shell 运行时，修复新后端无法使用 PowerShell 的问题。
- OpenCode 会话可以处理压缩上下文时的非标准消息标识；后台任务收尾期间发送的追问也会保留。
- 全文下载支持使用 Fake-IP DNS 的已配置代理。[下载恢复](../guides/troubleshooting.md#full-text-proxy)。
- 发布或恢复产物后，前台采用最新已发布版本，溯源面板也更清楚地展示版本关系。[核对文件版本](../guides/files.md#latest-published-version)。
- Composer 统一显示提供商、环境、输入、会话和内部错误，并给出对应恢复操作。[恢复请求](../guides/composer.md#request-recovery)。
- OCR 语言选项保存时保持响应，识别组件下载卡住也不会让普通 PDF 读取超出原有等待期限。

设置中的 Connector 说明更具体了。内置目录仍为 **48 个 Connector、418 项操作**；Pi、OCR 和文献导入入口不计入 Connector 数量。[科学数据库](../tools/databases.md#supported-databases) · [上一版](v1.0.6.md)。
