# 更新日志 · v1.3.2

发布于 **2026 年 11 月 20 日（UTC）**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.3.2)。

## 更多模型接入选择 {/* #models */}

在 **Model provider** 点 **Skip**，会添加不带 API key 的 Kilo Gateway，并继续到 Notebook runtime。完成后，**Main model** 可能显示 `kilo-auto/free`。发送第一条消息前，打开 **Settings → Model**，检查实际选中的提供商与模型；如果打算使用 Codex 订阅，就切换到对应连接。Skip 不会验证模型能否完成请求。 升级会保留已有凭据和 Main 模型选择。 [Kilo Gateway](../guides/providers.md#kilo).

OpenAI、MiniMax、百炼和火山方舟图像服务可在保存前刷新支持的图像模型目录。刷新会携带该连接的凭据访问所配置的提供商；目录中有模型与实际生成成功是两项不同的检查。见[图像模型目录](../guides/image-generation.md#image-model-catalog)。

## 研究会话更流畅 {/* #sessions */}

长会话占用更少内存；不再查看且已安全保存的会话正文可以释放，草稿和活动任务仍保留。回放中已完成步骤的提问与捕获按钮在悬停或键盘聚焦时显示，触屏设备保留可操作的入口。

Notebook 内存压力通知可关闭，并在六秒后消失。通知消失不代表被阻止的操作已经执行；检查任务状态，再决定是否重试。见 [Notebook 内存管理](../guides/notebook.md#memory-resources)。

## 影响日常操作的修复 {/* #fixes */}

- 修复内置 Agent、Claude Agent 和 Codex 新会话在特定 Notebook 准备过程中、首次模型请求前失败的问题；定时会话按预定提示词启动。
- PDF 翻译按阅读顺序重组换行的标题、图注和数学陈述，并保留原生公式、链接与图形。见[翻译版式检查](../guides/pdf-translation.md#scientific-layout)。
- 首页案例下载错误区分包缺失、超时、校验失败和存储问题。见[案例导入恢复](../guides/research-packages.md#case-download-recovery)。
- Windows 修复涉及 WSL Notebook 启动和 Reviewer 连接。

见[安装与更新](../guides/installation.md)及 [v1.3.1](v1.3.1.md)。
