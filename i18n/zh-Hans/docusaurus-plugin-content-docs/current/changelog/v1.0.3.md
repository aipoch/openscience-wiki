# 更新日志 · v1.0.3

发布于 **2026-10-26 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.3)。

## 沿着引用关系寻找文献 {/* #literature */}

通过 Semantic Scholar 查找论文的参考文献和引用论文，将选中的候选送到 Inbox 审阅。文献库也支持拖入文件、查找补充材料，并显示逐个附件的下载进度与预览。[文献发现与附件操作](../guides/library.md#citation-discovery)。

智能集合可以将全部候选的筛选决定导出为 CSV，与入选文献目录分开保存。[导出筛选决定](../workflows/screen-literature.md#screening-csv)。

## 搬运与阅读研究记录 {/* #research */}

- CLI 和已认证的本地网页支持导入、导出 `.science` 研究包，导入会话仍为只读。[本地研究包传输](../guides/research-packages.md#local-package-transfer)。
- 新建 PDF 译文时，可通过 **Advanced → Content first** 重排正文和图注。[译文排版](../guides/pdf-translation.md#content-first)。
- 在 Permissions 中控制本地 Notebook 与 Shell 的文件夹访问；更改设置会停止运行中的进程并清空变量。[文件夹限制](../reference/permissions.md#notebook-folder-restrictions)。

## 查询更多科研来源 {/* #sources */}

新增访问覆盖 TCIA、KEGG、OmniPath、LIPID MAPS、PDBe 验证、UniChem 映射、DepMap/CCLE 和 PDB 结构相似性。使用结果时保留来源对应的标识、许可和测量量纲。[选择并连接来源](../tools/databases.md#expanded-sources)。

模型目录加入 Kimi K3.1 Pro。Windows 协议注册、网络审批的持久保存、会话恢复、研究包传输及 PDF 处理也有修复。[模型选择](../guides/providers.md#kimi-k31) · [上一版本：v1.0.2](v1.0.2.md)。
