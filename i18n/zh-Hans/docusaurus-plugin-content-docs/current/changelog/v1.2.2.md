# 更新日志 · v1.2.2

发布于 **2026-11-18 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.2.2)。

## 为 Notebook 选择更严格的网络规则 {/* #strict-network */}

**Settings → Network → Manage access** 新增 **Relaxed** 和 **Strict** 模式。Strict 只允许手动白名单中匹配协议、域名或 IP、端口的请求；未匹配的请求直接阻止，不再弹出授权。Relaxed 仍为默认模式。规则可以分组，Built-in 和 Manual 标记表示规则来源。[网络设置步骤](../guides/network.md#public-network-rules)。

## 从中断处继续生成研究影片 {/* #film-checkpoints */}

影片生成会保留已验证的场景、旁白和时间安排，应用进程重启后也能继续利用这些内容。可以从检查点恢复，也可以明确选择重新生成；进度界面会显示当前阶段。[恢复步骤](../guides/research-films.md#film-recovery)。

## 阅读 PDF 与恢复本地工作 {/* #recovery */}

- 原生 PDF 提取改进了图形、图注、表格内容和阅读顺序的保留。使用提取结果或翻译版面时，仍应与原 PDF 对照。[PDF 提取](../guides/previews.md#pdf-extraction)。
- Windows 在保存受保护文件夹授权前检查访问权限，并改进更新、卸载恢复与诊断信息保留。
- `.science` 导入区分取消、无效研究包和超时。超时导致结果未确认时，先检查会话是否已导入，再决定是否重试。[导入研究包](../guides/research-packages.md)。
- 本地服务断开时，工作区显示恢复状态，并保留输入框草稿。
- 百炼 Token Plan 加入 **Qwen4 Max Preview**，提供对应区域的目录选项；实际可用性取决于账户。[提供商设置](../guides/providers.md#provider-regions)。

参见[安装与更新](../guides/installation.md)和 [v1.2.1](v1.2.1.md)。
