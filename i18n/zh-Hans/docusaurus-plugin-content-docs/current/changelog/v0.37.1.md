# 更新日志 · v0.37.1

发布于 **2026-10-12 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.37.1).

## 保留科学 PDF 的结构

图像提取更完整地保留图注、图例与多面板图。公式旁的线框表格保留分组表头、行结构及单元格来源引用，图注、图形和文字也更准确地归属于原文中的对应元素。

使用 [Figures & Tables](../guides/previews.md#pdf-extraction) 时，引用前对照原始页面检查完整面板、图例、表头、单位与脚注。翻译 PDF 重新生成时，也能识别嵌入字体中合理的字形名称差异并保留原文字形；检查方法见[对照与导出](../guides/pdf-translation.md#compare-export)。

## Windows 与安装

- 桌面 CLI 支持包含中文等非 ASCII 字符的安装路径，保留调用终端的代码页与退出码。旧启动器误读路径时，更新应用并重新打开终端，见 [CLI 设置](../reference/cli.md#terminal-setup)。
- 本地 PDF 翻译正确处理 Windows 盘符路径。
- Notebook 内核、环境指纹、软件包清单与锁定信息采集不再额外闪现控制台窗口。
- 桌面与独立运行包移除重复依赖和未使用资源，减小 v0.37.0 后端拆分带来的下载体积增长。

[v0.37.0](v0.37.0.md) 引入的独立 CLI 与 Node 后端继续适用。选择与平台匹配的压缩包，并保留解压后的运行目录结构。
