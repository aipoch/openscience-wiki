# 更新日志 · v0.30.2

发布于 2026 年 9 月 17 日。本次更新主要改善 Skill 加载、旁聊、科研数据查询和运行恢复的可靠性。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.30.2) · [相较 v0.30.1 的变更](https://github.com/aipoch/open-science/compare/v0.30.1...v0.30.2)

## 日常使用变化

| 范围 | 对使用的影响 |
| --- | --- |
| Specialist Skills | 为专家对话轮次和委派任务准备绑定的 Skill；OpenCode 可读取应用提供的 Skill 参考文件。选择与使用方法见[扩展分析案例](../workflows/extend-analysis.md) |
| Side Chat | Main 正在运行或等待审批本身不再阻止旁聊；切换应用视图时保留旁聊，仍需满足旁聊自身的历史保存、恢复和只读状态要求。[Side Chat](../guides/delegation.md) |
| 网页搜索授权 | 受支持的 Claude Agent 原生搜索可以记住 **Allow for this conversation**；搜索与网页读取仍是两项独立授权。[权限说明](../guides/approval-modes.md#remember-web-search) |
| Reviewer | 启动会话时保留 Auto-review 设置，关联纠错轮次保留纠错所需的反馈；仍需检查修改后的输出及后续审阅。[Reviewer](../specialists/reviewer.md) |

## 数据与证据

[Connector 操作参考](../reference/connector-operations.md)与下载目录已更新至 v0.30.2。Reactome 按请求的受支持物种查询；Ensembl 返回实际解析的物种，并将 VEP 区域查询规范为正链。UCSC 拒绝无效坐标，gnomAD 区域坐标须小于十亿。CellGuide 和 OLS 会报告相关获取或分页失败，避免把它们呈现为空证据。

PubMed 作者解析更正了姓氏、名字缩写与后缀的区分。`literature-review` Skill 会检查 Crossref 两个方向的撤稿关系；未发现标记不能证明论文从未撤稿。参阅[元数据核对](../guides/library.md)和[文献证据提取](../workflows/literature-review.md)。

## Notebook 与恢复

Windows 修复涉及 conda R 启动、环境准备后的可执行文件查找、R 内核恢复，以及验证环境中的 pip 入口。Notebook 重放可恢复受支持的同轮输入与标准库导入；Linux 临时挂载目录下的读取授权也已修正。参阅[运行环境](../guides/runtimes.md)和[可复现性](../guides/reproducibility.md)。

以上依据发布说明和对应源码。既有 Windows 与 Specialist 截图保留原版本，不是 v0.30.2 新实测结果。缺失的输入证据或环境锁仍需处理，可复现检查仍针对具体的已捕获结果版本。

## 其他改进

提供方目录加入 DeepSeek V4.1 Flash，并更新火山引擎 Ark 模型，同时保留旧的固定模型选择。市场卡片在缺少作者时显示来源；OpenCode 委派任务使用独立运行时。另修正 CLI 排队会话快照，以及部分设置、标签、文献和工具卡片交互。

更新步骤见[安装与更新](../guides/installation.md)，前一版本见 [v0.30.1](./v0.30.1.md)。
