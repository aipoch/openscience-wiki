# 更新日志 · v1.3.3

发布于 **2026 年 11 月 22 日（UTC）**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.3.3)。

## 让更新配合你的工作节奏 {/* #updates */}

符合条件的 macOS 官方稳定版可在退出应用时安装已准备好的更新。Windows 和 Linux 可在桌面处于后台空闲时，为下次启动准备更新。自动下载要求非计量、未受限制的网络连接和足够存储空间；不支持的安装位置或渠道仍使用手动方式。Linux AppImage 更新保留应用路径。Windows v1.3.3 使用完整安装包；[v1.3.4](v1.3.4.md#updates) 恢复小体积差分包。见[自动与手动更新](../guides/installation.md#update-progress)。

macOS 和 Windows 的安装体积缩小，离线 npm 运行时也改为面向 Node 22 的打包形式，减少零散文件。

## 各种安装方式统一默认使用内置 Agent {/* #agent */}

新项目和会话默认使用 **Open-Science Agent**，包括全新的 CLI 和 SDK 安装。缺少外部 Agent SDK 不再阻止这些安装启动；仅在选择外部框架时才需要安装它，模型接入仍需单独配置。见 [Agent 设置](../guides/frameworks.md#built-in-agent)与 [CLI 设置](../reference/cli.md#terminal-setup)。

Settings 恢复了已安装 Skills、Specialists 和 Connectors 的快捷入口。百炼模型目录加入 qwen4 系列，其套餐默认模型改为 qwen4 预览版；开始任务前仍应检查账户实际可用的模型。

## 在会话中编辑图片 {/* #images */}

从预览进入 **Edit image**，在会话输入框中填写修改要求。编辑时仍可切换版本、比较图片，进入编辑也不会移动会话消息的位置。图片详情显示生成该次编辑的 Notebook 内核。见[图片编辑步骤](../guides/image-generation.md#edit)。

PDF 翻译进一步重组被分栏、图注和行内公式切断的正文，避免译文挤占原生符号、表单标签与相邻图形的位置。导出后仍需对照原文检查。见 [PDF 翻译](../guides/pdf-translation.md#scientific-layout)。

## 更清楚的错误与恢复提示 {/* #recovery */}

- 请求、加载、附件、导入和 Notebook 错误给出具体原因。提供商错误在重启后仍保留分类与请求 ID；用户停止的任务与未收到后续响应的任务分开显示。见[故障排查](../guides/troubleshooting.md#provider-errors)。
- Windows 保留内置 Agent 在重启前等待回答的问题，恢复 Notebook 运行时状态，并在冷启动时重新检查过期的文件占用。
- Notebook 内存检查考虑 Windows 物理内存、macOS 内存压力和 Linux 容器限制。见[内存与资源](../guides/notebook.md#memory-resources)。
- 会话研究包导出先等待 Notebook 读取结束，再说明导出失败的原因；同时修复已保存产物链接、确认后的记忆删除和 GitHub Skill 导入错误提示。

见[安装与更新](../guides/installation.md)及 [v1.3.2](v1.3.2.md)。
