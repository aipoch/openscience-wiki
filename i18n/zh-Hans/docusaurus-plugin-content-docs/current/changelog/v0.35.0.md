# 更新日志 · v0.35.0

发布于 **2026-10-04 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.35.0)。

## 回放并讨论研究过程

**View replay** 展示已记录会话，支持播放、步骤跳转、Notebook 记录和文件版本历史。**Ask about this step** 可将所选上下文带入可写会话讨论。导入的 `.science` 研究仍为只读，需要继续执行时应 Fork。回放不会重新运行代码，完整操作见新增的[会话回放指南](../guides/session-replay.md)。

## 科学数据库

本版新增 **13 个操作**，注册表达到 **34 个 Connector、339 个操作**：其中 33 个数据源家族共 337 个操作，另有离线 Molecule 的两个操作。

| 入口 | 新增能力 |
| --- | --- |
| Cellosaurus | 细胞系身份、别名和质量注释 |
| Monarch Initiative | 疾病或基因与表型的关联及来源证据 |
| IEDB | 表位、抗原、T 细胞、B 细胞和 MHC 实验及文献 |
| Omics Archives → GEO | 发现矩阵文件位置，预检查已经读取的矩阵文本 |
| Structures & Interactions → PDB | 按蛋白质序列搜索结构，支持一致性、E-value 和查询覆盖度筛选 |

见[能力与连接步骤](../tools/databases.md#cell-lines-phenotypes-immunity)及[更新后的操作目录](../reference/connector-operations.md)。GEO 预检查读取传入文本，不读取磁盘文件；矩阵发现也不会自动下载文件。

## PDF 与工作区操作

- 上传的 PDF 与生成的、文献库中的 PDF 一样，可以使用 **Figures and tables** 提取图表。受控并行分析改善处理速度，并加强复杂版式的处理，见 [PDF 提取](../guides/previews.md#pdf-extraction)。
- 可在会话区域拖入文件作为附件，发送前检查附件内容，见[拖放文件](../guides/composer.md#conversation-drop)。
- 用量图表支持连续查看不同日期，见[每日用量](../guides/usage.md#inspect-daily-usage)。
- Windows 标题栏加入原生应用菜单；PDF 大纲与笔记更好地适配窄窗口。

## 模型与网络访问

OpenCode Zen 模型目录扩展，在支持的角色中提供 Jev 分类模型。主模型与分类模型仍分别设置，见[模型目录](../guides/providers.md#catalog-models)。

网络设置区分公网域名规则与可信私有服务。私有授权绑定完整主机名、端口和审核过的 DNS 地址，保存前再次检查 DNS。见[公网规则](../guides/network.md#public-network-rules)和[私有服务](../guides/network.md#trusted-private-services)。

## 修复

修复涵盖会话结果和等待审批状态的保存、回放 Notebook 状态和文件列表、科学执行溯源、Codex 文件夹权限、Windows 运行时启动及沙箱访问，以及 WSL 文件夹路径。`.science` 包内相同对象会去重；提供商和项目草稿增加防止意外丢失的保护。
