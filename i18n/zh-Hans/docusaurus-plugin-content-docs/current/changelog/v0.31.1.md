# 更新日志 · v0.31.1

发布于 2026 年 9 月 20 日。新增数据库操作覆盖测序运行、基因集富集和参考基因组身份核对；分类模型为可选设置。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.31.1) · [相对 v0.31.0 的变更](https://github.com/aipoch/open-science/compare/v0.31.0...v0.31.1)

## 新增数据库操作

| 能力 | 从哪里开始 |
| --- | --- |
| ENA 测序运行与 FASTQ 清单 | 解析 ENA/INSDC 登录号，检查截断标志，再查询文件地址、大小与上游校验值。工具本身不下载或校验文件。[测序数据](../tools/databases.md#ena-runs) |
| g:Profiler 富集 | 核对物种和数据源版本，指定基因集与背景，再检查映射及校正结果。[带结果文件的实操案例](../tools/databases.md#gene-set-enrichment) |
| NCBI 参考基因组 | 消除物种歧义，核对带版本的组装，并在合并来源前转换序列别名。[参考身份](../tools/databases.md#reference-genome) |

[操作参考](../reference/connector-operations.md)与下载注册表已更新到 v0.31.1：仍为 24 个 Connector，包含 **244 个数据源操作**及两个 Molecule 操作。

## 设置与恢复

[分类模型](../guides/models.md#classification-models)位于 **Settings → Model** 内的标签页。配置兼容服务后，可辅助受支持主会话的能力选择；不配置也可使用 **Use default method**。添加分类服务不会替换 Main。

[远程配对](../guides/remote-access.md#pairing-v0311)将待处理请求放到受信浏览器列表上方，并显示到期倒计时。接受前核对屏幕代码；撤销当前浏览器会移除它自己的访问权限。

网络保护阻止 R 运行时，[内联提示](../guides/network.md#r-network-warning)会说明单元格未执行，并链接到相关设置。修改设置不等于已经重跑成功。

## 修复 {/* #修复与验证范围 */}

修复涉及 Windows 常驻内核与包列表、会话恢复、审批卡片焦点、PDF 图表提取、GTEx 分页、Open Targets 部分错误及 hg19 保守性默认轨道。

使用方法见[研究包](../guides/research-packages.md)、[数据库查询](../tools/databases.md)和[分类模型](../guides/models.md#classification-models)。上一版为 [v0.31.0](./v0.31.0.md)。
