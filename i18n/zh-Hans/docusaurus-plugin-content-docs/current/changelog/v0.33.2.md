# 更新日志 · v0.33.2

发布于 **2026-09-24**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## 安装与文献阅读

官方 Windows 安装程序加入代码签名；应用下载入口指向官方下载页及校验说明。见[安装与更新](../guides/installation.md)。来源网页预览保留登录会话等站点状态，再次访问及重启应用后可继续使用。见[来源网页预览](../guides/previews.md#persistent-source-preview)。

**Auto** 模式减少内置文献库操作的重复批准提示，文件、网络和资源规则仍然适用。见[文献库批准规则](../guides/approval-modes.md#library-auto)。

## STRING 互作富集

**Protein Annotation** 新增 STRING PPI enrichment，检查一组蛋白的互作数量是否高于背景预期。它与通路富集是不同的统计问题。见[基因集富集工作流](../workflows/gene-set-enrichment.md#enrichr-string)及[参数参考](../reference/connector-operations.md#get_string_ppi_enrichment)。

## 改进与修复

委派任务完成的结果在后续清理失败时得以保留；更新 Figure Composer 流程、文件预览图标及智能集合布局。另修复 macOS Notebook 清理状态隔离、代理路由与退出处理，并关闭 Codex 后端的插件和应用发现。
