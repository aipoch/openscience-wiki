# 更新日志 · v1.0.8

发布于 **2026-11-04 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.8)。

## 把一份阅读清单带进文献库 {/* #literature */}

手头有一串论文编号？**Add from DOI or link** 现在一次可以接收最多 100 个非空行，混合填写 DOI、arXiv、PMID、PMCID 或支持的官方论文链接。核对识别结果和重复记录处理方式后再导入；找到文献信息不等于已经取得全文。[批量导入教程](../guides/library.md#doi-link-import)。

文献详情新增 **Study overview**。配置好的主模型会根据可用来源，整理研究问题、研究对象、方法、主要发现和局限五个部分。来源标签区分摘要、全文和选取的段落。可以用它快速了解论文，再回到原文核查重要论断。[生成论文概览](../guides/library.md#study-overview)。

## 设置各归其位 {/* #settings */}

**Appearance** 和 **Notifications** 成为 **System** 下的独立面板。General 保留应用信息、诊断、命令行工具和帮助，并提供手动安装指南入口。设置中心现在共 **四组、19 个面板**。[设置总览](../settings/overview.md) · [外观与通知](../guides/appearance.md)。

## 科研与日常使用的修复 {/* #reliability */}

- eQTL Catalogue 在旧 REST API 停用后，改用 release-7 索引文件。查询必须明确提供 **GRCh38** 坐标，不能再只传基因 ID。[坐标要求](../tools/databases.md#eqtl-coordinates)。
- PDF 排序结合文字位置区分正文分栏与表格行；提取时检查裁剪边界，无法可靠解释的单元格保留原始文字并提示可靠性问题。[PDF 阅读与提取](../guides/previews.md#automatic-pdf-reading-order)。
- R 复现检查会在可能触发参数求值或方法分派的操作后，撤销过期的文件证据。溯源面板会解释执行证据不完整的情况；打开旧 Markdown 产物时会修复过期的历史指向。[理解验证证据](../guides/reproducibility.md#execution-evidence)。
- 五种 Agent 框架在会话完成后释放提供方和工具进程；修复打包桌面版中 Pi 的安装问题。
- 更新准备更清楚地显示阻塞进程，并修复 macOS 只读文件占用、Windows 进程识别和过期 Notebook 恢复记录的问题。诊断包保留桌面恢复失败的实际错误。[更新指南](../guides/installation.md#update-preparation)。
- 下载完成后，目标目录不可读或后续清理报错不再使已保存的文件失效。Windows PDF 退出清理和保护检查更稳定；PATH 中的旧 Node 无法使用代理时，Notebook 命令行工具可以使用应用自带的 Node。
- 重新查找全文成功后会清除之前的 PDF 添加错误；Composer 不再重复显示模型不可用提示。

腾讯 TokenHub 新增 Hy4 和支持百万 Token 上下文的 DeepSeek V4.1 Flash 路由，并为 GLM-5.3-Flash、Kimi K3、MiniMax M3 增加图像输入。实际可用性取决于提供方账户和所选路由。[提供方配置](../guides/providers.md)。

内置目录仍为 **48 个 Connector、418 项操作**。[当前目录](../tools/databases.md#supported-databases) · [上一版本](v1.0.7.md)。
