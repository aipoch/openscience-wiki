# 更新日志 · v0.33.1

发布于 **2026 年 9 月 24 日**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.33.1)。

## 文献筛选与 PDF 阅读

智能集合新增实时 **Screening process**，可暂停、继续，并跳转到范围对应的项目或集合。续跑要求保存的运行仍与规则、文献兼容，人工决定仍决定最终成员。见[筛选与复核文献](../workflows/screen-literature.md)。

PDF 证据可随工作区第一条消息发送。在 Library 打开 PDF，选择 **Read with agent** 和项目，发送问题前检查 Reading 中的文件。见 [PDF 上下文](../guides/previews.md#first-message-pdf)。

## 科学数据库 Connector

- **HMMER** 新增按程序选择的蛋白序列／profile／比对检索、任务状态与完整结果。
- **InterProScan** 查询已有注释任务并获取 TSV，不支持提交任务。
- **Genomes** 新增 Clustal Omega，输入至少三条 FASTA，见[多序列比对工作流](../workflows/multiple-sequence-alignment.md)。
- **OpenAlex** 在应用中不再强制要求密钥，服务方限额仍适用，见[可选凭据配置](../tools/credentials.md)。

完整注册表现有 **28 个 Connector、271 个操作**，其中包括离线 Molecule Connector。[数据库能力](../tools/databases.md) · [操作参考](../reference/connector-operations.md)。

## 设置、诊断与修复

提供商目录新增 GPT-6 和 Claude Opus 5.5，能否使用仍取决于账户权限和框架兼容性，见[模型提供商](../guides/providers.md#catalog-models)。

会话诊断区分研究包导出触发的脱敏扫描证据和原始文件。原始敏感文件默认不勾选，仅主动选择后包含，导出保存在本地，见[诊断导出](../guides/troubleshooting.md#session-diagnostics)。

设置页头与局部搜索使用不同快捷键；升级会保留历史数据位置。其他修复包括 Windows 托管 Python 发现、R 访问被拒绝提示、运行环境与计算设置保存竞争、ACP 图像能力变化、首次发送的 PDF 标识、重复发送，以及图像裁剪和修订流程。[快捷键](../guides/shortcuts.md#local-settings-search) · [存储位置](../guides/storage.md#historical-data-location)。
