# 更新日志 · v0.32.0

发布于 2026 年 9 月 21 日。本版新增持久保存的 PDF 阅读笔记、序列相似性检索，以及公共测序和蛋白质组数据的发现方式。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.32.0) · [相对 v0.31.1 的变化](https://github.com/aipoch/open-science/compare/v0.31.1...v0.32.0)

## PDF 批注与文档笔记

高亮段落、标记区域，或添加页面笔记和文档笔记。笔记属于受管理的文件版本，可附评论与标签。可以在笔记视图或全局搜索中找回，并导出 Markdown、CSV 或带批注的独立 PDF。原始 PDF 字节保持不变。

文献库附件在使用同一受管理版本的位置共享笔记；项目上传文件和产物在所属项目的会话间共享。标注、搜索和导出步骤见[带截图的 PDF 笔记教程](../guides/pdf-notes.md)。这类笔记与[会话私有书签](../guides/bookmarks.md)用途不同。

## 序列与组学数据发现

| 能力 | 使用入口 |
| --- | --- |
| UniProt 发现 | 按基因、蛋白名称短语和物种查找条目，再获取选中条目的序列。见[蛋白检索](../workflows/protein-sequence-search.md#sequence-search) |
| NCBI BLAST | 提交公开的核酸或蛋白序列，保留 RID，按规定间隔查询状态并获取完成后的报告。见[序列检索](../workflows/protein-sequence-search.md#sequence-search) |
| ENA 发现 | 组合物种、文库策略和关键词条件，分别列出归档 FASTQ 与原始提交文件。见[发现与文件清单](../workflows/public-omics-data.md#omics-discovery) |
| PRIDE 文件列表 | 分页读取项目文件元数据和公开下载位置，无需下载数据文件。见[文件清单](../workflows/public-omics-data.md#omics-discovery) |

[操作参考](../reference/connector-operations.md)现覆盖 **251 个数据源操作**，另有两个 Molecule 操作，共 24 个 Connector。gnomAD 线粒体查询接受 `gnomad_r3` 和 `gnomad_r4` 数据集。

## 模型与自动化

- **Custom HTTP service** 可把能力选择连接到兼容 TypeSafe 的分类服务。它有独立的端点、模型和密钥，不会更换 Main。见[分类模型](../guides/models.md#custom-classification)。
- **StepFun Step-5 Preview** 新增 China 和 Global 区域，在[提供方设置](../guides/providers.md#stepfun-regions)中选择端点区域。
- 本地 PDF 解析模型在主下载源不可达时，可使用经过批准并校验完整性的备用镜像。见[PDF 提取](../guides/previews.md#pdf-extraction)。
- [CLI](../reference/cli.md#unattended-runs) 和 [SDK](../reference/api.md#unattended-runs) 任务可使用 `permission-prompts none` 拒绝需要等待人工处理的请求。原有审批规则仍然生效，不会自动授予权限。

本版还在导出后端增加完整的 RO-Crate 1.1 打包配置：包含已验证的产物版本及精确输入文件，核对声明的大小与校验和、合并相同内容，并拒绝冲突。Wiki 中的桌面操作仍按现有 [.science 交接](../guides/research-packages.md)和[逐版本可复现性检查](../guides/reproducibility.md)教程进行。

## 修复与交互变化

[Side Chat](../guides/delegation.md#side-chat-可用范围) 的对话和待送达建议保留在本次应用运行中。切换视图或重新加载界面时可重新连接。确认 **Close Side chat** 会移除该旁聊，完整重启应用会清除其余旁聊。已经送达 Main 的消息仍保留在 Main 中。

其他变化涉及启动和长会话性能、链接 PDF 阅读、后台计算结果交付与取消、OpenCode 会话间工具隔离、PDF 文本选择、设置搜索、文件焦点和恢复提示。完整列表见官方发布说明。上一版为 [v0.31.1](./v0.31.1.md)。
