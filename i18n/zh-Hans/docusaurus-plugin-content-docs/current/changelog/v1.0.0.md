## 升级到 1.0 {/* #upgrade */}

1.0 将现有科研工作区纳入稳定版本线，继续支持历史配置升级与 `.science` 导入；版本号变化不要求新建配置或更换数据格式。先备份配置和科研数据、结束活动任务，再使用官方桌面安装器升级。降级程序不会撤销数据变化。

本次仅发布**桌面安装包**，不含独立 CLI 归档和 Linux CLI `.deb`／`.rpm`；网站下载和自动更新通道单独发布。需要 1.0 命令行入口时使用桌面附带的启动器，不要重命名旧归档，也不要推断 Homebrew／npm 已提供同版本。`open-science update` 已移除，改用桌面控件或原安装器／包管理器。见[安装与 1.x 兼容范围](../guides/installation.md#version-compatibility)。

## 继续中断的工作 {/* #recovery */}

原桌面控制连接断开后，兼容桌面可以接管仍存活的桌面后端；CLI 启动的服务仍保持独立。关闭准备失败时保留窗口，重连会先恢复原会话状态，再允许继续操作。响应丢失时先检查已保存操作，避免重复提交。见[服务归属与恢复](../reference/server.md#desktop-service-recovery)。

ACP 会话按选中的代理继续；切换 Specialist 后，Codex 脱离会话的恢复也得到修复。发送下一条消息前，[检查所选代理与原会话](../guides/sessions.md#resume-selected-agent)。本版同时修复文献选择状态和上下文压缩期间的取消处理。

## 回答问题与阅读 PDF {/* #interaction */}

- 澄清卡片支持更长的选项列表和多选。前后检查回答，最后点 **Finish**；仅选中选项仍是草稿。见[回答澄清问题](../guides/composer.md#clarification-questions)。
- PDF 笔记按钮在悬停、聚焦或选中标记时出现，减少阅读遮挡。见[按需显示笔记入口](../guides/pdf-notes.md#reveal-note)。
- PDF 提取和翻译进一步保留复杂排版、原生表格与图片归属、科学分式。**New translation** 会重新准备源文本，复用前仍需对照原文。见[提取核对](../guides/previews.md#scientific-structure-check)与[全文翻译](../guides/pdf-translation.md#scientific-layout)。

## 保留科学数据的背景 {/* #data-context */}

| 来源 | 变化 |
| --- | --- |
| ArrayExpress | 区分 SDRF 关系行与去重后的样本标识，标识不完整时样本计数可为未知 |
| MetaboLights | 保留样本表重名列及原始顺序，避免覆盖值 |
| Bgee | 保留解剖结构与细胞类型，缺失细胞类型仍为 `null` |
| dbSNP | 保留同一定位结果关联的全部染色体／组装信息 |
| OpenAlex | 按会话记住已拒绝的凭据提示 |

复用旧查询前，查看[字段解读说明](../tools/databases.md#scientific-context)与 [v1.0.0 Connector 参考](../reference/connector-operations.md)。Notebook 风险分析也改进了 Promise 回调的处理；原有批准要求仍然适用。

## 1.0 没有改变的范围 {/* #scope */}

录制的会话回放不执行代码。产物验证需要符合条件的输入记录与可用环境，不代表科学结论已成立，也不保证整个会话确定性复现。导入的 `.science` 仍为只读，继续编辑需 Fork；包不会恢复凭据、Side Chat 或私人书签。远程计算继续支持 SSH／Slurm；托管云 GPU 提交、本地 GPU 后端和多人实时编辑不在本版范围内。
