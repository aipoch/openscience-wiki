# 更新日志 · v0.35.1

发布于 **2026-10-06 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.35.1)。

## 开始与管理会话

新会话页把研究任务建议放在输入区旁，并简化 **Import previous research** 入口。选择建议会填入可编辑的草稿，不会直接发送。见[从研究任务建议开始](../guides/composer.md#research-starters)。

会话顶部的 **Session actions** 菜单集中提供编辑、置顶、Side Chat、Fork、导出及归档。导出子菜单区分对话、研究包和诊断材料。Side Chat 标签与工具栏也更加紧凑。见[会话操作](../guides/sessions.md#session-header-menu)。

## 科学数据库

新增四个操作，注册表达到 **34 个 Connector、343 个操作**：33 个数据源家族提供 341 个操作，另有两个离线 Molecule 操作。

| 入口 | 新增能力 | 使用说明 |
| --- | --- | --- |
| Human Genetics → GWAS Catalog | 发现完整汇总统计文件的位置、元数据和声明的参考基因组，不下载大型文件 | [GWAS 文件](../tools/databases.md#gwas-summary-statistics) |
| InterProScan | 提交蛋白序列，再查询状态并获取 TSV 注释 | [联系邮箱与提交步骤](../tools/databases.md#interproscan-submit) |
| IEDB | 检索 TCR 与 BCR 受体证据，保留实验与来源引用 | [受体证据](../tools/databases.md#iedb-receptors) |

[操作参数参考](../reference/connector-operations.md)同步补充必填字段、限制和准确调用示例。聚合后的受体证据不能证明所有条件在同一实验中成立。

## Requesty 与模型目录

**Requesty** 加入官方提供商选择器，提供内置连接验证和整理后的模型列表。OpenRouter 目录也已更新。实际可用协议与模型取决于当前 Agent 和账号权限，不会自动替换已保存的 Main 模型。见 [Requesty 配置](../guides/providers.md#requesty)。

## PDF 阅读与笔记

首次请求开始前会保留 PDF 上下文，包括刚上传的附件。见[上传后直接阅读](../guides/previews.md#uploaded-first-message)。复杂版式提取有所改进，阅读器减少了持续显示的提示。

经核验内容相同的 PDF 副本可以跨项目共享文档笔记，包括上传文件和产物。同名文件不足以建立共享关系，笔记也不会跨设备同步。见[笔记共享范围](../guides/pdf-notes.md#笔记的共享范围)。

## 稳定性修复

修复涉及回放追问的滚动与记录文件提问、导入会话的只读历史，以及会话绑定变化时输入区上下文的保留。回放读取已有记录，不会重新运行代码。见[会话回放](../guides/session-replay.md)。

Notebook 修复涉及跨语言文件来源关系、损坏运行记录的隔离恢复，以及路径包含空格时的 R 环境。其他修复包括默认隔离共享登录设置、解释无人值守 Claude 的权限拒绝，以及书签、标题栏浮层和产物事务重试。
