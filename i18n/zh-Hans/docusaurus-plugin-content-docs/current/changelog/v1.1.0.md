# 更新日志 · v1.1.0

发布于 **2026-11-06 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.1.0)。

## 把会话做成研究影片 {/* #research-films */}

已完成的会话可以生成带英文旁白的短片。安装本地旁白资源后，从桌面端会话启动生成，检查播放内容，再分享便携播放器或导出 MP4。影片用于呈现已有研究，不会重新执行或验证分析。[研究影片教程](../guides/research-films.md)。

## 批量处理阅读清单 {/* #literature */}

一次选择最多五篇文献，批量生成论文概览。可以暂停、继续未完成项目或重试失败条目，已完成的概览会保留。CLI 与 MCP 也新增了文献库搜索、引用格式化和文献管理操作。[批量概览](../guides/library.md#batch-overviews) · [文献命令](../reference/cli.md#literature-library)。

## 用手机打开工作区 {/* #mobile */}

手机或平板可以扫描二维码，通过同一 WiFi 或 Pinggy 互联网隧道连接。保持主机运行，并在扫码前检查连接状态。[连接方式](../guides/remote-access.md#mobile-pairing)。

## 日常使用改进 {/* #reliability */}

- Compute 设置移至 **Connections** 分组，研究案例库调整了布局和导入目的地提示。
- 改善中断和存储失败后的会话恢复，更及时地释放已完成或闲置的 Agent 连接。
- 诊断导出保留 Notebook 执行证据与历史后端日志；Windows 新增可选的资源记录功能，方便排查问题。
- PDF 提取改善可搜索扫描件的图表恢复，Codex Chat 支持原生图片输入。
- Notebook 优先使用已就绪的应用托管运行环境；Shell 执行失败以工具错误返回。
- Windows 更新准备检查进程身份和占用文件，本地 `.science` 与 MP4 导出更可靠地处理桌面保存对话框。

另见[安装与更新](../guides/installation.md)及[上一版本](v1.0.8.md)。
