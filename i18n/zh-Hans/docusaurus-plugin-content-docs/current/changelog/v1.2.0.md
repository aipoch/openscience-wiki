# 更新日志 · v1.2.0

发布于 **2026-11-09 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.2.0)。

## 选择计算在哪里运行 {/* #remote-compute */}

在 Direct SSH 和 Slurm 之外，新增 Kubernetes、Hugging Face Jobs、Modal 和 Ray。配置目标后，核对冻结的输入、命令、资源及输出收集范围，再逐次批准外部提交。重启后可依据恢复记录继续收集，已发布的输出从 **Compute Preview** 打开。这些方式使用你自己的基础设施或云账户。[远程计算配置](../guides/remote-compute.md#compute-backends)。

## 从内置 Agent 开始 {/* #agent */}

全新配置默认使用 **Open-Science Agent**，这是随应用提供、可连接兼容模型服务商的内置运行时。Claude Agent、OpenCode、Codex、CodeBuddy 和 Pi 仍然可用。运行时与模型提供方是独立选择，现有 Codex 配置不必更换。[Agent 选择](../guides/frameworks.md#built-in-agent)。

## 围绕具体研究步骤讨论 {/* #discussions */}

导入的 `.science` 研究及回放步骤支持关联的子讨论。**Ask about this step** 会把选中的证据带入讨论，也包括已记录的 Notebook 运行。导入历史突出显示 **Fork to continue**，用于建立可继续操作的分支。侧栏按 **Pinned**、**Imported research**、**Active**、**Recents** 分组。[回放讨论](../guides/session-replay.md#discuss-replay) · [研究包](../guides/research-packages.md#linked-discussions)。

## 更轻的更新和更清晰的操作 {/* #reliability */}

- macOS 更新可只下载变化的数据块，需要时自动回退到完整下载；安装检查会核对正在运行的应用，并指出占用文件或进程。
- **Local capabilities** 取代 **Local parsing models** 标签页，集中管理 PDF 提取、OCR 和研究旁白。[本地资源](../guides/models.md#local-capabilities)。
- 手动添加文献允许只输入标识符而不填标题，包括 PMID；影片控件避免在加载时闪现不可用操作。
- PDF 提取改善正文与表格结构；固定版式翻译在个别页面失败时保留其他成功页面，分享前应检查未完成页。[PDF 翻译](../guides/pdf-translation.md)。
- Notebook 分析移出界面线程；Windows 修复托管 R 的 DLL 加载及任务栏周围的窗口边界。
- 在较早的会话位置发送消息时保留阅读位置，并改善工具错误、来源链接预览和启动诊断。

另见[安装与更新](../guides/installation.md)。研究影片及批量概览见 [v1.1.0](v1.1.0.md)，完整修复列表见官方发布说明。
