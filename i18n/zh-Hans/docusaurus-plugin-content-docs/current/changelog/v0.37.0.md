# 更新日志 · v0.37.0

发布于 **2026-10-11 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.37.0).

## 不打开桌面窗口也能运行

桌面、浏览器、CLI 和 Notebook 现在共用普通 Node 后端。`open-science start` 不再启动隐藏的 Electron 进程。官方发行版提供包含 Node 与后端的独立 CLI 压缩包，使用这些压缩包无需另装 Node。未指定端口时，桌面后端会选择空闲端口。

安装与 Codex 登录见[终端设置](../reference/cli.md#terminal-setup)。关闭桌面客户端或停止共享后端前，先了解[服务归属与关闭规则](../reference/server.md#backend-ownership)。

## 更多数据库证据

接口目录现有 **36 个 Connector、361 项操作**：其中 35 类数据源包含 359 项操作，另有两项离线 Molecule 操作。

| 入口 | 变化 | 说明 |
| --- | --- | --- |
| ENCORI | 十项操作，覆盖 miRNA 靶标、RNA–RNA 与 RBP 互作、ceRNA 网络、motif 扫描、结合位点、参考表和批量文件 | [连接与结果边界](../tools/databases.md#encori) |
| ChEMBL | 实验详情，以及超过前 1,000 条记录的活性数据分页 | [实验条件与分页](../tools/databases.md#assay-submission-evidence) |
| ClinVar | 查询 VCV 记录中的逐条 SCV 提交证据 | [比较提交记录](../tools/databases.md#assay-submission-evidence) |

保留结果的物种、参考基因组、过滤条件与证据类型。实验置信度描述靶标归属；ClinVar 提交记录不等于独立临床诊断。精确字段与可下载目录见[操作参考](../reference/connector-operations.md)。

## PDF 阅读与 Notebook 执行

PDF 翻译改进原生阅读顺序与嵌套文本标签。结构提取更完整地保留归属于原文的图像和表格记录。仍应对照原文检查[图表](../guides/previews.md#pdf-extraction)与[翻译页面](../guides/pdf-translation.md#compare-export)。

已就绪的默认 Notebook 运行时减少重复设置授权，混合 Conda/pip 环境、micromamba 构建信息以及输入和回调依赖的记录更加准确。这些记录可辅助[重跑验证](../guides/reproducibility.md)，本身不代表结果可复现。

## 恢复与平台修复

- 修复 `.science` 导入新项目时的目录接纳失败。导入会话仍为只读，继续分析请使用 [Fork](../guides/research-packages.md)。
- 智能集合重试失败批次并保留已完成部分，见[集合筛选](../guides/library.md#smart-collections)。
- 改进 Plan 批准／关闭和 Codex 流式工具参数的恢复；Auto 模式减少受支持查看操作的重复授权。
- Windows 修复含空格或括号的 Python 路径、选定后端配置与 Specialist 交接；Linux 凭据避免首次秘密操作后重复探测 Secret Service。
- PDB 拒绝格式异常的查询响应，并保留未完成的分页状态；报错不能解释为零命中。
- 首页增加首次创建项目引导；无界面及 SDK 执行恢复对附带 Notebook 资源的定位。
