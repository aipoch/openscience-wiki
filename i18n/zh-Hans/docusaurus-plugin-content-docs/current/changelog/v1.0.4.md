# 更新日志 · v1.0.4

发布于 **2026-10-27 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.0.4)。

## 让其他工具连接科研工作台 {/* #mcp */}

独立 CLI 提供 stdio MCP 适配器。先启动已认证的本地服务，再让客户端连接该配置。工具可以创建项目、修改配置，并在已有权限范围内运行研究任务，包括写入文件和产生模型费用。[MCP 配置与控制](../reference/cli.md#external-mcp)。

## 检查论文的出版通知 {/* #publication */}

在文献库中，可对具有有效 DOI 的记录手动查询 Crossref 撤稿与更正通知。结果保留来源和检查时间；没有返回通知并不保证论文不受影响。[检查与解读通知](../guides/library.md#publication-checks)。

## 日常工作更容易整理 {/* #workspace */}

- 一轮结束后收起中间消息与工具分组，搜索和批注可以展开对应内容。[展开会话](../guides/sessions.md#collapsed-conversation)。
- 将已授权文件夹内的文件保存为会话中的不可变产物。[导入本地文件](../guides/files.md#import-local-artifact)。
- 收藏已扫描的 GitHub Skill 仓库，便于再次使用；不会自动更新 Skill。[保存仓库](../skills/manage.md#saved-repositories)。
- 问题卡提供明确的 **Skip** 和 **Skip all** 操作。[问题卡控制](../guides/composer.md#skip-question)。

安装包体积缩小，同时修复 Windows Notebook 标准模式执行、选定保存位置后研究包导出仍等待、文件夹授权对话框、问题卡恢复及回放事件展示等问题。[研究包传输](../guides/research-packages.md#local-package-transfer) · [上一版本：v1.0.3](v1.0.3.md)。
