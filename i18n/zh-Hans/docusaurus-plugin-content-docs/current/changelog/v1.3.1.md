# 更新日志 · v1.3.1

发布于 **2026-11-19 UTC**。[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v1.3.1)。

## 查找来源，沿引用继续阅读 {/* #sources */}

内置 Open-Science Agent 可以搜索公开网页并阅读正文，来源引用随会话保留。搜索授权卡片会展示搜索词和过滤条件。搜索词发送到 Exa，阅读网页则连接目标网站。[网页搜索与阅读](../tools/web-search.md)。

文献库新增交互式引用图。可以筛选参考文献和施引文献，把相关论文设为新的中心，再返回原始论文。候选文献先在 Inbox 审核，再收入文献库。[探索引用图](../guides/library.md#citation-discovery)。

## 连接外部 Agent 与组织资源 {/* #connections */}

外部 MCP 客户端连接时，现在可以自动启动或复用本地 Open-Science 服务。客户端断开后，服务仍会运行；使用完毕后需要主动停止。[MCP 配置](../reference/cli.md#external-mcp)。

桌面版可登录 Lab 账户，使用组织分配的模型和共享研究案例。模型请求和共享研究包会发送到配置的 Lab 服务器。[Lab 账户设置](../guides/providers.md#lab-account) · [组织案例](../guides/research-packages.md#organization-cases)。

## 更清楚地管理模型与资源 {/* #controls */}

- 在 Settings 刷新受支持提供商的模型列表。刷新失败会保留原有列表；会话错误会说明认证、额度、限流等具体原因。[提供商设置](../guides/providers.md#refresh-models)。
- 保存图像服务前，可以选择执行一次测试生成。尚无默认模型时，会自动选中首个模型。[图像服务配置](../guides/image-generation.md#configure)。
- Notebook 执行前会检查内存。可以在 Compute 检查并释放某个会话的本地 Notebook 资源，再决定是否重试任务。[内存与资源管理](../guides/notebook.md#memory-resources)。
- 项目首页启动更快。重新连接时保留草稿，恢复较长的分支历史和待回答问题；研究影片播放不再等待与播放无关的质量审查。

## 从 v1.3.0 更新 {/* #update */}

v1.3.0 更新程序可能把应用自身进程误判为占用安装目录的外部程序。如果因此阻止更新，先完成当前任务，彻底退出应用及其后台服务，再手动安装官方 v1.3.1 安装包。新安装包无法改变正在运行的 v1.3.0 更新程序。[手动更新步骤](../guides/installation.md#update-from-130)。

本版还修复了 Windows 更新或卸载时设置文件过大导致的失败、可选 WSL 设置阻塞首次启动、Windows 导入会话删除不完整，以及 Linux AppImage 更新误判应用自身管道的问题。研究目录不可用时，启动恢复对话框会显示具体路径，方便重新连接对应磁盘。

参见[安装与更新](../guides/installation.md)和 [v1.3.0](v1.3.0.md)。
