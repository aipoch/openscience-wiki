# 更新日志 · v0.31.0

发布于 2026 年 9 月 18 日。本版新增独立会话副本，并改进会话与连接恢复后的继续使用体验。

[官方发布说明](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [相对 v0.30.2 的变更](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## 继续使用与检查会话

- **Fork** 在桌面端创建可写副本，包含对话分支、Notebook 记录、文件版本、文献、批注和私有书签。副本使用新标识，源会话保持不变；导入会话本身仍只读。见 [Fork 操作](../guides/sessions.md#fork-session)和[研究包](../guides/research-packages.md)。
- 点击会话标题可打开[信息卡片](../guides/sessions.md#session-information)，查看来源、数量并置顶。继续创建的会话还会链接到来源消息。
- 上下文重建后，[Session Plan](../guides/planning.md#resume-plan) 保留标识、修订和待审批状态。计划恢复不代表待办步骤已经获批或执行。

## 设置与数据行为变化

| 范围 | 需要核对的内容 |
| --- | --- |
| 提供方设置 | 修改通过验证后才替换已保存配置；运行时被拒绝会更新可用状态。[模型接入](../guides/providers.md#validated-provider-save) |
| Windows R | 标准模式执行不再要求先配置保护模式；受保护执行仍有独立前提。[运行环境](../guides/runtimes.md) |
| gnomAD | 使用 `include_populations: true` 请求各人群计数和频率，同时保留数据集、参考组装与质量过滤。[参数](../reference/connector-operations.md#get_variant) |
| 产品名称 | 界面统一使用 Open-Science；已有安装位置、设置和数据保留，不要为了名称一致而重命名存储目录。[安装](../guides/installation.md#product-name) |

**STRING 兼容性变化：**`nodes` 现在描述完整返回网络，包含新增邻居。只需映射后的输入节点时筛选 `is_query`，需要全部输入别名时使用 `queries`。不能再把 `n_nodes` 当作提交蛋白数量。[STRING 使用说明](../tools/databases.md#string-network)

其他修复涉及 Codex 推理强度切换、取消与继续、UniProt 次级登录号、Ensembl 标识、临床试验纳入条件和 cBioPortal 分母。完整列表见官方发布说明。

Fork 截图在 v0.31.1 中实测取得。这里的 Windows R 变化依据发布说明与源码，旧平台截图保留原来的测试背景。下一版为 [v0.31.1](./v0.31.1.md)。
