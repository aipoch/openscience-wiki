# 設定の概要 {/* #settings-overview */}

ワークスペースの左下隅から **Settings** を開きます。 **Intelligence**、**Connections**、**Workspace**、**System**の4つのグループに、17のパネルが編成されています。 目的別にパネルを選択し、ヘッダーから検索します。 これらのガイドでは、例えば、**Settings → Model**は、インテリジェンス内のモデルパネルを参照します。

| グローバル・コントロール | ビーキャビター |
| --- | --- |
| `Back` / `Forward` | メイン設定パネルと詳細、追加、またはインポートのサブビュー間を移動する |
| Breadcrumb バックボタン | サブビューからメインパネルへ戻ります |
| `Maximize` / `Restore` | 大きいダイアログとフルスクリーン設定間の切り替え |
| `Close settings` | 正常に保存された設定を失うことなく、元のプロジェクトとセッションに戻る |
| `Dismiss settings error` | エラーバナーを閉じます。 失敗した操作は自動的に引き付けられません |
| モバイルナビゲーションボタン | 設定ナビゲーションドロワーを開くか、閉じる |

## 設定を探す {/* #find-a-setting */}

1. 設定を開き、ヘッダーに**Search settings**をフォーカスします。 **ディレクター: ⌘K** お問い合わせ macOS または **Ctrl+Kの特長** お問い合わせ Windows///////////////////////Linux 設定が有効である間、この検索に焦点を合わせます。
2. `Package mirror`、`Main model`、`Diagnostics`などのパネル名やタスクを入力します。
3. **アップ/ダウン** を使用して、結果と **エントリー** を選択してパネルを開くか、結果をクリックします。 宛先パネルは、簡単に強調表示されます。 名前付き設定を見つけます。
4. **Back** を使って戻ります。 別の設定を検索するクエリをクリアします。 パネル独自の検索フィルタは、すべての設定を検索するのではなく、リストを表示します。

この検索は、すべてのフィールドや研究文書ではなく、すべてのパネル全体に代表的な設定をカバーします。 用語が一致しない場合は、以下のパネル名またはナビゲーショングループを使用します。 会話やファイルを検索するには、設定を閉じて、[グローバル検索](../guides/navigation.md)を使用します。

## モデル設定タブ {/* #model-tabs */}

内置: **Model**, 使用 **Conversation models** プロバイダーとタスクモデルのため、 **Classification models** 任意のため Skill///////////////////////Connector 選択、および **Local parsing models** ローカルの解析リソース 分類は、モデル設定内のタブで、追加のトップレベルの設定パネルではありません。 [分類のセットアップ](../guides/models.md#classification-models) を参照してください。
