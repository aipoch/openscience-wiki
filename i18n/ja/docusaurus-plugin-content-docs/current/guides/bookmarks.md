# 個人用の読書ブックマーク {/* #private-reading-bookmarks */}

ブックマークを使用して、再訪する通路、チェックするテーブル、または後で読むためのメモを保持します。 **For me**は、現在のセッションでプライベートな読書記録を保存します。 **To Agent**は要求のための注釈を準備します; ブックマークを保存すると、メッセージが送信されず、エージェントのコンテキストに追加されます。

## 通路またはPDF領域を保存 {/* #save-a-passage-or-pdf-region */}

1. 既存の保存されたセッションを開きます。 会話またはサポートされているテキストプレビューでテキストを選択します。 PDFでは、テキストを選択するか、その領域選択制御を使用して、必要な領域をマークします。
2. 選択のアノテーション制御を開き、**For me**を選択します。
3. 「これらのパーセンテージを比較する前に、デノミネーターをチェックする」など、**Note (optional)**を追加します。 **Bookmark**を選択します。
4. Composer で **Bookmarks** を開き、保存されたエントリを確認します。 意図した通路またはPDF領域に戻すことを確認するためにそれを選択します。

会話が保存された後にブックマークが利用可能になりました。 コントロールが利用できなくなった場合は、再試行する前に既存のセッションに戻ります。 すべての埋め込まれたか、または外部に開いた視聴者は、ブックマークのテキスト選択をサポートしています。

## 戻り、編集または削除 {/* #return-edit-or-remove */}

セッションの**Bookmarks**リストを開き、エントリを選択したり、**Show bookmark source**を使用します。 管理されたファイルの場合、ブックマークは参照する保存されたファイルバージョンを再開します。 新しい結果と比較すると、ページ、通路、バージョンをチェックします。

**Edit bookmark note** をリストまたはパーシステントマーカーから選択し、ノートを編集し、**Save**を選択します。 **Cancel**は保存されたノートを変更されない残します。 **Delete bookmark**は読書透かしを取除きます; ソースメッセージやファイルを削除します。

ソースが利用できなくなったり、その正確な位置が見つからない場合は、表示されたメッセージを使用して、それらのケースを区別します。 ブックマークを交換する前に、手動でソースを検索します。 一番近い表示テキストは元の選択です仮定しません。

## プライベートと共有されているもの {/* #what-stays-private-and-what-is-shared */}

- アプリケーションを再起動した後にセッションを再開するときにブックマークとノートパーシスト。
- そのセッションに所属しています。 別のブランチに転送したり、マシン間で同期したり、セッションを削除したりすることはありません。
- [.science 研究パッケージ](research-packages.md)は、これらのプライベートブックマークを除外します。 情報を同僚が保存したレポートや会話に必要としているので、手持ちの準備をしてください。
- 受入に関するエージェントに尋ねるには、**To Agent** を使用し、送信前に意図したドラフトでアノテーションを見直してください。 Mainとサイドのディスカッション間のアノテーションを[Side Chat](delegation.md)でカバーします。

## フォークのブックマーク {/* #bookmarks-in-fork */}

v0.31.0から、[複製](sessions.md#fork-session)はプライベートブックマークとメモを新しいセッションにコピーします。 コピー中の後で編集は、ソースブックマークを編集しません。 これは、ブランチの切り替えや`.science`ファイルのエクスポートとは異なります。プライベートブックマークは、パッケージのエクスポートに参加したり、マシン間で同期したりしません。

## PDFドキュメントノート {/* #pdf-document-notes */}

セッションではなく、管理されたPDFに属するアノテーションでは、[PDFの注釈と文書のメモ](pdf-notes.md)を使用します。 ライブラリの添付ファイルでは、そのファイルバージョンが使用されている文書のメモを共有します。 プロジェクトのアップロードとアーティファクトは、セッション全体で共有します。 **For me**ブックマークのセッションスコープやパッケージ除外は変更されません。 **To Agent**はメッセージのドラフトを準備します。
