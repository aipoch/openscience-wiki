# ファイルの開きとプレビュー {/* #opening-and-previewing-files */}

保存した結果を開き、選択したバージョンを調べます。 このページでは、共有ビューイングコントロールと通常のドキュメントフォーマットについて説明します。 データ解釈と[科学ビューア](../tools/viewers.md)をシーケンスと構造制御に用いる[テーブル](../tools/tables.md)を使用してください。

## 開いて、拡大し、戻りて下さい {/* #open-enlarge-and-return */}

生成されたファイルカードはプレビューを開きます。 **セッションの横にある分割ビューで...**は会話を見えるようにします。 別のタブを選択して、ファイルを切り替える, **フルスクリーンプレビューを開く...** で拡大する, そして **プレビューを閉じる...** その表面を閉じるために. **Collapse preview panel** は、開いているファイルを削除せずにパネルを非表示にします。 フルスクリーンプレビューとフルスクリーンのファイルライブラリは異なるビューです。

| ヘッダー制御 | 意味する |
| --- | --- |
| ファイル名とバージョン | ダウンロードまたは引用する前に選択した結果を確認します。 |
| ダウンロード | その結果のコピーを保存します |
| ファイルアクション → Provenance | 管理されたアーティファクト版に付随する証拠を点検して下さい |
| コンテキストで表示する | アーティファクトを制作したセッションに戻る |
| 前 / 次のファイルバージョン | 利用できる場合の不変な保存された修正を操縦して下さい |
| 編集/比較 | 管理されたコンテンツのみが利用可能。 詳しくはこちら [ファイル](files.md) |
| 閉じる | ビューを却下する。 これは削除されません |

上記のクローズ動作は、ファイルプレビューに適用されます。 [Side Chatタブ](delegation.md) は別の確認を持っています: 終了は、その側の議論を中止し、その会話を削除します。 完全なアプリケーションは、残りのサイドチャットも消去します。 Main に既に配信されたメッセージは保存されます。

自分の読書場所を保存するために、テキストまたはPDF領域を選択し、**For me**を選択します。 [読書ブックマーク](bookmarks.md) を参照してください。

## フォーマットでファイルを読み込む {/* #read-files-by-format */}

### 結果表を読む {/* #read-a-result-table */}

<p className="example-label"><strong>実践例</strong> RNA-seq QCのテーブル、図およびレポートを読んで下さい</p>

`rnaseq-sample-qc.csv` を開きます。 この例では、**12行・6列** を表示し、先頭行をヘッダとして使用します。 水平スクロールは、長いソース列の名前とメトリクスを右側に露出します。 テーブルの行番号は、遺伝子やサンプルIDではなく、表示位置です。

![12サンプルQCテーブル](/img/open-science/guides-walkthrough/42-rnaseq-table.webp)

列ラベルとフル識別子が読みやすくなることを確認します。 フィールド定義と共有ベースラインに対するチェックは[テーブルとデータセット](../tools/tables.md)です。

ソース`.txt`はタブ区切りの行列です。 テキストビューアは、CSVグリッドではなくテキストとして表示することができます。 ファイルの拡張子の名前を変更し、その区切り文字や科学的な意味が変更されたと仮定しないでください。 非常に大きいプレビューは縛ることができます; 可視サブセットをフルデータセットとして扱う前に表示された行/列の限界を読んで下さい。 フォーマットの制限は[リファレンス](../reference/formats.md)です。

### 数字を調べる {/* #inspect-the-figure */}

`rnaseq-library-sizes.png` を開きます。 **Zoom in**、**Zoom out**および**Reset zoom**を使用して下さい; 軸ラベルが小さすぎるとフルスクリーンが開きます。 ズームはビューだけを変更します。 ソース行列を再サンプルしたり、統計結果を更新したりしません。

![フルスクリーンのプレビューで実際の生計の合計数字](/img/open-science/guides-walkthrough/54-rnaseq-figure.webp)

CSV/report内の全12個のサンプルラベルとマッピングを読み込みます。 異なるバー高さだけでは、差動式を確立しません。 例は、正規化または仮説テストなしで記述的事前解析チェックです。

### メソッドと実績を一緒に読む {/* #read-methods-and-provenance-together */}

Markdownは見出し、リスト、コード、リンクをレンダリングします。 プロットされた結果を受け入れる前にレポートのチェックサムとメソッドを読みます。 認可されたリンクは、該当するソースビューまたは外部ブラウザアクションを介して、その宛先を開きます。 証拠として扱う前に、完全なホスト名を検査します。 失敗またはブロックされたソースプレビューは、そのコンテンツが読み込まれた確認ではありません。

**Provenance** を使用して、選択したアーティファクトのコード、実行ログ、メッセージ、環境、レビューを調べます。 **partial**、**バウンディング**、**No review for this version** ラベルを [Notebookと実行証拠](notebook.md) で読み込みます。

### その他のサポートビューア {/* #other-supported-viewers */}

次の表は、サポートされているファイルタイプ用のプレビューモードと制御をリストします。

| ファミリー | 検査について | 制御と境界 |
| --- | --- | --- |
| PDF | ページ番号、読みやすいテキスト、ソースPDF | サムネイル、概要、ドキュメント検索、ページナビゲーション、ズームおよび選択可能な領域。 スキャンされたページは検索可能なテキストが不足している可能性があります |
| コード/プレーンテキスト | 関連するブロックと言語の完全化 | 行番号、構文の表示、コピー/ダウンロード; 特大コンテンツは限定可能 |
| JSON / HTML | 構造またはレンダリングされた文書 | レンダリングは、アプリケーション権限でコードを実行する権限ではありません。 |
| 画像/TIFF | 解像度と選択した画像 | イメージのズームレンズ/パン; TIFFには専用のレンダリングパスがあります。 |
| オフィスファイル | 管理されたレンダラーが成功するかどうか | DOCX/XLSX/PPTX プレビューが利用できなくなった場合は、外部にダウンロード/開く。 プレビューは完全にオフィス編集ではありません |
| 生物学的シーケンス | シーケンスアイデンティティと範囲 | 支えられたFASTAの入力のためのシーケンス指向の眺め |
| 分子構造 | パースされたモデルと選択した表現 | 回転、ズーム、パンおよび支持された漫画/Stick/Sphere/Surface/Line 表現; 構造データの欠如は表現を無効化できます |
| 未知または未サポートのファイル | 名前、サイズおよびフォールバックメッセージ | 適切な外部ビューアのためにダウンロードします。 拡張子から有効なコンテンツを継承しない |

PDF 文脈では、現在のタスクに関連する論文のみをリンクし、次のタスクが使用しないようにリンクします。 アプリは、セッションごとに最大3つのリンクされたPDFをサポートしています。 添付されたPDFのない文献レコードは、完全なテキストが読まれた証拠ではなく、メタデータを提供します。 [ライブラリ](library.md) を参照してください。

### ダイアグラムソースとフォーマット固有の制御 {/* #diagram-source-and-format-specific-controls */}

対話でレンダリングされたマーメイドの図のために、そのアクションバーの**View source**を選択して、下にある図テキストを読み込みます。 **View diagram** はレンダリングに戻ります。 エラーが図を置き換えるときにレンダーし、無効になった後にトグルが使用可能になります。 解析ファイルやソースファイルではなく、ビューを変更します。

<p className="example-label"><strong>例</strong> 人魚図とソース間の切り替え</p>

新しい会話では、**Show a Mermaid flowchart with three steps: Attach a file → Inspect the preview → Save a report. Do not include file links.** をレンダーしたら、図の上にカーソルを合わせ、**View source** を選択し、3 つのノードを確認します。 **View diagram** を選択して返します。 ラベルが小さい場合は、**フルスクリーンを見る** を使用します。

図は、要求された手順を表示します。 保存したファイルをチェックするには、実際のファイルカードを開きます。 図ノードだけでは、アーティファクト参照ではありません。

| 形式 | 確認する |
| --- | --- |
| シングルページ PDF | 複数のページの読書記入項目無し; PDFの通常のプレビューコントロールを使用する |
| CSV | 表示される範囲を点検して下さい; 埋め込まれたプレビューは、完全な入出力/エクスポートとして扱われるべきではありません |
| オフィスワークブック | 選択したワークシートとレンダラエラーをチェックします。 サポートされていない編集のために元のファイルを使用して下さい |
| TIFF(ティーフ) | ピクセル/サンプル値を解釈する前に、選択したページとレンダリング結果を確認してください。 |
| JSON | 問題のフォーマット時に保存されたソースのテキストを解釈する |
| マークダウンテーブル | キーボードとのコピー/ダウンロード/フル スクリーン制御を使用するテーブルの行為を集中して下さい |

実装参照: [人魚制御](https://github.com/aipoch/open-science/commit/5f6e7995)、[PDF条件](https://github.com/aipoch/open-science/commit/2722da2a)、[CSV](https://github.com/aipoch/open-science/commit/9275c2c0)、[事務所案内](https://github.com/aipoch/open-science/commit/0291871f)、[TIFF(ティーフ)](https://github.com/aipoch/open-science/commit/52152ed4)。

## PDF図と表を抽出する {/* #pdf-extraction */}

文献PDFから図や再使用可能な表が必要な場合は、これを使用してください。 [ライブラリ](library.md)でPDFを最初に追加し、点検して下さい; bibliographicメタデータだけは抽出の入力ではないです。

1. PDF プレビューを開き、**Figures and tables** を **Original PDF** 横に選択します。
2. まず、必要なモデルリソースをインストールするために、**Download and continue** を選択します。 インストールと整合性チェックを待ちます。 リソースの準備ができたら、**Analyze PDF** を使用します。
3. ページの進行状況をフォローしてください。 完了後、候補を選択し、ソースページ、キャプション、周囲のテキストとそれを比較するために**Show in PDF**を使用します。
4. 図については、画像のプレビューを開き、**Copy image** または **Download image** を使用します。 テーブルでは、**Table** を選択し、**TSV**、**HTML** または **Markdown** を選択し、コピー/ダウンロードアクションを使用します。 ソースクロップを検査する必要がある場合は、**Image**を選択します。
5. エクスポートされたファイルを再オープンします。 列/列のアライメント、マージされたヘッダ、ユニット、フットノート、およびクロスページのコンテンツを解析またはレポートで使用する前にチェックします。

抽出は、モデルリソースのダウンロード後にローカルで実行されます。 同じ PDF を再オープンすると、キャッシュされた結果を再利用することができます。 **Analyze again** は、必要に応じて抽出を再実行します。 停止する必要がある場合は、進捗管理をキャンセルします。 解析が不完全な場合は、可視候補を完全な文書として扱うのではなく、失敗したページ通知を調べます。

**Unplaced table text**と**Table notes**は、レビューが必要なコンテンツを保存します。 構造化された細胞が利用できなくなったら、ソースの作物および元のPDFを使用して下さい; 欠損細胞を注入しません。 スキャンされたページと回転したページは、この抽出ワークフローではサポートされていません。 抽出が利用できなくなった場合でも、PDFは読みやすくなります。

### 抽出した図や表のエージェントに尋ねる {/* #pdf-agent-evidence */}

1. 意図したPDFを開き、**Read with agent**を使用して現在のセッションにリンクし、関連するページ用の**Figures and tables**解析を完了します。 質問を送信する前に、PDF が Composer の読み込みコンテキストに残っていることを確認してください。 単独でのライブラリレコードはリンクされたPDFではなく、単独でリンクしてもこの解析を実行しません。
2. 特定の図、表、アルゴリズムについて尋ねます。 回答が必要なラベルやページ、質問を含めてください。
3. ツールのアクティビティを調べる: **list_pdf_elements** は利用可能な抽出された要素を見つけます。 **read_pdf_element** は、選択した証拠を読み込みます。 回答のソースページと欠落または不確実なコンテンツを求める。
4. ヘッダー、単位およびノートを含む元の図かテーブルとの答えを比較して下さい。 抽出が不在または不完全である場合、欠落したページと再試行を分析します。 キャプション単独では、トレンドや正確なテーブル値を設定することはできません。

<p className="example-label"><strong>例</strong> リンクされた紙からテーブルの証拠を要求する</p>

> リンクされたPDFの抽出された要素からテーブル1を読みます。 物理的な PDF ページを報告します。, コラムの見出しと私の質問に関連した値. ユニットとフットノートを保存し、欠損細胞や不完全な抽出物を識別します。

これらのツールは、既存の抽出結果を読みます。 PDF解析は起動しません。 表出力は複数のバッチで到着し、図/アルゴリズムの証拠はイメージとして配達することができます。 選択したモデルが必要な画像入力をサポートしていることを確認してください。 納品したイメージだけでは、正しく解釈されたことを証明しません。

## リモートメディアを意図的にロードする {/* #remote-media */}

モデル応答からリンクされている画像、オーディオ、ビデオがロードを活性化するのを待ちます。 先に進む前に制御によって示される目的地のホスト名を読んで下さい。 承認は、すべての将来の応答やドメイン全体ではなく、表示された要素とそのURLに適用されます。 プレビューを閉じると、既に送信されたリクエストは行いません。

リモート画像を含むマーメイドの図は、読み込み前にブロックすることができます。 必要なときに埋め込まれた画像なしで通常の図を要求します。 Open-Science はモデルに送信されたイメージのために、元のファイルを維持しながらモデル入力コピーから任意のメタデータを削除します。 これは、画像に視覚的に存在する敏感なコンテンツを削除しません。

## ダウンロードしたファイルを確認する {/* #verify-the-downloaded-file */}

意図したプレビューを開き、**Download**を選択し、システム保存ダイアログのファイル名と場所を確認し、保存します。 ダウンロードしたコピーを開き、その内容を確認できます。 ダウンロードは元のファイルを保存します。 TIFFページやExcelシートの切り替えは、そのページやシートへのダウンロードを制限しません。

## プレビューが失敗したときに {/* #when-a-preview-fails */}

保存したファイルを正常に確認し、正しいバージョンとフォーマットを確認してください。 ダウンロードして、利用可能なファイルからビューアの制限を区別してください。 ローカルファイルがアプリ外で変更されるため、提供されたリロードを使用してください。 入力を上書きしてレンダリングの問題を修復しないでください。 ファイル名、タイプ、サイズ、アプリのバージョン、表示エラーをレポートします。 診断のために必要とされない限り、プライベートファイルコンテンツは除外されます。

## PDF をアノテート {/* #annotate-a-pdf */}

**Notes & Annotations** を開き、ハイライト、エリアマーク、ページノート、ドキュメントノートの管理を行います。 **Show notes sidebar**は、元のページ以外にメモを保持します。 ダウンロードメニューは**Download PDF with annotations**から**Download original PDF**を分離します。 [PDFの注釈と文書のメモ](pdf-notes.md) は、完全な読書、検索、およびエクスポートのウォークスルーのために続きます。

**図表**では、初めてのローカルモデルのインストールは、プライマリソースが到達できないときに承認されたダウンロードミラーを試すことができます。 **Analyze PDF**を選ぶ前にダウンロードと整合性をチェックするのを待ってください。 ミラーは、これらのリソースをインストールする必要はありません。 キャッシュされた結果は、新しい分析なしで再オープンすることができます。

## 最初のメッセージで PDF を読みます {/* #first-message-pdf */}

1. **Library**で読みやすいPDFで紙を開き、**Read with agent**を選択します。
2. 対象プロジェクトと**New conversation**を選択します。 **閲覧** の下の PDF と、プレビューは **In session context** を示しています。
3. すぐに質問をしてください。 紙をリンクする前に、別の紹介メッセージを送信する必要はありません。

<p className="example-label"><strong>実践例</strong> Lang et al., 2019 のメカニズムについて尋ねる</p>

たとえば、CC BY 4.0 のオープンアクセスペーパーである [非欠陥安定熱的に安定した単原子触媒](https://doi.org/10.1038/s41467-018-08136-3) は、**Codex subscription** を使っています。

![初めてのメッセージの前に、読み下でリンクされているPDFとの新しい会話](/img/open-science/v0331/pdf-first-message.webp)

```text
Using the linked PDF, explain how Lang et al. distinguish non-defect
stabilization from defect trapping. Give the paper title and DOI,
two specific findings with PDF page or figure locations, and one
limitation. Keep the answer in English and cite only evidence you
can actually read.
```

応答は、リンクされたPDFからパスを取得し、紙、メカニズム、場所を識別してチェックします。 引用されたページをレスポンスとともに開き、元の各クレームを検証します。 テキストの図を参照して、図イメージが抽出されたり視覚的に解釈されたりするという意味ではありません。 画像証拠が必要な場合は、[図表](#pdf-extraction) を使用します。

![元のPDFの横にある英語の応答, 読書のコンテキストは保持されます](/img/open-science/v0331/pdf-first-response.webp)

ハイライトとドキュメントレベルのノートについては、[PDFの注釈](pdf-notes.md) を続けてください。
