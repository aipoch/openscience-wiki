# ジャーナルデータセットと参照属性 {/* #journal-datasets-and-reference-attributes */}

**Library → Journals** を使用して、ジャーナルディレクトリ、メトリック、分類をインポートし、一致する参照の横に表示します。 **Source** と **Metric year** のデータを保存します。 Open-Scienceは、商用ランキングデータベースへのサブスクリプションを提供していません。 保有するデータをインポートし、その実績を保持する権利があります。 ジャーナルの属性は、個々の論文の品質や発見ではなく、ジャーナルを記述します。

## 小さなデータセットを用意する {/* #prepare-dataset */}

<p className="example-label"><strong>実践例</strong> 既存の紙にパブリッシャー情報を追加</p>

<ExampleDownload path="/examples/journals/journal-publisher-directory.csv">3journal CSVの特長</ExampleDownload>をダウンロードします。 自然通信、PLOSの薬、BMJ、電子ISSN、出版社、ウェブサイトのアドレスが含まれている。 ソースは、[ネイチャーコミュニケーションズ](https://www.nature.com/ncomms/)、[PLOSの薬](https://journals.plos.org/plosmedicine/)、[BMJの購読者情報](https://www.bmj.com/about-bmj/resources-subscribers)です。 **2026** のパブリッシャー・ディレクトリ・スナップショットで、発明されたインパクト要因やクォリティアよりもテキスト・属性を伴います。

マッチングリファレンスでは、Ju et al.'s paper **CO2の電子化学的削減のための金属窒素ドープカーボン触媒の活性と選択性を理解する**, DOI **10.1038/s41467-017-01035-z** を使用します。 ライブラリにまだない場合、[書誌のレコードを追加](library.md) とソースに対してジャーナルとISSNをチェックします。 ジャーナル属性を表示するには、完全なテキストを必要としません。

CSV、TSV、XLSX、ジャーナルバンドルは**32 の MB**まで対応しています。 **Download template**は、スタートレイアウトを提供します。 アイデンティティ カラムを属性から分離します。 ISSN をテキストとして保存します。, hyphens と任意の最終的な X.

## 列のインポートとマップ {/* #import-columns */}

1. **Library → Journals → Import attributes** を開くか、アップロードエリアをクリックします。 データセットが既に存在している場合は、**Journal dataset**セレクターを開き、**New dataset**を選択します。 CSV を選択します。
2. **Header row** と **Preview** をチェックします。 このファイルは、行 **1** を列名として使用します。 ソースが列に並べられたジャーナルがある場合にのみ、**Transpose**を使用してください。
3. **Source**を`Publisher websites`と**Metric year**を`2026`に設定します。 推奨値:ファイル内の年型番号が1年間誤って表示できます。 実際のメトリックデータセットでは、その年の値は、ファイルの公開年と異なる可能性があります。
4. 下記の4つの列をマップします。 それぞれ保存された属性を別の名前で指定します。 **Skip** は列を外します。
5. **Review import** を選択し、各行をチェックし、**Import attributes** を選択します。 この例では、**3は準備が整いました; 0は注意を必要としています** と **Journal attributes imported** が続く。

| オリジナルコラム | 輸入として | 値タイプ |
| --- | --- | --- |
| ジャーナル名 | ジャーナル名 | アイデンティティ分野 |
| ISSN | ISSN | アイデンティティ分野 |
| 出版社 | ジャーナル属性 | テキスト |
| 学会ホームページ | ジャーナル属性 | テキスト |

![ジャーナルのアイデンティティとパブリッシャーの属性を明示的なソースと年でマッピングする](/img/open-science/v0340/journal-column-mapping.webp)

各列のロールを最初に選択します: ジャーナル(名前、ISSN、略称または外部ID)、**Journal attribute**を表示、または**Skip**に一致するように使用されるアイデンティティフィールド。 確認する前にマッピングのヒントを読んでください。 自動提案は、フィールドの意味を確立しません。

**Abbreviation** と **External journal ID** は、追加のアイデンティティオプションです。 外部 ID は、その名前空間を必要とします。 異なるカタログの識別子は変更できません。 属性型には、 **テキスト**, , **番号 番号**, , **Single choice** そして、 **Multiple choices**. . . . 数値メトリックの数値は、ISSNや分類基準の対象ではありません。

行は **Matched**、**New**、**Ambiguous match**、**Invalid** または **Duplicate** である場合もあります。 インポート前の競合識別子と繰り返し行をチェックします。 カラムのロールを修正するために**Edit mapping**に戻ります。 問題の行をエクスポートするか、明示的に提供されるときに注意が必要な行をスキップします。 新しい列がマークされ、ジャーナルエントリが作成され、あなたの伝記の新しい紙ではありません。

## 参照に属性を表示 {/* #show-attributes */}

1. 選択したデータセットが **出版サイト 2026** と **Show in literature** であることを確認してください。
2. **All references**に戻り、`Understanding activity`を検索します。
3. 紙を開けて下さい。 **Journal attributes** では、**Publisher → Springer Nature** とジャーナルのウェブサイトをチェックします。 属性の情報制御を選択して、ソース/年を調べます。
4. インポートされたジャーナルで参照の**ISSN 2041-1723の特長**を比較します。 **2017** は、データセットの **2026** スナップショットとは別々に残っています。

![文献表示機能で読み込まれたジャーナルデータセット](/img/open-science/v0340/journal-dataset.webp)

![既存の Nature Communications リファレンス上のパブリッシャー属性](/img/open-science/v0340/journal-reference-attributes.webp)

**Show in literature**は、共有ライブラリ、プロジェクトビュー、コレクション、および参照の詳細全体に適用されます。 **ソース1年**のみを一度に表示します。 同じソースから別の年が表示された年を置き換えることを可能にします。 異なる年の値で欠損属性は満たされていません。 参照テーブルでは、**Customize** を使用して、どの利用可能なジャーナル列が表示するのかを選択します。

## ジャーナルマッチを解決し、データセットを維持 {/* #journal-matches */}

ジャーナル**More actions → Journal alignment**エントリーと**ライブラリの確認/ライブラリのチェック**を使用して、マッチした、比類のない、あいまいなレコードを検査します。 このチェックは、ライブラリを読み込みます。 参照メタデータを静かに書き直しません。 ジャーナル名とISSNを元の出版物に確認し、誤った一致を解決します。

**Find journal candidates → Choose journal → Confirm journal association**は、提供したジャーナルに選択した参照をリンクします。 同様のタイトルですべての紙ではなく、その参照に適用されます。 確認を取除くことはそれに自動一致に返します; 参照のジャーナル ID の変更は、関連付けを無効化できます。

**Update dataset** を使用する前に意図したデータセットを選択します。 ソース、年、マッピングを再度確認し、インポート後に影響を受ける参照を確認してください。 別の年のデータを別のデータセットとして、意味を上書きするのではなく、保存してください。 データセットアクションを使用して、名前/ソース/年を編集したり、ジャーナルバンドルをエクスポートしたり、データと列の設定を保持します。 元のソースファイルとそのアクセス条件のコピーを保管してください。
