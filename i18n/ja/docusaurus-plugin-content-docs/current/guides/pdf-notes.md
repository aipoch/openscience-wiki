# PDFの注釈と文書のメモ {/* #pdf-annotations-and-document-notes */}

PDF ノートを使用して、通路の横にある質問を記録したり、グループ会議の図をマークしたり、全体でコメントを収集したりできます。 Annotations は管理された **ファイルバージョン** に属しています。そのため、そのバージョンがノートを返すように再オープンします。 エージェントにメッセージを送信したり、元のPDFバイトを変更したりしません。

## 正しい読書ツールを選択してください {/* #choose-the-right-reading-tool */}

| ツール | それが守るもの | どこから見ても |
| --- | --- | --- |
| PDF **Notes & Annotations** | 管理されたPDF版のためのハイライト、エリアマーク、ページのノートおよび文書のノート | PDFのノートビューまたはサイドバー。 メモと引用テキストも検索可能 **Library** |
| **For me** ブックマーク | セッションに属するプライベートな読み取り場所とオプションのノート | そのセッション **Bookmarks** リスト; 詳しくはこちら [個人用の読書ブックマーク](bookmarks.md) |
| **To Agent** アノテーション | 質問または指示のために準備される材料 | 意図したメッセージの草案; 送信前にレビューする |

## 通路をマークし、質問を続けます {/* #annotate-passage */}

<p className="example-label"><strong>実践例</strong> 単原子触媒グループ会議の読書メモを用意する</p>

この例では、[グループミーティングワークフロー](../workflows/journal-club.md) で使用されるオープンアクセスペーパーである Lang et al., [非欠陥安定熱的に安定した単原子触媒](https://doi.org/10.1038/s41467-018-08136-3) を使用します。 出版社からPDFを取得し、[ライブラリ](library.md)にインポートします。 参照行からPDF添付ファイルを開きます。 紙が安定化メカニズムをどのようにサポートしているかを例に挙げます。 抽象的な強調は、そのメカニズムの独立した検証ではありません。

1. **Original PDF**では、通路を見つけ、ページ番号を確認してください。 テキストが小さすぎるとズームを使用してください。
2. **Annotate selected text** を選択し、テキストをドラッグします。 **Mark style** はテキストマークスタイルを選択します。 この例では、ページの1つの抽象の1番目の部分が強調表示されます。
3. **Annotation note** を開き、質問を書いて、リマインダーを読んで、**Save** を選択します。 例えば、提案された同等金属のサポート相互作用と欠陥の安定化を比較し、支持する実験を点検するために読者に尋ねます。
4. **Show notes sidebar** を選択して、PDF の横に保存されたメモを保持します。 **Add tag** で既存のタグを追加します。 この例では、**Favorites** を使用します。
5. テキストをマークした時に**Select**に戻します。 **Undo annotation change** と **Redo annotation change** は、ソース PDF を変更するのではなく、最新のアノテーション編集に使用します。

![保存されたハイライトと元のPDFの横の読書ノート](/img/open-science/v0320/pdf-highlight-sidebar.webp)

図やスキャンしたページでは、**Select area to annotate** を使用して、意図した領域をマークします。 地域マークはエリアを特定します。 テキストを抽出したり、図を検証したりしません。 テキストが選択できない場合は、エリアマークは再訪が必要な場所を保存することができます。

## ページと文書のメモを収集する {/* #document-notebook */}

1. **Notes & Annotations** を開くか、サイドバーから **Open full notes view** を選択します。
2. **Add note → Add document note**は紙全体に関する質問に使用します。 **Add page note**は特定のページで使用し、保存する前にページフィールドをチェックします。
3. ノートを入力し、**Save**を選択します。 ここでは、マイクロコピー、分光、触媒測定が、加熱後のナノ粒子から分離された原子を区別するかどうかを文書に記します。
4. **Search & filter** を使用して、テキスト、タイプ、タグでメモを見つけます。 サイドバーでは、**All notes** と **Current page** が注釈が表示されるように変更します。
5. **Show annotation source** は、保存された場所に戻るための通路や地域ノートで選択します。 **Edit annotation note** はコメントを変更します。 **Delete annotation**は、PDFではなく、その注釈を削除します。

![ドキュメントノートとタグ付けされたハイライトは、フルノートと注釈ビューで](/img/open-science/v0320/pdf-notebook.webp)

## 別のビューからメモを探す {/* #find-notes */}

**Cmd/Ctrl+Kの**でグローバル検索を開き、ノートからフレーズを入力し、**Library**を選択します。 この例では、`covalent metal-support` を検索します。 **Quoted text**から**Notes**を別々に読み、**Show annotation source**を選択して、マークされた通路でPDFを開きます。

![グローバル検索は、引用されたPDFテキストから保存された読書ノートを分離します](/img/open-science/v0320/pdf-search-details.webp)

メモを再訪する際にファイル名、ファイルバージョン、ページをチェックします。 PDF ノートは、Main の新しいメッセージや指示が自動で行いません。 **To Agent** を使用して、材料に関するエージェントを尋ねるときにドラフトを検査します。

## 輸出メモまたは読書コピー {/* #export-notes */}

| 出力 | ステップ | 確認するべきこと |
| --- | --- | --- |
| マークダウンまたはCSVノート | で **Notes & Annotations**, 選ぶ **Markdown** や **CSV**, それから **Export notes** | 保存したファイルを開き、引用、コメント、ページ、タグをチェックします。 サブセット フィルターを使って、 **Export filtered notes** サブセットをエクスポートします。 すべての注意が必要なときにフィルターをクリアします。 |
| 注釈付きPDF | PDFのダウンロードメニューを開き、選択します **Download PDF with annotations** | 別のファイルを保存し、PDFリーダーで再オープンします。 ファイルが存在するだけでなく、強調表示とメモの内容を確認できます。 |
| 原文 | をネットワークで使用しているプロキシアドレスに記入します。 **Download original PDF** | これは、ドキュメントノートブックのマークを追加せずにソースバイトを保存します。 |

## メモが共有される場所 {/* #where-notes-are-shared */}

**図書館の添付ファイル**は、同じ管理されたファイルバージョンを使用する、リファレンス、プロジェクト、セッション全体でノートブックを共有します。 **プロジェクトのアップロードとアーティファクト**は、自分のノートブックを独自のプロジェクト内で共有します。 新しいファイルバージョンは、異なる注釈ターゲットです。マークを仮定する前にバージョンを確認してください。変更された文書に属します。

これらのノートはローカルに保存され、機械を渡って同期しません。 ハンドオーバーのために、ノートや注釈付きPDFをエクスポートし、受信者が受け取るものを確認してください。 これは、プライベートセッションのブックマークを変更したり、[.scienceの研究のパッケージ](research-packages.md)のすべての読書ノート部分を作成したりしません。
