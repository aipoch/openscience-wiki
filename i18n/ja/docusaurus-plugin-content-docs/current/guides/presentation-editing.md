# PowerPointプレゼンテーションの編集 {/* #edit-a-powerpoint-presentation */}

デスクトップアプリを使用して、プロジェクトプレビューで`.pptx`を開き、スライドテキストとOpen-Scienceを離れることなくフォーマットを変更します。 元の状態を保ち、保存した結果を確認してから共有してください。 レガシー`.ppt`ファイルはPPTXエディタにルーティングされていません。

## スライドコンテンツのオープンと選択 {/* #open */}

1. `.pptx`を会話に伝え、メッセージを送信するか、プロジェクトファイルから既存のプレゼンテーションを開きます。 デスクトップオフィスのプレビューが利用できなくなったら、ブラウザのアクセスがダウンロードされます。
2. プレビューでスライドを選択します。 編集前に、既存のタイトルとコンテンツを読み込みます。
3. 鉛筆**Edit**アクションをクリックします。 変更したいテキスト要素をダブルクリックします。 フラットなイメージの一部であるテキストは編集可能なテキストボックスではありません。

## テキストの編集とバージョンの保存 {/* #edit */}

テキストを変更し、フォントサイズ、太字、斜文字、アンダーライン、リンク、カラーコントロールを使用します。 **Apply**を選択し、オーバーフロー、クリップされたテキスト、および変更されたラインブレイクのスライド全体をチェックし、**Save**(**Save changes**アクション)を選択します。 保存は新しいファイルバージョンを作成します。 エディタは、プレゼンテーションの OOXML 構造を保持します。これは、すべての高度な PowerPoint 効果が同一にレンダリングされることを保証するものではありません。

<p className="example-label"><strong>実践例</strong> QC プレゼンテーションのタイトルを明確にする</p>

[GSE60450 QCの提示](/examples/gse60450/office/GSE60450-qc-overview.pptx)を開きます。最初のスライドのタイトルを`GSE60450 sample QC`から`GSE60450: descriptive sample QC`に変更し、適用して保存します。変更するのはタイトルだけで、元の解析は変更しません。

![タイトルテキストをライブプレビューで編集し、コントロールを適用します](/img/open-science/v130/pptx-edit.webp)

![バージョン2 改訂されたタイトルとバージョン履歴に保持されたオリジナル](/img/open-science/v130/pptx-history.webp)

**Undo** または **Redo** を使用して、不要なローカル編集を行います。 編集面では、**Add text box**、**Add slide**、**Duplicate slide**、**Move slide earlier**、**Move slide later**、**Edit speaker notes**などのスライドや形状制御も行っています。 構造変更の前に選択したスライドを確認してください。

エージェントがプレゼンテーションの変更を提案する場合、**Review edits** を開き、比較を検査し、**Accept** または **Reject** を選択します。 **AI suggested edits**のドラフトは受け入れられたバージョンではありません。 一方、ソースが変更された場合は、提案を適用する前に、現在のソースに対するリロードとレビューを行います。

## 比較してエクスポートする {/* #export */}

バージョン履歴を開き、保存された変更を調べ、意図したバージョンを比較します。 共有したいプレゼンテーションをダウンロードし、プレゼンテーションソフトウェアで開きます。 スライドの順序、スピーカーのノート、壷、図の配置およびデータ ラベルを点検して下さい。 同僚がスライドの背後にある証拠を必要とするとき、根本的な[研究パッケージ](research-packages.md)を維持します。

他のフォーマットについては、[ファイルプレビュー](previews.md)を参照してください。 スライドのイメージを作成するには、[画像生成](image-generation.md) を参照してください。
