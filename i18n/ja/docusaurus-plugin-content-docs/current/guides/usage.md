# トークンの使用と活動 {/* #token-usage-and-activity */}

**Settings → Usage** を使用して、報告されたトークンのボリュームとローカルアクティビティを調べます。 応答の**Token usage**メニューまたはセッション**Context window**を使用して、より狭いビューに使用できます。 これらの回答は、現在のコンテキストがはるかに小さいウィンドウを占有している間、総呼び出しは多くのトークンを消費することができます。

表示された期間とメトリックを使用して、各チャートを解釈します。 報告されたトークンは、活動の記述をカウントします。 サブスクリプションの制限やプロバイダーとの請求をチェックします。

## 概要をフィルタリングする {/* #filter-the-summary */}

1. 使用法を開け、**Today**、**This week**、**Last 30 days**または**All time**を選んで下さい。
2. 鮮度ラベルを読みます。 画面が階段の場合、完了した実行後に**Refresh**を使用してください。
3. 4つのトークンフィールドと新規/合計アクティビティカウンターを比較します。
4. チャートの期間ラベルをまとめて比較する前にチェックしてください。

![今日は、別々の毎日チャートで集計](/img/open-science/guides-walkthrough/13-usage-today.webp)

| フィールド | 通訳・通訳 |
| --- | --- |
| 合計トークン数 | 選択した期間の集計を報告しました。 |
| 入力トークン数 | レポートされた入力コンポーネント; ローカルテキストの長さの推定を代入しません。 |
| キャッシュトークン数 | 使用法は報告のバックエンドによってキャッシュに起因します。 |
| キャッシュ率 | 関連する入力/キャッシュのボリュームの割合。 ダッシュは、ゼロ価格の実行ではなく、利用できなくなることを意味します。 |
| 出力トークン数 | 生成された出力コンポーネントをレポートしました。 |
| 新しいセッション/プロジェクト/実行/アーティファクト | 選択した期間に作成されたアイテム。 |
| トータルセッション/プロジェクト/実行/アーティファクト | 全体的なカウント; 期間の新しいカウントを等しくする必要はありません。 |

本日の運用状況では、現在の実行が使用状況を記録する前にトークンの合計がゼロであったが、修正された30-dayチャートは昨日のアクティビティも含まれていました。 意図しないカウントではなく、想定される期間の動作です。 アップロードと生成されたアーティファクトは異なるリソースです。 ソースファイルをアップロードしても、生成されたアーティファクトを作成できません。

## 毎日の活動と構成を読む {/* #read-daily-activity-and-composition */}

**Daily activity metric**は、トークン、トークン、トークン、キャッシュトークン、新しいセッション、新しいプロジェクト、新しいアーティファクト、ランの合計を提供しています。 メトリックを選択し、日付セルを調べます。 ダークセルは、表示されたスケール内で大きな値を表します。

**Daily token usage** は、スタックされた入力、キャッシュ、出力コンポーネントを示しています。 両チャートは**最後の30日**をラベル付けされます。 集計期間の変更は、固定範囲の変更は行いません。 結論を上げる前の期間の比較。

## 欠損または予期しない値の説明 {/* #explain-missing-or-unexpected-values */}

| シンプトム | チェックイン |
| --- | --- |
| 完全な会話は使用していません | 一部のプロバイダと古いレコードはテレメトリーを省略します。 一度リフレッシュし、応答の自身の使用法を点検して下さい。 |
| 高い合計が小さいコンテキストはパーセンテージを使用しました | 総利用量はコールを蓄積します; コンテキストは、時系列で占める時間を測定します。 |
| トークンを使用せずに新しいカウンタの変更 | モデルリクエストなしでプロジェクト作成とセッション管理を行うことができます。 |
| 合計は請求書に似ていません | このページは、プロバイダの請求元帳やサブスクリプションリミットダッシュボードではありません。 |
| 大きいキャッシュコンポーネント | 報告された故障を読んで下さい; プロバイダーの実際の請求ルールなしで現金貯金を差し控えないでください。 |

このページには、報告された使用のみが含まれています。 失った歴史を再構築しません。 コンテキスト構成とコンパクト化については、[記憶と会話のコンテキスト](./memory.md) を参照してください。

ソース: [使用法のパネルおよびチャート制御](https://github.com/aipoch/open-science/blob/v0.26.0/src/renderer/src/pages/settings/TokenUsagePanel.tsx).

## 隣接する日を調べる {/* #inspect-daily-usage */}

**Daily token usage**チャートを移動して、成功の日付と入力、キャッシュ、および出力の故障を検査します。 キーボードアクセスには、**タブ/シフト+タブ** を使用して、1 日を集中し、**エスケープ** を詳細を閉じます。 表示された日付とコンポーネントを比較します。 このチャートは、最後の30日をカバーし、不足しているプロバイダのテレメトリーを再構築しません。
