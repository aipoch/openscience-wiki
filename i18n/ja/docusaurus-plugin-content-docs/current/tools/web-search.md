# ウェブを検索し、ソースを読みます {/* #search-the-web-and-read-sources */}

**Open-Science Agent** のビルトインを使って、パブリックページを見つけ、会話でテキストを読みます。 報告ガイドライン、ソフトウェア文書、研究発表の設置に便利です。 書誌の記録と全文の論文については、[科学データベース](databases.md) と [ライブラリ](../guides/library.md) を使用します。

## 質問から始める {/* #start */}

1. **Settings → Agent** では、**Open-Science Agent** を選択します。 **Settings → Model**でサポートされているMainモデルを接続します。 Codex サブスクリプションは、モデルを供給することができます。
2. プロジェクトの会話を開きます。 あなたが見つけたい状態、優先順位付けするソースと日付制限。 回答の前に、エージェントに関連したページを読んでください。
3. 承認が現れた場合は、検索クエリ、時間範囲、結果制限、ドメインフィルタを調べます。 意図した要求だけ承認して下さい。 ページの読み込みの承認は、宛先URLに懸念します。
4. ツールのアクティビティを拡大し、返されたソースを調べます。 クレームを使用する前に、回答の引用を証拠に戻します。

以下のように依頼できます。

```text
Find the official PRISMA 2020 checklist page on the public web.
Read the relevant official page and explain what the checklist is for.
Give the source URL and distinguish the webpage text you read from any
linked PDF you did not open. Keep the answer in English.
```

ビルトイン検索は、Exaアカウントを要求することなく、**Exa**に問い合わせを送信します。 このページを読んで、そのウェブサイトに連絡します。 許可モードが適用され、キャンセルは既に送信されたリクエストをリトラクトできません。 機密の研究データを公開検索クエリに含めないでください。

## 証拠を読んで、スニペットだけでなく、 {/* #read-sources */}

検索結果はページの抜粋です。Agent に選択したページを読ませ、回答の根拠となる箇所を引用するよう依頼してください。読み取りに対応するのは公開された HTML、Markdown、プレーンテキストです。ログインは行わず、ブラウザの Cookie を使わず、サイトの JavaScript も実行しません。論文や添付ファイルには PDF と Library の手順を使い、HTML の紹介ページを論文全文として扱わないでください。

返されたテキストが破棄されると、エージェントは、結論を引く前に保存されたページを引き続き読み続けるように依頼します。 保存されたソースは、その時点で取得されたものを反映しています。 現在の言葉の問題時に新鮮なフェッチを依頼してください。 保持されたソースは、セッションブランチと資格のある研究パッケージのエクスポートに従うことができます。 当ウェブサイト全体がアーカイブされるわけではありません。

## ソースが読み取れない場合 {/* #recover */}

- レート制限の場合、再試行の前に示された間隔を待ちます。 同じ失敗したクエリを繰り返し送信しないでください。
- 必要なフィルターがサポートされていない場合、その要件を保ち、別のソースまたは検索ルートを選択します。 検索をサイレントに広げないでください。
- ログインウォール、ブロックされたページ、またはサポートされていないファイルタイプについては、公式のソースを自分で開き、適切な時にアクセス可能な許可されたファイルを供給します。 未読ページを検証証拠として記述しないでください。

研究開発論文の調査・審査については、[集中文献検索](../workflows/focused-literature-search.md)を継続します。
