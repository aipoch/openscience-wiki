# 更新履歴 · v1.0.1

公開日： **2026-10-20 UTC**. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.1).

## 研究パッケージをアプリに取り込む {/* #packages */}

対応する Web サイトでは、 `.science` パッケージを同じコンピューターのデスクトップアプリへ転送できます。ブラウザーから Open-Science を開くことを許可し、転送中はページを開いたままにします。アプリでパッケージと取り込み先を確認してください。受信は最終的なインポート承認ではありません。ローカルファイルはプロジェクトのホームにもドロップできます。参照： [ブラウザーからのインポート](../guides/research-packages.md#browser-import).

## 更新と入力待ちセッションの確認 {/* #interaction */}

更新ダイアログにダウンロード、リリースノート、インストール準備をまとめました。Windows のインストールへの引き継ぎと起動を修正しましたが、自動インストールの可否はチャネルに依存します。 [更新状況の確認](../guides/installation.md#update-progress) に従い、再起動後に実際のバージョンを確認してください。

回答や承認を待つセッションは、ホーム、サイドバー、会話に待機状態を表示し続けます。保留中のカードを開いて操作してください。サイドバーのセッションをダブルクリックするとエディターが開きます。参照： [入力待ち](../guides/sessions.md#waiting-for-input).

## データソースと認証情報 {/* #sources */}

- PDC に公開症例の人口統計・診断メタデータを追加しました。研究バージョンの選択と外部参照に対応します。異なるデータソースの ID を混同しないでください。 [PDC の臨床フィールド](../reference/connector-operations.md#pdc_list_clinical).
- 両方の MiniMax リージョンで M3.1 Flash を利用できます。添付画像も Skill 選択の材料になります。 [モデルの選択](../guides/providers.md#catalog-models).
- OAuth 認証情報は、発行元の認可サーバーに結び付けられます。必要に応じて [再認可](../guides/connectors.md#oauth-reconnect) を行ってください。
- PDF 検索範囲が不完全な場合に通知します。2 段組みの読み取り、翻訳レイアウト、文献の状態、Notebook の復旧も修正しました。 [PDF の検索範囲の確認](../guides/previews.md#pdf-search-coverage).

デスクトップパッケージとスタンドアロン CLI アーカイブを再び提供します。Linux CLI パッケージも含まれます。参照： [現在のインストールガイド](../guides/installation.md). [前のリリース：v1.0.0](v1.0.0.md).
