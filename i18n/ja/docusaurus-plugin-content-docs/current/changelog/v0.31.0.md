# 変更ログ・v0.31.0 {/* #changelog--v0310 */}

9月 18, 2026 リリース このリリースでは、独立したセッションコピーを追加し、会話や接続が復元されたときに継続性を改善します。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [v0.30.2から変更](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## セッションの継続と検査 {/* #continue-and-inspect-a-session */}

- **Fork**は、会話ブランチ、Notebookレコード、アーティファクトバージョン、文学、アノテーション、プライベートブックマークで書き込み可能なデスクトップコピーを作成します。 新鮮なアイデンティティを割り当て、ソースを保存します。 インポートされたセッション自体は、読み取り専用のままです。 [フォークウォークスルー](../guides/sessions.md#fork-session)と[研究パッケージ](../guides/research-packages.md)を参照してください。
- セッションタイトルは、ソース、カウント、ピンコントロールで[インフォメーションカード](../guides/sessions.md#session-information)を開きます。 ソースのターンに続く会話リンク。
- [セッションプラン](../guides/planning.md#resume-plan)は、コンテキスト再構築後のアイデンティティ、リビジョン、および保留承認を保持します。 回復は、保留中のステップが承認または実行されていないという意味ではありません。

## セットアップとデータ動作の変更 {/* #changed-setup-and-data-behavior */}

| 範囲 | 確認する |
| --- | --- |
| プロバイダの設定 | 保存された設定を置き換える前に、編集が検証されます。 ランタイム拒絶の更新の可用性。 [プロバイダーのセットアップ](../guides/providers.md#validated-provider-save) |
| Windows R | 標準モードの実行は保護モードのセットアップを必要としません。 保護された実行は別の条件を備えています。 [ランタイム](../guides/runtimes.md) |
| ノマド | リクエスト `include_populations: true` パー人口カウントと頻度のため。 データセット、ビルド、品質フィルターを保持します。 [パラメーター](../reference/connector-operations.md#get_variant) |
| 商品名 | インターフェイスは Open-Science を使用します。 設置場所、設定、データが保存されます。 保存フォルダの名前を変更して一致しません。 [導入事例](../guides/installation.md#product-name) |

**強固な互換性の変更:** `nodes`は、追加隣人を含む完全な返されたグラフを説明します。 マッピングされた入力の`is_query`をフィルターし、すべての入力エイリアスに`queries`を使用します。 提出されたタンパク質の数として`n_nodes`を使用しないでください。 [ストリングガイド](../tools/databases.md#string-network)

その他の修正は、Codex 推論効果の変更、キャンセルおよび継続、UniProt二次アクセス、識別子、臨床的有資格および cBioPortal 減衰器を組み立てます。 完全リストの公式リリースを使用してください。

次のリリースは [v0.31.1](./v0.31.1.md) です。
