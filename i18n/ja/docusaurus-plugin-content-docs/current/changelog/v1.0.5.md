# リリースノート · v1.0.5

**2026-10-28 UTC** 公開。[公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.5)。

## 文献の読書状況を管理する {/* #reading */}

Library に手動の **Unread**、**Reading**、**Read** が追加されました。列表示、フィルター、一括変更に対応します。出版通知の確認は **Check now** と **Check again** を使い、Crossref の結果と確認時刻を保存します。[読書状況](../guides/library.md#reading-status) · [出版通知](../guides/library.md#publication-checks)。

## ブラウザーで研究パッケージを転送する {/* #packages */}

認証済みのローカル Web で `.science` ファイルをアップロードしてインポートし、完成したエクスポートをダウンロードできます。ホームの研究事例には **Details** と **Import** があります。保存先と取り込んだ資料を確認してから **Fork to continue** で研究を続けます。[ブラウザー転送と事例](../guides/research-packages.md#local-package-transfer)。

## サービスを継続する条件を理解する {/* #service */}

CLI で明示的に `start` を実行すると、最後の App を終了してもサービスが継続します。通常の CLI、Web、SDK の操作だけでは継続しません。通常の `stop` はこの設定を解除しますが、App が接続中ならサービスは残ります。`stop --force` はサービス全体の停止を要求し、作業を中断する可能性があります。`start` は `--json` に対応しました。[コマンドと停止結果](../reference/server.md#lifecycle-commands)。

## 科学データと公式ファイルを探す {/* #data */}

Europe PMC、研究データセットの利用条件と公開ファイル、ChEA3、bioDBnet、CTD の入口を追加。HGNC、Cellosaurus、openFDA も拡充されました。カタログには **48 個の組み込み Connector と 418 操作**が含まれます。内訳は、47 個のデータソース Connector の 416 操作と、オフラインの Molecule Connector 1 個の 2 操作です。リンクの取得は、ファイルのダウンロードや制限付きデータの利用許可を意味しません。[データソースと接続](../tools/databases.md#scientific-file-discovery)。

## 更新と日常操作の改善 {/* #fixes */}

- 手動更新の手順を表示し、確認済みのダウンロード済みインストーラーを開いたフォルダーで確認できます。[手動インストール](../guides/installation.md#manual-update)。
- **Full access** では公開ネットワーク宛先ごとの承認が不要です。制限の強いモードへ変更すると既存接続を閉じます。全体に適用した許可も設定へ即時反映されます。[ネットワーク権限](../guides/network.md#network-mode-changes)。
- Windows の Notebook パッケージインストーラーで BiocManager を明示指定できます。[Bioconductor](../guides/runtimes.md#windows-bioconductor)。
- DOCX のテンプレート配置、表、罫線、ページ構造の保持を改善しました。[Word 出力](../guides/previews.md#docx-templates)。

OpenCode 2.x、macOS Notebook の外部 Node 検出、Windows のネットワーク保護設定中のチャット起動、管理対象 Skill 参照資料の読み取り、会話のスクロール位置、表のスクロールバーも修正。About にセキュリティーポリシーへのリンクが加わりました。[前の版：v1.0.4](v1.0.4.md)。
