# リリースノート・v1.0.7

公開日： **2026-11-02 UTC**. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.7).

## 論文リンクから読書メモへ {/* #literature */}

**Add from DOI or link** DOI、doi.orgリンクまたはarXiv抄録/PDFリンクを参考にし、レビューと保存ができます。 フルテキスト検索は別のステップのままです。 [参照を追加する](../guides/library.md#doi-link-import).

Reading セッションでは、Agent に段落を探し、リンクした PDF にハイライト、領域マーク、メモを保存するよう依頼できます。保存先と内容は、再度開いた **Notes & Annotations** で確認してください。 [Agent による注釈](../guides/pdf-notes.md#agent-annotations).

スキャンされたページは、オプションの OCR を使うことができます。 認識コンポーネントをダウンロードし、9つの言語パックから選択し、PDFをもう一度読み、ページカバレッジを調べます。 認識はテキストを回復するのに役立ちます。ページイメージに対する引用語句と数値値を確認してください。 [OCRセットアップ](../guides/previews.md#scanned-pdf-ocr).

## Piとリサーチケース市場 {/* #agents-and-cases */}

Pi が第五の Agent フレームワークとして加わり、Claude Agent、OpenCode、Codex、CodeBuddy と並んで選べます。別途インストールし、対応するモデルへのアクセスを設定して接続を確認してください。Open-Science の更新だけでは使用中の Agent は切り替わりません。 [Pi セットアップ](../guides/frameworks.md#pi-agent).

**Sharing marketplace** ホームと会話のワークスペースから利用できます。 カテゴリーをブラウズし、キーワードで検索し、その説明を調べたり、パッケージをダウンロードしたりするケースを開きます。 プロジェクトから返すと、閲覧状態が保持されます。 [研究ケースを探す](../guides/research-packages.md#use-case-gallery).

## 継続的な作業のための修正 {/* #reliability */}

- Windows の Notebook は初回使用前に Shell ランタイムを準備し、新しいバックエンドで PowerShell を使用できない問題を修正しました。
- OpenCode はコンテキスト圧縮時の非標準メッセージ ID を処理します。バックグラウンド処理の終了待ち中に送った追加質問も保持されます。
- フルテキスト検索処理は、Fake-IP DNS を使用して設定されたプロキシを処理します。 [回復をダウンロード](../guides/troubleshooting.md#full-text-proxy).
- 成果物の公開や復元後は最新の公開版が前面に表示され、来歴パネルで版同士の関係を確認しやすくなりました。 [ファイルバージョンをチェックする](../guides/files.md#latest-published-version).
- Composer はプロバイダー、環境、入力、セッション、内部エラーを共通の通知領域に表示し、復旧操作を案内します。 [リクエストを回復する](../guides/composer.md#request-recovery).
- OCR 設定の保存中も画面を操作できます。コンポーネントのダウンロードが停止しても、通常の PDF 読み取りは既定の待機期限を超えません。

コネクターの記述は設定でより具体的です。 ビルトインカタログは残っています **48 Connectors with 418 operations**;Pi、OCRおよび参照輸入制御は付加的なコネクターではないです。 [サポートされているデータベース](../tools/databases.md#supported-databases) · [過去のリリース](v1.0.6.md).
