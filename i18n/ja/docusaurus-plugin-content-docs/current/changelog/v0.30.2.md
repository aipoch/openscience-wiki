# 変更ログ・v0.30.2 {/* #changelog--v0302 */}

9月 17, 2026 リリース このアップデートは、信頼性の高いSkillローディング、側面の議論、科学的なデータクエリと実行の回復に焦点を当てています。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.30.2) · [v0.30.1から変更](https://github.com/aipoch/open-science/compare/v0.30.1...v0.30.2)

## 日々の使いやすさの変化 {/* #changes-to-everyday-use */}

| 範囲 | あなたにとって何が変わるのか |
| --- | --- |
| Specialist Skills | Specialistターンと委任されたタスクのためにBound Skillsが準備されます。 OpenCode は、暫定された Skill リファレンスを読み込みます。 詳細はこちら [Specialist ワークフロー](../workflows/extend-analysis.md) 選択および使用法のため。 |
| Side Chat | Mainは、承認がSide Chatを単独でブロックしなくなったり、承認を待っていたりします。 Side Chatはアプリケーションビューにマウントされています。 独自の歴史、復元、読み取り専用チェックがまだ適用されます。 [Side Chat](../guides/delegation.md) |
| Web検索承認 | Claude Agent ネイティブ検索をサポート **Allow for this conversation**に進んでください。 検索とページ読み込みの助成金は別々に残ります。 [権限](../guides/approval-modes.md#remember-web-search) |
| レビュアー | 自動レビュー設定は、会話のスタートアップを生き残る。 リンクされた補正は、補正サイクルに必要なフィードバックを保持します。 修正された出力とその後のレビューを調べます。 [レビュアー](../specialists/reviewer.md) |

## データと証拠 {/* #data-and-evidence */}

[Connector リファレンス](../reference/connector-operations.md) およびダウンロード可能なレジストリは、v0.30.2 を使用します。 Reactome は、要求されたサポートされている種を尊重します。 分解された種を取り戻し、前方ストランドにVEP領域のクエリを正規化します。 UCSCは、不正な座標の境界を拒絶し、gnomAD領域の座標は1億未満でなければなりません。 CellGuide と OLS は、空の証拠としてそれらを提示する代わりに、関連するフェッチやペジネーションの失敗を報告します。

PubMed の作者をパースすると、姓/初期/サフィックスの区別が保存されます。 `literature-review` Skillは、両方の方向におけるクロスリーフのリトラクション関係をチェックします。 紙が引き起こされていないという証拠がないマーカーです。 [メタデータチェック](../guides/library.md)と[文献証拠](../workflows/literature-review.md)を参照してください。

## Notebookと回復 {/* #notebook-and-recovery */}

WindowsはカバーコンダRの起動、環境の準備の後で実行可能なルックアップを修理します、Rカーネルの回復およびPipの記入項目は確認の環境でポイントを置きます。 Notebook 再生は、同じターン入力と標準ライブラリのインポートをサポートしました。 Linux は仮の台紙の下の補助金をまた訂正します読みました。 [ランタイム](../guides/runtimes.md)と[再現性](../guides/reproducibility.md)を参照してください。

これらは、リリース/ソース・バック・フィックスです。 既存のWindowsとSpecialistスクリーンショットは、元のバージョンを保持します。 v0.30.2 のテスト結果は新しいものではない。 入力証拠や環境ロックを欠くと、注意が必要になり、再生チェックは、キャプチャされた結果バージョンに固有のままです。

## その他の改善 {/* #other-improvements */}

プロバイダーカタログは、DeepSeek V4.1 フラッシュを追加し、古いピン留めされた選択肢を維持しながら、Volcengine Arkモデルをリフレッシュします。 マーケットプレースカードは、著者が不在であるときにソースを表示します。 OpenCode委任されたタスクは、独立したランタイムを使用します。 キューされたCLIの会話スナップショットといくつかの設定、タブ、文学とツールカードの相互作用を修正しました。

[インストールと更新](../guides/installation.md) は更新のために使用します。 前回のリリースは[v0.30.1](./v0.30.1.md)です。
