# 変更ログ・v0.30.1 {/* #changelog--v0301 */}

9月 16, 2026 リリース このアップデートでは、サイドディスカッション、レビュー方法の変更、研究資料の共有方法を改善します。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [v0.30.0から変更](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## ワークフローの更新 {/* #updated-workflows */}

| 範囲 | あなたにとって何が変わるのか |
| --- | --- |
| Side Chat | 空のドラフトを開き、メインの会話のモデルと推論の努力を継承したり、次の送信のために異なるモデルを選択したりします。 コンテンツのドラフトは、ナビゲーションを生き残る; 無接触の空のドラフトはクリーンアップされます。 [Side Chat](../guides/delegation.md) |
| Skillアップデート | ファイルの変更、行番号、追加/削除された行を調べる **既存のスキルを更新**に進んでください。 影響を受けたスペシャリストとローカル編集を見直し、交換します。 [Skill マーケットプレイス](../skills/marketplace.md) |
| 研究パッケージ | **Full export** 利用できる文献PDFを含んで下さい; **Customize contents** 個別に選択します。 エッセンシャル輸出オムツオプションPDF; 必要な証拠は削除できません。 Side Chatの会話は除外されます。 [研究パッケージ](../guides/research-packages.md) |
| ローカルゲートウェイ | ループバックカスタムゲートウェイは、サーバーが認証を必要としない場合、APIキーブランクを残すことができます。 リモートゲートウェイには、認証情報とHTTPSが必要です。 [プロバイダーのセットアップ](../guides/providers.md) |
| Web 読み込み承認 | 他のウェブサイトの後ページを含む会話のために、サポートされているWeb-readingリクエストを記憶することができます。 [権限](../guides/approval-modes.md) |
| タグ | リソースタグのピッカー内で検索し、矢印キーを使用して、新規タグを作成および割り当てます。 [タグ](../guides/tags.md) |
| インストールと回復 | macOSは、更新前にアプリケーションに読み取り専用のコピーをガイドします。 Windowsは、プレビューとタイプされた確認で、別の、破壊的なリセットユーティリティを持っています。 インストーラーはプロジェクトライセンスを表示します。 [インストールと更新](../guides/installation.md) · [Windowsリセット](../guides/troubleshooting.md#windows-data-reset) |

## 報告された修正 {/* #reported-fixes */}

リリースでは、MCPのタイムアウト、歴史的なアーティファクトバインディング、タスクのキャンセル、およびキュードNotebookの実行中に計画承認の修正も報告しています。 PDFパーシングは、ブロックされた状態とレポート抽出障害から回復することができます。 図/テーブルレイアウトの回復が向上しました。 Connector は、gnomAD 領域の引数とデータセットのリファレンスビルドを検証し、ESM-2 バッチ残余プールを修正しました。

プロバイダは、テストされたプロバイダのルートを使用することを確認します。 ファイルバックの Codex サインイン を欠くと、よりクリアなインポートエラーが届きます。 文学的見解は、発信する会話に戻り、OpenCode Side Chatの指示はMainとは別々にとどまります。

[インストールと更新](../guides/installation.md) は更新手順で使用します。 前回のリリースは[v0.30.0](./v0.30.0.md)です。
