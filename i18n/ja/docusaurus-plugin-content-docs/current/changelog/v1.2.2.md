# リリースノート・v1.2.2 {/* #release-notes--v122 */}

**2026-11-18 UTCの**にリリース [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.2.2).

## 厳格なノートブックネットワークを選択する {/* #strict-network */}

**Settings → Network → Manage access**は**Relaxed**と**Strict**モードを提供します。 Strictは、プロトコル、ホスト名、IP、ポートによる手動ホワイトリストマッチのみを許可します。 比類のない要求は、承認プロンプトなしでブロックされます。 リラックスしたデフォルトは残ります。 規則はグループに組織することができます。 組み込みと手動ラベルは、その起源を示す。 [ネットワーク設定](../guides/network.md#public-network-rules).

## 中断された研究のフィルムを再開して下さい {/* #film-checkpoints */}

フィルム生成は、プロセス間で検証されたシーン、ナレーション、タイミングの作業を保持します。 チェックポイントから再開するか、意図的に新鮮な生成を開始します。 Progress は、現在のステージを識別します。 [回復ステップ](../guides/research-films.md#film-recovery).

## PDFを読んで、ローカルの仕事を回復する {/* #recovery */}

- ネイティブPDF抽出は、図、キャプション、テーブルコンテンツ、読書注文を保存します。 抽出された材料と翻訳されたレイアウトを元のPDFと比較して下さい。 [PDF抽出](../guides/previews.md#pdf-extraction).
- ウィンドウズは、保護されたフォルダへのアクセスをチェックして、付与を保存します。 更新とアンインストールの回復は、より良い診断を保存します。
- `.science`は、キャンセル、無効なパッケージ、タイムアウトを区別します。 未確認のタイムアウトの後、再度提出する前に、インポートされたセッションを確認してください。 [研究パッケージのインポート](../guides/research-packages.md).
- ローカルサービスが切断されると、ワークスペースは回復状態を示し、コンポーザーの草案を保存します。
- バイリアントークンプランは、地域カタログの選択肢を含む**Qwen4 最高のプレビュー**を追加します。 空室状況は選択したアカウントによって異なります。 [プロバイダーのセットアップ](../guides/providers.md#provider-regions).

[インストールとアップデート](../guides/installation.md)と[v1.2.1の特長](v1.2.1.md)をご覧ください。
