# リリースノート・v0.33.2 {/* #release-notes--v0332 */}

**2026-09-24**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.33.2).

## インストールと文献読書 {/* #installation-and-literature-reading */}

公式Windowsインストーラは、コード署名を獲得します。 アプリのダウンロードリンクは、公式のダウンロードページと検証ノートにつながります。 [導入事例](../guides/installation.md) を参照してください。 ライブソースプレビューは、訪問とアプリの再起動を通じてウェブサイトのセッションを保持します。 [ソースプレビュー](../guides/previews.md#persistent-source-preview) を参照してください。

**Auto** モードは、組み込みのライブラリ操作のための繰り返し承認プロンプトを減らします。 ファイル、ネットワーク、リソースのルールはまだ適用されます。 [図書館の承認行動](../guides/approval-modes.md#library-auto) を参照してください。

## STRINGの相互作用の豊かさ {/* #string-interaction-enrichment */}

**蛋白質のアノテーション**は、タンパク質セットがその背景から期待されるよりも相互作用がより多くあるかどうかをテストするためにSTRING PPIの豊かさを追加します。 パスウェイの豊かさから異なる統計的な質問をします。 [遺伝子セットワークフロー](../workflows/gene-set-enrichment.md#enrichr-string) と [操作の参照](../reference/connector-operations.md#get_string_ppi_enrichment) をフォローします。

## 改善と修正 {/* #improvements-and-fixes */}

完了した委任の結果は、後でクリーンアップの失敗を生き残ります。 アップデートでは、図コンポーザーワークフロー、ファイルタイプのプレビュー、スマートコレクションのレイアウトもカバーします。 FixはmacOS Notebookのクリーンアップの状態を隔離し、代理店のルーティングおよび操業停止を改善します; Codex バックエンドプラグインとアプリのディスカバリーは無効になっています。
