# リリースノート・v1.3.0 {/* #release-notes--v130 */}

**2026-11-18 UTCの**にリリース [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.3.0).

## 次の研究タスクをスケジュールする {/* #scheduled-tasks */}

エージェントメッセージを送信したり、Python、R、Shellスクリプトを実行したりするワンタイムまたはリピートタスクを作成します。 既存の会話やメッセージの実行のための新しい会話を選択し、個々の実行レコードを調べます。 アプリケーションが実行されているままでなければなりません。スケジュールは、設定された権限、認証情報、プロバイダーのクォータを使用します。 [スケジュールされたタスク](../guides/scheduled-tasks.md).

## 画像の作成とプレゼンテーションの編集 {/* #creation */}

画像生成サービスを構成し、プロンプトから生成し、バージョン化された編集で画像を精製します。 画像生成は、メインとビジョンを分離する独自のモデル設定を持っています。 [画像生成と編集](../guides/image-generation.md).

PPTXプレビューは、スライドテキストとフォーマットを編集できるようになりました。 保存したバージョンを確認し、共有する前にダウンロードしたプレゼンテーションを再開します。 [プレゼンテーションの編集](../guides/presentation-editing.md).

## 研究を記述するか、または操作を再生して下さい {/* #films */}

研究フィルムのダイアログで**Research explanation**または**Operation replay**を選択します。 枝は独立したフィルムの出力を保ちます。 ダイアログでは、生成前のモデルの使用状況を説明します。セッションメニューは既存のフィルムを開きます。 [フィルム制作](../guides/research-films.md#generate-film).

## 長い仕事の間のより多くの制御 {/* #other-changes */}

- スケジュールされた実行には、独自の歴史があります。ノートブックのプロセス監視は、所有プロセスを示し、**Terminate**を提供します。 [プロセス監視](../guides/notebook.md#process-monitor).
- CodeBuddyのサブスクリプションは、管理されたCLIを通じてモデルの発見で、中国と国際アカウントをサポートしています。 [アカウント設定](../guides/providers.md#codebuddy-subscription).
- エージェントの質問は、トレードオフで選択します。 タスクを継続する前に選択を見直します。
- ドキュメント・ファイア・スキルは、最初に使用して管理された環境で必要なライブラリを用意します。
- 増加セッションの持続、フィルムの回復およびWindowsのインストール/更新の改善は繰り返された仕事および不必要な資源の使用を減らします。

[インストールとアップデート](../guides/installation.md)と[v1.2.2の特長](v1.2.2.md)をご覧ください。
