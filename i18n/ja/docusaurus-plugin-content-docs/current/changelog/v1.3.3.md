# 変更ログ・v1.3.3 {/* #changelog--v133 */}

**2026-11-22 UTCの特長**リリース [公式リリースノート](https://github.com/aipoch/open-science/releases/tag/v1.3.3).

## あなたの仕事の周りに収まる更新 {/* #updates */}

必須の公式の安定した macOS インストールは、あなたが終了したときに準備された更新をインストールすることができます。 WindowsとLinuxは、デスクトップがバックグラウンドでアイドルしている間、次の起動のための更新を準備することができます。 自動ダウンロードは、制限されていない、無メーターの接続と十分なストレージが必要です。 サポートされていない設置場所およびチャネルは手動道を保持します。 Linux AppImage はアプリケーションパスを保存します。 Windows v1.3.3は完全なインストーラを使用します。 [v1.3.4](v1.3.4.md#updates) のコンパクト デルタのリターン。 [自動および手動更新](../guides/installation.md#update-progress).

インストールしたmacOSとWindowsアプリは小さくなります。 オフライン npm のランタイムは Node 22 にバンドルされ、 緩いファイル数を減らすことができます。

## 組み込み Agent は、どこにいてもデフォルトです。 {/* #agent */}

新しいプロジェクトとセッションのデフォルト **Open-Science Agent**、きれいを含む CLI そして、 SDK インストール。 存在しない外部エージェント SDK は、それらのインストールが開始から防ぎません。 外部フレームワークは、使用するときにのみインストールします。 モデルアクセスは、設定を必要としています。 [エージェントのセットアップ](../guides/frameworks.md#built-in-agent) · [CLI セットアップ](../reference/cli.md#terminal-setup).

設定は、Skills、スペシャリスト、コネクタをインストールするためのショートカットを復元します。 Bailianのカタログはqwen4ファミリーを追加し、その計画のデフォルトはqwen4プレビューに変更しました。 作業開始前に、アカウントに利用可能なモデルを確認してください。

## 会話で画像を編集する {/* #images */}

プレビューから**Edit image**を入力し、会話コンポーザーで編集します。 画像バージョンのナビゲーションと比較は利用できなくなり、編集時に会話が行われます。 画像詳細では、編集後Notebookカーネルを識別します。 [画像編集手順](../guides/image-generation.md#edit).

PDF の翻訳はコラム、キャプションおよびインライン式でテキスト分割をよりよい再接続し、不満の表記、形態のラベルおよび隣接するグラフィックを避けます。 エクスポートされたページを元のページから確認し続けてください。 [PDF 翻訳](../guides/pdf-translation.md#scientific-layout).

## 明確な失敗と回復 {/* #recovery */}

- リクエスト、読み込み、添付ファイル、インポート、Notebookエラーは、原因を説明しています。 プロバイダのエラーは、分類とリクエスト ID を再起動中に保持します。 作業を中止し、不必要な作業を区別します。 [トラブルシューティング](../guides/troubleshooting.md#provider-errors).
- Windowsは、保留中の組み込みのエージェントの質問を再起動し、Notebookのランタイムステータスを復元し、コールド起動時にストールファイルブロッカーを再確認します。
- Notebookメモリは、Windows物理メモリ、macOSメモリ圧力、Linuxコンテナの制限のアカウントをチェックします。 [記憶と資源](../guides/notebook.md#memory-resources).
- セッションパッケージのエクスポートは、エクスポートの失敗を報告する前に、Notebook が解決するのを待ちます。 保存されたアーティファクトリンク、確認されたメモリ削除、GitHub Skillインポートエラーも修正されます。

[インストールとアップデート](../guides/installation.md)と[v1.3.2](v1.3.2.md)を参照してください。
