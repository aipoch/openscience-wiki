# 変更ログ・v1.3.4 {/* #changelog--v134 */}

**2026-11-23 UTCの特長**リリース [公式リリースノート](https://github.com/aipoch/open-science/releases/tag/v1.3.4).

## ビルトインエージェントをトレースで調べる {/* #tracing */}

プロジェクトに **Agent tracing** が追加されました。既定では無効です。有効にすると、ターン、モデルへのリクエスト、MCP ツール呼び出しの関連記録を、運用者が設定した OTLP/HTTP 接続先に送信します。汎用 Collector と Langfuse に対応しています。Open-Science は収集サービスを提供しません。内容収集の 4 設定は省略すると有効になるため、開始前に確認してください。[プロジェクトでの操作](../guides/projects.md#agent-tracing) · [接続先と収集設定](../reference/diagnostics.md#agent-tracing)。

1つの操業のために、CLI `--otel-traces`かSDK `otelTraces: true`はプロジェクト スイッチが消えるときでさえ、明示的にtracingを可能にします。 保存したプロジェクトやセッションの設定は変更されません。 [CLI](../reference/cli.md#otel-traces) · [SDK](../reference/api.md#otel-traces).

## Windows アップデートと Notebook 応答性 {/* #updates */}

Windowsアップデートの準備は、アプリの組み込みエージェントと画像ヘルパーを認識し、外部ブロッカーとして扱うことによって引き起こされたストールを固定します。 安定したWindowsの更新は密集したインストーラのデルタを取り戻します; v1.3.3はフルインストーラーを使用しました。 [更新と回復手順](../guides/installation.md#windows-134).

長い Notebook のヒストリーは少数の繰り返された読書を使用し、耐久のチェックポイントに修飾された操業転移をバッチで止めます。 Windows Pythonは、非関連カーネル回復フェンスにもはや固定しません。 計算メモリ使用は、macOS のキャッシュを除外します。 Windows は、物理的な使用量と限界に対するコミットされたメモリを示しています。 [メモリの要約](../guides/notebook.md#memory-summary).

## モデルと明確なタスク結果 {/* #models-recovery */}

- CodeBuddyは、モデルごとのサポート推論の取り組みを発見し、選択したモデルとトークンセージの更新を再開したセッションで復元し、最初の映画の許可要求を修正しました。 ZhipuはGLM-5.4を追加します。 [プロバイダーの選択肢](../guides/providers.md#codebuddy-reasoning).
- 否定されたツールアクションは、保持された説明で終了します。 拒否された呼び出しは、完了した作業とは異なるままです。 [承認の承認](../guides/approval-modes.md#denied-action).
- Explicit プロバイダ HTTP 402 不十分な残高などの応答は、ステータスと有用な請求の詳細を保持します。 [リカバリー](../guides/troubleshooting.md#provider-balance).
- 映像を生み出すことで、その会話をアクティブに保ちます。 ブロックされた映画ダイアログは、ジョブを所有する会話を開くことができます。 [フィルムの進行](../guides/research-films.md#film-recovery).
- 公開中に編集された画像バージョンが公開され、画像のドラフトが有効であるときにProvenance履歴がアクセス可能になります。 [画像編集](../guides/image-generation.md#edit).
- 内蔵のエージェントサイドチャットは、独自のプロファイルのチェックポイントを使用します。 null の ID フィールドでツールの継続は、ターンを失敗しません。

[インストールとアップデート](../guides/installation.md)と[v1.3.3](v1.3.3.md)を参照してください。
