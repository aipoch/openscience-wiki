# リリースノート · v1.0.3

**2026-10-26 UTC** 公開。[公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.3)。

## 引用関係から文献を探す {/* #literature */}

Semantic Scholar で参考文献と引用論文を探し、候補を Inbox で確認できます。文献庫はファイルのドロップ、補足資料の検索、添付ごとの進捗とプレビューにも対応します。[文献の発見と添付](../guides/library.md#citation-discovery)。

スマートコレクションは全候補の判断を CSV で出力でき、採択文献の目録とは別に保管できます。[選定結果の出力](../workflows/screen-literature.md#screening-csv)。

## 研究記録を移し、読む {/* #research */}

- CLI と認証済みローカル Web アプリで `.science` を入出力できます。取込記録は読み取り専用です。[ローカル転送](../guides/research-packages.md#local-package-transfer)。
- 新しい PDF 翻訳版の **Advanced → Content first** で本文と図注を再配置できます。[翻訳レイアウト](../guides/pdf-translation.md#content-first)。
- Permissions でローカル Notebook・Shell のフォルダーアクセスを管理します。変更するとプロセスが停止し変数が消去されます。[フォルダー制限](../reference/permissions.md#notebook-folder-restrictions)。

## 科学データの取得先を増やす {/* #sources */}

TCIA、KEGG、OmniPath、LIPID MAPS、PDBe 検証、UniChem、DepMap/CCLE、PDB 構造類似検索が加わりました。結果には識別子、ライセンス、測定尺度を保持してください。[取得先の選択と接続](../tools/databases.md#expanded-sources)。

Kimi K3.1 Pro がモデル一覧に加わりました。Windows プロトコル登録、ネットワーク承認の保持、会話復旧、パッケージ転送、PDF 処理も修正されています。[モデル選択](../guides/providers.md#kimi-k31) · [前の版：v1.0.2](v1.0.2.md)。
