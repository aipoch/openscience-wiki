# リリースノート・v0.37.0 {/* #release-notes--v0370 */}

**2026-10-11 UTCの特長**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.37.0).

## デスクトップウィンドウなしで実行する {/* #run-without-a-desktop-window */}

デスクトップ、ブラウザ、CLI、Notebook は、通常の Node バックエンドを共有できるようになりました。 `open-science start` は、隠れたエレクトロンホストを起動しなくなりました。 公式リリースには、NodeとバックエンドがバンドルしたスタンドアローンCLIアーカイブが含まれています。 これらのアーカイブにはNodeのインストールは別途必要ありません。 デスクトップのバックエンドは、指定されていない場合、無料のポートを選択します。

インストールとCodexのログインに[ターミナル セットアップ](../reference/cli.md#terminal-setup)を使用します。 デスクトップクライアントを閉じるか、共有バックエンドを停止する前に、[サービス所有権と操業停止](../reference/server.md#backend-ownership) を読みます。

## より多くのデータベース証拠 {/* #more-database-evidence */}

レジストリは、**36コネクターおよび361操作**:359の操作と2つのオフラインのMolecule操作で35のデータソースファミリーが含まれています。

| エントリーフォーム | 変更点 | ガイド |
| --- | --- | --- |
| ENCORI | miRNAターゲット、RNA-RNAおよびRBPの相互作用、ceRNAネットワーク、motifスキャン、結合サイト、参照テーブルおよびバルクファイルのための10の操作 | [セットアップと結果の境界](../tools/databases.md#encori) |
| チャムBL | 1,000 レコードを越える試行錯誤と生体活動のペジネーション | [アッセイコンテキストとペジネーション](../tools/databases.md#assay-submission-evidence) |
| ClinVar | VCVレコードの個々のSCV投稿証拠 | [投稿を比較する](../tools/databases.md#assay-submission-evidence) |

生物、アセンブリ、フィルター、エビデンスの種類を結果に保ちます。 アッセイの自信は、ターゲットの割り当てについてです。 ClinVar の提出は独立した臨床診断ではないです。 [操作の参照](../reference/connector-operations.md)は、正確なフィールドとダウンロード可能なレジストリを提供します。

## PDF 読み込みと Notebook 実行 {/* #pdf-reading-and-notebook-execution */}

PDF 翻訳は、ネイティブの読み込み順とネストされたテキストラベルを改善します。 構造抽出は、図とテーブルレコードをソース要素で保持します。 [数字と表](../guides/previews.md#pdf-extraction) と [翻訳ページ](../guides/pdf-translation.md#compare-export) をオリジナルにチェックし続けます。

Ready デフォルト Notebook のランタイムは冗長なセットアップの承認を避けます。 混合されたConda/pip環境およびmicromambaの造りのメタデータは入力およびコールバックの依存関係と共により正確に捕獲されます。 これらのレコードは、[再実行検証](../guides/reproducibility.md)をサポートしています。 彼らは自分自身が再現性を確立しません。

## 回復とプラットフォームの修正 {/* #recovery-and-platform-fixes */}

- 新しいプロジェクトにインポートすると、`.science`カタログ-adoption の失敗が修正されます。 インポートされたセッションは読み取り専用のままです。 [複製](../guides/research-packages.md) を使用して解析を継続します。
- 完成した作業を保ちながら、失敗したバッチを再試行するスマートコレクション。 [コレクションをスクリーニングする](../guides/library.md#smart-collections) を参照してください。
- 承認/却下とCodexのストリームされたツール引数を計画して、より確実に回復します。 自動モードはサポートされた点検操作のための余分な承認を避けます。
- Windowsは、スペースや括弧を含むPythonパスをカバーし、バックエンドプロファイルとSpecialistハンドオフを選択します。 Linuxの資格情報は最初の秘密操作の後で繰り返された秘密サービス調査を避けます。
- PDB は、誤った検索応答を拒否し、不完全なペグネーション状態を維持します。 エラーはゼロヒットとして読み込まれません。
- ホームは最初のプロジェクトガイダンスを追加します。 Headless と SDK の実行は、Notebook のリソースを再度解決できます。
