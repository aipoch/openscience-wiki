# リリースノート・v0.36.0 {/* #release-notes--v0360 */}

**2026-10-08 UTCの特長**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.36.0).

## 完全なPDFを翻訳する {/* #translate-a-full-pdf */}

完全な文書の翻訳は、保存された段落の進行、再開可能な版および元の/翻訳された比較を加えます。 同じ管理された PDF は、エントリ ポイントを読み込みながら保存されたエディションを再使用できます。 新しい[PDF 翻訳ガイド](../guides/pdf-translation.md)は準備、モデル要件、用語集、再開および輸出をカバーします。 Codexのサブスクリプションモデルは、v0.36.0のこの翻訳操作では利用できません。

## Notebook 実行前のレビューコード {/* #review-code-before-notebook-execution */}

ディスパッチの前にエージェントが割り当てられたNotebookコードが画面に表示されます。 リスクや不十分な理解した操作は、影響を受けるソースラインと明示的な決定とレビューカードを示しています。 通常のサポート読み取りと分析は、追加のリスクの承認を必要としません。 完了した結果の見直しとは別々です。 [実行レビュー](../guides/notebook.md#execution-review) を参照してください。

## 科学データベース {/* #scientific-databases */}

6つの新しい操作は**35コネクターおよび349操作**にレジストリをもたらします:34のデータソース家族と347の操作、および2つのオフライン分子操作。

| エントリーフォーム | 機能機能 | ガイド |
| --- | --- | --- |
| PDC | がんプロテオミクス研究、バイオスピーメン協会、量的ファイルメタデータ | [PDCの設定とスコープ](../tools/databases.md#pdc) |
| ゲノム → Ensembl | ポピュレーション固有のペアワイズ LD と近くのプロキシバリアント | [LD クエリ](../tools/databases.md#ensembl-ld) |

[操作の参照](../reference/connector-operations.md) は、正確なフィールドに使用します。 PDCの発見はデータをダウンロードしません; 高いLDは因性を確立しません。

## 日々のワークスペースが変化する {/* #everyday-workspace-changes */}

- ライブラリとInboxは、ロードされたページ選択オールコントロールを追加します。 バッチアクションを適用する前に、選択したカウントをチェックします。 サーバサイドのマッチを全て選択しません。 [バッチ選択](../guides/library.md#loaded-page-selection) を参照してください。
- ファイルカードをドラッグするか、コンポーザーにアーティファクトを開き、ファイルの言及を差し込みます。 送信前に草案を見直します。 [ファイルの言及](../guides/composer.md#drag-file-mention) を参照してください。
- 公式のAnthropicカタログは、Claude Haiku 5.5を追加します。 モデルのカタログは選択に失敗できるコンテキストサイズのエイリアスを削除します。 古い識別子をコピーするのではなく、現在利用可能なモデルを選択します。 保存したMainモデルは自動置換されません。

## 読書および信頼性の修正 {/* #reading-and-reliability-fixes */}

PDF抽出は、複雑なテーブル、マルチレベルのヘッダー、フッター、マルチパネルレイアウトを改善します。 科学的解釈がレイアウトに依存するたびにソースを調べる。 [PDF抽出物](../guides/previews.md#pdf-extraction) を参照してください。

Notebook は Python/R の読者、容器の変形およびコールバックの処理を改善します。 これは依存関係をキャプチャするのに役立ちます。 [再実行検証](../guides/reproducibility.md) を交換しません。 他の修正は、リモートWebで新しい会話、空のワークスペース検索、コンパクトな言及チップとSpecialistマーケットプレイスのファイルパネルからの言及をカバーします。
