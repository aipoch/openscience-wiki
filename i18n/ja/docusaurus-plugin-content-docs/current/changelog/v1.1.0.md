# リリースノート・v1.1.0

リリース **2026-11-06 UTCの**. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.1.0).

## 研究フィルムにセッションを回す {/* #research-films */}

完成したセッションは、英語のナレーションでショートフィルムになることができます。 ローカルナレーションリソースをインストールします。, デスクトップセッションから生成し、ポータブルプレーヤーを共有したり、MP4をエクスポートする前に再生を確認. フィルムは、記録された研究を提示します。それは分析を再実行または検証しません。 [研究フィルムガイド](../guides/research-films.md).

## 読書リストによる作業 {/* #literature */}

最大5つの参照を選択して、学習概要をバッチとして生成します。 完了した概要を保ちながら、未完成の作業や再試行に失敗したアイテムを再利用し続けます。 CLI と MCP は、ライブラリの検索、引用の書式化、参照管理操作も得ます。 [バッチ概要](../guides/library.md#batch-overviews) · [文学コマンド](../reference/cli.md#literature-library).

## モバイルデバイスでワークスペースを開く {/* #mobile */}

QRペアリングは、同じWiFi上の電話またはタブレット、またはPinggyを介してインターネット接続をサポートしています。 実行中のホストを維持し、スキャンする前に接続状況を調べます。 [接続オプション](../guides/remote-access.md#mobile-pairing).

## 日常利用の変化 {/* #reliability */}

- 計算設定は移動します **Connections**お問い合わせ 研究ケースライブラリは、リフレッシュされたレイアウトとクリアなインポート先を持っています。
- 中断および貯蔵の失敗の後で会話はより確実に回復します。 完了またはアイドルエージェントの接続は、より一貫してリソースを解放します。
- 診断はノートブックの実行証拠および歴史的なバックエンドログを保持します。 Windowsはトラブルシューティングのための任意資源の録音を加えます。
- PDF抽出は、検索可能なスキャンから図とテーブルの回復を改善し、Codexチャットはネイティブイメージ入力をサポートしています。
- Notebook は、既定の app-managed runtime を好む。 シェルは、成功した結果ではなく、ツールのエラーとして表面を失敗します。
- Windows Updateの準備は、プロセスのアイデンティティと占有ファイルをチェックします。 ローカル `.science` そしてMP4の輸出流れはデスクトップの保存のダイアログをもっと確実に扱います。
