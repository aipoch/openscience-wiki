# リリースノート・v1.2.0

リリース **2026-11-09 UTCの**. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.2.0).

## 計算が実行される場所を選択してください {/* #remote-compute */}

Kubernetes, Hugging 顔のジョブ, Modal and Ray 参加直接 SSH と Slurm. ターゲットを設定し、凍結した入力、コマンド、リソース、出力コレクションを見直し、各外部の投稿を承認します。 回復記録は、再起動後にコレクションを再開し、公開された出力が開いているのを助けます **Compute Preview**お問い合わせ これらのオプションは、独自のインフラストラクチャまたはクラウドアカウントを使用します。 [リモート・コンピューティングのセットアップ](../guides/remote-compute.md#compute-backends).

## 組み込みのエージェントから始めましょう {/* #agent */}

新しいセットアップはデフォルトで **Open-Science Agent**、互換性のあるモデル・プロバイダと機能する組み込みのランタイム。 Claudeの代理店、OpenCode、Codex、CodeBuddyおよびPiは利用できます。 実行時間とモデルプロバイダは別々の選択肢です。既存のCodex設定は置換する必要はありません。 [エージェントの選択肢](../guides/frameworks.md#built-in-agent).

## 正確な研究ステップを議論 {/* #discussions */}

インポート `.science` 研究と再生のステップは、リンクされた子供の議論をサポートしています。 **Ask about this step** 記録されたノートブックの実行を含む選択した証拠を、議論に運びます。 インポートされた履歴ハイライト **Fork to continue** 書き込み可能な継続を開始する。 サイドバーグループセッション **Pinned**, **Imported research**, **Active** そして、 **Recents**. [ディスカッションを再生する](../guides/session-replay.md#discuss-replay) · [研究パッケージ](../guides/research-packages.md#linked-discussions).

## より小さい更新およびより明確な制御 {/* #reliability */}

- macOSの更新は、必要に応じて、変更されたブロックをダウンロードし、完全なダウンロードに戻すことができます。 インストールは、実行中のアプリを検証し、ファイルやプロセスのブロックを特定します。
- **Local capabilities** 交換する **Local parsing models** タブとグループ PDF抽出、OCRおよび研究ナレーション。 [ローカルリソース](../guides/models.md#local-capabilities).
- マニュアル参照エントリは、PMIDを含むタイトルなしで識別子を受け入れます。 フィルムコントロールは、ロード中に使用できないアクションを点滅させないようにします。
- PDF抽出はテキストとテーブル構造を改善します。 固定レイアウトの翻訳は、別のページが失敗した場合、成功したページを保持します。 共有する前に、不完全なページを調べます。 [PDF 翻訳](../guides/pdf-translation.md).
- メモ帳解析はUIスレッドの外で実行されます。 Windowsはカバー管理されたR DLLのローディングを修理し、タスクバーのまわりの窓の境界を妨げます。
- 以前のターンを読みながらメッセージを送信すると、読み取り位置が保存されます。 ツールエラー、ソースリンクプレビュー、およびスタートアップ診断はより明確です。
