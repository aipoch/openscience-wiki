# リリースノート · v1.0.6

**2026-10-30 UTC** リリース。[公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.6)。

## Zotero の文献を取り込む {/* #zotero */}

同じコンピューターで実行中の Zotero 10 以降から、個人ライブラリーまたは選択したコレクションをインポートできます。メタデータ、ローカル PDF、タグ、コレクション階層を取り込む前にプレビューし、既存の文献を再利用する場合は一致内容を確認します。これはインポートであり、双方向同期ではありません。[Zotero インポート手順](../guides/library.md#zotero-import)。

通常の文献検索で、保存した個人メモの語句も検索できるようになりました。**Notes** 列に読む理由を記録し、**Search references** から探せます。[個人メモで検索](../guides/library.md#personal-note-search)。

## PDF の読み取り順序を自動化 {/* #pdf */}

関連付けられた PDF のテキストを自動で並べます。完全な論理タグを優先し、利用可能なテキストやレイアウトに応じて別の方式へ切り替えます。保存型の手動読み取り順序設定は廃止され、領域を保存した過去のメッセージにも自動順序が適用されます。複雑なページから引用する際は原文を確認してください。翻訳済み PDF の表示も高速化され、DOCX ツールバーはスクロール中も文書の上に表示されます。[PDF の読み取り順序](../guides/previews.md#automatic-pdf-reading-order)。

## 更新後も作業を続ける {/* #reliability */}

- Windows インストーラーはファイル数を減らし、並列展開を使用します。アプリの隣に保存した研究データを維持し、深いインストールパスにも対応します。[Windows 更新後の確認](../guides/installation.md#windows-update-data)。
- アシスタントの応答処理が終了するまで生成ファイルを公開できます。長時間タスク中に従来の 2 時間の期限で公開権限が失効する問題を修正しました。
- **npx** または **npm** を使うカスタムローカル Connector は、システムにコマンドがない場合、同梱ランタイムを利用できます。インストール済みコマンドが優先されます。[ローカルコマンド](../guides/connectors.md#bundled-npm)。
- Slurm はログ収集前に最終状態を保存し、キュー・コントローラー・ジョブ履歴の情報を個別に処理します。キャンセルの最終結果は一度だけ返されます。[ジョブ状態と結果収集](../guides/remote-compute.md#slurm-outcome-recovery)。
- システム認証情報の対話式アクセス許可は最長 5 分待機します。タイムアウトには専用の復旧メッセージがあります。[起動時の許可](../tools/credentials.md#system-authorization)。

このほか、OpenCode のツール呼び出しと Windows 起動制限、Windows の Cookie 保存データの起動処理、空白を含む R 一時パス、セッション同期、準備停止後の下書き復元、インポートしたセッションのエラー履歴を修正しました。分割ボタンのメニュー表示も統一されました。WSL のミラーネットワークには **Windows 11 22H2 以降** が必要です。[WSL2 の設定](../guides/runtimes.md#wsl2-preview)。

組み込みカタログは変更ありません。**48 個の Connector、418 操作**で、データソース用 47 個・416 操作と、オフライン Molecule 1 個・2 操作からなります。[対応データソース](../tools/databases.md#supported-databases) · [前のリリース：v1.0.5](v1.0.5.md)。
