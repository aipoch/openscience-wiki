# 変更ログ・v1.3.2 {/* #changelog--v132 */}

**2026-11-20 UTCの特長**リリース [公式リリースノート](https://github.com/aipoch/open-science/releases/tag/v1.3.2).

## モデルを接続するより多くの方法 {/* #models */}

**Model provider** で **Skip** を選ぶと、API key なしの Kilo Gateway が追加され、Notebook runtime に進みます。設定後の **Main model** に `kilo-auto/free` が表示される場合があります。最初のメッセージを送る前に **Settings → Model** でプロバイダーとモデルを確認し、Codex subscription など、使いたい接続に切り替えてください。Skip は推論の動作をテストしません。 アップグレードでは既存の認証情報と Main の選択が保持されます。 [Kilo Gateway](../guides/providers.md#kilo).

OpenAI、MiniMax、Bailian、Volcengine Arkのイメージサービスは、保存する前に、サポートされているイメージモデルのカタログをリフレッシュできます。 これは、接続の認証情報で設定されたプロバイダに連絡します。 カタログの可用性と成功した生成は、別々のチェックです。 [画像モデルカタログ](../guides/image-generation.md#image-model-catalog).

## スムーズな研究セッション {/* #sessions */}

長い会話は、記憶が少なく、安全に保存された会話ボディは、もはや見ていないときに解放することができます。 ドラフトや活動的な作品の保持。 完了した再生手順は、ホバーまたはキーボードのフォーカスで彼らの尋ね/キャプチャー制御を示しています。 接触装置はアクセス可能な制御を保持します。

Notebookメモリ圧力通知は、6秒後に解除され、有効期限が切れる可能性があります。 ブロックされた操作が実行されていないという通知は消えません。 実行状態とリトライを意図的に見直します。 [Notebookメモリ](../guides/notebook.md#memory-resources).

## 日常的な仕事に影響する修正 {/* #fixes */}

- Claude Agent と Codex は、影響を受けた Notebook 準備パスで最初のモデルリクエストの前に失敗しません。 スケジュールされたセッションは、意図したプロンプトで始まります。
- PDF 翻訳は、ネイティブの式、リンク、グラフィックを保持しながら、読書順序で包まれたタイトル、キャプション、数学的な文を再構築します。 [翻訳されたレイアウトをチェックする](../guides/pdf-translation.md#scientific-layout).
- ページのユースケースのダウンロードエラーは、不足しているパッケージ、タイムアウト、検証障害、ストレージの問題を区別します。 [輸入の回復](../guides/research-packages.md#case-download-recovery).
- WindowsはカバーWSL Notebookの起動および査読者の関係を修理します。

[インストールとアップデート](../guides/installation.md)と[v1.3.1](v1.3.1.md)を参照してください。
