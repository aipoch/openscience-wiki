# リリースノート・v0.35.0 {/* #release-notes--v0350 */}

**2026-10-04 UTCの特長**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.35.0).

## 研究の再生と議論 {/* #replay-and-discuss-research */}

**View replay**は、再生、ステップナビゲーション、Notebookレコード、ファイルバージョン履歴で録画セッションを提示します。 **Ask about this step**は、選択したコンテキストを書き込み可能な会話に引き込むことができます。 インポートされた`.science`の研究は、読み取り専用のまま; 実行を継続するためにフォークします。 リプレイはコードを再実行しません。 [セッションリプレイガイド](../guides/session-replay.md) をフォローしてください。

## 科学データベース {/* #scientific-databases */}

このリリースでは、**13の操作** を追加し、レジストリを **34コネクターおよび339操作**: 33 のデータソースファミリーと 337 オペレーション、さらに 2 つのオフラインの Molecule 操作。

| エントリーフォーム | 追加された機能 |
| --- | --- |
| Cellosaurus | 細胞ラインのアイデンティティ、同義語および質のアノテーション |
| Monarch Initiative | 病害・遺伝子対フェノタイプ 原発証拠との関連付け |
| IEDB | エピトープ、抗原、T細胞、B細胞およびMHCの試金および出版物 |
| Omics アーカイブ → GEO | 行列ファイルの場所とプリフライトを既に読み込む行列テキストを発見 |
| 構造と相互作用 → PDB | アイデンティティ、E値、クエリ カバー フィルターでタンパク質シーケンスによって構造を見つける |

[機能と接続手順](../tools/databases.md#cell-lines-phenotypes-immunity) と [更新された操作カタログ](../reference/connector-operations.md) を参照してください。 GEO preflight は、提供されたテキストをディスクにダウンロードしたファイルではなくチェックします。 行列の検出はファイルをダウンロードしません。

## PDFおよびワークスペース制御 {/* #pdfs-and-workspace-controls */}

- **Figures and tables**抽出物で生成されたPDFとライブラリPDFをアップロードしました。 境界線分析により、複雑なレイアウトの処理が向上します。 [文学PDFに埋め込まれたテーブルでは、](../guides/previews.md#pdf-extraction) を参照してください。
- チャットエリア内のファイルをどこにでもドロップして添付してください。 送信前に添付ファイルを検査します。 [ファイルのドロップ](../guides/composer.md#conversation-drop) を参照してください。
- 利用チャートでは、日中連続で検査が可能です。 [日常の使い方](../guides/usage.md#inspect-daily-usage) を参照してください。
- Windows は、titlebar にネイティブなアプリケーションメニューを追加します。 PDFの輪郭およびノートは狭い窓によりよい合わせます。

## モデルとネットワークアクセス {/* #models-and-network-access */}

OpenCode ゼンカタログは、Jev の分類エントリを含む拡張機能を展開します。 Main-modelと分類の選択肢は別々に残ります。 [モデルカタログ](../guides/providers.md#catalog-models) を参照してください。

ネットワーク設定は、信頼できるプライベートサービスからパブリックドメインのルールを区別します。 プライベートの付与は、保存前に別のDNSチェックで、ホスト名、ポート、レビューされたDNSアドレスにバインドします。 [パブリックルール](../guides/network.md#public-network-rules)と[プライベートサービス](../guides/network.md#trusted-private-services)を参照してください。

## フィックス {/* #fixes */}

Fix カバーはセッション結果と承認待ち、Notebook状態とファイルギャラリー、科学的な実行行列、Codexフォルダの許可、Windowsランタイム起動とサンドボックスアクセス、およびWSLフォルダパスを再生します。 `.science`パッケージのIdenticalオブジェクトは重複しています。 提供者およびプロジェクト草案は不慮の損失に対する保護を得ます。
