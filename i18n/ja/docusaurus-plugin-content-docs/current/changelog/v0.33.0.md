# 更新履歴 · v0.33.0

9月 23, 2026 リリース このリリースでは、個々のエージェントのリソースアクセス制御、および研究パッケージ内のRO-Crateメタデータを追加し、スマート文献スクリーニング、リソースアクセス制御を追加します。

[公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.33.0) · [v0.32.0から変更](https://github.com/aipoch/open-science/compare/v0.32.0...v0.33.0)

## 明示的な基準のスクリーン文献 {/* #screen-literature-with-explicit-criteria */}

**Smart collection** は、ライブラリレコードを包含および除外基準に対して評価します。 スコープを選択し、4つの決定ビューを調べ、読みセットを使用する前にモデルの判断を見直します。 試験は結果を保存します; ライブドラフトプレビューはしません。 オプションのフルテキストの証拠と自動更新は、別々の制御を持っています。

新しい[スクリーニングワークフローの作業](../workflows/screen-literature.md)は、検索、モデル結合、ルール、トライアル、マニュアルレビュー、エクスポートをカバーしています。 [分類設定](../guides/models.md#smart-collection-model) は **Automatic capability selection** から **Smart collections** を区別できるようになりました。 MainはCodexに滞在することができます。

## リソースアクセスと研究ハンドオーバーの管理 {/* #manage-resource-access-and-research-handovers */}

- SkillまたはConnectorの**Manage access**はMainの代理店およびSpecialistの関連付けを一緒に示します。 役割の活発化、資格情報および操作の承認は別々に残ります。 [リソースアクセス](../guides/connectors.md#resource-access) を参照してください。
- `.science`パッケージは、RO-Crate 1.1メタデータを含む新品をエクスポートしました。 `ro-crate` 機能をサポートするリーダーが必要です。 古いパッケージは読みやすくなります。 [パッケージの両立性](../guides/research-packages.md#package-compatibility) を参照してください。
- セッション中の**Export diagnostics…**は、選択したソースからローカルのアーカイブを作成します。 アーカイブをアップロードしたり、モデルに送信したりしません。 [診断輸出](../guides/troubleshooting.md#session-diagnostics) を参照してください。

## 新しいデータベース操作 {/* #new-database-operations */}

| リソース | 追加された機能 | バウンダリー |
| --- | --- | --- |
| ゼノドー | パブリックレコードを検索し、バージョン固有のメタデータとファイル在庫を調べる | ファイルアップロードやダウンロードはありません。 パブリックメタデータは、ファイルアクセスを阻害しません。 |
| GDCの特長 | がんプロジェクト/ケース、検索ファイル、ファイルメタデータを調べ、マニフェストを生成する | 制御されたデータは、許可を必要としています。 |
| ジャンルとオノトロジー | UniProt バッチ識別子マッピング: 投稿、確認、ページ取得 | すべてのページ、ワンツーマンのマッチと、比類のないIDを保持します。 |

**26 は 263 操作のコネクターを組み込みました**:**25データソースコネクタ/261操作**、および2つのオフライン分子操作があります。 [データベースカタログ](../tools/databases.md) を使用して、サービスと [v0.33.0パラメータ参照](../reference/connector-operations.md) を正確に入力します。 UCSC の保存のデフォルトはマウスのアセンブリのために訂正されます。

## モデル、ランタイム、プラットフォームの修正 {/* #models-runtime-and-platform-fixes */}

プロバイダーのカタログは、MiMo v2.6とGrok 4.7を追加し、Zen/Goをリフレッシュします。 [プロバイダーの選択](../guides/providers.md#provider-catalog-updates) を参照してください。 **Claude Agent** は、準備中のサポートされていない CLI バージョンを報告しました。 v0.33.0は**2.1.118以降**を要求します。 [代理店の取付け](../guides/frameworks.md) を参照してください。

他の修正は、ストリーミングと長い会話を改善します, スタイルランの回復, 研究パッケージのクレデンシャルチェック, 長期実行 Notebook シェルの進捗, パッケージのインストール中にフォルダーの付与, 解読 Notebook 通知, Windows R 在庫とリセット処理, Fedora スタートアップパッケージ, および Search/PDF 相互作用. 完全なリストの公式リリースを参照してください。 前回のリリースは[v0.32.0](./v0.32.0.md)です。
