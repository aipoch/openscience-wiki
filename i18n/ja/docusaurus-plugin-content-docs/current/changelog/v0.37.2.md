# リリースノート・v0.37.2 {/* #release-notes--v0372 */}

**2026-10-13 UTCの特長**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.37.2).

## スタートアップとランタイム接続の復元 {/* #recovery */}

スタートアップ障害は、バックエンド、設定、ネットワークの初期化のための回復パスを提供します。 デスクトップ接続の中断は、**再接続**と**アプリを終了**でワークベンチを開いたままにします。 再接続は、元のライブバックエンドを復元します。 デッドバックエンドを再起動したり、送信された操作を自動的に繰り返すことはありません。 応答が失われていた作業をやり直す前に、元のタスクの状態を確認してください。

ブラウザインターフェイスは、見逃されたアップデートを復元しながら制御を一時停止し、必要に応じて再ロードまたは更新されたペアリングを提供します。 大規模なセッションとNotebookスナップショット転送、イベントバーストとリダイレクト診断ログはより堅牢に処理されます。 [接続とスタートアップの回復](../guides/troubleshooting.md#connection-recovery) と [バックエンドの所有権](../reference/server.md#backend-ownership) をフォローします。

## Linux CLIをパッケージとしてインストールする {/* #linux-cli */}

Linuxは、リリースアーカイブとHomebrew CLIとともに、x64とARM64用のスタンドアローン`.deb`と`.rpm` CLIパッケージを追加します。 CLIパッケージには、Node、バックエンド、ローカルWeb UI、`open-science-cli`を明示的なコマンドとして含まれています。 デスクトップインストーラとは別々で、システムサービスが自動的に起動しません。

[パッケージの選択、取付けおよび改善](../guides/installation.md#linux-cli-packages) を参照してください。 アップグレードまたは削除する前にパッケージを使用してすべてのプロファイルを停止します。 研究データとクレデンシャルストアを保管してください。
