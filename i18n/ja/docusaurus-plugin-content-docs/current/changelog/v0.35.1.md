# リリースノート・v0.35.1 {/* #release-notes--v0351 */}

**2026-10-06 UTCの特長**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.35.1).

## 会話の開始と管理 {/* #start-and-manage-a-conversation */}

新しい会話画面では、コンポーザーの横にある研究スターターを配置し、**Import previous research**をコンパクトに保ちます。 始動機を選ぶと、編集可能な草案を埋めます。 送信しません。 [研究の始動機](../guides/composer.md#research-starters) をフォローします。

セッションヘッダの**Session actions**メニューグループ編集、ピン、Side Chat、フォーク、エクスポート、アーカイブ。 その輸出submenuは会話、研究パッケージおよび診断出力を分けます。 Side Chatタブとツールバーもよりコンパクトになります。 [セッションコントロール](../guides/sessions.md#session-header-menu) を参照してください。

## 科学データベース {/* #scientific-databases */}

**34コネクターおよび343操作**:33のデータソースファミリーと341の操作、さらに2つのオフラインモーレキュラー操作。

| エントリーフォーム | 追加された機能 | スタート場所 |
| --- | --- | --- |
| ヒト遺伝学 → GWAS カタログ | 完全なサマリー統計ファイルの場所、メタデータおよび宣言された参照のゲノムを発見して下さい; 大型ファイルのダウンロードなし | [GWASファイル](../tools/databases.md#gwas-summary-statistics) |
| インタープロスキャン | タンパク質のシーケンスを提出し、ステータスに従い、TSVアノテーションを取得します。 | [電子メールおよび投稿に連絡する](../tools/databases.md#interproscan-submit) |
| IEDB | TCRとBCR受容体証拠を検索し、アッセイとソースの参照で | [受容体証拠](../tools/databases.md#iedb-receptors) |

[操作の参照](../reference/connector-operations.md)には、必要なフィールド、制限、および正確な例が含まれます。 集計された受容体証拠は、1つの実験ですべての条件が起こることを確立しません。

## Requestyとモデルカタログ {/* #requesty-and-model-catalogs */}

**Requesty**は、組み込み接続検証とキュレーションされたモデルリストを備えた公式プロバイダーピッカーに参加しています。 OpenRouterのカタログもリニューアルしました。 利用可能なプロトコルとモデルは、アクティブなエージェントとアカウントアクセスに依存します。 保存したMainモデルは自動置換されません。 [Requesty セットアップ](../guides/providers.md#requesty) を参照してください。

## PDF読書およびノート {/* #pdf-reading-and-notes */}

PDF コンテキストは、新規に添付した PDF を含む最初のリクエストが許可される前に保持されます。 [最初のメッセージアップロードと読み込み](../guides/previews.md#uploaded-first-message) をフォローします。 複雑なレイアウト抽出が改善され、永続的な読者の通知が減少します。

同じPDFコンテンツの検証されたコピーは、アップロードやアーティファクトを含むプロジェクト全体でドキュメントノートブックを共有します。 ファイル名だけでは不十分で、機械全体に同期しないメモ。 [メモが共有される場所](../guides/pdf-notes.md#where-notes-are-shared) を参照してください。

## 信頼性の修正 {/* #reliability-fixes */}

Fix フォローアップスクロールと録画ファイルの質問をリプレイ保存し、インポートされたセッションを読み取り専用に保ち、セッションバインディングが変更したときにコンポーザーコンテキストを保持します。 記録された仕事の再生; コードを再実行しません。 [セッションリプレイ](../guides/session-replay.md) を参照してください。

Notebookは、カバーのクロス言語ファイルライン、破損した実行文書の回復、およびスペースを含むパスのR環境を固定します。 その他の修正は、既定の共有ログ設定を分離し、未添付のClaude権限の拒否を説明し、ブックマーク、タイトルバーのオーバーレイとアーティファクトトランザクションの修正を改善します。
