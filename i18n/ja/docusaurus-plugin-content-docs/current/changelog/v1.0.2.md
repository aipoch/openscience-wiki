# 更新履歴 · v1.0.2

公開日： **2026-10-22 UTC**. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.2).

## 利用できる科学データソースの拡充 {/* #scientific-sources */}

| データソース | 利用する設定項目 |
| --- | --- |
| HGNC の遺伝子命名情報 | Genes &amp; Ontologies |
| PubTator 3 の論文注釈 | PubMed |
| DGIdb の薬剤・遺伝子相互作用 | Clinical Genomics |
| RNAcentral のレコードと相互参照 | RNA |
| Orphadata の希少疾患関連情報 | Orphadata（先に有効化） |

追加後のカタログは **36 のデータソース項目、371 の操作**です。別途、オフラインの Molecule が 2 操作あります。 [データソースの選択と接続](../tools/databases.md#new-source-access).

GDC は症例、検体種別、ワークフローでファイルを絞り込み、検体・分注試料との対応を保持します。Ensembl VEP は手動の座標変換なしで HGVS を受け付けますが、入力の参照バージョンの検証やゲノム座標変換は行いません。ClinicalTrials.gov の公開済み試験結果も取得できます。参照： [クエリ結果の解釈](../tools/databases.md#clinical-context) および [全操作リファレンス](../reference/connector-operations.md).

## CLI のインストールと確認 {/* #cli */}

CLI と Task SDK が npm で公開されました。まず [npm のインストール手順](../guides/installation.md#npm-cli)に従ってください。次のコマンドは `version`, `help` および `paths` バックエンドを起動せずに利用できます。表示されるのは実行したインストールのバージョンです。デスクトップ版とスタンドアロン版には Node 22.23.4 のセキュリティ更新が含まれます。 [ローカル情報コマンド](../reference/cli.md#local-information).

## 会話の状態を把握して続ける {/* #conversation */}

質問カードは **Single select** と **Multi select** を区別し、各質問の回答履歴を保持します。送信待ちメッセージのエラーには取り消し操作があり、未送信の下書きがあると終了・再読み込み時に警告します。認証情報の復旧では下書きを保持して次の操作を案内します。リモート Web チャットでも成果物をメンションできます。 [質問カードと下書き](../guides/composer.md#clarification-questions).

## 研究記録の改善 {/* #research-records */}

- 研究パッケージのダイアログを安定化し、一部が保存されたインポートを再試行してもセッションが重複しないようにしました。インポートしたタイトルは変更できますが、研究記録は読み取り専用のままです。 [研究パッケージ](../guides/research-packages.md#browser-import).
- 大規模セッションの読み込みと起動時の復旧を改善しました。診断情報の出力が一部だけの場合は警告します。 [セッションの診断情報](../guides/sessions.md#session-diagnostics).
- PDF の構造、DOCX の段落番号・罫線、連続する Python/R 処理のファイル来歴記録を修正しました。 [来歴の確認](../guides/notebook.md#chained-analysis-lineage).
- 大量の Skill はバッチ単位でインポートします。外部の予約名は安全なローカル名に変換します。Codex 経由の MiniMax M3.1 接続も修正しました。 [モデル接続の復旧](../guides/providers.md#credential-recovery).
