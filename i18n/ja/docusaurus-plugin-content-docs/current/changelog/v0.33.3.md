# リリースノート・v0.33.3 {/* #release-notes--v0333 */}

**2026-09-26**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.33.3).

## ファイルを読み、文学を管理 {/* #read-files-and-manage-literature */}

オフィスビューアはページナビゲーションと検索を追加し、ページ付きPowerPointの読み込みで。 [ファイルのプレビュー](../guides/previews.md)で既存のQCファイルを使用します。

ワークスペース **Library** は、現在のプロジェクトや全条件検索と抽象化のためのコンパクトなプレビューを追加します。 スマートなコレクションは**実行を放棄**を加えます:完了した結果は残りますが、それは再開できません。 Crossrefメタデータ補完は、ソース抽象をインポートします。 [ライブラリ](../guides/library.md)と[ペーパースクリーニング](../workflows/screen-literature.md)を参照してください。

## 新しい科学データベース操作 {/* #new-scientific-database-operations */}

**ジャンルとオノトロジー**はEnrichrライブラリの発見と充実度を追加します。 **臨床ゲノム**は、薬物、遺伝子、変異体、ガイドライン、ラベル、および人口の頻度のClinPGxクエリを追加します。 完全なレジストリは、**28コネクターおよび284操作**:27のデータソースコネクタと282の操作、および2つのオフラインのMolecule操作を持っています。 [データベース機能](../tools/databases.md) と [操作の参照](../reference/connector-operations.md) を参照してください。

## リサーチパッケージ、外観、設置 {/* #research-packages-appearance-and-installation */}

パッケージ転送は、バックグラウンド作業中に利用可能な進捗状況で、自動または固定ディスクアクティビティの制限を追加します。 デスクトップスケールのショートカットは、設定の90%、100%、110%、125%のステップを共有します。 Windowsの署名は束ねられた実行可能をカバーします。 [パッケージ転送](../guides/research-packages.md#transfer-settings)、[インターフェイススケール](../guides/appearance.md#interface-scale)、[導入事例](../guides/installation.md) をご覧ください。

## フィックス {/* #fixes */}

Fix PDF読書タブフォント、分離されたNotebookカーネルの回復、付与されたフォルダへのネイティブアクセス、回復可能なレトリーズと解読不能エラー。 アーカイブの回復プロンプトは、影響を受けるプロジェクトの範囲です。 その他の補正は、初期の分類モデル選択、診断アーカイブサフィックス、Skillメタデータ、管理されたPythonおよび研究パッケージの使用記録をカバーします。
