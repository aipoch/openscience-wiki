## 1.0リリースに移動 {/* #upgrade */}

1.0は、既存の研究ワークスペースを安定したリリースラインに持ち込んでいます。 歴史的プロファイルのアップグレードと`.science`のインポートを保持します。 バージョン変更は、新しいプロファイルやデータ形式を必要としません。 プロフィールと研究データをバックアップし、アクティブな作業を終了し、公式のデスクトップインストーラーでアップグレードします。 バイナリダウングレードはデータ変更を行わない。

この出版物は**デスクトップパッケージのみ**を含んでいます。 スタンドアローンCLIアーカイブとLinux CLI `.deb` / `.rpm`アセットは不在であり、ウェブサイト/自動更新プロモーションは別々です。 1.0 用のデスクトップ対応コマンドランチャーを使用します。 古いCLIアーカイブの名前を変更したり、Homebrew/npmを既に同じバージョンに提供していると仮定したりしないでください。 `open-science update` は削除されます: インストールを所有するデスクトップ制御またはインストーラ/パッケージマネージャを使用してください。 [インストールと1.xの互換性](../guides/installation.md#version-compatibility) を参照してください。

## 作業を中断し続ける {/* #recovery */}

互換性のあるデスクトップは、以前のコントローラーが切断した後、デスクトップで拡張されたバックエンドを存続させることができる。 CLI-launchedサービスは独立したままです。 失敗したシャットダウンの準備は窓を開け、仕事が続行する前に元の会話の状態を元通りに再接続します。 未知な結果でリクエストをキャンセルする前に、保存された操作を確認してください。 [サービスオーナーシップと回復](../reference/server.md#desktop-service-recovery) を参照してください。

ACP の会話は、選択したエージェントで再開します。 Codex セッションを取り外して、Specialist スイッチの直後に回復します。 次のターンを送る前に [選択したエージェントと元のセッションをチェックする](../guides/sessions.md#resume-selected-agent) を送信します。 文脈のコンパクト化中に文学選択とキャンセルも修正を受け取ります。

## 質問に答えてPDFを読んでください {/* #interaction */}

- クラリファイカードは、長いオプションリストと複数の選択をサポートしています。 質問の答えをレビューし、**Finish**を選択します。 選択されたオプションは、ドラフトです。 [明確化質問に答える](../guides/composer.md#clarification-questions).
- 注意ボタンはホバー、フォーカス、または選択に表示され、読みながらPDFクリアを維持します。 [ノートを明らかにする](../guides/pdf-notes.md#reveal-note).
- PDF抽出と翻訳は、より複雑なソースレイアウト、ネイティブテーブル/フィグレーションの関係、科学的な機能を維持します。 **New translation**は、新鮮なソーステキストを用意します。 再使用前に元の結果と比較して下さい。 [抽出チェック](../guides/previews.md#scientific-structure-check) · [翻訳](../guides/pdf-translation.md#scientific-layout).

## 科学的なデータコンテキストを保存 {/* #data-context */}

| ソース | 変更点 |
| --- | --- |
| アーレイエクスプレス | 異なるサンプル識別子からSDRFの関係列を区別する。 不完全な識別子は未知のサンプル数を返すことができます |
| メタボライト | サンプルテーブルの列を繰り返して、元の注文を上書きするのではなく、値を上書きする |
| Bgee | 解剖学的および細胞型コンテキストを保存します。 欠落した細胞タイプは残ります `null` |
| dbSNPの特長 | 配置のためのすべての染色体/アセンブリ協会を保存します |
| OpenAlex | セッションごとにクレデンシャルプロンプトを低下させないでください |

[フィールド通訳ガイド](../tools/databases.md#scientific-context) と [v1.0.0 Connectorリファレンス](../reference/connector-operations.md) を読んで、保存されたクエリを再利用する前に読んでください。 Notebookリスク分析は、約束のコールバックの治療も改善します。 既存の承認要件はまだ適用されます。

## 1.0 が変更されないこと {/* #scope */}

記録されたセッションの再生はコードを実行しません。 アーティファクト検証は、取得済みの入力と使用可能な環境が必要です。 全セッションの科学的妥当性や決定的な再生を確立しません。 インポートされた`.science`レコードは読み取り専用のままです。 書き込み可能な継続のためにフォークを使用してください。 パッケージからクレデンシャル、サイドチャット、プライベートブックマークは復元されません。 SSH/Slurm 計算はサポートされます; 管理されたクラウド-GPU 送信, ローカル GPU バックエンドとリアルタイムのマルチユーザ編集は、このリリースの外にあります.
