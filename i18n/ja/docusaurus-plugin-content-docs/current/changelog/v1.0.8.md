# リリースノート・v1.0.8

リリース **2026-11-04 UTC**. [公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.8).

## 文献リストをライブラリへ取り込む {/* #literature */}

ペーパー識別子のリストはありますか? **Add from DOI or link** では、DOI、arXiv、PMID、PMCID、対応する公式論文リンクを、空行を除き最大 100 行まで入力できます。検索結果と重複時の処理を確認してからインポートしてください。メタデータの取得だけでは全文は取得されません。 [バッチ輸入ウォークスルー](../guides/library.md#doi-link-import).

現在の参照の細部は下記のものを含んでいます **Study overview**。 構成されたメインモデルは、利用可能なソースを5つのセクションに整理します:研究質問、研究人口、方法、主な発見と制限。 ソースラベルは抽象的な、完全なテキストと選択した通路を区別します。 あなたの読書に向き合うためにそれを使用して下さい、そして元のペーパーの重要な要求を点検して下さい。 [概要を生成](../guides/library.md#study-overview).

## 設定項目を整理 {/* #settings */}

**Appearance** そして、 **Notifications** 別のパネルは下にあります **System**。 一般はアプリ情報、診断、コマンドラインツール、マニュアルインストールガイドを含むヘルプを保持します。 設定センターは現在持っています **4 グループ、19 パネル**. [設定マップ](../settings/overview.md) · [外観と通知](../guides/appearance.md).

## 研究・日常の信頼性 {/* #reliability */}

- eQTLカタログでは、REST API が退職後、インデックス化された release-7 ファイルを使用します。 Queriesはexplicitを必要とします **GRCh38** 遺伝子 ID 単独では、有効なクエリは行いません。 [座標要件](../tools/databases.md#eqtl-coordinates).
- PDF 注文は、テーブル行からプロセの列を区別するために、配置されたテキストを使用します。 抽出は、クロップ境界をチェックし、信頼性警告であいまいなセルテキストを保存します。 [PDF読書と抽出](../guides/previews.md#automatic-pdf-reading-order).
- R の再現性チェックでは、引数の評価やメソッドのディスパッチを伴う操作の後に、古くなったファイル証拠を無効にします。来歴パネルは実行証拠が不完全な状態を説明し、古い Markdown 成果物は開いたときに履歴の参照先を修復します。 [検証証拠を読む](../guides/reproducibility.md#execution-evidence).
- セッションのリリースプロバイダとツールは、すべての 5 つの Agent フレームワークで処理されます。 パッケージ化されたデスクトップのビルドの Pi のインストールは修復されます。
- 準備の更新は、より明確にプロセスをブロックする識別します。 Fix macOS読み取り専用ファイルホルダー、Windowsプロセスの検出とノートブックの回復レコードをアドレスします。 診断パッケージは、実際のデスクトップの回復エラーを保持します。 [アップデートガイド](../guides/installation.md#update-preparation).
- 保存先フォルダーを読み取れない場合や、その後の後処理でエラーが発生した場合でも、ダウンロード済みのファイルは保持されます。Windows の PDF 終了処理と保護チェックも改善されました。PATH の Node が古くプロキシに対応していない場合、Notebook のコマンドラインツールはアプリ同梱の Node を使用できます。
- 完全なテキスト検索は、以前のPDFの追加エラーをクリアし、Composerは利用できなくなったモデルの通知を繰り返すことはありません。

Tencent TokenHub に Hy4 と、100 万トークンのコンテキストに対応した DeepSeek V4.1 Flash のルートが追加されました。GLM-5.3-Flash、Kimi K3、MiniMax M3 は画像入力にも対応します。利用可否はプロバイダーのアカウントと選択したルートによって異なります。 [プロバイダーのセットアップ](../guides/providers.md).

ビルトインカタログは残っています **48 個の Connector、418 個の操作**. [現在のカタログ](../tools/databases.md#supported-databases) · [過去のリリース](v1.0.7.md).
