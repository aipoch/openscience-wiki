# リリースノート · v1.0.4

**2026-10-27 UTC** 公開。[公式リリース](https://github.com/aipoch/open-science/releases/tag/v1.0.4)。

## 外部ツールを研究環境へ接続する {/* #mcp */}

独立 CLI の stdio MCP アダプターを使えます。認証済みローカルサービスを先に起動し、そのプロファイルに接続します。既存権限でプロジェクト作成、設定変更、研究を実行でき、書込みやモデル利用料が発生し得ます。[MCP の設定と制御](../reference/cli.md#external-mcp)。

## 論文の出版通知を確認する {/* #publication */}

有効な DOI を持つ文献の撤回・訂正を Crossref に手動照会できます。結果には出典と確認時刻が残ります。通知がなくても問題がない保証にはなりません。[通知の確認と解釈](../guides/library.md#publication-checks)。

## 日々の作業を整理する {/* #workspace */}

- 完了したターンの中間メッセージとツール群を折りたたみ、検索や注釈から再表示できます。[会話を展開](../guides/sessions.md#collapsed-conversation)。
- 許可済みフォルダーのファイルを変更不能な会話の成果物として保存できます。[ローカルファイルの取込](../guides/files.md#import-local-artifact)。
- スキャンした GitHub Skill リポジトリを保存できます。Skill は自動更新されません。[保存済みリポジトリ](../skills/manage.md#saved-repositories)。
- 質問カードに **Skip** と **Skip all** が加わりました。[質問の操作](../guides/composer.md#skip-question)。

配布ファイルが小さくなり、Windows Notebook 標準モード、保存先選択後のエクスポート待機、フォルダー許可ダイアログ、質問の復旧、リプレイイベント表示が修正されました。[パッケージ転送](../guides/research-packages.md#local-package-transfer) · [前の版：v1.0.3](v1.0.3.md)。
