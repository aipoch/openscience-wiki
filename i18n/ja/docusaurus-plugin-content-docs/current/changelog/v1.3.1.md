# 変更ログ・v1.3.1 {/* #changelog--v131 */}

**2026-11-19 UTCの特長**リリース [公式リリースノート](https://github.com/aipoch/open-science/releases/tag/v1.3.1).

## ソースを見つけ、引用に従う {/* #sources */}

内蔵のOpen-Scienceエージェントは、パブリックWebと読み上げページを検索し、ソースの引用は会話と一緒に保持されます。 承認を検索すると、クエリとフィルタが表示されます。 Queries は Exa に行く。 ウェブサイトの連絡先をお読みください。 [Web検索と読み出し](../tools/web-search.md).

ライブラリはインタラクティブな引用グラフを追加します。 フィルター参照および引用のペーパーは、関連したペーパーを新しい中心として選ぶか、または元のペーパーに戻ります。 ライブラリに追加する前に、Inbox の候補をレビューします。 [引用グラフを見る](../guides/library.md#citation-discovery).

## エージェントと組織リソースを接続する {/* #connections */}

外部のMCPクライアントは、接続時にローカルOpen-Scienceサービスを開始または再利用できるようになりました。 クライアントが切断した後、サービスが実行されます。 終了時に明示的に停止します。 [MCPの設定](../reference/cli.md#external-mcp).

デスクトップアプリでは、Labアカウントは、組織の割り当てられたモデルと共有された研究ケースへのアクセスを提供します。 モデルリクエストと共有パッケージは、設定されたLabサーバーに移動します。 [ラボアカウントのセットアップ](../guides/providers.md#lab-account) · [組織の事例](../guides/research-packages.md#organization-cases).

## モデルとリソースをさらに制御 {/* #controls */}

- サポートされているプロバイダのモデルリストを &#91;設定&#93; で更新します。 更新が失敗すると、以前のカタログが保存されます。 会話エラーは、認証、クォータ、レートリミット、その他の原因を説明します。 [プロバイダーのセットアップ](../guides/providers.md#refresh-models).
- 画像サービスを保存する前に、テストイメージ生成を実行します。 デフォルトが存在しない場合、最初のモデルが自動的に選択されます。 [イメージサービスの設定](../guides/image-generation.md#configure).
- Notebook は実行前にメモリをチェックします。 Compute を使用して、セッションのローカル Notebook リソースを調べてリリースし、意図的に作業を再試行します。 [記憶および資源管理](../guides/notebook.md#memory-resources).
- スタートアップがプロジェクトを早くロードします。 リコネクションは、ドラフトを保存し、長い分岐履歴と保留中の質問を復元します。 研究フィルム再生は、関連する品質レビューを待たずに待つことはありません。

## v1.3.0からの更新 {/* #update */}

v1.3.0 updaterは、インストールを使用して別のプログラムのアプリ所有プロセスを間違える。 このブロックが更新をブロックしたら、アクティブな作業を終了し、アプリとその背景サービスを完全に終了し、公式のv1.3.1パッケージを手動でインストールします。 v1.3.1のインストールは、v1.3.0で既に実行されている更新者を修復することはできません。 [マニュアル更新手順](../guides/installation.md#update-from-130).

また、リリースは、Windows アップデート/アンインストール時に大きな設定ファイル障害を修正し、オプションの WSL セットアップブロックの最初の実行、Windows でインポートされたセッションの不完全な削除、および Linux AppImage 更新は、アプリ所有のパイプを誤認するチェックを行います。 スタートアップリカバリーのパスで、未だに研究フォルダが現れているので、そのドライブを再接続できます。

[インストールとアップデート](../guides/installation.md)と[v1.3.0](v1.3.0.md)を参照してください。
