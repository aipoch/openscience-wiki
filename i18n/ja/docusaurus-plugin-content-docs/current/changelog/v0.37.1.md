# リリースノート・v0.37.1 {/* #release-notes--v0371 */}

**2026-10-12 UTCの特長**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.37.1).

## 科学的なPDF構造を維持して下さい {/* #preserve-scientific-pdf-structure */}

図抽出は、キャプション、伝説、マルチパネルグラフィックスを保存します。 グループ化されたヘッダ、行構造、およびソースセルの参照を保持する式の横にルードテーブル。 キャプション、グラフィック、テキストは、隣接するものではなく、ソース要素で保持されます。

[図表](../guides/previews.md#pdf-extraction)を使うと、抽出された要素を引用する前に元のページと比較します。 完全なパネル、凡例、テーブルヘッダー、ユニット、フットノートをチェックします。 翻訳されたPDF再生は、元のソースインクを維持しながら、埋め込まれたグリフの名前の有効な違いも受け入れます。 [比較とエクスポートチェック](../guides/pdf-translation.md#compare-export)を使う。

## Windowsおよび取付け {/* #windows-and-installation */}

- デスクトップ CLI は、中国語や他の非 ASCII 文字を含むインストールパスを扱い、発信者のコードページと終了コードを保存します。 古いランチャーがそのパスを誤った場合、ターミナルを更新し、再開します。 [CLI セットアップ](../reference/cli.md#terminal-setup) を参照してください。
- ローカルPDFの翻訳は、Windowsドライブパスを正しく処理します。
- Notebookカーネル、環境指紋、パッケージの在庫、ロックキャプチャは、追加のコンソールウィンドウをフラッシュ避けます。
- デスクトップとスタンドアローンのランタイムパッケージは、未使用の重複依存関係とアセットを削除し、v0.37.0で導入されたダウンロードの拡大を削減します。

[v0.37.0](v0.37.0.md)で導入されたスタンドアローンCLIとNodeバックエンドは、サービス運用の基礎を保ちます。 プラットフォームに合ったパッケージを使用して、抽出されたランタイムディレクトリをそのまま保持します。
