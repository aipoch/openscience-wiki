# リリースノート・v0.34.0 {/* #release-notes--v0340 */}

**2026-09-28 UTCの特長**(**2026-09-29中国標準的な時間**)にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.34.0).

## ジャーナルデータセットと文献参照 {/* #journal-datasets-and-literature-references */}

ライブラリは、ジャーナルのデータセットをソース、年、列のマッピングで追加し、マッチングペーパーの属性を表示しています。 専用の[ジャーナルデータセットと参照属性ガイド](../guides/journal-datasets.md)に従ってください。

ワークスペースライブラリのアクションは、参照の詳細、明示的なバッチ選択、現在のまたは別の会話の草案で参照を追加します。 送信する際は、まだ選択します。 [ライブラリのアクション](../guides/library.md#add-reference-to-chat) を参照してください。

## 科学データベースの拡張 {/* #scientific-database-expansion */}

Pathway CommonsはBgee、cBioPortal、openFDAおよびMGnifyの適用範囲を拡大し、**16の操作**を加えます。 フルレジストリには、**29コネクターおよび300操作**:298の操作と2つのオフラインのMolecule操作で28のデータソースファミリーが含まれています。

詳しくはこちら [データベースの機能とセットアップ](../tools/databases.md#pathway-expression-clinical), , [操作パラメータ](../reference/connector-operations.md) そして、 [パスウェイインタラクションワークフロー](../workflows/inspect-pathway.md) 保存された例の結果を使って。

## インストール、モデル、デスクトップナビゲーション {/* #installation-models-and-desktop-navigation */}

- Linux は、ネイティブ ARM64 AppImage と Debian パッケージを追加します。 [導入事例](../guides/installation.md) を参照してください。
- Codex CLIの互換性ベースラインは**0.157.1**です。 既存の古いランタイムは、独自のアップデートが必要である可能性があります。 [Codexの更新](../guides/frameworks.md#update-codex) を参照してください。
- **MiniMax M3.1フラッシュプレビュー** と **クロード・ソンネット 5.5** のプロバイダカタログを追加しました。 [プロバイダーの設定](../guides/providers.md#catalog-models) を参照してください。
- デスクトップトレイ/メニューバーのナビゲーションは、実行、ピン留め、最近のセッションを開きます。 [クイックナビゲーション](../guides/navigation.md#tray-navigation) を参照してください。

## 改善と修正 {/* #improvements-and-fixes */}

より速いワークスペースの転換および少数のインタープリナーdiscoveryのサブプロセスとバージョン43への電子アップグレード。 エージェントの接続エラー、停止または再起動後の委任、中断されたレビュアー評価、PDF 図/テーブル抽出、文献メタデータ、WSLランタイムの信頼性とmacOSリモートディレクトリリスト後のカバー回復を修正しました。 保護、キーボードの焦点および許可の記述の編集はまた改善します。
