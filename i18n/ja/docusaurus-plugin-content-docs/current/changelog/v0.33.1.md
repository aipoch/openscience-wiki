# リリースノート・v0.33.1 {/* #release-notes--v0331 */}

**24 9月 2026**にリリース。 [公式リリース](https://github.com/aipoch/open-science/releases/tag/v0.33.1).

## 文学のスクリーニングとPDF読書 {/* #literature-screening-and-pdf-reading */}

スマートコレクションは、一時停止/再開制御とプロジェクトやコレクションスコープへのリンクで、ライブ**Screening process**を表示します。 保存された実行は、そのルールと紙と互換性があります。 マニュアルの決定はまだメンバーシップを決定します。 [スクリーンおよび検討のペーパー](../workflows/screen-literature.md) を参照してください。

PDF 証拠は、最初のワークスペースメッセージに同行することができます。 ライブラリ PDF を開き、**Read with agent** を選択し、プロジェクトを選択し、質問を送信する前に、読み込みの添付ファイルを確認します。 [PDF コンテキスト](../guides/previews.md#first-message-pdf) を参照してください。

## 科学コネクタ {/* #scientific-connectors */}

- **ムマー**はプログラム固有のタンパク質/プロファイル/アライメント検索、ステータスおよび完了した結果を追加します。
- **インタープロスキャン** は、既存のアノテーションジョブを確認し、TSV レポートを取得します。 ジョブを送信しません。
- **ゲノム**は、少なくとも3つのFASTAレコードのClustal Omegaを追加します。 [複数のシーケンス・アライメント・ワークフロー](../workflows/multiple-sequence-alignment.md) をフォローしてください。
- **OpenAlex** はアプリのキーを必要としません。 サービスの制限は適用します。 [オプションのクレデンシャル設定](../tools/credentials.md) を参照してください。

ビルトインレジストリには、オフラインのMolecule Connectorを含む**28コネクターおよび271操作**が含まれています。 [データベースの機能](../tools/databases.md) · [操作の参照](../reference/connector-operations.md).

## 設定、診断および修正 {/* #settings-diagnostics-and-fixes */}

提供者カタログはGPT-6およびClaude Opus 5.5を加えます; アカウントアクセスとフレームワークの互換性はまだ可用性を決定します。 [モデルプロバイダー](../guides/providers.md#catalog-models).

セッション診断は、パッケージエクスポートによってフラグが付けられた元のファイルから赤字の証拠を区別します。 元の機密ファイルはデフォルトでチェックされていないため、選択した時にのみ含まれています。 輸出はローカルにとどまります。 [診断輸出](../guides/troubleshooting.md#session-diagnostics).

設定ヘッダーとローカルパネルの検索は、別々のショートカットを持っています。 履歴データの場所は、アップグレード中に保持されます。 その他の修正アドレス Windows 管理 Python 発見, R アクセス拒否されたプロンプト, 実行時間/コンピューティング セーブレース, ACP ビジョン機能の変更, ファーストエンド PDF アイデンティティ, 重複送信, 数値のクロップ/リビジョン. [ショートカット](../guides/shortcuts.md#local-settings-search) · [ストレージ](../guides/storage.md#historical-data-location).
