# ページと管理のインデックス {/* #page-and-control-index */}

このページでは、アプリケーションのエントリ ポイントを検索可能なページバイページ リストに凝縮します。 状態に依存しない制御は、その条件が満たされた場合にのみ表示されます。 コントロールが無効な場合は、ツールチップと関連する既知の問題を読みます。 可能な原因は、セッション状態、欠落した前提条件および製品欠陥を含みます。


<span id="current-verification-coverage" />

## 詳細な指示を見つける {/* #find-the-detailed-instructions */}

このインデックスを使用して、コントロールを見つけます。 前提条件、手順、予想される結果および既知の問題のためのリンクされたチュートリアルに従ってください。 設定パネルの[設定の概要](../settings/overview.md)、一般的な操作のための[タスクのショートカット](controls.md)、エラーについては[トラブルシューティング](../guides/troubleshooting.md)を参照してください。

## オンボーディング {/* #onboarding */}

| ページ、ウィザードの順序で | コントロール | 結果または前提条件 |
| --- | --- | --- |
| 環境 | 再びチェック, 続行, 行をチェック | ホストの要件を再確認する。 渡る後続行して下さい |
| データの場所 | ブラウザ..., 代わりにデフォルトの場所を使用してください。, 戻る, 続行 | データの場所を選択します。 カスタム選択はデフォルトを保ち、確認を再開する必要があります |
| エージェントランタイム | フレームワークカード, インストール, 再検出, バック, 続行 | 既定のアクティブなランタイムをインストールまたは選択する |
| モデルプロバイダー | 提供者のタイプ、認証の選択、条件分野、テスト及び続行して下さい | 必要な入力を検証し、プロバイダを検証する前に、アドバンシングする |
| Notebook ランタイム | 通訳制御、環境のセットアップ、パッケージ、背部、終わり | 任意設定; 退去前に、すでに進行中の環境動作を終了または中止する |

[初回設定](../guides/onboarding.md) と [プロバイダの構成](../guides/providers.md) の詳細なウォークスルーを参照してください。

## グローバル設定制御 {/* #global-settings-controls */}

**Search settings**は4つのパネルグループを横断します。 `Back`、`Forward`、パン粉、`Maximize/Restore`、`Close settings`、モバイルナビゲーション、エラー`Dismiss`は、設定全体に適用されます。 グループと検索ショートカットの[設定の概要](../settings/overview.md)を参照してください。

### Skills {/* #skills */}

会話 Skill インポート, ソース フィルター, 検索, スキルを追加, カテゴリの崩壊, Skill 詳細情報, スイッチを有効にします。, 作成/アップロード/インポート, プレビュー, 編集, エクスポート, 削除, キャンセル, 保存.

### メモリ、タグ、認証情報、使用方法 {/* #memory-tags-credentials-and-usage */}

メモリカテゴリ/エントリの作成、編集、削除、およびクリア。 タグ 作成/編集/削除, 代入, お気に入り, フィルター, 再注文; クレデンシャルは、健康、使用量、およびConnector結合を生成/回復/削除します。 利用期間、メトリック、ヒートマップ、毎日のチャート、ターン/コール、およびグループ化制御。

### コネクタ {/* #connectors */}

フィルター/検索, 追加/インポート, 有効, 詳細, テスト/再接続, 編集, エクスポート, 削除. Addフォームには、タイプ、表示名、ID、説明、コマンド、引数、環境変数、URL、転送、認証、OAuthスコープ、認証サーバーURL、クライアントメタデータURL、ヘッダ、トラスト、キャンセル、および追加/保存が含まれます。

### スペシャリスト {/* #specialists */}

カテゴリー フィルター, 検索, 有効, 詳細, アクション, 作成, インポート. エディタには、アイコン、色、名前、説明、指示、完全なアクセス、機能タイプ、Skill/Connector検索、選択された機能、キャンセル、および保存が含まれます。 インポートには、ZIP、プレビュー、診断、キャンセル、およびインポートを選択します。

### コンピュート {/* #compute */}

ホスト、ホストカード/有効、プローブ/リトライ、詳細/編集/削除、リソース、Direct SSH/Slurm実行モード、詳細文書、スクラッチルート編集/入力/保存/キャンセル、および同時ジョブ制限の編集/入力/保存/キャンセル。 執行の承認は、Deny、一度、セッション、プロジェクト、およびグローバルを提供します。

### ネットワーク {/* #network */}

もう一度チェックしてください。 プロキシシステム/マニュアル/ダイレクト; Notebook ドメイン ウィットリスト; パッケージ ミラーの構成/編集; コンダチャンネル、ピップインデックス、およびCAバンドル。 ミラー、キャンセル、および保存の表示。

### モデル {/* #model */}

アクティブモデル、ラジオの受信、サブエージェント/リビューア/Vision/Session-detailsモデルポリシー; プロバイダーテスト/編集/削除/追加。 プロバイダーのフォームには、オンボーディングモデルページからすべてのフィールドとキャンセルと保存が含まれます。

### エージェント {/* #agent */}

OpenCode/Claude/Codex/CodeBuddyフレームワークカード, スイッチ, インストール/キャンセル/リトリー, ログをインストール, 修理, サインイン/auth, インポートコンフィグ/ホーム, そして、確認をアンインストール.

### 権限 {/* #permissions */}

デフォルトプロファイル、スコープフィルタ、付与スコープリンク、コネクタヒント、リヴォークと確認、および不完全なストアの警告またはリフレッシュ。

### ランタイム {/* #runtimes */}

Python/R; 環境 有効化, 通訳者を追加, ダウンロード/セットアップ, 修理, パッケージのインストールを許可します。, パッケージ, フィルター, 追加/インストール/削除パッケージ, 確認.

### ストレージ {/* #storage */}

応用貯蔵のReveal/修理; データの場所 変更、パス、ブラウズ、チェック、マイグレート/アドプト/キャンセル; 移行の進行 キャンセル/再試行/再起動/無効; 拡張可能なディスク使用カテゴリ。

### 一般 {/* #general */}

タスク通知、テーマラジオ、アプリのアイコンラジオ、クローズ動作、GitHubトークンオープン/インプット/セーブ/クリア、およびAbout/Checkの更新/インストール更新。

### リモート・コントロール {/* #remote-control */}

スタート/ストップ/リフレッシュ、コピー/オープンURL、QR Remote.It セットアップ/リトライ/ディスコネクト; 信頼されたブラウザのリヴォーク; ペアリング リクエスト 一度/常に信頼を取り戻す リクエストの拒否/削除。

### アーカイブ済み {/* #archived */}

プロジェクト管理、プロジェクトを復元、プロジェクトを削除 セッションの復元/削除; 削除確認 キャンセル・確認
