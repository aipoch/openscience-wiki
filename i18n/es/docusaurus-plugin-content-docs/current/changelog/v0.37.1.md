# Notas de lanzamiento · v0.37.1 {/* #release-notes--v0371 */}

Liberado en **2026-10-12 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.37.1).

## Estructura científica Preserve PDF {/* #preserve-scientific-pdf-structure */}

La extracción de figuras mejor conserva capciones, leyendas y gráficos multipanel. Las tablas regladas junto a las fórmulas conservan los encabezados agrupados, la estructura de filas y las referencias de las células fuente. Capciones, gráficos y texto se guardan con su elemento fuente en lugar de uno vecino.

Al utilizar [Figuras y tablas](../guides/previews.md#pdf-extraction), compare el elemento extraído con su página original antes de citarlo. Comprobar paneles completos, leyendas, cabeceras de mesa, unidades y notas de pie. La regeneración PDF traducida también acepta diferencias válidas en los nombres de glifos incrustados, preservando al mismo tiempo la tinta de origen original; usa el [comparaciones y comprobaciones de exportación](../guides/pdf-translation.md#compare-export).

## Windows e instalación {/* #windows-and-installation */}

- El escritorio CLI maneja las rutas de instalación que contienen caracteres chinos y otros caracteres no ASCII, preservando la página de código de llamada y el código de salida. Actualizar y reabrir el terminal si un lanzador mayor malinterpreta su camino; ver [CLI setup](../reference/cli.md#terminal-setup).
- La traducción local PDF maneja las rutas de la unidad Windows correctamente.
- Los núcleos Notebook, las huellas digitales del medio ambiente, los inventarios de paquetes y la captura de bloqueo evitan la aparición de ventanas de consola extra.
- Los paquetes de tiempo de ejecución autónomo y de escritorio eliminan las dependencias y activos duplicados no utilizados, reduciendo el crecimiento de descarga introducido en v0.37.0.

El backend CLI independiente y Node introducido en [v0.37.0](v0.37.0.md) siguen siendo la base para el funcionamiento del servicio. Utilice el paquete que coincida con su plataforma y mantenga intacto el directorio de tiempo de ejecución extraído.
