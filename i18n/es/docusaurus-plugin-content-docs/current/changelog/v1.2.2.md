# Notas de lanzamiento · v1.2.2 {/* #release-notes--v122 */}

Liberado en **2026-11-18 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v1.2.2).

## Elija más estricto Cuaderno de contactos {/* #strict-network */}

**Settings → Network → Manage access** ofrece ahora modos **Relaxed** y **Strict**. Strict permite sólo coincidencias manuales de lista blanca por protocolo, nombre de host o IP, y puerto. Las solicitudes sin igual están bloqueadas sin un aviso de autorización. Relajado sigue siendo el predeterminado. Las reglas se pueden organizar en grupos; las etiquetas incorporadas y manuales muestran su origen. [Creación de redes](../guides/network.md#public-network-rules).

## Recuperar películas de investigación interrumpidas {/* #film-checkpoints */}

La generación de películas conserva escenas validadas, narración y trabajo de tiempo a través del proceso se reinicia. Retire de un puesto de control o inicie deliberadamente una nueva generación. El progreso identifica la etapa actual. [Pasos de recuperación](../guides/research-films.md#film-recovery).

## Leer PDFs y recuperar trabajo local {/* #recovery */}

- La extracción de PDF nativa preserva mejor las figuras, cauciones, contenido de tabla y orden de lectura. Compare el material extraído y los diseños traducidos con el PDF original. [Extracción en PDF](../guides/previews.md#pdf-extraction).
- Windows comprueba el acceso de una carpeta protegida antes de guardar una subvención; actualizar y desinstalar recuperación preservar mejor diagnóstico.
- Las importaciones de `.science` distinguen la cancelación, paquetes inválidos y plazos. Después de un tiempo no confirmado, consulte la sesión importada antes de presentar nuevamente. [Importar un paquete de investigación](../guides/research-packages.md).
- Cuando el servicio local se desconecta, el espacio de trabajo muestra estado de recuperación y preserva el borrador del Compositor.
- Bailian Token Plans añadir **Qwen4 Max Preview**, incluyendo opciones de catálogo regional. La disponibilidad depende de la cuenta seleccionada. [Configuración del proveedor](../guides/providers.md#provider-regions).

Ver [instalación y actualizaciones](../guides/installation.md) y [v1.2.1](v1.2.1.md).
