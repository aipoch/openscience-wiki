# Changelog · v1.3.3 {/* #changelog--v133 */}

Liberado **2026-11-22 UTC**. [Notas oficiales de liberación](https://github.com/aipoch/open-science/releases/tag/v1.3.3).

## Actualizaciones que encajan alrededor de su trabajo {/* #updates */}

Las instalaciones oficiales estables de macOS pueden instalar una actualización preparada cuando se detiene. Windows y Linux pueden preparar actualizaciones para el próximo lanzamiento mientras que el escritorio está ocioso en el fondo. Las descargas automáticas requieren una conexión sin restricciones y un almacenamiento suficiente; ubicaciones y canales de instalación sin soporte conservan la ruta manual. Las actualizaciones de aplicaciones de Linux preservan el camino de aplicación. Windows v1.3.3 utiliza el instalador completo; compactos devuelven las deltas en [v1.3.4](v1.3.4.md#updates). [Actualizaciones automáticas y manuales](../guides/installation.md#update-progress).

Las aplicaciones macOS y Windows instaladas son más pequeñas. El tiempo de ejecución de las npm está incluido para Node 22, reduciendo el número de archivos sueltos.

## El agente incorporado es el predeterminado en todas partes {/* #agent */}

Nuevos proyectos y sesiones por defecto a **Open-Science Agent**, incluyendo instalaciones CLI y SDK limpias. Un agente externo ausente SDK ya no impide que esas instalaciones comiencen. Instalar un marco externo sólo cuando elija utilizarlo; el acceso modelo todavía necesita configuración. [Configuración del agente](../guides/frameworks.md#built-in-agent) · [CLI setup](../reference/cli.md#terminal-setup).

Ajustes restaura atajos para instalar Skills, Especialistas y Conectores. El catálogo de Bailian agrega la familia qwen4, con su plan por defecto cambiado a la vista previa qwen4. Compruebe el modelo disponible a su cuenta antes de comenzar el trabajo.

## Editar imágenes en la conversación {/* #images */}

Introduzca **Edit image** de una vista previa y escriba la edición en el compositor de conversación. La navegación y comparación de la versión de imagen siguen disponibles, y la conversación permanece en su lugar al entrar en la edición. Los detalles de la imagen identifican el kernel Notebook detrás de una edición. [Pasos de edición de imágenes](../guides/image-generation.md#edit).

La traducción PDF mejor vuelve a conectar texto dividido en columnas, capciones y fórmulas inline, y evita la notación desplazada, etiquetas de formularios y gráficos vecinos. Continuar comprobando las páginas exportadas contra el original. [PDF traducción](../guides/pdf-translation.md#scientific-layout).

## Fallos más claros y recuperación {/* #recovery */}

- Solicite, cargue, adjunto, importación y errores Notebook explican sus causas. Los errores del proveedor conservan su clasificación y solicitan ID en reiniciar; El trabajo detenido se distingue de una continuación sin respuesta. [Solución de problemas](../guides/troubleshooting.md#provider-errors).
- Windows conserva una pregunta de agente integrada pendiente en reiniciar, restaura el estado de funcionamiento de Notebook y vuelve a comprobar los bloqueadores de archivos estancados durante un lanzamiento frío.
- Los cheques de memoria Notebook representan memoria física Windows, presión de memoria macOS y límites de contenedores Linux. [Memoria y recursos](../guides/notebook.md#memory-resources).
- Las exportaciones de paquetes de sesiones esperan que Notebook diga que se establezca antes de informar sobre fallos de exportación. Enlaces de artefactos guardados, eliminación de memoria confirmada y errores de importación GitHub Skill también son corregidos.
