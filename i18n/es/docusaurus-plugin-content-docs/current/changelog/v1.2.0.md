# Notas de lanzamiento · v1.2.0

Publicado **2026-11-09 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v1.2.0).

## Elige dónde funciona un cálculo {/* #remote-compute */}

Kubernetes, Hugging Face Jobs, Modal y Ray se unen a SSH y Slurm Direct. Configure un objetivo, revise las entradas congeladas, el comando, los recursos y la colección de productos, a continuación, apruebe cada presentación externa. Los registros de recuperación ayudan a reanudar la recogida después de un reinicio, y los productos publicados abiertos de **Compute Preview**. Estas opciones utilizan su propia infraestructura o cuenta de nube. [Configuración de componentes remotos](../guides/remote-compute.md#compute-backends).

## Empieza con el agente incorporado {/* #agent */}

Nuevas configuraciones por defecto **Open-Science Agent**, un tiempo de ejecución integrado que funciona con proveedores de modelos compatibles. Claude Agent, OpenCode, Codex, CodeBuddy y Pi permanecen disponibles. El proveedor de tiempo de ejecución y modelo son opciones separadas; una configuración de Codex existente no necesita ser reemplazada. [Opciones de agente](../guides/frameworks.md#built-in-agent).

## Discuta el paso preciso de la investigación {/* #discussions */}

Importados `.science` Las medidas de investigación y repetición apoyan los debates relacionados con los niños. **Ask about this step** Lleva las pruebas seleccionadas, incluyendo una versión registrada de Notebook, a la discusión. Destacados de la historia importada **Fork to continue** para empezar una continuación. Las sesiones de grupos de barra lateral como **Pinned**, **Imported research**, **Active** y **Recents**. [Replay discussions](../guides/session-replay.md#discuss-replay) · [Paquetes de investigación](../guides/research-packages.md#linked-discussions).

## Actualizaciones más pequeñas y controles más claros {/* #reliability */}

- actualizaciones de macOS pueden descargar bloques cambiados, cayendo de nuevo a una descarga completa cuando sea necesario. Los controles de instalación verifican la aplicación de ejecución e identifican los archivos o procesos de bloqueo.
- **Local capabilities** reemplaza a los **Local parsing models** tab y grupos Extracción PDF, OCR y narración de investigación. [Recursos locales](../guides/models.md#local-capabilities).
- La entrada de referencia manual acepta un identificador sin título, incluyendo el PMID. Los controles de película evitan las acciones indisponibles al cargar.
- La extracción PDF mejora la estructura de texto y tabla. La traducción de archivo fijo conserva páginas exitosas si otra página falla; inspecciona la página incompleta antes de compartir. [Traducción en inglés](../guides/pdf-translation.md).
- El análisis de notebook se ejecuta fuera del hilo UI. Windows corrige la carga R DLL y los límites de la ventana alrededor de la barra de tareas.
- Enviar un mensaje mientras lee un giro anterior preserva su posición de lectura. Errores de herramientas, previsualizaciones de enlace fuente y diagnósticos de inicio son más claros.

Véase [instalación y actualizaciones](../guides/installation.md), [v1.1.0](v1.1.0.md) para películas de investigación y reseñas de lotes, y la versión oficial para la lista completa.
