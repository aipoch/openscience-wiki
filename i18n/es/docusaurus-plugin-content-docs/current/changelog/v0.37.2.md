# Notas de lanzamiento · v0.37.2 {/* #release-notes--v0372 */}

Liberado en **2026-10-13 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.37.2).

## Restaurar las conexiones de inicio y de tiempo de ejecución {/* #recovery */}

Las fallas de inicio ahora ofrecen vías de recuperación para backend, configuración e inicialización de la red. Una interrupción de la conexión de escritorio mantiene el banco de trabajo abierto con **Volver a conectar** y **Cerrar la aplicación**. Reconnect restaura el backend original en vivo; no reinicia un backend muerto o repite automáticamente las operaciones enviadas. Revise el estado de la tarea original antes de volver a iniciar el trabajo cuya respuesta se perdió.

La interfaz del navegador detiene los controles al restaurar las actualizaciones perdidas y ofrece recarga o renovado emparejamiento cuando sea necesario. Grandes sesiones y transferencias de instantáneas Notebook, ráfagas de eventos y registros de diagnóstico redirigidos se manejan de manera más robusta. Siga [conexión y recuperación de arranque](../guides/troubleshooting.md#connection-recovery) y [propiedad de backend](../reference/server.md#backend-ownership).

## Instalar el Linux CLI como un paquete {/* #linux-cli */}

Linux añade paquetes independientes `.deb` y `.rpm` CLI para x64 y ARM64, junto con archivos de lanzamiento y el Homebrew CLI. Los paquetes CLI incluyen Node, el backend y UI Web local, con `open-science-cli` como su comando explícito. Están separados del instalador de escritorio y no comienzan automáticamente un servicio del sistema.

Ver [selección de paquetes, instalación y actualizaciones](../guides/installation.md#linux-cli-packages). Detenga todos los perfiles usando el paquete antes de actualizar o eliminarlo; mantener los datos de investigación y la tienda credencial.
