# Cambios · v0.31.0 {/* #changelog--v0310 */}

Publicado en septiembre 18, 2026. Esta versión añade copias independientes de sesión y mejora la continuidad cuando se restaura una conversación o conexión.

[Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.31.0) · [Cambios desde v0.30.2](https://github.com/aipoch/open-science/compare/v0.30.2...v0.31.0)

## Continuar e inspeccionar un período de sesiones {/* #continue-and-inspect-a-session */}

- **Fork** crea una copia de escritorio con ramas de conversación, registros Notebook, versiones de artefactos, literatura, anotaciones y marcadores privados. Asigna identidades frescas y preserva la fuente. Las sesiones importadas en sí mismas permanecen solos. Vea el [Paseo de horquillas](../guides/sessions.md#fork-session) y [paquetes de investigación](../guides/research-packages.md).
- El título de sesión abre un [tarjeta de información](../guides/sessions.md#session-information) con su fuente, cuenta y control de pins. Una conversación continua se vincula a su turno de fuente.
- [Planes de sesiones](../guides/planning.md#resume-plan) conserva la identidad, la revisión y las aprobaciones pendientes después de la reconstrucción del contexto. La recuperación no significa que se haya aprobado o ejecutado un paso pendiente.

## Configuración modificada y comportamiento de datos {/* #changed-setup-and-data-behavior */}

| Área | Qué hacer para comprobar |
| --- | --- |
| Ajustes del proveedor | Las ediciones se validan antes de reemplazar una configuración guardada; actualizaciones de rechazo de tiempo de ejecución disponibilidad. [Configuración del proveedor](../guides/providers.md#validated-provider-save) |
| Windows R | La ejecución de los modos estándar ya no requiere la configuración de los modos protegidos. La ejecución protegida tiene requisitos separados. [Entornos de ejecución](../guides/runtimes.md) |
| gnomAD | Solicitud `include_populations: true` para los conteos y frecuencias de la población; conservar dataset, construir y filtros de calidad. [Parámetros](../reference/connector-operations.md#get_variant) |
| Nombre del producto | La interfaz utiliza Open-Science. Se conservan los emplazamientos, ajustes y datos existentes de la instalación; no renombrar carpetas de almacenamiento para coincidir. [Instalación](../guides/installation.md#product-name) |

**Cambio de compatibilidad de STRING:** `nodes` ahora describe el gráfico devuelto completo, incluyendo los vecinos añadidos. Filtrar `is_query` para entradas mapeadas y utilizar `queries` para todos los alias de entrada. No use `n_nodes` como el número de proteínas presentadas. [Orientación sobre la estructura](../tools/databases.md#string-network)

Otras correcciones cubren los cambios de razonamiento Codex, cancelación y continuación, adhesiones secundarias UniProt, identificadores ensembl, elegibilidad clínica-trial y denominadores cBioPortal. Utilice la versión oficial para la lista completa.

La siguiente versión es [v0.31.1](./v0.31.1.md).
