# Notas de lanzamiento · v0.35.0 {/* #release-notes--v0350 */}

Liberado en **2026-10-04 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.35.0).

## Repetir y discutir investigación {/* #replay-and-discuss-research */}

**View replay** presenta una sesión grabada con reproducción, navegación paso, registros Notebook e historial de conversión de archivos. **Ask about this step** trae el contexto seleccionado en una conversación de carácter. La investigación importada de `.science` sigue siendo de sólo lectura; Pídele que continúe la ejecución. Replay no reimprime el código. Siga el nuevo [guía de repetición de sesión](../guides/session-replay.md).

## Bases de datos científicos {/* #scientific-databases */}

Esta versión añade **Operaciones 13**, llevando el registro a **Conectores 34 y operaciones 339**: Familias de fuentes de datos 33 con operaciones 337, además de dos operaciones de Molecule sin conexión.

| Entrada | Capacidad adicional |
| --- | --- |
| Cellosaurus | Identidad celular, sinónimos y anotaciones de calidad |
| Monarch Initiative | Asociaciones de enfermedad/gene a fenotipo con evidencia fuente |
| IEDB | Epitopes, antígenos, T-cell, B-cell y MHC ensayos, y publicaciones |
| Archivos de Omics → GEO | Descubre ubicaciones de archivos de matriz y el texto de matriz ya leído |
| Estructuras " Interacciones → PDB | Encontrar estructuras por secuencia de proteínas con filtros de identidad, E-valor y cobertura de consultas |

Ver [capacidades y pasos de conexión](../tools/databases.md#cell-lines-phenotypes-immunity) y el [catálogo de operaciones actualizado](../reference/connector-operations.md). GEO preflight checks suministrado texto, no un archivo descargado en disco; matriz de descubrimiento no descarga archivos.

## Controles PDF y espacio de trabajo {/* #pdfs-and-workspace-controls */}

- Los PDFs cargados se unen a los PDF generados y Biblioteca en la extracción **Figures and tables**. El análisis paralelo mejorado mejora el procesamiento, con un mejor manejo de diseños complejos. Ver [Extracción PDF](../guides/previews.md#pdf-extraction).
- Suelte los archivos en cualquier lugar del área de conversación para adjuntarlos; inspeccionar los apegos antes de enviar. Ver [gotas de archivos](../guides/composer.md#conversation-drop).
- Las tablas de uso permiten una inspección continua a través de las fechas. Ver [uso diario](../guides/usage.md#inspect-daily-usage).
- Windows añade menús de aplicación nativos en la barra de títulos. Los contornos y las notas PDF se adaptan mejor a las ventanas estrechas.

## Modelos y acceso a la red {/* #models-and-network-access */}

El catálogo OpenCode Zen se expande, incluyendo entradas de clasificación Jev donde se admite. Las opciones de modelo Main y clasificación siguen siendo separadas; ver [catálogos modelo](../guides/providers.md#catalog-models).

Los ajustes de la red distinguen las reglas de dominio público de los servicios privados de confianza. Una subvención privada se une al nombre de host exacto, el puerto y las direcciones DNS revisadas, con otro cheque DNS antes de guardar. Ver [normas públicas](../guides/network.md#public-network-rules) y [servicios privados](../guides/network.md#trusted-private-services).

## Arreglos {/* #fixes */}

Las correcciones cubren los resultados de sesión y las esperas de aprobación, replay Notebook galerías de estado y archivos, linaje de ejecución científica, permisos de carpeta Codex, inicio de ejecución Windows y acceso de caja de arena, y las rutas de carpeta WSL. Los objetos idénticos en los paquetes `.science` son deduplicados; Los proyectos de proveedor y proyecto ganan protección contra pérdidas accidentales.
