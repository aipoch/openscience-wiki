# Notas de lanzamiento · v1.0.4

Publicado **2026-10-27 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v1.0.4).

## Conectar otras herramientas al banco de trabajo {/* #mcp */}

El CLI independiente proporciona un adaptador MCP stdio para clientes externos. Comience el servicio local autenticado primero, luego conecte al cliente a ese perfil. Las herramientas pueden crear proyectos, cambiar la configuración y ejecutar investigaciones bajo permisos existentes, incluyendo escrituras y costos de modelo. [Configuración y controles del PCM](../reference/cli.md#external-mcp).

## Revisa los avisos de publicación de un periódico {/* #publication */}

En la Biblioteca se puede comprobar manualmente una referencia con un DOI válido para retractaciones y correcciones a través de Crossref. Los resultados conservan su fuente y tiempo de comprobación. Un resultado vacío no es una garantía de que un papel no es afectado. [Revisar e interpretar avisos](../guides/library.md#publication-checks).

## Mantenga el trabajo diario manejable {/* #workspace */}

- Los giros completados colapsan mensajes intermedios y grupos de herramientas; búsqueda y anotaciones pueden revelar su contenido. [Ampliar una conversación](../guides/sessions.md#collapsed-conversation).
- Guardar un archivo de una carpeta autorizada como un artefacto de conversación inmutable. [Importación de archivos locales](../guides/files.md#import-local-artifact).
- Marcar un repositorio de habilidad GitHub escaneado para reutilizar; no actualiza Habilidades automáticamente. [Repositorios guardados](../skills/manage.md#saved-repositories).
- Las tarjetas de preguntas proporcionan explícitamente **Skip** y **Skip all** acciones. [Controles de preguntas](../guides/composer.md#skip-question).

Las descargas son menores. Las correcciones cubren la ejecución estándar de Windows Notebook, las exportaciones de paquetes esperando después de la selección de almacenamiento, diálogos de acceso a carpetas, recuperación de preguntas y presentación de eventos de repetición. [Transferencia de paquetes](../guides/research-packages.md#local-package-transfer) · [Versión anterior: v1.0.3](v1.0.3.md).
