# Notas de lanzamiento · v1.0.8

Publicado **2026-11-04 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v1.0.8).

## Importar una lista de lectura {/* #literature */}

¿Tienes una lista de identificadores de papel? **Add from DOI or link** ahora acepta hasta 100 líneas no vacías que contienen DOI, arXiv, PMID, PMCID o enlaces oficiales de artículo compatibles. Revisar las referencias resueltas y la política duplicada antes de importar. Encontrar metadatos no recupera automáticamente el texto completo. [Caminata de importación de lotes](../guides/library.md#doi-link-import).

Los detalles de referencia ahora incluyen **Study overview**. Su modelo principal configurado organiza la fuente disponible en cinco secciones: preguntas de investigación, población de estudio, métodos, principales hallazgos y limitaciones. La etiqueta fuente distingue un texto abstracto, completo y pasajes seleccionados. Úsalo para orientar tu lectura, luego comprueba importantes afirmaciones en el papel original. [Generar una visión general](../guides/library.md#study-overview).

## Ajustes mejor organizados {/* #settings */}

**Appearance** y **Notifications** son paneles separados bajo **System**. General mantiene información de aplicaciones, diagnósticos, herramientas de línea de comandos y ayuda, incluyendo una guía de instalación manual. El centro de configuración ahora tiene **19 paneles en cuatro grupos**. [Mapa de configuración](../settings/overview.md) · [Apariencia y notificaciones](../guides/appearance.md).

## Investigación y confiabilidad cotidiana {/* #reliability */}

- eQTL Catalogue utiliza archivos de versión 7 indexados después de su API REST retirado. Las consultas requieren explícitamente **GRCh38** coordenadas; una identificación de genes por sí sola ya no es una consulta válida. [Necesidades de coordinación](../tools/databases.md#eqtl-coordinates).
- Ordenación PDF utiliza texto posicionado para distinguir columnas de prosa de filas de mesa. Extracción revisa los límites de cultivo y preserva el texto celular ambiguo con una advertencia de fiabilidad. [Lectura y extracción en PDF](../guides/previews.md#automatic-pdf-reading-order).
- Las comprobaciones de reproducción de R invalidan las pruebas de archivo establo después de operaciones que pueden forzar argumentos o métodos de envío. La venganza explica evidencia de ejecución incompleta; los artefactos mayores de Markdown reparan un cabezal de historia de estancamiento cuando se abre. [Lea las pruebas de verificación](../guides/reproducibility.md#execution-evidence).
- Sesiones completas proveedor de liberación y procesos de herramientas en los cinco marcos de Agentes. Pi instalación en las construcciones de escritorio empaquetado se repara.
- La preparación de actualización identifica los procesos de bloqueo más claramente. Fija la dirección macOS sólo para los titulares de archivos, la detección del proceso de Windows y los registros de recuperación de Notebook. Los paquetes de diagnóstico conservan el error de recuperación de escritorio real. [Orientación actualizada](../guides/installation.md#update-preparation).
- Los archivos descargados se conservan aunque no se pueda leer la carpeta de destino o falle la limpieza posterior. Se mejora el cierre del proceso PDF y las comprobaciones de protección en Windows. Las herramientas de los notebooks pueden usar Node incluido con la aplicación si la versión de PATH es demasiado antigua para usar el proxy.
- Búsquedas exitosas de texto completo aclaran un error PDF-add anterior, y el Compositor ya no repite un aviso de modelo no disponible.

Tencent TokenHub incorpora Hy4 y rutas DeepSeek V4.1 Flash con un contexto de 1.000.000 de tokens, además de entrada de imágenes para GLM-5.3-Flash, Kimi K3 y MiniMax M3. La disponibilidad depende de la cuenta del proveedor y de la ruta elegida. [Configuración del proveedor](../guides/providers.md).

El catálogo incorporado permanece **48 Connectors con 418 operaciones**. [Catálogo actual](../tools/databases.md#supported-databases) · [Artículo anterior](v1.0.7.md).
