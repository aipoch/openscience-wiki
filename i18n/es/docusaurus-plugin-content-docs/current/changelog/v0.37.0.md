# Notas de lanzamiento · v0.37.0 {/* #release-notes--v0370 */}

Liberado en **2026-10-11 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.37.0).

## Corre sin una ventana de escritorio {/* #run-without-a-desktop-window */}

El escritorio, el navegador, CLI y Notebook ahora comparten un backend Node ordinario. `open-science start` ya no lanza un host Electron oculto. Las versiones oficiales incluyen archivos CLI independientes con Node y el backend incluido; no se necesita ninguna instalación Node separada para estos archivos. Los backends de escritorio eligen un puerto libre cuando no se especifica ninguno.

Utilice [terminal setup](../reference/cli.md#terminal-setup) para la instalación y el inicio de sesión Codex. Lea [propiedad y cierre del servicio](../reference/server.md#backend-ownership) antes de cerrar un cliente de escritorio o parar un backend compartido.

## Más pruebas de bases de datos {/* #more-database-evidence */}

El registro ahora contiene **Conectores 36 y operaciones 361**: 35 familias de fuentes de datos con operaciones 359, además de dos operaciones de Molecule sin conexión.

| Entrada | Qué cambios | Guía |
| --- | --- | --- |
| ENCORI | Diez operaciones para objetivos de miRNA, interacciones RNA-RNA y RBP, redes de ceRNA, escaneos de motivos, sitios de enlace, tablas de referencia y archivos a granel | [Configuración y límites de resultados](../tools/databases.md#encori) |
| ChEMBL | Detalles de ensayo y paginación de bioactividad más allá de los primeros registros 1,000 | [Ensayo contexto y paginación](../tools/databases.md#assay-submission-evidence) |
| ClinVar | Pruebas individuales de presentación SCV para un registro VCV | [Compare las comunicaciones](../tools/databases.md#assay-submission-evidence) |

Mantenga el organismo, el montaje, los filtros y los tipos de evidencia con los resultados. La confianza en los ensayos es sobre la asignación de objetivos; una presentación ClinVar no es un diagnóstico clínico independiente. El [referencia a la operación](../reference/connector-operations.md) proporciona campos exactos y un registro descargable.

## Ejecución de PDF y Notebook {/* #pdf-reading-and-notebook-execution */}

La traducción PDF mejora el orden de lectura nativa y las etiquetas de texto anidado. La extracción de estructuras mantiene figuras y registros de tablas con sus elementos fuente. Continuar comprobando [cifras y cuadros](../guides/previews.md#pdf-extraction) y [páginas traducidas](../guides/pdf-translation.md#compare-export) contra el original.

Los plazos de ejecución Notebook predeterminados evitan las aprobaciones de configuración redundantes. Los entornos mixtos Conda/pip y los metadatos de micromamba construyen se capturan con más precisión, junto con las dependencias de entrada y de llamada. Estos registros admiten [verificación de repeticiones](../guides/reproducibility.md); ellos mismos no establecen la reproducibilidad.

## Recuperación y soluciones de plataforma {/* #recovery-and-platform-fixes */}

- Importar en un nuevo proyecto fija un fallo de aprobación de catálogos `.science`. Los períodos de sesiones importados siguen siendo sólo de lectura; use [Bifurcar](../guides/research-packages.md) para continuar el análisis.
- Las colecciones inteligentes retratan el lote fallido mientras conservan el trabajo completado. Ver [selección de una colección](../guides/library.md#smart-collections).
- Plan de aprobación/dismissal y Codex de los argumentos de la herramienta de transmisión se recuperan más fiable. El modo automático evita la aprobación redundante para las operaciones de inspección apoyadas.
- Windows fija las vías Python que contienen espacios o paréntesis, perfiles de backend seleccionados y transmisiones Specialist. Las credenciales de Linux evitan las sondas del Servicio Secreto repetidas después de la primera operación secreta.
- PDB rechaza las respuestas de búsqueda malformadas y preserva el estado de la incompleta-paginación; un error no debe ser leído como cero golpes.
- El hogar añade orientación de primer proyecto. La ejecución sin cabeza y SDK puede resolver los recursos de Notebook agrupados de nuevo.
