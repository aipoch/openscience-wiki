# Notas de lanzamiento · v1.0.2

Publicado **2026-10-22 UTC**. [Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v1.0.2).

## Consultar más fuentes científicas {/* #scientific-sources */}

| Fuente | Ábrelo. |
| --- | --- |
| Nomenclatura del gen HGNC | Genes &amp; Ontologies |
| PubTator 3 anotaciones de artículo | PubMed |
| Interacciones entre fármacos y genes DGIdb | Clinical Genomics |
| Registros y referencias intergubernamentales | RNA |
| Orphadata rare-disease associations | Orfadata; habilitar primero |

Estas adiciones traen el catálogo a **36 entradas de fuentes de datos con 371 operaciones**, además de las dos operaciones de Molecule sin conexión. [Elija una fuente y conectarla](../tools/databases.md#new-source-access).

GDC filtra archivos por caso, tipo de muestra y flujo de trabajo conservando los vínculos entre muestras y alícuotas. Ensembl VEP acepta HGVS sin conversión manual de coordenadas, pero no valida la versión de referencia introducida ni realiza liftover. El catálogo incluye también resultados publicados de ClinicalTrials.gov. Consulte [contexto de consultas](../tools/databases.md#clinical-context) y el [referencia completa del funcionamiento](../reference/connector-operations.md).

## Instalar e inspeccionar el CLI {/* #cli */}

El CLI y Task SDK se publican en npm. Seguir [instalación npm](../guides/installation.md#npm-cli), entonces uso `version`, `help` y `paths` sin iniciar el backend. La versión mostrada corresponde a la instalación invocada. Las distribuciones de escritorio e independientes incluyen las actualizaciones de seguridad de Node 22.23.4. [Comandos locales de información](../reference/cli.md#local-information).

## Mantener el control de una conversación {/* #conversation */}

Las tarjetas de preguntas distinguen **Single select** desde **Multi select** y conservar la historia de la respuesta completa de cada pregunta. Los errores de mensajería demandada ofrecen una acción de deshacer; los borradores de desvío desencadenan advertencias de renuncia/recarga. La recuperación credencial da un próximo paso específico mientras preserva los proyectos. El chat web remoto admite menciones de artefacto. [Tarjetas y borradores de preguntas](../guides/composer.md#clarification-questions).

## Continuar la investigación con registros más claros {/* #research-records */}

- Los diálogos de paquetes permanecen estables; reintentar una importación parcialmente comprometida evita duplicar las sesiones. Los títulos importados se pueden editar mientras la investigación se mantiene solo lectura. [Paquetes de investigación](../guides/research-packages.md#browser-import).
- La carga de grandes sesiones y la recuperación de arranque mejoran. Las exportaciones de diagnóstico parcial muestran advertencias. [Diagnóstico de sesión](../guides/sessions.md#session-diagnostics).
- Estructura PDF, numeración DOCX/fronteras y captura de archivo Python/R encadenada reciben correcciones. [Controles de linaje](../guides/notebook.md#chained-analysis-lineage).
- Las grandes importaciones de habilidad usan lotes; los nombres externos reservados obtienen nombres locales seguros. MiniMax M3.1 a Codex es fijo. [Recuperación del proveedor](../guides/providers.md#credential-recovery).
