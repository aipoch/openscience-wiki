# Cambios · v0.30.1 {/* #changelog--v0301 */}

Publicado en septiembre 16, 2026. Esta actualización mejora la forma en que se preparan las discusiones laterales, los cambios de método de revisión y compartir materiales de investigación.

[Liberación oficial](https://github.com/aipoch/open-science/releases/tag/v0.30.1) · [Cambios desde v0.30.0](https://github.com/aipoch/open-science/compare/v0.30.0...v0.30.1)

## Corrientes de trabajo actualizadas {/* #updated-workflows */}

| Área | Qué cambios para ti |
| --- | --- |
| Side Chat | Abrir un borrador vacío, heredar el modelo de conversación principal y el esfuerzo de razonamiento, o elegir un modelo diferente para el próximo envío. Los borradores con contenido sobreviven a la navegación; Se limpian borradores vacíos sin tocar. [Side Chat](../guides/delegation.md) |
| Actualizaciones de Skill | Inspeccione los cambios de archivo, números de línea y líneas agregadas / eliminadas antes **Actualizar la habilidad existente**. Revisar los Especialistas afectados y las ediciones locales que serán reemplazadas. [Catálogo de Skills](../skills/marketplace.md) |
| Paquetes de investigación | **Full export** incluye los PDFs de literatura disponibles; **Customize contents** los selecciona individualmente. Exportación esencial omite PDFs opcionales; no se pueden eliminar las pruebas requeridas. Las conversaciones Side Chat están excluidas. [Paquetes de investigación](../guides/research-packages.md) |
| Carreteras locales | Un loopback Custom Gateway puede dejar su API llave en blanco si el servidor no necesita autenticación. Las pasarelas remotas todavía requieren credenciales y HTTPS. [Configuración del proveedor](../guides/providers.md) |
| Aprobación de la lectura de la web | Una solicitud de lectura web compatible puede ser recordada para la conversación, incluyendo páginas posteriores en otros sitios web. [Permisos](../guides/approval-modes.md) |
| Etiquetas | Buscar dentro de los recolectores de etiquetas de recursos, utilizar las teclas de flecha y Enter, o crear y asignar una nueva etiqueta. [Etiquetas](../guides/tags.md) |
| Instalación y recuperación | macOS guía copias de sólo lectura en Aplicaciones antes de actualizar. Windows tiene una utilidad de reset independiente y destructiva con una previsualización y confirmación escrita. Los instaladores muestran la licencia del proyecto. [Instalar y actualizar](../guides/installation.md) · [Windows reseteo](../guides/troubleshooting.md#windows-data-reset) |

## Arreglos notificados {/* #reported-fixes */}

El lanzamiento también reporta correcciones para las aprobaciones del plan durante los timeouts MCP, las acoplamientos históricos del artefacto, cancelación de tareas y las carreras Notebook. El paresing PDF puede recuperarse de estados bloqueados y reportar fallas de extracción; se mejora la recuperación de la figura/tabla. Connector corrige los argumentos de la región de gnomAD y los conjuntos de datos de referencia construye, y correcto almacenamiento de residuos de lote ESM-2.

Los cheques del proveedor usan la ruta del proveedor probado. Los registros Codex desactivados en archivos reciben un error de importación más claro. Las vistas de la literatura vuelven a su conversación originaria, y las instrucciones OpenCode Side Chat permanecen separadas de Main.

Utilice [Instalar y actualizar](../guides/installation.md) para el procedimiento de actualización. La versión anterior es [v0.30.0](./v0.30.0.md).
