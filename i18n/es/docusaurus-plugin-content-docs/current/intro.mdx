# Open-Science {/* #open-science */}

Utilice Open-Science para organizar fuentes de investigación, trabajar con un agente, realizar análisis e inspeccionar resultados guardados.

Para conocer el producto, consulta [What Is AIPOCH Open-Science?](https://aipoch.com/blog/what-is-open-science).

## Empieza aquí. {/* #start-here */}

1. [Capacidades y insumos compatibles](./guides/capabilities.md): Elija un camino para sus archivos o pregunta de investigación.
2. [Instalación](./guides/installation.md) y [configuración por primera vez](./guides/onboarding.md): preparar la aplicación, agente, modelo y tiempo de ejecución.
3. [Su primer proyecto y resultado](./guides/first-project.md): abrir una pequeña mesa de datos públicos y guardar un resumen comprobado.
4. [Permisos](./guides/approval-modes.md): inspeccionar las acciones solicitadas y gestionar el acceso recordado.
5. [Notebook y pruebas de ejecución](./guides/notebook.md): examinar el código, las variables y la procedencia del resultado.

## Antes de ejecutar un ejemplo {/* #before-running-an-example */}

Los caminantes locales utilizan papeles PRISMA públicos y la matriz GSE60450 RNA-seq. Descargue las entradas enlazadas y confirme el modelo, el tiempo de ejecución y los permisos requeridos por cada tarea.

[Computación remota](./guides/remote-compute.md) incluye un análisis Direct SSH RNA-seq, la colección de salida, la recuperación de reiniciar y la cancelación. Slurm terminal monitoring needs working accounting; La inferencia GPU necesita un entorno de software compatible.

Utilice [Referencia](./reference/index.md) para límites técnicos y configuración, y [Cambio](./changelog/v0.31.1.md) para la historia de la liberación.
